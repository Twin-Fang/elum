## 이룸은 어떤 서비스인가요?

보호자가 평소 말투로 오늘의 일과를 적으면, 이룸의 AI가 그림이 있는 짧은 **행동 카드**로 나눠 줘요. 이룸이는 카드를 하나씩 따라 하고 체크하면서 칭찬과 별을 받아요.

이룸이에게는 이해하기 쉬운 일과와 해냈다는 긍정적인 경험을, 보호자에게는 같은 준비를 반복하는 부담을 덜어 줘요.

## 왜 만들었나요?

- **보호자**는 같은 지시를 끝없이 반복하고, 시각 일정표와 그림 카드를 직접 만드는 데 많은 시간을 써요.
- **발달장애가 있는 이룸이**는 추상적이거나 여러 가지가 섞인 지시를 이해하기 어렵고, 일상의 행동을 스스로 이어서 해내기 어려워요.

이룸의 목표는 보호자가 매번 곁에서 개입하지 않아도 이룸이가 스스로 일과를 해낼 수 있도록 돕는 자립 보조 서비스예요.

## ABA 원리를 참고한 설계

이룸의 3단계 구조는 ABA(응용행동분석)의 원리를 참고해 만들었어요.

| 단계 | 이룸에서는 |
| --- | --- |
| **1. 지시** | 카드마다 한 가지 행동을 짧고 명확하게 안내해요. |
| **2. 행동** | 이룸이가 그림을 보며 한 단계씩 따라 해요. |
| **3. 강화** | 보호자가 정한 보상을 행동 전, 중, 후에 떠올리게 해요. |

앱 안의 별은 해낸 만큼을 보여 주는 성취 연출이에요. 간식, 놀이, 산책 같은 실제 보상은 보호자가 정해요.

## 주요 기능

- 하루 일과를 적으면 AI가 만드는 **그림 행동 카드**
- 카드를 읽어 주는 **음성 안내**
- 모든 카드에 함께 나오는 **친근한 캐릭터**
- 이룸이에게 보이기 전에 **보호자가 모든 카드를 확인하고 수정**
- **보호자가 정하는 보상**과 행동을 마칠 때마다 받는 별
- 한 앱 안에 **보호자 화면과 이룸이 화면**이 있고, 비밀암호로 오가요
