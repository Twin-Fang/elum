## 대조하는 법

```bash
# 1. export를 새로 받는다 (받아 둔 것을 그냥 쓰지 않는다)
#    mcp__figma__download_figma_images → docs/figma/<주제>/

# 2. 앱 화면을 렌더한다
flutter test test/figma_conformance_test.dart --update-goldens

# 3. 픽셀로 맞대본다
python3 tool/figma_diff.py \
  --render test/figma/stars_364-8219.png \
  --design ../docs/figma/stars/child_stars_364-8219.png \
  --out /tmp/diff.png
```

**대조에 새 화면을 올릴 때** — 시안이 그린 내용을 **그대로** 채운다. 이름·문구·개수가
다르면 차이 그림이 통째로 붉어져 정작 봐야 할 어긋남이 묻힌다.

### 시안은 아이폰 한 기종으로만 그려져 있다 ⚠️

대조는 기준 기기(393×852) **하나에서만** 돈다. 거기서 맞는다고 다른 기기에서도 맞는
것이 아니다 — 가로가 좁으면 글자가 다른 자리에서 꺾이고, 세로가 짧으면 아래가 잘린다.

**`test/device_sizes_test.dart`가 화면비가 다른 기기 넷에서 세워 본다.**

| 기기 | 크기 | 왜 |
|---|---|---|
| iPhone 16 | 393×852 | 시안 기준 |
| iPhone SE | 375×667 | 가장 좁고 짧다 — 잘림이 먼저 드러난다 |
| Galaxy | 360×800 | 안드로이드에서 가장 흔한 폭 |
| Galaxy Ultra | 412×915 | 가장 넓고 길다 — 남는 자리를 어떻게 쓰는지 |

시안과 픽셀로 맞대지는 않는다(크기가 다르니 맞출 수 없다). **깨지지 않는지**만 본다 —
오버플로는 `flutter_test_config.dart`가 실패로 만들므로 **렌더가 통과하면 버틴다는 뜻**이다.

> 화면을 새로 만들면 이 테스트에도 한 줄 더한다. 기기를 늘릴 때는 **화면비가 가장
> 다른 것**을 고른다 — 비슷한 것을 여러 개 넣으면 같은 자리만 반복해 본다.
