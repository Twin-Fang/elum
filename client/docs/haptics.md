# 이룸이 진동 명세

진동은 화면·소리가 알린 것을 손으로 한 번 더 느끼게 하는 **보조 신호**다. 의미를 새로 만들지 않는다.
구현은 `lib/core/haptics/child_haptics.dart`, 켜고 끄는 스위치는 보호자 설정·이룸이 설정이 같은 값 하나를 본다
(기본 켜짐, 로그아웃으로 지워지지 않는다). 꺼져 있으면 아래 모든 진동이 울리지 않는다.

## 원칙

1. **자주 일어나는 것은 짧고 약하게, 드문 순간은 길고 세게.** 길이와 세기가 중요도다.
2. **세기는 올라가며 끝난다.** 성취(별·완료)는 점점 세지고, 실패(암호 틀림)는 일정하고 부드럽다.
3. **질책하지 않는다.** 오류 진동은 세게 울리지 않는다.
4. **진동 때문에 화면이 멈추지 않는다.** 하드웨어가 없거나 호출이 실패해도 로그만 남기고 진행한다.
5. 동작 줄이기와 별개다 — 움직임과 진동은 다른 감각이다. 끄는 것은 스위치가 정한다.

## 종류

패턴은 `[쉬는, 울리는, 쉬는, 울리는 …]` ms, 세기는 1~255.

| 종류 | 언제 | 느낌 | 총 길이 | 세기 |
|---|---|---|---|---|
| `check` | 카드 체크 | 쿵-톡 (센 한 번 + 잔향) | 100ms | 220 → 110 |
| `star` | 별 화면이 뜰 때 | 반짝반짝 (세 번, 점점 세게) | 165ms | 80 → 130 → 190 |
| `complete` | 일과를 모두 끝냄 | 빵·빠·바·빠아앙 팡파르 | 610ms | 120 → 160 → 200 → 255 |
| `uncheck` | 체크 해제 | 스윽 | 12ms | 50 |
| `tap` | 버튼·배지·뒤로가기 | 톡 | 14ms | 80 |
| `select` | 카드 넘김 | 사락 | 8ms | 45 |
| `error` | 암호 틀림 | 툭툭툭 (일정, 부드럽게) | 160ms | 90 |
| `unlock` | 암호 맞아 화면 전환 | 딸깍-둥 | 110ms | 100 → 190 |

## 화면별 배치

| 화면 | 동작 | 진동 |
|---|---|---|
| 이룸이 홈 | 별 배지 · 설정 · 보호자 배지 · 일과 타일 누름 | `tap` |
| 카드 진행 | 뒤로가기 | `tap` |
| 카드 진행 | 스피커(읽기 시작·멈춤) | `tap` |
| 카드 진행 | 카드 넘김(손·옆 카드 누름·자동 이동) | `select` |
| 카드 진행 | 체크 / 해제 | `check` / `uncheck` |
| 카드 진행 → 별 화면 | 별 화면 진입 | `star` |
| 카드 진행 → 일과완료 | 마지막 카드까지 끝냄 | `complete` |
| 별 · 보상 · 일과완료 · 누적 별 | 닫기·홈으로 버튼 | `tap` |
| 화면 전환(암호) | 틀림 / 맞음 | `error` / `unlock` |
| 이룸이 설정 | 스위치를 켤 때 | `check` (느낌 미리보기) |

## 기기별

- 패턴·세기를 쓰는 휴대폰(iOS 13+, Android 8+): 위 표대로.
- 못 쓰는 휴대폰: 기본 진동으로 갈음한다. `star`는 가볍게 세 번, `complete`는 세 번 올라가다 세게 한 번.
- 진동 하드웨어 없음: 아무 일도 하지 않는다.
