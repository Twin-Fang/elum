# 행동카드 이미지 저장 · 인쇄 (Pro) 설계

- 이슈: #1073 · 총괄 #1081 · 시안 요청 #1070
- 작성: 2026-11-05 · 상태: 사용자 승인 대기 (Free 로고·워터마크 · Pro 테마·워터마크 없음 · PDF·이미지 공유)

## 1. 왜 하는가

행동카드를 종이로 뽑아 쓰는 보호자가 많다. 냉장고·벽에 일과표로 붙이거나, 카드를 오려 코팅한 뒤 벨크로 보드에 붙인다.
지금 앱에는 카드를 앱 밖으로 꺼낼 방법이 없어서, 보호자가 화면을 캡처해 잘라 쓰고 있다고 본다(추정).

**Free도 쓸 수 있고, Pro는 더 좋게 쓴다** (2026-11-05 사용자 결정, 처음의 "이미지·인쇄는 전부 Pro"를 바꿈).

| | Free | Pro |
|---|---|---|
| 출력물 3종 | ✓ | ✓ |
| 이룸 로고 · 워터마크 | **들어감** | 없음 |
| 카드 디자인 테마 | 기본 1개 | 전부 |

Free 출력물이 밖에서 돌면 이룸 홍보가 되고, 깨끗한 출력물과 디자인 테마가 Pro로 바꿀 이유가 된다.

**성공의 모습:** 보호자가 일과 하나를 열고 세 번 안쪽으로 눌러 프린터나 카톡으로 보낼 수 있다. 뽑힌 종이는 바로 자르거나 붙여 쓸 수 있다.

## 2. 목표 · 하지 않는 것 · 실패로 치는 것

**목표**

- 출력물 3종
  - **카드 한 장 이미지:** 카드마다 PNG 하나, 여러 장이면 PNG 여러 개
  - **일과 한 장 정리본:** A4 한 장 PDF에 순서대로 모든 카드
  - **오려 쓰는 카드:** A4 PDF, 한 쪽에 카드 6장, 자를 선 포함
- 보내기는 **PDF·이미지를 공유 시트로** (저장·카톡·파일·PDF 앱에서 인쇄). 바로 인쇄 버튼은 2차.
- **Free 출력물에 이룸 로고와 워터마크** (4.6)
- 카드 모양은 **기본 = 지금 앱 카드 디자인** (사용자: "지금도 나쁘지 않다"), Pro는 **카드 디자인 테마** (4.7)

**하지 않는 것**

- 서버에서 출력물을 만들지 않는다.
- 카드 크기 고르기, 여러 일과 한 번에 뽑기, 출력물 편집은 하지 않는다.
- 앱 안 바로 인쇄(`printing` 패키지)는 2차로 미룬다 (2026-11-05: "PDF·이미지로 충분").

**실패로 치는 것 (기술적으로 돌아가도)**

- 뽑은 종이에서 그림이 흐리거나 글자가 잘린다.
- 자를 선을 따라 잘랐는데 카드가 삐뚤다.
- 이룸이 화면에 인쇄나 Pro 안내가 보인다.
- 아직 결제할 방법이 없는데 Free 사용자에게 "Pro예요" 잠금이 먼저 보인다.

## 3. 정한 것 (사용자 결정)

- Free도 출력물 3종을 쓸 수 있다. **Free 출력물에는 이룸 로고와 워터마크를 제대로 넣는다.** Pro는 워터마크가 없다.
- **Pro는 카드 디자인 테마와 워터마크 없음** (2026-11-05 사용자 결정).
- 출력물 3종(카드 한 장 · 일과 한 장 · 오려 쓰는 카드)을 만든다.
- 테마 그림과 워터마크의 모양은 디자이너가 정한다(#1070).

## 4. 어떻게 만드는가 (개발 판단 — 사용자 확인 필요 표시는 ⓘ)

### 4.1 화면 흐름

```
일과 상세 시트 / 일과관리 ⋯ 메뉴
        │  "인쇄용으로 받기"
        ▼
┌───────────────────────────────┐
│  인쇄용으로 받기               │
│                               │
│  ◉ 일과 한 장   (A4 1장)       │
│  ○ 오려 쓰는 카드 (A4 · 6장씩) │
│  ○ 카드 한 장씩 (이미지)       │
│                               │
│  [✓] 카드 문장 넣기            │
│                               │
│  카드 디자인                   │
│  (기본)(바다 Pro)(우주 Pro)…    │
│                               │
│  Free: 이룸 워터마크가 들어가요  │
│                               │
│  [ 미리 보기 ]                 │
└───────────────────────────────┘
        │
        ▼
 미리 보기 (만든 결과를 그대로 보여 줌, 디자인을 바꾸면 바로 바뀜)
        └─ [ 보내기 ]  →  OS 공유 시트 (사진 저장 · 파일 · 카톡 · PDF 앱에서 인쇄)
```

- **진입점 2곳:** 일과 상세 시트(오늘·지난·일과관리 원본 모두)와 일과관리 `⋯` 빠른 메뉴.
- **카드 문장 넣기 ⓘ:** 그림만 쓰는 보호자(그림 교환 방식)를 위해 끌 수 있게 했다. 기본은 켜짐.
- **미리 보기:** 종이로 뽑기 전에 결과를 확인하는 자리다. 흐림이나 잘림이 있으면 여기서 드러난다.

### 4.2 출력물 지면

**일과 한 장 (A4 세로)**

```
┌──────────────── A4 ────────────────┐
│  아침 등교 준비                     │
│  ┌──────┐ ┌──────┐ ┌──────┐        │
│  │ 1    │ │ 2    │ │ 3    │        │
│  │ 그림  │ │ 그림  │ │ 그림  │        │
│  │ 세수해요│ │ 옷 입어요│ │ 밥 먹어요│    │
│  └──────┘ └──────┘ └──────┘        │
│  ┌──────┐ ┌──────┐ ┌──────┐        │
│  │ 4 …  │ │ 5 …  │ │ 6 …  │        │
│  └──────┘ └──────┘ └──────┘        │
│                         (이룸 표시?)│
└────────────────────────────────────┘
```

- 카드는 최대 10장이다(`RoutineStepLimits.MAX_STEP_COUNT`). 1~4장은 2열, 5~9장은 3열, 10장은 2열×5줄로 해서 한 장에 들어가게 한다.
- 카드에는 번호·그림·문장이 들어가고, 번호는 일과 순서와 같다.

**오려 쓰는 카드 (A4 세로, 한 쪽에 6장 = 2열×3줄)**

```
┌──────────────── A4 ────────────────┐
│ ┌ ─ ─ ─ ─ ─ ─ ┐ ┌ ─ ─ ─ ─ ─ ─ ┐    │
│   그림            그림               │
│   세수해요        옷 입어요           │
│ └ ─ ─ ─ ─ ─ ─ ┘ └ ─ ─ ─ ─ ─ ─ ┘    │
│ ┌ ─ ─ ─ ─ ─ ─ ┐ ┌ ─ ─ ─ ─ ─ ─ ┐    │
│   …               …                 │
│ └ ─ ─ ─ ─ ─ ─ ┘ └ ─ ─ ─ ─ ─ ─ ┘    │
│ ┌ ─ ─ ─ ─ ─ ─ ┐ ┌ ─ ─ ─ ─ ─ ─ ┐    │
│   …               …                 │
│ └ ─ ─ ─ ─ ─ ─ ┘ └ ─ ─ ─ ─ ─ ─ ┘    │
└────────────────────────────────────┘
```

- 카드 하나는 약 9×8.5cm로, 코팅지나 벨크로 보드에 맞는 크기다. 7장을 넘으면 다음 쪽으로 넘어간다.
- 자를 선은 점선이고, 카드 사이에 자를 여백이 있다.
- **번호는 넣지 않는다 ⓘ.** 오린 카드는 순서를 바꿔 붙여 쓰기 때문이다.

**카드 한 장 이미지 (PNG)**

- 앱의 카드 모양 그대로 그림과 문장을 담는다. 해상도는 긴 변 2000px 안팎이다.
- 고른 카드마다 한 장씩 만든다. 공유 시트에서 사진 저장이나 카톡 보내기를 할 수 있다.

### 4.3 만드는 방식

| 안 | 판단 |
|---|---|
| **A. 앱이 출력물을 Flutter 위젯으로 그려 고해상도 이미지로 굽고, PDF는 그 이미지를 쪽마다 넣는다** | **채택.** 지면 원본이 위젯 하나라 PNG와 PDF가 어긋나지 않는다. 화면과 같은 글꼴·색 토큰을 쓰고, 서버 비용도 없다 |
| B. PDF는 `pdf` 패키지 도형으로 따로 그림 | 지면을 두 번 만들어 사본이 생긴다(단일 원본 위반) |
| C. 서버가 만들어 파일로 내려줌 | 서버 렌더링(글꼴·그림)을 새로 만들어야 하고 비용이 든다 |

- **해상도:** A4는 300dpi(2480×3508)로 굽는다. 카드 그림은 서버가 1536×1024로 만들므로, 9cm 폭 카드면 300dpi에 충분하다.
- **그림 준비:** 굽기 전에 카드 그림을 전부 내려받고 캐시해 둔다. 하나라도 실패하면 굽지 않고 실패 안내를 띄운다.
- **새 패키지:** `pdf` 하나. 공유는 이미 있는 `share_plus`를 쓰고, 사진첩 권한은 받지 않는다(공유 시트의 "이미지 저장"을 씀).
- **크기:** PDF 쪽 크기를 A4로 고정한다. 다른 앱에서 인쇄할 때 "실제 크기"를 고르면 오려 쓰는 카드가 9×8.5cm로 나온다(미리 보기 아래 한 줄 안내).
- **위치:** `features/card_export/`(application · domain · presentation). 지면 위젯은 `presentation/print_layouts/`에 둔다.

### 4.4 Pro 판정

- 서버 권한 2개 (켜기/끄기, Free 꺼짐 / Pro 켜짐, 관리자 화면에서 바꿀 수 있음)
  - `CARD_EXPORT_WITHOUT_WATERMARK`: 워터마크 없이 내보내기
  - `CARD_EXPORT_ALL_THEMES`: 카드 디자인 테마 전부
- 내보내기 자체는 모두에게 열려 있어서, 결제(#1072)가 나오기 전에도 출시할 수 있다. 결제가 생긴 뒤에는 Free에게 Pro 테마를 배지와 함께 보여 주고, 누르면 요금제 화면을 연다. 미리 보기 아래에는 "Pro는 워터마크 없이 받아요" 한 줄을 둔다 ⓘ. **결제 전에는 Pro 테마와 이 줄을 숨긴다** (살 방법이 없는데 잠금만 보이지 않게).
- 출력물을 앱이 만들기 때문에 판정은 앱이 회원 정보의 권한 값으로 한다. 앱을 조작해 우회할 위험은 받아들인다. 권한 값을 못 받으면 Free로 보고 워터마크를 넣는다.

### 4.6 Free 로고 · 워터마크

- **제대로 넣는다:** 쪽마다 아래 띠에 이룸 로고와 "이룸 앱으로 만들었어요"를 넣고, 바탕에는 옅은 이룸 무늬 워터마크를 넣는다. 카드 한 장 이미지에도 로고와 워터마크가 들어간다.
- **이룸이가 쓰는 데 방해되면 안 된다:** 워터마크는 그림 가운데와 카드 문장을 덮지 않는다. 발달장애아동이 그림을 알아보는 게 먼저이고, 카드 바깥 여백·바탕·모서리에 둔다.
- 로고는 `AppAssets` 로고 원본을 쓰고, 새로 그리지 않는다.
- 진하기와 무늬는 디자이너가 정한다(#1070).

### 4.5 지켜야 할 것

- **글꼴 권리:** 카드 문장은 티머니 둥근바람으로 그린다. PDF·이미지에 그 글꼴로 그린 글자가 들어가 앱 밖으로 나가는데, 티머니의 앱 포함 허용은 #1046에서 아직 확인 중이다. **그래서 확인 전까지 출력물은 Pretendard(OFL)로 그린다** (8번 9).
- **픽토그램 출처:** 그림 대신 Mulberry 픽토그램(CC BY-SA 4.0)을 쓴 카드가 있으면 출력물 아래에 `Mulberry Symbols · CC BY-SA 4.0`을 작게 넣는다.
- **일과 언어:** 카드 문장은 일과 언어(`ContentLocale`)로 그린다.
- 보호자 입력 원문(일과 만들 때 쓴 글)은 출력물에 넣지 않고, 카드 문장만 넣는다.
- 이룸이 화면에는 진입점이 없다.

### 4.7 카드 디자인 테마 (Pro)

- 테마는 **카드 테마 토큰 한 곳**(`CardDesignTheme`)에 모은다: 바탕, 테두리 모양·색·굵기, 꾸밈 그림(모서리·테두리 장식), 번호 배지 모양. 세 출력물이 같이 쓴다.
- **1차는 출력물에만 입힌다 ⓘ.** 앱 안 카드(이룸이가 보는 카드)는 바꾸지 않는다. 앱 카드까지 넓힐지는 출력물 반응을 보고 정한다.
- 후보 (그림은 디자이너가 그림, 꾸밈은 전부 에셋으로 — 코드로 도형을 그리지 않음)

| 테마 | 모양 | Free |
|---|---|---|
| 기본 | 지금 앱 카드 | ✓ |
| 단순 | 장식 없이 굵은 테두리 (집중이 어려운 이룸이용) | Pro |
| 루미와 친구들 | 모서리에 캐릭터가 얼굴을 내밂 | Pro |
| 바다 | 물결 테두리, 조개·물고기 장식 | Pro |
| 우주 | 남색 바탕 별 테두리, 번호가 행성 | Pro |
| 공룡 | 발자국 테두리, 공룡 번호 배지 | Pro |
| 계절 | 봄 꽃 · 여름 수박 · 가을 낙엽 · 겨울 눈 | Pro |

- **만드는 순서:** 테마 구조 + 기본 + 단순(그림 에셋 없이 됨)을 먼저 만들고, 나머지는 디자이너 그림이 오는 대로 하나씩 더한다. 테마 하나 더하기 = 토큰 한 묶음 + 에셋.
- 꾸밈은 카드 그림과 문장을 가리지 않는다 (워터마크와 같은 규칙).

## 5. 실패 경로

| 상황 | 화면 | 코드 |
|---|---|---|
| 그림이 아직 안 만들어진 카드 | 미리 보기에서 그 칸은 문장만 넣고 "그림이 아직 없어요" 안내 | — |
| 그림 내려받기 실패 (네트워크) | 실패 팝업 + 다시 시도 | `E-EXPORT-IMAGE` |
| 굽기 실패 (메모리 등) | 실패 팝업 | `E-EXPORT-RENDER` |
| 공유 시트·인쇄 화면에서 취소 | 미리 보기에 그대로 둠, 안내 없음 | — |
| 카드 0장 일과 | 진입점을 비활성으로 두고 이유 한 줄 | — |
| 권한 값 못 받음 | Free로 보고 버튼 숨김 (서버 방식과 같은 쪽으로 기움) | — |

## 6. 확인 방법

- 실기기(iPhone, Android)에서 세 출력물을 테마별로 공유 시트로 보내 실제 A4로 뽑는다. 오려 쓰는 카드는 자를 선대로 잘라 9×8.5cm인지 자로 잰다.
- Free 계정·Pro 계정(관리자 지정)으로 각각 뽑아 워터마크 유무를 확인한다.
- 운영 그림(`gpt-image-1-mini`, low)으로 만든 카드를 인쇄해 흐림을 확인한다. 흐리면 #1075의 고품질 그림과 묶는다.
- 글자 200%와 긴 문장(두 줄 넘김)에서 출력물 글자가 잘리지 않는지 본다. 출력물은 시스템 글자 크기를 따르지 않고 지면에 맞춰 고정한다.
- 정적 검사는 `flutter analyze`와 `tool/check_*`로 한다(앱 테스트는 두지 않음, #848).

## 8. 개발이 정한 것 (ⓘ, 사용자 확인 필요)

1. 보내기는 PDF·이미지 공유 시트. 바로 인쇄는 2차 (사용자: "PDF·이미지로 충분")
2. 카드 문장 넣기 켜기/끄기
3. 오려 쓰는 카드에는 번호를 넣지 않음, 한 쪽 6장 고정
4. ~~결제 출시 전에는 버튼을 숨김~~ → 내보내기는 모두에게 열림. Free는 로고·워터마크 (사용자 결정)
5. **카드 문장은 제목(한 줄 행동)만 넣음.** 일과 한 장·오려 쓰는 카드는 제목만, 카드 한 장 이미지는 앱 카드처럼 제목 + 설명. 제목이 길면 최대 2줄, 그 이상은 글자를 줄여 맞춤 (잘리지 않음)
6. **카드 한 장씩은 미리 보기에서 고름.** 처음엔 전부 선택, 카드마다 체크를 끌 수 있음 (화면을 따로 만들지 않음)
7. **그림 없는 카드:** 출력물에는 그림 칸에 제목만 크게 넣음. "그림이 아직 없어요" 안내는 미리 보기 **종이 밖** 띠에만 보임 (미리 보기의 종이 = 출력물 그대로 유지)
8. **시안 전에 임시 지면으로 먼저 만듦** (앱 토큰·카드 색 그대로). 시안(#1070)이 오면 지면 위젯만 바꿈. 잉크를 아끼는 흑백 버전은 하지 않음
9. **출력물 글꼴은 따로 한 곳에 둠**(`printFontFamily`). 티머니 출력물 사용 허용이 확인되기 전까지 **Pretendard(OFL)** 로 그림. 확인되면 상수 하나만 바꿈
10. **실제 크기:** PDF는 A4 고정. 다른 앱에서 "실제 크기"로 뽑아야 9×8.5cm가 됨 (미리 보기 아래 한 줄 안내)
11. 결제가 생긴 뒤에만 Free에게 Pro 테마 배지와 "Pro는 워터마크 없이" 한 줄을 보임
13. 카드 디자인 테마는 1차에 출력물에만 입힘 (앱 카드는 그대로)
14. 테마는 기본 + 단순 먼저, 나머지는 그림이 오는 대로
12. 워터마크는 그림 가운데와 카드 문장을 덮지 않음

## 9. 나중 Pro 후보 (이번 범위 밖)

- 카드 디자인 테마를 **앱 안 카드에도** 입히기
- 인쇄 옵션: 잉크 절약, 흑백(색칠 놀이용)
- 앱 안 바로 인쇄 (`printing` 패키지)
- 그 밖에 Pro 내보내기 혜택 후보: 고해상도, 카드 크기 고르기(4·6·8장), 여러 일과 한 번에 뽑기
