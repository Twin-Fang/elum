# 일과 보낸 뒤 이룸이에게 이어 주기 (가벼운 버전, 2026-11-16)

## 왜
사용 분석(#1436): 일과 만듦 24명 > 카드 체크 9명. 저장하면 바로 보내지는데, 이룸이가 실제로 쓰는 데까지 이어지지 않는다. 예약 보내기(Pro)는 만든 뒤 상세 시트에서만 정할 수 있어 잘 안 보인다.

## 고른 방향
새 화면 없이 있는 화면에 조금씩 더한다 (사장님 "가볍게"). 검토 후 뺀 것: "언제 보낼까요" 선택 화면, 일과 관리에만 두기, 체험 모드, 건네기 화면, 첫 완료 푸시.

## 할 것 4가지
1. **카드 확인**: 저장(보내기) 버튼은 그대로. 바로 아래 글자 링크 `요일·시각 정해서 보내기` — Free 는 PRO 배지 > Pro 안내(기존 openProOnlyNotice/요금제 화면, 혜택 routineSchedule), Pro 는 기존 반복 시트(요일·시각) > 저장하면 보내기와 같은 저장 + 반복 설정
2. **보낸 뒤 축하 화면(첫 보내기)**: 버튼 `이룸이 화면에서 보기` 추가 > 이 기기에서 이룸이 화면 열기(기존 모드 전환 흐름 재사용, 돌아올 땐 기존 비밀암호). 두 번째부터의 알림 띠는 그대로
3. **보호자 홈 안내 카드**: 보낸 일과가 있고, 보낸 지 24시간이 지났는데 이룸이 카드 체크가 0이면 기존 안내 카드(ElumInfoCard) 한 장: `아직 {이룸이 이름}가 카드를 안 해 봤어요` + `이룸이 화면 열기` · (기기 미연결이면) `이룸이 기기 연결`. 체크가 생기면 사라짐, 닫으면 7일 뒤 다시. 푸시 없음
4. **일과 관리 목록**: 반복이 정해진 일과에 `평일 08:00` 같은 한 줄 표시 (기존 routineScheduleSummary 문구)

## 중간에 나가도 괜찮게
- 1은 저장하는 순간 이미 보내짐. 반복 시트를 닫으면 반복만 안 정해지고 일과는 그대로
- 2·3은 언제 건너뛰어도 됨. 3이 안전망

## 실패 경로
- 반복 저장 실패: 일과 저장은 된 상태로 두고 실패 팝업 + 코드(기존 반복 시트 실패 처리)
- 홈 안내 카드 판정 데이터 조회 실패: 카드를 띄우지 않음(홈은 그대로), 로그만

## 하지 않는 것
서버 스키마 변경, 새 푸시, 체험 기록 분리. 서버 변경은 3의 판정에 필요한 값이 이미 내려오지 않을 때만 최소로.
