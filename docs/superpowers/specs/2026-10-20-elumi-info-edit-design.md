# 이룸이 정보 고치기 (#660)

## 결정

- 내정보 이룸이 줄 오른쪽에 연필 버튼. 줄을 누르면 지금처럼 이룸이 바꾸기(여럿일 때), 연필을 누르면 `○○ 정보` 화면
- 정보 화면: 캐릭터 배지 > 이름 · 캐릭터 · 그림 방식 줄. 줄마다 시트로 바꾼다 (이름은 일과 이름 바꾸기 시트 재사용)
- 도움 목표는 넣지 않는다
- 시안: `docs/projectops/design-brief/20261020_003_이룸이_정보_고치기/screenshots/` (A안). 입구는 › 대신 연필로 확정

## 저장 대상

- 서버 `PATCH /api/member/{nickname|character|image-style}` 는 `X-Profile-Id` 이룸이에 저장한다
- 앱은 요청 `extra[targetProfileId]` 로 헤더를 그 이룸이로 바꾼다 (`ProfileHeaderInterceptor.targetProfileKey`)
- 저장 뒤 회원 정보를 다시 받는다. 저장 응답은 쓰지 않는다 — 응답의 도움 목표 등이 고친 이룸이 것이라 고른 이룸이 로컬 값에 섞인다
- 고른 이룸이를 고쳤으면 다시 받은 회원 정보로 프로필 세션이 로컬 이름·캐릭터·그림 방식을 맞춘다

## 실패 경로

| 상황 | 동작 |
|---|---|
| 저장 실패 | 실패 팝업 + 서버 문구 또는 `E-ELUMI-SAVE` |
| 저장 성공 · 회원 정보 재조회 실패 | 성공 알림, 화면은 이전 값 유지 (다음 주기 갱신에 맞춰짐) |
| 회원 정보 없음 · 그 이룸이가 목록에 없음 | `E-ELUMI-LOAD` 오류 화면 + 다시 시도 |
| 저장 중 다른 줄 누름 | 막음 (저장 중인 줄만 스피너) |
