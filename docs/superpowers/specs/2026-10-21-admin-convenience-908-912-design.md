# 관리자 편의 기능 일괄 보강 (#908 · #909 · #910 · #911 · #912)

DB 를 열지 않고 관리자 화면에서 원인을 찾고, 비용·남용 값을 배포 없이 조정하게 한다.

## 결정

- **스키마 변경 없음.** 저장하지 않는 값(광고 단위, 콜백 원문, 푸시 발송 결과, 초대 코드 원문)은 화면에 "저장하지 않아요"로 안내한다.
- **초대 코드 취소는 하지 않는다.** 도메인에 코드 하나를 취소하는 공개 동작이 없다. 기기 연결 해제는 기존 `DeviceLinkService.revoke` 를 그대로 쓴다(확인창 · POST · CSRF · 감사 로그).
- **일과 최대 단계 수는 설정으로 두지 않는다.** 앱 상수·Gemini 스키마 `maxItems`·프롬프트·오류 문구가 모두 10 으로 묶여 있어,
  설정만 낮추면 앱과 서버가 어긋난다. 서버 중복 두 곳만 `RoutineStepLimits.MAX_STEP_COUNT` 로 모은다.
- **사용 한도 기본값 = 옮기기 전 코드 값.** 배포만으로는 동작이 같다. 요청마다 30초 캐시로 읽어 다음 요청부터 반영된다. TTS 동시 실행은 재시작 없이 바뀌게 카운터로 바꾼다.
- **검증 규칙 단일 원본.** `ConfigKey` 에 범위·형식을 선언하고 `SystemConfigValueValidator` 한 곳에서 저장 거부와 기존 값 경고에 같이 쓴다. 저장할 때만 막고, 이미 저장된 어긋난 값은 경고 배지로만 보여 준다(읽기·기동은 깨지지 않음).
- **모델명은 DB 값이 이긴다.** yml 은 DB 가 비었을 때의 기본값이자 첫 시딩 값이다. 화면에 값 출처를 함께 보여 준다.
- **목록 필터는 정의에 선언.** `AdminListDefinition.Filter` 에 입력 방식(NONE/TEXT/DATE)을 두면 공통 필터 바가 칸을 그린다. 기존 3인자 생성자는 그대로다.
- **CSV 는 공통 `AdminCsvExporter` 한 곳.** UTF-8 BOM, 수식 주입 방지(`= + - @ 탭 CR` 앞에 `'`), 개인정보 최소 열, 최대 10,000건(버튼 비활성 + 서버 재확인).
- **개인정보 일부만.** 푸시 토큰·nonce·거래 ID 는 앞 6자 + `…` (`AdminValuePreview`).

## 실패 경로

| 상황 | 동작 |
|---|---|
| 회원 상세의 연결 조회 실패 | 상세 본문은 열리고 그 영역만 경고 `E-ADM-CONN-001` |
| 이미 끊긴 기기 해제 | 상세로 돌아와 `E-ADM-LINK-001` |
| 광고 보상·알림 요약 조회 실패 | 목록은 보이고 `ADMIN-AD-REWARD-SUMMARY` / `ADMIN-NOTIFICATION-SUMMARY` |
| 회원 고르기 검색 실패 | `E-CFG-MEM` 안내, ID 만으로 칩 표시 |
| 범위 밖 저장값 | 기본값으로 대신하고 영어 로그 |
| CSV 상한 초과 | 같은 조건 목록으로 돌아와 안내 |
| 잘못된 날짜·필터 값 | 보정 단계에서 버림 |

## 하지 않는 것

- 의견 앱 버전 필터의 버전 경계 일치(`1.1` 이 `1.10` 도 잡음). 앞부분 일치로 둔다.
- 회원 CSV 의 IN 묶음 나누기(10,000건 이내라 Postgres 한도 안).
- 클라이언트 `_maxSteps`, `CreditQueryService.MAX_CARDS_PER_ROUTINE`, `GeminiRoutineSchemas` 의 10 통합.
