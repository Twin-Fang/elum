# 카드 저장하기 화면 설계 (#1461)

## 왜

일과 상세의 ↓ 버튼으로 여는 화면이 「인쇄용으로 받기」로 짜여 있었다. 형태·배치를 글 줄과 고르기 시트로 고르고, 아래에 `인쇄하기` · `보내기`(공유 시트)가 있었다.
보호자는 대부분 카드를 기기에 **저장**하려고 누른다(#1461). 인쇄나 카톡 전송은 저장한 그림으로 사진 앱에서 하면 된다(사장님, 2026-11-23).
그래서 화면을 **저장 하나**로 다시 짠다. 목표는 처음 보는 보호자도 설명 없이 「모양 고르고 > 미리 보고 > 저장하기」로 끝나는 것이다.

## 정한 것 (시안 `save-screen`, 2026-11-23 승인)

| 자리 | 내용 |
|---|---|
| 제목 | `카드 저장하기` (일과 상세 ↓ 버튼 낭독 이름도 같음) |
| 순서 | 미리 보기 > 모양 고르기 > 꾸미기 > (Free) Pro 안내 |
| 미리 보기 | 가운데 크게, 옆으로 한 장씩 넘김(쪽 점 표시). 카드 한 장씩이면 카드 **안쪽 위** ✓ 로 빼고 넣기, 머리 오른쪽 `눌러서 빼고 넣어요` |
| 모양 고르기 | 그림 타일 3개 한 줄: 카드 한 장씩 / 일과 한 장 / 오려 쓰는 카드. 고른 타일은 남색 테두리. Free 는 A4 두 타일에 PRO 배지 |
| 꾸미기 | 디자인 칩 5개(기본 · 단순 · 잉크 절약 · 흑백 · 큰 글자, 잠긴 칩은 PRO 배지) · 카드 문장 넣기 켜고 끄기 · A4 일 때만 용지 방향 칩 · 오려 쓰는 카드일 때만 한 쪽에 몇 장 칩 · 카드 크기 칩 |
| 아래 버튼 | `저장하기 (N장)` 하나, 아래 고정. 사진 앱에 바로 저장 > 토스트 `사진에 N장 저장했어요` |
| 없앤 것 | `보내기`(공유 시트) · `인쇄하기` · PDF 만들기 · 고르기 시트 · `다른 앱에서 인쇄할 때는 실제 크기` 안내 |

- A4 모양(일과 한 장 · 오려 쓰는 카드)도 쪽마다 그림(PNG) 한 장으로 사진 앱에 저장한다.
- Free: 잠긴 타일·칩을 누르면 지금처럼 그 값의 Pro 미리 보기 판(`CardExportProTeaser`)을 미리 보기 위에 보이고, 저장은 고를 수 있는 값(카드 한 장씩 · 기본)으로만 나간다. 저장 그림 아래 이룸 로고 띠는 그대로.
- 요금제 혜택 문구의 「인쇄」 를 「저장」 으로 맞춘다.

## 검토한 안

| 안 | 고르지 않은 이유 |
|---|---|
| 저장하기 + 공유 · 인쇄 보조 버튼 | 인쇄·공유는 사진 앱이 이미 한다. 버튼이 셋이면 무엇을 누를지 다시 고민한다 |
| A4 는 PDF 로 파일 앱에 | iOS 는 저장 위치 고르는 창이 한 번 더 떠서 「누르면 끝」이 아니고, 저장 위치가 둘로 갈린다 |
| 공유 시트 이름만 「저장하기」 | 눌러도 저장이 아니라 메뉴가 떠서 말과 동작이 어긋난다 |

## 어떻게 (구현)

- 사진 저장: `gal` 패키지. iOS `NSPhotoLibraryAddUsageDescription`(넣기만, 5개 언어 InfoPlist.strings), Android 9 이하만 `WRITE_EXTERNAL_STORAGE`(maxSdkVersion 29).
- 안 쓰게 된 `printing` 패키지와 인쇄 코드, 고르기 시트를 지운다. PDF 만들기 · 공유 시트(`buildA4Pdf` · `share`)는 주간 리포트 · AI 메모 내보내기가 계속 써서 남긴다.
- 화면은 지금 `CardExportScreen` 의 상태·굽기(RepaintBoundary > PNG)를 그대로 쓰고 겉만 바꾼다. 미리 보기는 가로 스크롤에 전부 그려 두어(지연 생성 없음) 넘기지 않은 쪽도 구울 수 있게 한다.
- 새 부품: 모양 타일 줄(`CardExportFormatTiles`), 칩 줄. 칩은 공통 `ElumChoiceChip` 에 PRO 배지 자리를 더해 쓴다.

## 실패 경로

| 상황 | 화면 | 코드 |
|---|---|---|
| 사진 추가 권한 거부 | 실패 팝업 `사진에 저장하려면 설정에서 사진 추가를 허용해 주세요` + 설정 열기 | `E-EXPORT-SAVE-DENIED` |
| 사진 저장 실패(용량 등) | 실패 팝업 `사진에 저장하지 못했어요` | `E-EXPORT-SAVE` |
| 굽기 실패 | 실패 팝업 `저장할 그림을 만들지 못했어요` | `E-EXPORT-RENDER` |
| 그림 일부 못 받음 | 지금처럼 대신 그림·제목 + 미리 보기 위 한 줄 + 다시 시도 | `E-EXPORT-IMAGE` |
| 카드를 모두 뺌 | 버튼 `저장하기 (0장)`, 누르면 `저장할 카드를 하나 이상 골라 주세요` | — |
| 카드 0장 일과 | 빈 상태(지금 그대로) | — |

## 하지 않는 것

- 앨범 만들기, 저장 뒤 사진 앱 열기
- 공유·인쇄 버튼을 다른 자리(메뉴)에 남기기
- Free · Pro 권한 구조 변경 (서버 권한 그대로)
