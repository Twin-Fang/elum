# 테스트 정리와 테스트 설계 가이드라인

- 이슈: #623
- 날짜: 2026-10-10

## 문제

클라이언트 테스트가 281개 파일·5만 7천 줄로 늘어 전체 실행이 234초(12코어) 걸렸다.
결함을 잡지 못하는 단언이 많았다 — 화면 문구를 그대로 베낀 단언, 끝난 ARB 이전 작업을
확인하는 wiring 테스트, 같은 상태를 두 번 찍는 골든.

## 측정 — 시간이 어디에 쓰이나

`flutter test --reporter json` 으로 파일·테스트별 시간을 쟀다.

| 항목 | CPU |
|---|---|
| 파일 로딩(컴파일) | 784초 (56%) · 파일당 평균 2.8초 |
| 테스트 실행 | 603초 (44%) |

느린 개별 테스트 상위는 로그 파일 상한 테스트 두 개(각 14초, 1KB 줄 2500번 파일 I/O)였다.

## 판단 기준

테스트마다 "구현을 망가뜨리면 이 테스트가 사용자 문제를 알리며 실패하는가"를 물었다.
470개 파일(클라 281 · 서버 189)을 분류하고, 삭제·정리 후보는 직접 대조했다.

- **남긴다** — 서버 계약(`apiValue`·필드명·에러 코드), 실패·대체 경로, 조사·끼워넣기·분기 로직,
  과거 결함 회귀, 시안 대조(`*_conformance_test`·`figma_conformance_test`), 구조 불변식
- **지운다** — 로직 없는 문구 복사, 끝난 이전 작업 확인, 같은 상태 중복 골든
- 애매하면 남긴다

## 결정

| 대상 | 처리 | 근거 |
|---|---|---|
| `l10n/guardian_screens_wiring_test` · `guardian_widgets_wiring_test` (2800줄) | 삭제 | 화면이 ARB 키를 읽는지 확인하던 이전 작업용. `tool/check_hangul_literals_lib_test` 가 lib 의 한글 리터럴 0줄을 정적으로 막는다 |
| `pin_change_screen_golden_test` + 골든 4장 | 삭제 | `pin_change_conformance_test` 가 같은 네 상태를 찍고 시안 대조에도 쓰인다 |
| `l10n/*_messages_ko_test` 11개 · `child_wiring_test` | 문구 복사·화면 wiring 만 덜어냄 | 조사·끼워넣기·에러 코드·계약 단언은 남김 |
| 온보딩 PIN 불일치 안내 표시·해제 | `pin_screen_test` 로 옮김 | 문구가 아니라 상태 전이라 남길 가치가 있다 |
| `dev_log_file_test` 상한 테스트 | 50KB 줄 50번으로 축소 | 같은 동작을 1초 안에 검증. 첫 줄 버리기를 지우면 실패하는 것을 확인 |
| 골든 | 유지, `golden` 태그로 평소 실행에서 제외 | 시안 대조는 디자인 회귀를 잡는다. CI 는 이미 제외 |
| 서버 테스트 | 유지 | Spring 컨텍스트 2~3개뿐이라 느리지 않다. 정리 후보가 메서드 몇 개라 이득보다 운영 위험이 크다 |

에이전트 분류가 DELETE 로 낸 것 중 아래는 남겼다.

- 시안 좌표·모서리·그림자 단언 — 디자인 어긋남은 사용자 결함이다
- `card_review_badge_test`("가린다" 배지가 없다) — AI 개인정보를 가린다고 말하지 않는다는 원칙을 지킨다
- 서버 레코드 JSON 직렬화 테스트 — 필드명 계약이다

## 실패 경로

- 지운 테스트가 유일하게 잡던 결함이 있으면 회귀가 묻힌다 → 지운 테스트 이름을 전부 훑어
  로직 단언(약관 저장 실패 코드, 공지 링크 실패 코드, 밑줄 범위, 휴대폰별 빈 상태, PIN 불일치)이
  남았거나 다른 파일에 있는지 확인했다
- 정리 후 전체 테스트와 analyze 를 돌려 깨진 것이 없는지 본다

## 결과

같은 기기(12코어)에서 `flutter test` 전체를 정리 전후로 한 번씩 돌렸다.

| | 정리 전 | 정리 후 |
|---|---|---|
| 전체 시간 | 234초 | **166초 (-29%)** |
| 파일 / 테스트 | 281 / 3072 | 278 / 2936 |
| CPU 합 (로딩 + 실행) | 784 + 603초 | 571 + 412초 |

실패는 정리 전후 모두 `server_error_sync_test` 1건이다. 서버에 새 로그 관리 에러 코드
5개가 생겼는데 앱 enum 에 없어서 나는 실패이고, 이 작업과는 무관하다.
