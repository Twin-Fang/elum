# 보호자 홈 반응형 개편: 오늘 중심, 알림 시트, 가이드 앱 안 읽기 (2026-11-18 · #1455)

## 왜

- 태블릿 홈이 폰 홈을 가운데 열에 늘어놓은 모양이라 빈 곳이 많고, 보라색 `새로운 일과 만들기` 버튼이 칸 끝까지 닿지 않음
- `알림을 켜 둘까요?`가 홈 카드·전체 화면으로 떠서 오늘 일과를 밀어냄. 코치마크와 순서가 섞임
- 가이드 카드(`행동 카드란?`)를 누르면 앱 밖 브라우저로 나감
- 보호자가 가장 원하는 일: **일과를 만들어 보내고, 이룸이가 했는지 보기** (운영 숫자: 일과 만듦 63% → 카드 체크 24%)

## 시안과 고른 안 (사장님 확인)

- 시안 v1(대시보드·작업대·주간 보드·이룸이 중심 4안) > v2(오늘 중심, `이번 주` 없음)
- 폰: **B 상단 알약** (`이룸이 오늘 2/5`)
- 태블릿 세로: **오늘 일과 2열**, 화면 폭 전체
- 태블릿 가로: **왼쪽 목록 | 오른쪽 고른 일과 상세**
- 만들기 버튼: 칸 폭 끝까지
- `이번 주`(주간 보드)는 예약·반복(#1443) 뒤 다시 판단

## 무엇을 바꾸나

| 영역 | 바꾸는 것 |
|---|---|
| 알림 켜기 | 홈 카드·전체 화면 → **폰 아래 시트 / 태블릿 가운데 창** (`app/notification_intro_prompt.dart`). 홈 첫 진입 순서: 안내 > 시스템 권한 창 > 코치마크. 코치마크를 이미 본 보호자는 공지 런처가 같은 안내 한 번, 그 뒤 7일 다시 권하기 |
| 홈 알림 꺼짐 카드 | 삭제 (안내 카드 종류 3개: 크레딧 부족 > 권유 > 자동 보내기 안내) |
| 가이드 카드 | 홈에서 **오늘 일과 아래** 한 장 (다음에 할 일이 끝난 뒤, 닫으면 다음 팁). 누르면 **앱 안 읽기 화면**(웹뷰, 사이트 글 그대로). 설정 > `보호자 가이드` 목록에서 언제든 다시 봄 |
| 폰 머리 줄 | 로고 · 요금제 칩 … **이룸이 오늘 진행 알약** · ? · 종 · 배지. 오늘 일과 0개면 숨김, 누르면 이룸이 화면 |
| 태블릿 세로 | 화면 폭 전체(페이지 여백), 오늘 일과 2열 (2열에서는 길게 눌러 순서 바꾸기 없음, 밀어서 편집·삭제는 그대로) |
| 태블릿 가로 | 왼쪽 5 : 오른쪽 6. 왼쪽 인사말·만들기·오늘·지난 일과(스크롤), 오른쪽 고른 일과 상세(일과 시트와 같은 부품을 화면 칸 안에) |

## 하지 않는 것

- 주간 보드, 홈에서 예약 설정 (#1443)
- 가이드 글을 앱 부품으로 다시 그리기 (사이트 글 한 곳에서 고치면 앱도 바뀌는 쪽을 택함)
- 지난 일과 2열

## 실패 경로

- 알림 상태 확인 실패: 안내 없이 바로 코치마크 (다음 실행에 다시)
- 안내를 띄우는 중 코치마크 재호출: 진행 중 표시로 막음
- 가이드 글 불러오기 실패(본문): `가이드를 열지 못했어요` + `E-GUIDE-LINK` + 다시 시도. 사이트 밖 링크는 외부 브라우저
- 모르는 가이드 주소(slug): 첫 가이드
- 가로 태블릿에서 고른 일과가 사라짐(삭제·날짜 바뀜): 첫 일과, 0개면 안내 문구
