# 보호자 칸 아이콘 누름 · 고름 애니메이션 설계 (#934)

2026-10-21 · 브라우저 시안(실제 아이콘 SVG·색)으로 비교해 사용자와 정함.

## 왜

보호자 하단 바(폰)와 옆 메뉴(태블릿)는 칸을 눌러도 "골랐다"는 순간에 움직임이 없다.
누를 때 칸 전체가 0.93배로 줄었다 돌아오고, 색은 그 자리에서 바뀌는 것이 전부다.
Play Store 하단 바처럼 아이콘이 자기 모양에 맞게 살짝 움직이는 디테일을 넣어 앱이 살아 보이게 한다.

## 정한 것

### 고른 안

| 안 | 내용 | 결과 |
|---|---|---|
| A | 아이콘마다 자기 동작 | **채택** |
| B | 네 칸 같은 통통 튐 + 이름 아래 점이 따라옴 | 아이콘 개성이 없어 제외 |
| C | 고른 칸 뒤 알약 배경 + A 절반 세기 | 시안에 없는 요소라 제외 |

A의 일과 관리(뚜껑 열림)는 별로여서 후보 4개(카드 쏙 · 한 바퀴 · 말랑 흔들 · 체크)를 비교해 **F4 체크**로 바꿨다.

### 동작

| 순간 | 움직임 |
|---|---|
| 누름 (공통) | **아이콘만** 0.82배 + 1(viewBox 단위) 가라앉음, 즉시 반영. 칸 전체·이름은 그대로 |
| 뗌 (공통) | `AppPressable`과 같은 스프링으로 살짝 넘쳤다 제자리 |
| 고름 · 홈 | 찌그러짐 > 튀어 오름 > 착지하며 찌그러짐 > 제자리 (바닥 기준) |
| 고름 · 일과 관리 | 폴더 톡 커짐 > 안쪽 체크가 왼쪽부터 그려짐 > 잠깐 머묾 > 흐려지며 사라짐 |
| 고름 · 이야기 | 말풍선이 잦아들며 흔들림 + 글줄 두 개가 차례로 써짐 |
| 고름 · 내 정보 | 머리가 쏙 올라왔다 내려옴 + 몸이 눌렸다 펴짐 |
| 색 | 아이콘 · 이름 · 옆 메뉴 바탕이 `AppMotion.fast`(200ms)로 번짐 |

- 폰 하단 바와 **태블릿 옆 메뉴 둘 다** 같은 아이콘 위젯으로 같은 동작을 한다 (사용자 요청).
- 이미 고른 칸을 다시 눌러도 동작이 한 번 더 나온다. 첫 화면으로 돌아가는 기존 기능은 그대로.
- 고를 때 `HapticFeedback.selectionClick` 한 번.
- 동작 한 번 = `AppMotion.tabIconSelect`(1000ms). 500ms 상한을 넘기는 이유: 체크가 그려진 뒤 머물러야 읽힌다.
  칸 전환은 누르는 순간 끝나 아무것도 막지 않는다. 나머지 아이콘은 앞 660ms 안에서 멎는다.

### 만드는 방식 (내 판단, 사용자 승인)

- 새 라이브러리(Lottie · Rive) 없이 Flutter 기본 애니메이션만 쓴다.
- **아이콘 SVG 사본을 만들지 않는다.** 원본 한 장을 viewBox 영역으로 잘라 부위(머리 · 몸, 말풍선 테두리 · 글줄)를 따로 움직인다.
  원본이 바뀌면 동작도 그대로 따라간다. 영역 좌표는 SVG 모양에 맞춰 두었으므로 아이콘을 다른 모양으로 바꾸면 영역도 다시 본다.
- 체크는 원래 아이콘에 없는 모양이라 `nav_folder_check.svg` 하나를 더한다 (폴더와 같은 24×22 viewBox).
- 도형을 코드로 그리지 않는다 (client 규칙). 체크도 에셋이고, "그려짐"은 왼쪽부터 드러내기로 한다.

## 구조

| 파일 | 맡는 일 |
|---|---|
| `guardian_tab_icon.dart` | 눌림 컨트롤러(스프링) · 고름 컨트롤러 · 색 전환 · 동작 줄이기 판정 |
| `guardian_tab_icon_motion.dart` | 아이콘별 부위 자르기와 시간표 (진행 0 > 1, 1 은 제자리) |
| `guardian_tab_pressable.dart` | 칸 누름 영역: 누름 상태 · 고른 횟수 · 진동 (칸 전체는 줄이지 않음) |
| `guardian_bottom_nav.dart` · `guardian_side_nav.dart` | 위 셋을 엮고 이름 · 바탕 색 전환 |
| `AppMotion.tabIconSelect` · `AppPressable.releaseSpring` · `AppPressable.scaleNone` | 공통 토큰 |

## 하지 않는 것

- 이룸이 화면에는 넣지 않는다
- 칸 순서 · 아이콘 모양 · 색 · 크기 · 이름은 바꾸지 않는다
- 알약 배경 · 이름 아래 점 같은 새 요소는 더하지 않는다
- 칸(화면) 전환 애니메이션은 범위 밖

## 실패 경로

| 상황 | 동작 |
|---|---|
| 동작 줄이기 켬 | 눌림 · 고름 동작 없이 색만 즉시 바뀜. 칸 이동은 그대로 |
| 진동 하드웨어 없음 · 꺼짐 | 진동만 빠짐 (호출 결과를 기다리지 않음) |
| 빠르게 여러 번 누름 | 진행 중 동작을 처음부터 다시 재생 (겹쳐 쌓이지 않음) |
| 누른 채 칸 밖으로 끌어내 뗌 | 아이콘만 제자리로 돌아오고 칸은 안 바뀜 |
| 칸 위젯이 사라짐 (폰 ↔ 태블릿 전환) | 컨트롤러 dispose, 새 위젯은 제자리 상태로 시작 |
