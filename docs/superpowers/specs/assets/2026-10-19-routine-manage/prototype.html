일과관리 전체 동작

가운데 화면은 실제로 눌러 볼 수 있어요. 오른쪽은 보낸 결과가 이룸이 홈에 어떻게 보이는지예요 (B안: 묶음을 상자로 감싸 펼쳐 보여 주기).

기본

누르면 열기 · 길게 누르면 메뉴(보내기·이름·묶음에 넣기·복사하기·지우기) · 메뉴가 뜬 채로 끌면 정리 상태로 · 가운데 아래 + 일과 만들기

정리 상태 (흔들림) — 따로 "편집" 버튼 없음

끌어서 일과 위 = 새 묶음 · 묶음 위 = 넣기 · 사이 = 자리 이동 · ⊖ = 지우기 / 묶음 풀기 · 가운데 버튼이 "완료"로 바뀜

일과 하나는 한 곳에만

묶음에 넣으면 그 일과는 묶음 안으로 옮겨져요. 같은 일과를 다른 묶음에도 쓰려면 복사하기.

묶음 열림

번호 = 이룸이에게 보이는 순서 · 이름 바로 고치기 · 순서 편집 · + 일과 넣기 · 보내기
해 볼 것
  1. "등교 준비" 누르고 → 보내기
  2. "빨래 개기" 길게 누르기 → 메뉴
  3. 길게 누른 채로 끌어서 "장보기" 위에 놓기
  4. + 일과 만들기 → 새 묶음 → 일과 고르기
  5. 길게 눌러 끌기 시작 → ⊖ 로 묶음 풀기 → 완료
  6. "양치하기"가 든 묶음을 길게 눌러 복사하기
  7. 오른쪽 이룸이 화면에서 줄 눌러 완료
