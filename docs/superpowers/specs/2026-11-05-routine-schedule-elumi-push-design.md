# 요일별 반복 일과 · 주간 계획 · 이룸이 기기 일과 시간 알림 (#782, #1080)

> 2026-11-05 · 소유자 위임으로 에이전트가 결정 (근거는 이슈 #782 · #1080 댓글)

## 정한 것

| 질문 | 결정 | 이유 |
|---|---|---|
| 예약을 어디에 | 서버 `routine_schedule` (일과관리 원본 하나에 한 줄: 요일 비트 + 시각 + 알림 여부) | 보호자·이룸이 기기·여러 보호자가 같은 값을 봐야 함 |
| 오늘 일과는 언제 생기나 | **게으른 생성 + 1분 작업** 둘 다. `GET /api/routines/today` 직전에 오늘 요일 예약을 오늘 일과로 만들고, 정한 시각 1분 작업도 없으면 만든다 | 새 자정 작업 없이 아침부터 목록에 뜸. 아무도 안 열어도 시각에 생김 |
| 두 벌 막기 | 예약 행 날짜 차지(`update ... where last_materialized_date < today`) + 기존 "오늘 이미 보냈나" 규칙 | 조회 겹침·서버 둘(블루·그린)에서도 한 번만 |
| 만드는 방법 | 일과관리 `오늘 보내기`와 같은 카드 복사(`RoutineRules.copyCardsOf`), 예정 시각 = 정한 시각 | AI 호출 없음. 홈 정렬(보이는 순서 > 예정 시각)이 곧 오늘 시간표 |
| 알림 | 서버 1분 작업(매분 0초 KST) > FCM `ELUMI_ROUTINE_TIME` > 이룸이 기기, 누르면 그 오늘 일과 | 기존 이룸이 기기 푸시(`ELUMI_ROUTINE_ARRIVED`) 길을 그대로 씀 |
| 놓친 시각 | 5분 되짚기 (자정 넘겨 어제로는 안 감) | 배포·재시작으로 몇 분 비어도 그날 알림 살림 |
| 끝낸 일과 | 알림 생략 | 다 한 일을 재촉하지 않음 |
| 알림 소리 | 기존 `elumi_routines` 채널(기본 알림음 1번, 반복·전체화면·알람 소리 없음), 문구 "일과를 시작할 시간이에요" (제목 없음 — 잠금 화면) | 놀라지 않게. 소리는 기기 설정에서 끔 |
| 이룸이 기기 알림 꺼짐 | 서버는 살아 있는 연결의 등록 토큰 유무로 판정 (`NO_DEVICE`·`OFF`·`ON`) > 보호자 시트·주간 계획에 한 줄 | 토큰은 권한이 있을 때만 등록됨 |
| 여러 보호자 | 원본 하나에 예약 하나. 마지막 저장한 보호자가 주인, 그 사람 요금제로 실행 | 단순. 다른 보호자는 보고 끌 수 있음 |
| Free·Pro | 반복 저장·주간 계획·이룸이 기기 알림 = **Pro** (`ROUTINE_SCHEDULE` FLAG, Free false / Pro true). `오늘 보내기`·보호자 기기 알림(#777) = Free 그대로 | 새 기능은 Pro (#1081) |
| Pro 끝나면 | 예약 유지, 만들기·알림만 멈춤(`paused`), 보호자 화면에 "Pro가 끝나 멈췄어요". 끄기는 언제나 됨 | 지우지 않음 원칙 |
| Free 화면 | 결제(#1072) 전에는 입구를 숨김. 예약이 남아 있으면(멈춤) 보임 | #1073 과 같은 규칙 (`PlanAccess.canPurchasePro`) |
| 이룸이 화면 | 바뀐 것 없음 (Pro·결제 표시 없음). 오늘 목록이 시각 순으로 채워짐 | 아동 화면 규칙 |

## 실패 경로

- 예약 하나 실패 > 로그만, 다음 예약 계속. 만들기 실패가 오늘 일과 조회를 막지 않음
- 푸시 실패 > 리스너가 기록, 그날 다시 울리지 않음 (차지한 날짜 유지)
- 원본을 일과관리에서 지움 > 실행 때 예약 정리, 주간 계획에서 빠짐
- 주간 계획 조회 실패 > 다시 하기 + `E-WEEKLY-PLAN`, 저장·끄기 실패 > 팝업 + `E-SCHEDULE`
- Free 가 저장 > 403 `ROUTINE_SCHEDULE_NOT_ALLOWED`, 요일 0개·시각 틀림 > 400 `ROUTINE_SCHEDULE_INVALID`

## 하지 않는 것

- 특정 날 예외(휴일), 하루 여러 시각, 이룸이에게 그림 주간 계획 보여 주기 — 다음 이슈
- 이룸이 기기 안 예약(오프라인 울림) — 서버 푸시만
- 권한을 나중에 끈 기기 감지 — 토큰이 남아 있으면 `ON` 으로 보임 (한계)

## API

`GET /api/routine-schedules` · `PUT /api/routine-schedules/{routineId}` `{weekdays, time "HH:mm", notifyEnabled}` · `DELETE /api/routine-schedules/{routineId}` (보호자만). 마이그레이션 `V61__create_routine_schedule.sql` (V60 은 #1083).
