# 1. 전체 플로우 — Before / After

## 보호자 흐름

```
Before
일과 입력 → AI 질문 → 카드 생성 → 카드 검토 → 아이 화면으로

After
일과 입력 → AI 질문 → 【보상 설정】🆕 → 카드 생성 → 카드 검토 → 아이 화면으로
                           ↑                          ↑
                      건너뛰기 가능              보상 표시 + 수정

                        (검토 화면에서 뒤로가기)
                              ↓
                        【이탈 팝업】🆕

```

```
Before

  ↑          ↑           ↑

"오늘 전부 완료" 상태
```

# 2. 화면별 명세

## ① 보상 설정 화면 🆕

**위치**: AI 추가 질문 다음 · 카드 생성 전 · 진행 표시 `3 / 4`

```
┌──────────────────────────────────┐
│ ←                          3 / 4 │
│                                  │
│  다 하면 무엇을 할 수 있나요?      │  ← 제목
│                                  │
│  평소에 "이거 다 하면 젤리 먹자"   │  ← 설명 3줄
│  라고 말씀하시죠? 미리 정해두면    │
│  하늘이가 카드를 보는 내내 그걸    │
│  기억할 수 있어요.                │
│                                  │
│  최근에 정한 보상                 │  ← 섹션 (조건부)
│  [🍪 젤리] [📺 유튜브 10분]        │
│                                  │
│  [🍪 좋아하는 간식] [📺 유튜브 10분]│  ← 프리셋 2열
│  [🧸 좋아하는 놀이] [🚶 산책]      │
│  [✏️ 직접 입력]                   │
│                                  │
│  💡 한 달 뒤 선물보다 오늘 받을    │  ← 안내
│     수 있는 게 더 잘 통해요        │
│     왜 필요한가요? ›              │  ← 바텀시트 진입
│                                  │
│  [ 건너뛰기 ]        [ 다음 ]     │
└──────────────────────────────────┘
```

### 필요한 요소

| 요소 | 규격 | 상태 |
| --- | --- | --- |
| **프리셋 칩** | 이모지 + 라벨 · 2열 그리드 | 기본 / 선택됨 |
| **최근 보상 칩** | 프리셋과 동일 형태, 크기 작게 | 기본 / 선택됨 |
| **직접 입력 칩** | 탭하면 하단에 텍스트 필드 노출 | 기본 / 입력중 |
| 텍스트 필드 | **최대 20자** · 글자수 표시 | 기본 / 포커스 / 초과 |
| `건너뛰기` | **보조 버튼** (약하게) | 항상 활성 |
| `다음` | 주 버튼 | **항상 활성** (미선택도 진행 가능) |
| `왜 필요한가요? ›` | 텍스트 링크 | — |

### 상태 분기 2가지

| 상태 | 화면 |
| --- | --- |
| 최근 보상 **있음** | `최근에 정한 보상` 섹션 노출 |
| 최근 보상 **없음** | **섹션 전체를 숨긴다** (제목도 안 보임) |

### 바텀시트 — `왜 필요한가요?`

```
┌──────────────────────────────┐
│  보상을 정하는 이유            │
│                              │
│  해야 할 일만 알려주면 그 일을 │
│  하고 싶어지지는 않습니다.     │
│  끝나고 무엇이 있는지 알면     │
│  지금 하는 일에 의미가 생깁니다.│
│  실제로 좋아하는 것으로        │
│  정해주세요.                  │
│                              │
│           [ 확인 ]            │
└──────────────────────────────┘
```

> ⚠️ **"강화", "행동중재" 같은 전문 용어를 화면에 쓰지 않는다.**

## ② 카드 검토 화면 — 보상 줄 추가

```
┌─────────────────────────────┐
│  비 오는 날 학교 가기          │
│                             │
│  [카드 1] [카드 2] [카드 3]   │  ← 기존
│                             │
│ ───────────────────────────  │
│  🍪 다 하면: 젤리 먹기  [수정] │  ← 🆕 한 줄
│ ───────────────────────────  │
│     [ 아이 화면으로 시작 ]     │  ← 기존
└─────────────────────────────┘
```

| 상태 | 표시 |
| --- | --- |
| 보상 **있음** | `🍪 다 하면: 젤리 먹기` + `수정` 버튼 |
| 보상 **없음** | `+ 보상 정하기` (점선 테두리 등 비어 있음을 표현) |

## ③ 검토 이탈 팝업 🆕

```
┌──────────────────────────────────┐
│  아직 아이에게 보내지 않았어요      │
│                                  │
│  임시저장하면 나중에 이어서        │
│  수정할 수 있어요.                │
│                                  │
│  [ 삭제하기 ]      [ 임시저장 ]   │  ← 좌: 위험 / 우: 주 버튼
│                                  │
│       계속 편집하기                │  ← 텍스트 버튼
└──────────────────────────────────┘
```

| 버튼 | 위계 |
| --- | --- |
| `임시저장` | **주 버튼** |
| `삭제하기` | 위험(빨강 계열) · 주 버튼보다 약하게 |
| `계속 편집하기` | 텍스트 버튼 (기본 동작) |

> 아이도 볼 수 있는 기기다. **경고색·에러 아이콘을 과하게 쓰지 않는다**
> (기존 PIN 화면 규칙과 동일).

## ④ 보호자 홈 — 섹션 정리 + 배지

```
┌────────────────────────────────┐
│ [헤더]                          │
│ [새로운 일과 만들기 카드]         │  ← 기존
│                                │
│ 오늘                            │  ← 섹션 제목 🆕
│ ┌────────────────────────────┐ │
│ │ ☂️ 비 오는 날 학교 가기       │ │
│ │ ●●●○○  3/5                 │ │
│ │ 🍪 다 하면: 젤리 먹기        │ │  ← 🆕 보상 줄
│ └────────────────────────────┘ │
│ ┌────────────────────────────┐ │
│ │ 🏥 병원 가기     [ 임시저장 ]│ │  ← 🆕 배지
│ │ 이어서 수정할 수 있어요       │ │
│ └────────────────────────────┘ │
│                                │
│ 지난 일과  ▾                    │  ← 🆕 접힘 섹션
│ ┌────────────────────────────┐ │
│ │ 🎒 아침 등교 준비   5/5      │ │
│ │              [ 다시 하기 ]  │ │  ← 🆕 버튼
│ └────────────────────────────┘ │
│                                │
│ 추천 일과                       │  ← 기존
└────────────────────────────────┘
```

### 필요한 요소

| 요소 | 설명 |
| --- | --- |
| **섹션 제목** | `오늘` / `지난 일과 ▾` — 기존 `추천 일과` 제목 스타일 재사용 |
| **접기/펼치기** | `지난 일과`만. 기본 **접힘** |
| **보상 줄** | 타일 하단 · 이모지 + 짧은 텍스트 |
| **`임시저장` 배지** | 타일 우측 상단 · 중립색 (경고 아님) |
| **`다시 하기` 버튼** | 지난 일과 타일에만 · 작은 보조 버튼 |

### 상태 분기 4가지

| 상태 | 화면 |
| --- | --- |
| 오늘 일과 있음 | 정상 |
| 오늘 일과 **0건** | "오늘은 등록된 일과가 없어요" |
| 임시저장 있음 | 배지 + 설명 문구 |
| 지난 일과 **0건** | **섹션 자체를 숨긴다** |

## ⑤ 아동 홈 — 보상 배너 + 완료 상태

```
평소                              오늘 전부 완료
┌──────────────────────┐        ┌──────────────────────┐
│ ⭐12          하늘이   │        │ ⭐15          하늘이   │
│                      │        │                      │
│ 🍪 다 하면 젤리 먹어요! │  🆕    │        🎉            │  🆕
│                      │        │  오늘 할 일을 다 했어요! │
│  지금 할 일            │        │                      │
│ ┌──────────────────┐ │        │  🍪 젤리를 먹어요      │
│ │    [그림]         │ │        │                      │
│ │  학교 가기 준비    │ │        ├──────────────────────┤
│ │   ●●○○○          │ │        │ ✅ 학교 가기 준비      │
│ │   [ 시작 ]        │ │        │ ✅ 아침 약 먹기        │
│ └──────────────────┘ │        └──────────────────────┘
│                      │
│ ✅ 아침 약 먹기        │        일과 0건 → 기존 빈 상태 유지
└──────────────────────┘
```

| 요소 | 설명 |
| --- | --- |
| **보상 배너** | 상단 · 이모지 크게 + 짧은 문장 |
| **지금 할 일 카드** | 미완료 중 하나만 **크게** |
| **완료 타일** | 아래쪽 · 작게 · ✅ (기존 `childTileDone` 색 활용) |
| **전부 완료 상태** | `지금 할 일` 카드 자리를 축하 문구로 **교체** |

### 상태 분기 3가지

| 상태 | 화면 |
| --- | --- |
| 일과 있음 + 미완료 | `지금 할 일` 카드 |
| 일과 있음 + **전부 완료** | 🎉 축하 + 보상 문구 |
| 일과 **0건** | 기존 빈 상태(`_NoRoutine`) 그대로 |

> 보상이 설정되지 않은 일과면 **배너를 띄우지 않는다.**

## ⑥ 아동 수행 화면 — 상단 고정 보상 바

```
┌─────────────────────────┐
│ 🍪 젤리     ●●○○○       │  ← 🆕 스크롤·카드 전환에도 고정
├─────────────────────────┤
│                         │
│      [카드 이미지]        │  ← 기존
│                         │
│     가방을 챙겨요         │
│                         │
│      [ 했어요! ]          │
└─────────────────────────┘
```

| 규칙 | 내용 |
| --- | --- |
| 위치 | **상단 고정** — 카드가 바뀌어도 유지 |
| 구성 | 보상 이모지/그림 + 짧은 라벨 + 진행률 |
| 높이 | **카드 이미지를 가리지 않는 최소 높이** |
| 보상 없음 | 바를 숨기고 **진행률만** 표시 |

> ⚠️ **자문의 핵심 요구다.** *"수행하는 동안 최종 보상을 계속 확인할 수 있어야 한다."*

# 3. 보상 프리셋 — 아이콘/일러스트 필요 🎨

**아동 화면에 그림으로 띄우려면 프리셋별 시각 자산이 필요하다.**
자유 텍스트만 받으면 글자를 못 읽는 사용자에게 의미가 없다.

| key | 라벨 | 이모지 | 아동용 그림 |
| --- | --- | :---: | --- |
| `SNACK` | 좋아하는 간식 | 🍪 | 필요 |
| `VIDEO` | 유튜브 10분 | 📺 | 필요 |
| `PLAY` | 좋아하는 놀이 | 🧸 | 필요 |
| `WALK` | 산책 | 🚶 | 필요 |
| `CUSTOM` | 직접 입력 | ✏️ | 기본 아이콘 + 글자 |

> 이모지로 시작하고, 여유가 되면 캐릭터 톤에 맞는 일러스트로 교체한다.

# 4. 디자인 판단이 필요한 것

| # | 정할 것 | 선택지 |
| --- | --- | --- |
| 1 | 보상 배너가 **캐릭터와 겹치지 않게** 배치 | 상단 고정 / 캐릭터 아래 |
| 2 | `임시저장` 배지 색 | 중립 회색 / 브랜드 서브 컬러 (**경고색은 피한다**) |
| 3 | `지난 일과` 접힘 인터랙션 | 화살표 회전 / 높이 애니메이션 |
| 4 | 상단 고정 바 높이 | 카드 이미지 가림 최소화 |
| 5 | 프리셋 칩 2열 vs 가로 스크롤 | 2열 권장 (한눈에 보임) |

# 5. 기존 컴포넌트 재사용

| 새 요소 | 재사용 가능 |
| --- | --- |
| 프리셋 칩 | 온보딩 `도움 목표` 선택 칩 |
| 섹션 제목 | 보호자 홈 `추천 일과` 제목 |
| 이탈 팝업 | 기존 다이얼로그 스타일 |
| 진행률 | `RoutineProgressRing` |
| 완료 타일 | `childTileDone` 색상 |

**새로 그려야 하는 것은 실질적으로 3개다** — 보상 설정 화면 · 상단 고정 보상 바 · 임시저장 배지.
