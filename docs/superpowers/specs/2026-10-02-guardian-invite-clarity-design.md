# 함께하는 사람 화면을 앱 깐 사람 기준으로 읽히게 한다 (#506)

> 상태: 구현 (2026-10-02) · 근거: 이슈 #506, 시안 요청 #479 · 명세 [2026-09-23-multi-guardian-design.md](./2026-09-23-multi-guardian-design.md), [2026-10-01-elumi-phone-settings-and-disconnect-design.md](./2026-10-01-elumi-phone-settings-and-disconnect-design.md)
> 확정한 결정(다중 보호자 명세 2장·4장)은 뒤집지 않는다. 이 문서는 **화면에 나가는 글자**만 다룬다.

## 1. 왜 고치나

다중 보호자(#361~#363)는 시안 없이 먼저 만들었고, 시안 요청(#479)은 개발 이슈 번호 기준으로 적혔다.
앱을 처음 깐 보호자는 **"다른 휴대폰을 붙이는 길이 둘"**인데 화면에서 차이를 알 수 없었다.

| | 이룸이 휴대폰 연결 | 함께하는 사람(보호자 초대) |
|---|---|---|
| 누구를 붙이나 | 이룸이 당사자가 쓰는 휴대폰 | 다른 보호자(엄마, 아빠, 센터 선생님) |
| 붙으면 | 일과를 보고 체크만 한다 | 일과를 같이 만들고 관리한다 |
| 쓰는 코드 | 연결 코드 (시안 문구) | 초대 코드 |
| 시작 위치 | 설정 > 이룸이 휴대폰 연결하기 | 설정 > 함께하는 사람 |

## 2. 바꾼 것

화면 구조·배치·서버·데이터는 그대로다. 글자와 설명 줄만 바꿨다.

| 자리 | 전 | 후 |
|---|---|---|
| 함께하는 사람 · 설명 | `{이름}를 함께 돌보는 사람이에요` | 그대로 + `일과를 같이 만드는 가족이나 선생님이에요. 이룸이가 쓰는 휴대폰은 설정의 이룸이 휴대폰에서 연결해요` |
| 혼자일 때 목록 아래 | 없음 | `아직 혼자 돌보고 있어요. 가족이나 선생님을 초대해보세요` |
| 줄 1 | 초대 코드 만들기 | 다른 보호자 초대하기 |
| 줄 2 | 초대 코드 넣기 | 받은 초대 코드 넣기 |
| 줄 3 | 이 이룸이에서 나가기 | 함께 돌보기 그만두기 |
| 줄 3 아래 | 없음 | 다른 보호자 있음: `내가 만든 일과만 사라지고, 다른 보호자의 일과는 그대로예요` / 혼자: `혼자 돌보고 있어서 그만두면 이룸이와 일과, 별이 모두 사라져요` |
| 확인 팝업 | `이 이룸이에서 나갈까요?` / 버튼 `나가기` | `함께 돌보기를 그만둘까요?` / 버튼 `그만두기` (본문은 그대로) |
| 초대 코드 만들기 | 없음 | `이룸이가 쓰는 휴대폰은 여기서 붙이지 않아요 / 설정의 이룸이 휴대폰에서 연결해요` |

## 3. 실패 경로 (바뀌지 않았다, 확인한 것)

| 상황 | 동작 |
|---|---|
| 목록을 못 받음 | 혼자인지 모르므로 그만두기 설명을 말하지 않고, 그만두기도 누를 수 없다. 에러 코드와 다시 시도를 보인다 |
| 이룸이 없음 | 설명 없이 이유와 에러 코드(`E-PPL-NONE`)만 보인다 |
| 그만두기 실패 | 화면에 머문다. 이유와 에러 코드(`E-LEAVE`) |
| 글자 크기 200% | 설명 줄은 줄바꿈되고 확인 팝업 버튼을 가리지 않는다 (기존 테스트로 확인) |

## 4. 하지 않은 것 (시안이 있거나 합의된 문구라 디자이너 확인이 필요하다 — #479 댓글에 질문으로 남김)

- 설정의 `함께하는 사람` 줄 이름·위치 (설정 시안 1022:4467에 없는 줄)
- 이룸이 휴대폰 연결 화면의 `코드` 표기 (#228 합의)
- 이룸이 휴대폰 설정의 `로그아웃`·`회원탈퇴` 두 줄 (시안 19번 구성)
- 실패 문구와 에러 코드 화면의 모양 (시안 없음)

## 5. 검증

- 위젯 테스트: 혼자 / 여럿 / 목록 실패에서 설명이 다르게 나온다, 이룸이 휴대폰 안내가 늘 보인다.
- 수정을 되돌리면 새 테스트가 실패하는 것을 확인했다 (15건 실패).
