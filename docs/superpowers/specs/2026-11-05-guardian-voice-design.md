# 보호자 목소리로 카드 읽기 (Pro) 설계 — #787

2026-11-05 · 담당 에이전트 결정(사용자 위임). 상위: #1081 · 약관: #1079

## 범위

- 보호자가 **카드마다** 자기 목소리를 녹음한다 (직접 녹음. AI 목소리 복제는 나중).
- 이룸이 기기는 녹음이 있으면 **녹음 > 기존 음성 순서**로 읽는다.
- 일과 제목 녹음은 이번에 하지 않는다 (카드 읽기만).

## 결정

| 항목 | 결정 | 이유 |
|---|---|---|
| 권한 | `Entitlement.GUARDIAN_VOICE` (Free false · Pro true, 관리자 설정 `FREE_/PRO_GUARDIAN_VOICE`) | CARD_EXPORT_* 와 같은 방식 |
| Free 표시 | 녹음 칸 숨김 (`PlanAccess.canPurchasePro` 가 false 인 동안) | 살 방법이 없는데 잠금만 보이면 막힌 기능처럼 느껴짐 |
| Pro 가 끝나면 | 녹음 **남김**. 이룸이는 기본 음성. 보호자는 듣기·지우기 가능(다시 녹음은 없음) | 데이터를 조용히 지우지 않음 (#1081) |
| 재생 판정 | 서버 `GET .../voice`: 이룸이 기기는 **녹음한 보호자**(열쇠 앞부분 memberId)가 지금 Pro 일 때만 200, 아니면 404 | 앱 캐시가 남아도 매번 확인해 Pro 종료가 바로 반영 |
| 저장 | 카드 그림 폴더 아래 `guardian-voice/{memberId}/{UUID}.m4a`, DB `routine_step.guardian_voice_path` (V64) | 그림과 같은 열쇠 방식, 서버 이전 내보내기에 함께 들어감 |
| 형식·한도 | m4a(AAC) 만, 바이트로 판정(ftyp + moov/mvhd 길이), 1MB · 15초(+1초 여유) | 선언된 Content-Type 은 믿지 않음 |
| 일과 복제·보내기 | 같은 열쇠 공유 (일과관리 원본 > 오늘 일과에서도 들려야 함). 파일은 아무 카드도 안 가리킬 때만 삭제 | 그림과 같음 |
| 이야기·링크 공유 | 녹음은 넘기지 않음 | 보호자 목소리는 개인정보 |
| 글 수정 | 녹음 유지 (보호자가 다시 녹음·삭제) | 조용히 지우지 않음 |
| 지우기 | 요금제와 상관없이 언제나. 카드·일과 삭제 때 안 가리키는 파일 삭제, 탈퇴·완전 삭제 때 보호자 폴더째 삭제 | 개인정보 |
| 보호자 화면 재생 | Pro 일 때만 녹음으로 미리 읽기 (이룸이가 듣는 것과 맞춤) | |
| 일과 언어 | 녹음은 언어와 상관없이 튼다 | 보호자가 그 카드를 직접 읽은 소리 |

## 실패 경로

| 상황 | 동작 |
|---|---|
| 마이크 거부 | 칸에 안내 + 설정 열기. 카드는 기본 목소리로 계속 읽힘 |
| 너무 짧음(0.5초 미만)·녹음 실패 | `E-VOICE-SHORT` · `E-VOICE-RECORD` |
| 올리기 실패(망·5xx) | 문구 + 에러 코드 + 같은 녹음으로 다시 하기 |
| 4xx(형식·길이·Pro 아님) | 서버 문구 + 코드, 새로 녹음 |
| 이룸이 재생 실패·404·망 없음 | 캐시가 있으면 캐시(망 없음만), 아니면 기존 음성 순서로 |
