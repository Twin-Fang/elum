# 함께하기 이름 표시 정합성 (#562)

사용자 승인: 두 홈이 같은 연결 프로필의 등록 이름을 사용하도록 수정하고 회귀 테스트를 추가한다. 2026-10-05 사용자가 빠른 수정을 요청하며 설계를 승인했다.

## 문제와 범위

기존 두 홈은 선택 프로필 목록을 보지 않고 회원 응답의 nickname을 직접 표시한다. 회원 응답에 기본 이름 또는 이전 프로필 이름이 남으면 연결한 QA 이름을 덮는다. 운영 로그의 회원 조회는 성공했지만 응답 본문은 없어 제보 당시 응답 값 자체는 확정하지 못했다.

## 정상 경로

두 홈은 공통 이름 결정 함수를 사용한다. 선택 ID와 같은 프로필의 등록 이름을 사용한다. 이름 앞뒤 공백은 제거한다. 조회 중에도 AsyncValue의 이전 응답을 사용할 수 있으나 선택 ID가 일치하는 값만 사용한다.

## 실패와 호환 경로

선택 프로필의 이름이 비었거나 이전 프로필 목록만 남으면 현재 온보딩 이름을 유지한다. 목록을 주지 않는 구버전 및 이룸이 휴대폰은 회원 nickname을 유지한다. 회원 이름도 비었거나 조회 실패면 로컬 이름, 실제 미등록이면 기존 기본 이름을 사용한다. 프로필 선택·합류·서버 저장 API는 변경하지 않는다.

## 검증

기본 회원 이름보다 QA 우선, 다른 프로필 목록 잔존, 빈 이름, 구버전 호환, 조회 대기·실패, 보호자 홈과 이룸이 홈의 실제 인사말을 검증한다. 관련 프로필·홈·진행률 테스트 102건 및 정적 분석을 통과했다. 운영 휴대폰 재현은 새 테스트 앱에서 후속 확인한다.

## 테스트 앱 버전

사용자가 iOS 출시 버전 충돌 해소를 위해 버전 상향을 명시 요청했다. version_manager.py set 2.16.3으로 version.yml·pubspec.yaml·build.gradle을 함께 맞춘다. main 릴리스·앱스토어 심사 제출은 수행하지 않는다.
