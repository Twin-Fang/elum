# 알림 목록 줄 모양 통일과 의견 처리 알림 내용 보기 (#1514)

2026-11-26 · 이슈 https://github.com/Twin-Fang/elum/issues/1514

## 문제

- 시각 칸의 긴 날짜(`2026년 11월 16일`)가 제목 칸을 좁혀 제목이 잘리거나 한 글자만 다음 줄로 넘어간다
- 회색 설명 줄이 운영자 알림에만 있고 최대 3줄이라 줄 높이가 제각각이다
- 의견 처리 알림은 눌러도 아무 일이 없고, 여러 건이 오면 서로 구분되지 않는다

## 목표와 하지 않는 것

- 목표: 모든 알림 줄이 같은 틀로 보이고, 의견 처리 알림에서 내가 보낸 의견을 다시 읽을 수 있다
- 하지 않는 것: 관리자 답글, 보낸 의견 목록 화면, 종류별 아이콘 색

## 검토한 안

| 안 | 내용 | 결정 |
|---|---|---|
| 앱만 수정 | 누르면 안내 시트만 | 어떤 의견인지 여전히 모름. 버림 |
| 의견 1건 조회 API | 시트를 열 때 따로 조회 | 시트에 로딩, 실패 상태가 더 생김. 버림 |
| 알림 목록 응답에 의견 본문 포함 | 기존 `body` 칸 재사용, `feedbackSentAt` 추가 | 호출이 늘지 않고 옛 앱은 `body` 를 운영자 알림에서만 읽음. 채택 |

## 설계

서버
- `NotificationItemResponse.body`: 운영자 알림 본문 또는 의견 처리 알림의 보낸 의견 본문. `feedbackSentAt` 추가
- `FeedbackService.sentFeedbacksOf(memberId, ids)`: 그 회원이 보낸 의견만 돌려줌 (쪽마다 쿼리 1회, 남의 의견 id 는 결과에 없음)

앱
- 줄 틀: 아이콘 > 제목(최대 2줄, 어절 단위 줄바꿈) · 오른쪽 위 시각과 안 읽음 점 > 회색 설명 1줄
- 설명 줄: 운영자 알림 본문, 보낸 의견 앞부분(따옴표), 주간 리포트 기간. 보여 줄 정보가 없는 종류는 제목만
- 시각: 오늘과 어제는 시각, 올해는 `11월 16일`, 다른 해만 연도 포함 (`DateLabels.shortDateOf`)
- 의견 처리 알림을 누르면 안내 시트(폰) 또는 가운데 창(태블릿): 그림 `feature_icon_feedback_resolved.png`, 제목, 고마움 한 줄, 보낸 날짜와 의견 전문, 확인

## 실패 경로

| 상황 | 화면 |
|---|---|
| 의견이 지워졌거나 본문이 빔 | 설명 줄 없이 제목만, 누르면 의견 칸 없는 시트 |
| 주간 리포트 알림에 주 시작일이 없거나 형식이 다름 | 설명 줄 없이 제목만 |
| 서버가 옛 버전(`feedbackSentAt` 없음) | 보낸 날짜 머리글만 빠짐 |
| 의견이 김(최대 2000자) | 의견 칸 안에서 스크롤 |

## 테스트

- 서버 `NotificationQueryServiceTest.page_feedbackResolved_carriesSentMessageAndSentAt`: 본문이 안 실리면 의견을 구분 못 함, 지워진 의견은 null
- 앱: `flutter analyze`, `tool/check_*`, 실제 위젯 렌더 캡처
