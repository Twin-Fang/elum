## 1. 왜 하는가

실증 1차에서 보호자 A가 말한 구조는 3단계였다.

```
등교 준비 (묶음)
 └ 밥 먹기 > 놀이 > 세수 > 양치 > 옷 입기 (일과)
     └ 물 마시기 · 앉아서 먹기 · 갖다 놓기 (카드)
```

지금 앱은 일과 > 카드 2단계뿐이고, 같은 아침 일과를 매일 다시 만들어야 한다.
보호자 B는 "첫 화면에 오늘 시간표(등교 준비 → 학교 다녀와서 → …)"를 원했다.
디자이너와 논의 결과, 기능이 늘어날 자리를 위해 **보호자 화면에 하단 바**를 둔다.

## 3. 하단 바

| 칸 | 내용 |
| --- | --- |
| 홈 | 지금 보호자 홈 그대로 (오늘 일과 · 지난 일과) |
| 일과관리 | 이 문서의 주제 |
| 이야기 | 나중에 토론·커뮤니티. 지금은 준비 중 안내 |
| 내정보 | 프로필 · 설정 (지금 설정 화면) |

- 시안 A안(기본 4칸)으로 확정. 가운데 만들기 칸(5칸)은 글씨가 작아져 뺐다.
- **오른쪽 위 "이룸이 화면" 버튼은 모든 칸에서 같은 자리**에 둔다 (지금 홈 머리의 전환 버튼과 같은 역할).

## 4. 일과관리 칸

### 4-1. 화면 구성

- 머리: `일과관리` 제목 + 오른쪽 위 `🐱 이룸이 화면`.
- 안내 한 줄: `누르면 열기 · 길게 누르면 메뉴` (정리 상태에서는 문구가 바뀐다).
- 본문: 4열 아이콘 격자. **낱개 일과 = 아이콘 하나**, **묶음 = 폴더 모양**(안 일과 그림 최대 4개, 2×2).
- 가운데 아래 떠 있는 버튼 `+ 일과 만들기` (글자가 있는 둥근 버튼, 오른쪽 아래 아님). 정리 상태에서는 `완료`로 바뀐다.
- 오늘 보낸 것은 아이콘 오른쪽 아래 민트 ✓ 표시.
- "편집" 버튼은 두지 않는다 — 무엇을 하는 버튼인지 알기 어렵다는 피드백.

### 4-2. 상태 3가지와 동작

**기본 상태**

| 동작 | 결과 |
| --- | --- |
| 일과 누르기 | 일과 상세 시트 (카드 미리보기 · 보내기 · 카드 고치기) |
| 묶음 누르기 | 흐린 배경 위로 묶음 열림 |
| 길게 누르기 (0.45초) | 빠른 메뉴 (아래 표) |
| 길게 누른 채 끌기 | 메뉴가 닫히고 **정리 상태**로 바뀌며 끌기 시작 (휴대폰 바탕화면과 같다) |
| `+ 일과 만들기` | 만들기 시트 |

**빠른 메뉴**

| 일과 | 묶음 |
| --- | --- |
| 오늘 하늘이에게 보내기 | 오늘 하늘이에게 보내기 |
| 이름 바꾸기 | 이름 바꾸기 |
| 묶음에 넣기 → 묶음 고르기 시트 | 순서 바꾸기 → 묶음 열림 + 순서 편집 |
| 복사하기 | 복사하기 (안 일과까지 복사) |
| 지우기 (빨강, 확인 팝업) | 묶음 풀기 (확인 팝업) |

**정리 상태 (아이콘이 흔들림)**

| 동작 | 결과 |
| --- | --- |
| 끌어서 일과 **가운데**에 놓기 | 새 묶음 생성 → 바로 묶음 열림, 이름 칸에 커서 (`새 묶음` 선택됨) |
| 끌어서 묶음 가운데에 놓기 | 그 묶음 맨 뒤에 들어감 |
| 끌어서 아이콘 **가장자리(사이)**에 놓기 | 자리 이동 (세로 파란 선으로 들어갈 자리 표시) |
| 아이콘 모서리 ⊖ | 일과: "지울까요?" / 묶음: "풀까요? 안 일과는 남아요" |
| 묶음 누르기 | 정리 상태 그대로 묶음 열림 |
| 가운데 `완료` | 기본 상태로 |

**묶음 열림**

| 동작 | 결과 |
| --- | --- |
| 이름 누르기 | 그 자리에서 바로 고침 (최대 12자, 비우면 `새 묶음`) |
| 일과 줄 누르기 | 일과 상세 시트 (`등교 준비 묶음 · 2번째` 표시, 버튼은 `이 일과만 오늘 보내기`) |
| 오른쪽 위 `순서 편집` | ≡ 끌어서 순서 바꾸기 · ⊖ 묶음에서 빼기 |
| ⊖ 빼기 | 일과는 묶음 밖으로 나가 남는다 (지워지지 않음). 1개만 남으면 묶음이 자동으로 풀린다 |
| `+ 일과 넣기` | 고르기 화면 → 고른 순서대로 맨 뒤에 붙음 |
| `오늘 하늘이에게 보내기` | 묶음째 이룸이 홈으로 |
| 바깥 · ✕ | 닫힘 |

### 4-3. 만들기

`+ 일과 만들기` → 시트 `무엇을 만들까요?`

1. **새 일과 만들기** — 지금 일과 만들기 화면 그대로.
2. **새 묶음 만들기** — 고르기 화면: 묶음 이름 + 낱개 일과 목록. **누른 순서대로 1·2·3 번호**가 붙고 그 번호가 묶음 순서가 된다. 2개 이상 골라야 `N개로 묶기`가 켜진다.

끌어서 묶기는 숨은 동작이라 처음 쓰는 보호자는 모른다. **끌기로 하는 일은 전부 메뉴·버튼으로도 할 수 있어야 한다.**

### 4-4. 규칙

1. **일과 하나는 한 곳에만 있다.** 묶음에 넣으면 그 일과는 묶음 안으로 *옮겨진다*. 격자에 같은 일과가 두 번 보이지 않는다.
2. 같은 일과를 두 묶음에 쓰려면 **복사하기**. 복사본 이름은 `원래 이름 복사`.
3. **묶음을 지워도 일과는 지워지지 않는다.** 묶음에는 `풀기`만 있다 — 일과 여러 개를 한 번에 잃지 않게.
4. 묶음은 일과가 2개 이상일 때만 존재한다 (1개가 되면 자동으로 풀림).
5. 순서는 의미가 있다 — 번호 = 이룸이에게 보이는 순서. 휴대폰 폴더와 다른 점.
6. 같은 날 같은 것을 두 번 보내면 `오늘 이미 보냈어요`.
7. 홈에서 만든 일과도 일과관리에 자동으로 들어온다.

## 5. 이룸이 홈

시안 B안: **지금 홈(제목 + 회색 일과 줄 + 진행률 동그라미)을 그대로 두고 묶음만 얹는다.**

- 묶음 = 흰 상자로 감싼 일과 줄 묶음. 상자 머리에 `🗂️ 등교 준비` + `2 / 4` 진행.
- **항상 펼쳐 둔다.** 이룸이가 폴더를 열 필요 없다 (이룸이는 접힌 것을 찾아 열기 어렵다).
- 일과 줄은 지금 줄 그대로 — 누르면 지금 카드 화면, 끝내면 지금처럼 칭찬·민트 체크.
- 묶음의 일과를 모두 끝내면 묶음 완료 축하를 한 번 더.
- 낱개로 보낸 일과는 지금처럼 상자 없이 한 줄.

다른 후보: A안(이름표 + 번호만, 가장 적게 바뀜), C안(묶음도 한 줄, 누르면 한 단계 안쪽 목록). B를 고른 이유 — 펼쳐져 있으면서 "어디까지가 한 덩어리"가 눈으로 구분되고, 지금 일과 줄을 그대로 다시 쓴다.

## 6. 결정 필요 ⚠️

**일과관리 속 일과는 "보관해 둔 원본"인가?**

지금 일과는 날짜에 붙어 있다(오늘 일과 / 지난 일과). 일과관리가 생기면 일과는 보관해 두는 원본이 되고,
`보내기`를 누를 때마다 그날의 일과가 하나 새로 생기는 구조가 자연스럽다. 이러면 서버 데이터 모델이 바뀐다
(원본 · 묶음 · 보낸 기록 분리). 구현 전에 정한다.

## 7. 실패 경로

| 상황 | 동작 |
| --- | --- |
| 보내기 실패 (네트워크) | 실패 팝업 + 에러 코드, 보낸 표시를 붙이지 않음 |
| 묶음 저장 실패 | 화면 상태를 되돌리고 실패 팝업 |
| 일과가 0개 | 격자 대신 빈 상태 안내 + `+ 일과 만들기` |
| 고르기 화면에 낱개 일과가 없음 | "묶을 수 있는 일과가 없어요" + 새 일과 만들기 안내 |

## 8. 이 문서에서 내가 정한 것 (사용자 확인 전)

- 길게 누르기 시간 0.45초, 끌기 시작 거리 10px.
- 가운데 놓기 = 묶기 / 가장자리 놓기 = 자리 이동 (판정 폭: 아이콘 양쪽 10px).
- 묶음 최소 2개 · 이름 최대 12자 · 기본 이름 `새 묶음`.
- 묶음 지우기 대신 풀기만.
- 이룸이 홈 묶음 상자 아이콘 🗂️ (실제 구현은 에셋으로).
