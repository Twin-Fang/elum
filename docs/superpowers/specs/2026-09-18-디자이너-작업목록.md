# 2. 전체 흐름 — 어디에 무엇이 끼는가

## 보호자

```
로그인 → 약관 → 【역할 선택】🆕 → 이름 → 목표 → 캐릭터 → PIN → 【코드 발급】🆕 → 홈
                                                            (건너뛰기 가능)

일과 만들기
일과 입력 → AI 질문 → 카드 생성 → 카드 검토 → 【보상 설정】🆕 → 사용자 화면으로
                                    (1/4)  (2/4)   (3/4)        (4/4)
                                             ↑              ↑
                                    추가·삭제·순서    건너뛰기 가능
                                             │
                                        뒤로가기
                                             ↓
                                   【이탈 팝업】🆕
```

## 사용자(당사자)

```
로그인 → 약관 → 【역할 선택】🆕 → 【코드 입력】🆕 → 사용자 홈
                                                     ↓
                                    홈 → 카드 수행 → 보상 완료
                                     ↑       ↑          ↑
                                 보상 배너  고정 바   보상 문구
```

> **사용자 기기는 온보딩을 하지 않는다.** 이름·캐릭터·목표·PIN은 보호자가 정한 값을 받는다.
> 사용자가 하는 입력은 **연결 코드 6자리 하나뿐**이다.

# 3. 🆕 역할 선택 화면

**위치** — 약관 동의 다음

```
┌──────────────────────────────────┐
│                                  │
│   이 기기는 누가 사용하나요?        │
│                                  │
│   나중에 바꿀 수 있어요             │
│                                  │
│   ┌────────────────────────────┐ │
│   │ [아이콘]  보호자예요         │ │
│   │          일과를 만들고       │ │
│   │          관리해요            │ │
│   └────────────────────────────┘ │
│                                  │
│   ┌────────────────────────────┐ │
│   │ [아이콘]  제가 사용해요       │ │
│   │          받은 코드로         │ │
│   │          연결해요            │ │
│   └────────────────────────────┘ │
│                                  │
└──────────────────────────────────┘
```

| 요소 | 규격 |
| --- | --- |
| 선택 카드 | 아이콘 + 제목 + 한 줄 설명 · **세로 2개** |
| 선택 상태 | 온보딩 `도움 목표` 칩 선택 스타일 재사용 |
| 진행 | **탭하면 바로 넘어간다.** 하단 `다음` 버튼 없음 |
| 뒤로가기 | 없음 (약관까지 끝낸 상태) |

> ⚠️ **"아이"가 아니라 "사용자"로 쓴다.** 성인 당사자도 이 화면을 본다.
> 문구에 연령을 암시하는 말을 넣지 않는다.

**필요 에셋** — 아이콘 2종 (보호자 / 사용자). 캐릭터 톤과 맞춘다.

# 4. 🆕 기기 연결 — 코드 발급 · 코드 입력

## 4-1. 코드 발급 (보호자 기기)

**진입 2곳** — PIN 설정 직후 / 홈 → 설정 → `사용자 기기 연결`

```
┌──────────────────────────────────┐
│ ←                                │
│                                  │
│  사용자 기기를 연결할까요?          │
│                                  │
│  사용자 기기에서 아래 코드를        │
│  입력하면 연결돼요                 │
│                                  │
│      ┌──────────────────┐        │
│      │                  │        │
│      │    [ QR 코드 ]    │        │
│      │                  │        │
│      └──────────────────┘        │
│                                  │
│        4 8 2   1 9 3             │  ← 3-3 묶음 · 자간 넓게
│           [ 복사 ]                │
│                                  │
│        09:42 남음                 │
│                                  │
│  [ 코드 다시 만들기 ]              │
│  [ 나중에 할게요 ]                 │  ← 온보딩에서 들어왔을 때만
└──────────────────────────────────┘
```

| 요소 | 규격 |
| --- | --- |
| QR | 정사각 · 흰 배경 · 여백 넉넉히 |
| 6자리 코드 | **가장 큰 글자** · 자간 넓게 · 3-3 묶음 |
| `복사` | 작은 텍스트 버튼 · 누르면 "복사했어요" 토스트 |
| 남은 시간 | `09:42` · **10분** 카운트다운 |
| `코드 다시 만들기` | 보조 버튼 → **만료되면 주 버튼으로 승격** |
| `나중에 할게요` | 텍스트 버튼 |

**QR과 숫자는 같은 값의 두 표현이다.** 카메라가 없거나 못 쓰는 경우를 대비해 둘 다 준다.

### 상태 3가지

| 상태 | 화면 |
| --- | --- |
| 정상 | 위 그대로 |
| **만료** | QR·숫자 흐리게 + 오버레이 `코드가 만료됐어요` · `다시 만들기` 강조 |
| **연결 성공** | `사용자 기기가 연결됐어요` + 체크 → 홈으로 |

## 4-2. 코드 입력 (사용자 기기)

```
┌──────────────────────────────────┐
│                                  │
│  보호자에게 받은 코드를            │
│  넣어주세요                       │
│                                  │
│   ┌─┐┌─┐┌─┐  ┌─┐┌─┐┌─┐          │  ← PIN 화면 6칸 스타일 재사용
│   │4││8││2│  │ ││ ││ │          │
│   └─┘└─┘└─┘  └─┘└─┘└─┘          │
│                                  │
│      [ QR로 연결하기 ]             │
│                                  │
│   ┌─────────────────────┐        │
│   │   1    2    3       │        │  ← PIN 화면 숫자패드 재사용
│   │   4    5    6       │        │
│   │   7    8    9       │        │
│   │        0    ⌫       │        │
│   └─────────────────────┘        │
└──────────────────────────────────┘
```

| 상태 | 화면 |
| --- | --- |
| 입력 중 | 채운 칸 강조 · **6자리 채우면 자동 제출** |
| **코드 틀림** | 칸 흔들림 + `코드가 맞지 않아요` · 입력 초기화 |
| **만료** | `코드가 만료됐어요. 보호자에게 새 코드를 받아주세요` |
| **카메라 거부** | QR 버튼 자리에 `숫자로 입력해주세요` 안내. **앱은 계속 쓸 수 있다** |
| 연결 성공 | `연결됐어요!` → 사용자 홈 |

> ⚠️ **사용자 기기다. 빨간 경고·에러 아이콘을 크게 쓰지 않는다.**
> PIN 화면과 같은 톤으로, 놀라지 않게 처리한다.
> 다만 화면 구석에 **작은 에러 코드**는 남긴다 (문의가 들어왔을 때 추적용).

# 5. 🔧 카드 검토 — 추가 · 삭제 · 순서 변경

## 🔴 가장 중요한 제약 — **카드 그림은 다시 만들지 않는다**

> **AI 이미지 생성 비용 때문에, 이미 만들어진 카드의 그림 교체는 지원하지 않는다.**

디자인에 직접 영향을 준다.

| 동작 | 그림은? | 디자이너가 그려야 할 것 |
| --- | --- | --- |
| 카드 **문구 수정** | **그대로 유지** | 수정 시트에서 **그림 교체 버튼을 빼야 한다** |
| 카드 **추가** | **그림이 없다** | 🎨 **그림 없는 카드 디자인이 필요하다** |
| 카드 **순서 변경** | 그림이 따라간다 | — |
| 카드 **삭제** | — | — |

### 🎨 그림 없는 카드 — 두 안 중 하나를 고른다

```
A안 — 기본 일러스트 (권장)          B안 — 글자 중심 카드
┌─────────────────┐              ┌─────────────────┐
│                 │              │                 │
│   [기본 그림]     │              │                 │
│                 │              │   가방을 챙겨요    │  ← 글자를 크게
│                 │              │                 │
│  가방을 챙겨요     │              │                 │
│                 │              │                 │
└─────────────────┘              └─────────────────┘
 다른 카드와 형태가 같다             그림 자리를 없애 어색함이 없다
 그림이 내용과 무관해 보일 수 있다      카드들이 서로 달라 보인다
```

> 💡 **A안 권장.** 카드가 캐러셀에서 나란히 넘어가는데 형태가 다르면 눈에 띈다.
> 다만 기본 그림은 **내용을 암시하지 않는 중립적인 것**이어야 한다
> (캐릭터가 서 있는 모습, 빈 카드 느낌 등).
>
> 🎨 **필요 에셋 — 기본 카드 그림 1종.** 여유가 되면 2~3종을 돌려 쓴다.

## 5-1. 검토 화면 전체

```
┌─────────────────────────────────┐
│ ←                        3 / 4  │
│                                 │
│  비 오는 날 학교 가기             │
│                                 │
│  ┌───┐  ┌─────────┐  ┌───┐     │
│  │   │  │         │  │   │     │  ← 카드 캐러셀 (기존)
│  │   │  │ [그림]   │  │   │     │
│  │   │  │가방을    │  │   │     │
│  │   │  │챙겨요    │  │   │     │
│  └───┘  └─────────┘  └───┘     │
│           ● ● ○ ○               │
│                                 │
│  [ 이 카드 수정 ] [ 삭제 ]        │  ← 기존 + 삭제
│  [ + 카드 추가 ] [ ⇅ 순서 바꾸기 ]│  ← 🆕
│                                 │
│ ───────────────────────────────  │
│  다 하면: 젤리 먹기       [수정]  │  ← 보상 줄
│ ───────────────────────────────  │
│                                 │
│     [ 사용자 화면으로 시작 ]      │
└─────────────────────────────────┘
```

| 요소 | 상태 |
| --- | --- |
| `이 카드 수정` | 항상 활성 · 바텀시트 (**제목·설명만**, 그림 교체 없음) |
| `삭제` | 카드 2장 이상일 때만 활성 |
| `+ 카드 추가` | 항상 활성 |
| `⇅ 순서 바꾸기` | 카드 2장 이상일 때만 활성 |
| 보상 줄 | 보상 있음 → `다 하면: ○○` + `수정` / 없음 → `+ 보상 정하기` (점선) |

> 버튼이 4개로 늘었다. **한 줄에 다 넣으면 좁다.** 2줄로 나누거나
> 부가 동작(추가·순서)을 아이콘 버튼으로 줄이는 방향을 검토한다.

## 5-2. 카드 추가

`+ 카드 추가` → **기존 카드 수정 바텀시트를 그대로 연다** (빈 상태로).

```
┌──────────────────────────────┐
│  카드 추가                    │
│                              │
│  무엇을 하나요?                │
│  ┌──────────────────────┐   │
│  │ 가방을 챙겨요          │   │  ← 제목
│  └──────────────────────┘   │
│                              │
│  설명 (선택)                  │
│  ┌──────────────────────┐   │
│  │                      │   │
│  └──────────────────────┘   │
│                              │
│  그림은 기본 그림이 들어가요    │  ← 🆕 안내 한 줄
│                              │
│  [ 취소 ]        [ 추가 ]     │
└──────────────────────────────┘
```

| 정할 것 | 권장 |
| --- | --- |
| 추가 위치 | **맨 뒤** (지금 보는 카드 다음이 아니라) |
| 그림 | **기본 그림** · 안내 문구로 미리 알린다 |
| 빈 제목 | `추가` 버튼 비활성 |

## 5-3. 순서 변경 모드

```
┌──────────────────────────────┐
│ ←   카드 순서 바꾸기   [ 완료 ]│
│                              │
│  ☰  1  가방을 챙겨요          │
│  ☰  2  신발을 신어요          │  ← 드래그 중: 들린 느낌 + 그림자
│  ☰  3  우산을 챙겨요          │
│  ☰  4  문을 나서요            │
│                              │
└──────────────────────────────┘
```

| 요소 | 규격 |
| --- | --- |
| 행 | 드래그 핸들 + 순번 + 제목 · **작은 썸네일 넣을지 결정** |
| 드래그 중 | 살짝 들리고 그림자 · 나머지 행이 부드럽게 비켜난다 |
| `완료` | 저장하고 검토 화면으로 |
| **저장 실패** | `순서를 저장하지 못했어요` + 원래 순서로 되돌린다 |

> **캐러셀에서 직접 끌지 않는다.** 좁은 화면에서 오조작이 난다. 별도 모드로 뺀다.

│  카드를 보는 내내 그걸 기억할 수     │
│  있어요.                          │
│                                  │
│  최근에 정한 보상                  │  ← 없으면 섹션째 숨김
│  [간식] [유튜브 10분]              │  ← 작게
│                                  │
│  [ 좋아하는 간식 ] [ 유튜브 10분 ]  │  ← 프리셋 2열
│  [ 좋아하는 놀이 ] [ 산책       ]  │
│  [ 직접 입력                   ]  │
│                                  │
│  한 달 뒤 선물보다 오늘 받을        │
│  수 있는 게 더 잘 통해요            │
│  왜 필요한가요? ›                  │  ← 바텀시트
│                                  │
│  [ 건너뛰기 ]        [ 다음 ]      │
└──────────────────────────────────┘
```

| 요소 | 규격 | 상태 |
| --- | --- | --- |
| **프리셋 칩** | 그림 + 라벨 · **2열 그리드** | 기본 / 선택됨 |
| **최근 보상 칩** | 같은 형태, **작게** | 기본 / 선택됨 |
| **직접 입력 칩** | 탭하면 아래에 텍스트 필드가 열린다 | 기본 / 입력 중 |
| 텍스트 필드 | **최대 20자** · 글자 수 표시 | 기본 / 포커스 / 초과 |
| `건너뛰기` | **보조 버튼**(약하게) | 항상 활성 |
| `다음` | 주 버튼 | **항상 활성** — 아무것도 안 골라도 넘어간다 |

### 상태 2가지

| 상태 | 화면 |
| --- | --- |
| 최근 보상 **있음** | `최근에 정한 보상` 섹션 노출 (최대 3개) |
| 최근 보상 **없음** | **섹션 전체 숨김** (제목도 안 보인다) |

| --- | :-: |
| 좋아하는 간식 | 🍪 |
| 유튜브 10분 | 📺 |
| 좋아하는 놀이 | 🧸 |
| 산책 | 🚶 |
| 직접 입력 | ⭐ |

> **이모지는 임시다.** 사용자 화면에 그림으로 띄워야 하므로 **5종 일러스트가 필요하다.**
> 글자를 못 읽는 사용자에게 텍스트만 보여주면 아무 의미가 없다.

# 8. 🔧 보호자 홈 — 4구역 + 설정

```
┌────────────────────────────────┐

│ ┌────────────────────────────┐ │

│ ┌────────────────────────────┐ │

│ ┌────────────────────────────┐ │

│ │                    [ 수정 ] │ │  ← 🔴 핵심 요구
│ └────────────────────────────┘ │
│                                │
│ 최근 일과                       │  ← ④
│ ┌────────────────────────────┐ │
│ │ 아침 등교 준비      5/5      │ │
│ │              [ 다시 하기 ]  │ │
│ └────────────────────────────┘ │
│                                │
│ 추천 일과                       │  ← 기존 유지

| 섹션 | 무엇이 들어가나 | 0건이면 |
| :-: | --- | --- |
| ① **오늘 일과** | 오늘 할 일 · 아직 시작 안 함 | `오늘은 등록된 일과가 없어요` |
| ② **진행 중** | 오늘 것 중 **일부만 완료된 것** | **섹션 숨김** |
| ③ **임시저장** | 만들다 만 것 · 사용자에게 안 보임 | **섹션 숨김** |
| ④ **최근 일과** | 지난 날짜 · 최근 10개 | **섹션 숨김** |

> ①과 ②는 **같은 타일 디자인**을 쓴다. 섹션 제목만 다르다.
> ③은 `[수정]` 버튼이, ④는 `[다시 하기]` 버튼이 추가로 붙는다.

## 🔴 `수정`이 핵심이다

> 메모 원문: *"수정을 눌러서 그 화면에서 생성 — 이게 필요하다"*

**임시저장 타일의 `수정`을 누르면 카드 검토 화면으로 바로 들어간다.**
거기서 이어서 고치고 보상 정하고 사용자에게 보내는 것까지 끝낸다.
**새 화면이 아니라 진입 경로**의 요구다.

# 10. 🔧 온보딩 도움 목표 — 칩이 깨진다

**문구는 바꾸지 않는다.** 렌더링만 고친다.

## 🔴 4번 칩 텍스트가 잘려 떨어진다

```
현재                                     고쳐야 할 모습
┌───────────────────────────────┐       ┌───────────────────────────────┐
│ [퍼즐] 혼자 끝까지 해내는 경험을 만들어│       │ [퍼즐] 혼자 끝까지 해내는      │
│        요                      │       │        경험을 만들어요         │
└───────────────────────────────┘       └───────────────────────────────┘
      "요" 한 글자만 떨어진다                  2줄이면 2줄답게 나뉜다
```

칩 높이가 **68로 고정**인데 4번 문구만 한 줄에 안 들어간다.

| 안 | 내용 |
| --- | --- |
| **A. 칩 높이를 내용에 맞춘다 (권장)** | 68을 **최소** 높이로 두고 2줄이면 늘어난다 |
| B. 4번 문구를 줄인다 | `혼자 끝까지 해내요` 등 |
| C. 4개 전부 2줄 높이로 통일 | 1줄짜리에 여백이 크게 남는다 |

> 📐 **정해야 할 값** — 2줄일 때 칩 높이 · 줄 간격 · 세로 정렬.

## 아이콘 톤이 하나만 다르다

| # | 목표 | 아이콘 | 톤 |
| :-: | --- | --- | --- |
| 1 | 해야 할 일을 순서대로 이해해요 | 블록 쌓기 | 컬러 |
| 2 | 필요한 준비물을 스스로 챙겨요 | 색연필 | 컬러 |
| 3 | 새로운 상황을 미리 준비해요 | 체크리스트 | ⚠️ **무채색** |
| 4 | 혼자 끝까지 해내는 경험을 만들어요 | 퍼즐 | 컬러 |

**3번만 회색이라 혼자 안 띈다.** 의도가 아니면 컬러로 맞춘다.

# 11. 모든 화면 공통 — 실패했을 때도 그린다

> **행복 경로만 그린 디자인은 미완성으로 본다.** 저장소 규칙이다.

| 상황 | 그려야 할 것 |
| --- | --- |
| 불러오기 실패 | 빈 화면·무한 로딩 금지. **상태 문구 + 재시도 버튼** |
| 목록 0건 | **로딩(스켈레톤)과 구분되는** 빈 상태 |
| 권한 거부 (카메라·알림) | 거부해도 앱은 동작한다. **왜 필요한지 + 우회 경로** |
| 예상 못 한 오류 | 화면을 붉게 덮지 않는다. **작은 에러 코드**를 남긴다 |

**이번 신규 화면에서 놓치기 쉬운 것**

| 화면 | 빠뜨리기 쉬운 상태 |
| --- | --- |
| 코드 발급 | 만료 · 발급 실패 · 연결 성공 |
| 코드 입력 | 틀림 · 만료 · **카메라 거부** |
| 보상 설정 | 최근 보상 없음 · 20자 초과 |
| 카드 순서 변경 | 저장 실패 → 원래 순서로 되돌림 |
| 보호자 홈 | 로딩 · 실패 · 섹션별 0건 |

# 12. 에셋 요청 정리 🎨

| # | 에셋 | 개수 | 어디에 쓰나 |
| :-: | --- | :-: | --- |
| A | **보상 프리셋 그림** | 5 | 보상 설정 칩 · 사용자 홈 배너 · 고정 바 · 완료 화면 |
| B | **카드 기본 그림** | 1~3 | **추가한 카드** (AI 그림을 만들지 않는다) |
| C | 역할 선택 아이콘 | 2 | 보호자 / 사용자 |
| D | 설정 메뉴 아이콘 | 2 | 알림 · 기기 연결 |
| E | 목표 아이콘 3번 | 1 | 무채색 → 컬러 보정 |
| F | 드래그 핸들 | 1 | 순서 변경 리스트 |

> **A와 B가 가장 급하다.** 둘 다 없으면 해당 화면이 성립하지 않는다.
> A는 임시로 이모지를 쓸 수 있으나, B는 **대체할 것이 없다.**

| 보상 프리셋 칩 | 온보딩 **도움 목표 칩** |
| 카드 추가 시트 | **카드 수정 바텀시트 그대로** |
| 홈 섹션 제목 | 보호자 홈 **추천 일과 제목** |
| 이탈 팝업 | 기존 **확인 다이얼로그** |
| 설정 시트 | 기존 **시트 스타일** |
| 진행률 | 기존 **진행률 링** |
| 완료 타일 | 기존 **완료 타일 색** |

**형태를 처음부터 잡아야 하는 것은 5개뿐이다.**

1. QR + 6자리 코드 발급 화면
2. 보상 설정 화면 레이아웃 (프리셋 2열)
3. 상단 고정 보상 바
4. 순서 변경 드래그 리스트
5. **그림 없는 카드**
