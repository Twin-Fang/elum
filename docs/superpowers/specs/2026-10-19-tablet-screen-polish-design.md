# 태블릿 전용 화면 다듬기 설계 (#789)

> 기반: #774 (창 등급·배율·폰 비율 열). 디자인 요청: #776.
> 사용자 승인: 2026-10-19 대화 — "추천하는 대로, 판단하는 대로 다 해줘. 모바일 디자인은 바뀌면 안 된다."

## 왜

이룸이의 주 기기가 태블릿이다(현장 실증). #774 는 화면을 깨지지 않게 여는 데까지였고, 넓어진 공간은
폰 화면을 키우거나 가운데 열에 담아 휑하다. 사용자가 짚은 문제:

1. 이룸이 홈 가로: 왼쪽 캐릭터 테두리 그림이 **보호자 화면 가기 버튼과 같은 그림**이라 버튼처럼 보이고 왼쪽이 비었다.
2. 카드 상세: 옆 카드가 잘려 보이고, 체크 버튼이 카드와 떨어진 오른쪽 빈 곳에 떠 있다. "다하면 🍪 젤리 먹기"가 제목인지 보상인지 애매하다.
3. 보상 화면: 폰 크기가 가운데 작게 떠 양옆이 빈다.
4. 보호자 홈 가로: 로고·이룸이 화면 가기·설정이 왼쪽 칸에 몰렸고, 일과 상세가 폰과 같은 바텀시트다.
5. 일과 만들기 입력: 배경 원이 창 왼쪽에 치우친다(폰 좌표를 창 왼쪽 기준으로 그림 — 버그).

## 목표 / 하지 않을 것

- 목표: 태블릿(창 등급 medium·expanded)에서만 넓은 공간을 쓰는 배치. 앞으로 화면이 늘어도 조합해 쓰는 공통 부품.
- **반드시 지킬 것: 폰(compact) 화면은 한 픽셀도 바뀌지 않는다.** 모든 갈래는 `layoutMetrics.isScaleOverridden` 뒤. 폰 골든·폰 위젯 테스트가 그대로 통과해야 한다.
- 하지 않음: 폰 문구 변경, 서버·API 변경, 일과 만들기 흐름의 다른 화면 재배치(폰 비율 열 유지), 새 패키지.

## 화면별 결정

### 1. 이룸이 홈 (가로 두 칸)
- 왼쪽 칸: **장면 그림** `TabletHeroScene` — 둥근 카드 안에 하늘 그라데이션, 언덕, 구름, 반짝이는 별, 캐릭터 전신(루루 `character_cat` / 포포 `character_fox`)이 언덕 위에 선다. 인사말은 장면 위에 크게.
- 버튼(보호자 화면 가기 배지·설정)은 위쪽 줄에만 둔다. 장식으로 버튼 그림을 쓰지 않는다.
- 오른쪽: 일과 목록(기존 타일). 세로 태블릿은 가운데 열 그대로 두되 인사말 아래 장면 띠를 둔다.

### 2. 카드 상세 (태블릿 전용 배치)
- 위: **순서 줄** `ChildStepStrip` — 단계마다 번호 칸(카드 색), 한 것은 체크, 지금 카드는 크게·테두리. 끝 칸은 **보상 목표**("다 하면" 작게 + "🍪 젤리 먹기" 크게). 칸을 누르면 그 카드로 간다. 보상이 없으면 끝 칸 없음.
- 가운데: **가로형 카드** `ChildTabletStepCard` — 한 장이 영역을 꽉 채운다(옆 카드 잘림 없음). 가로로 넓으면 왼쪽 그림·오른쪽 번호/제목/소리+설명/체크 버튼, 세로로 길면 위 그림·아래 글과 체크 버튼. **체크 버튼은 카드 안**에 있어 무엇을 체크하는지 묶인다.
- 넘기기(스와이프)는 그대로 PageView. 체크 → 별 화면 → 다음 안 한 카드 흐름은 그대로.
- 기존 상단 보상 칩은 태블릿에서 순서 줄 끝 칸으로 옮긴다(폰은 그대로).

### 3. 보상 · 일과 완료 · 별 화면
- 가운데 배치 유지(축하 순간은 시선이 한 점). 태블릿 전폭 배경 `ChildNightSkyBackdrop` 에 **별 밭**(정해진 자리에서 천천히 반짝, 동작 줄이기면 정지)을 더한다 — 라우트 배경으로만 쓰이므로 폰에 영향 없음.

### 4. 보호자 홈 (가로 두 칸)
- 위쪽 줄을 **창 전체 폭**으로: 왼쪽 로고, 오른쪽 이룸이 화면 가기 배지·설정. 코치마크 키(`modeKey`)는 배지에 그대로.
- 왼쪽 칸: 인사말·부제 + 새 일과 만들기 버튼 + 루미 그림(`home_new_routine_illust`) 장면 카드.
- 일과를 누르면 **가로 태블릿은 오른쪽 옆 패널**, 그 외(폰·세로 태블릿)는 기존 시트. 공통 함수 `showElumSheet` 가 판단한다 — 화면 코드는 바뀌지 않는다.

### 5. 일과 만들기 배경 (오로라)
- 두 원 묶음을 **창 가운데 기준**으로 놓는다(393 폭 묶음을 창 폭 가운데로 옮김). 폰은 창 폭 = 393 x 배율이라 옮김 0 → 그대로.
- 태블릿에서는 같은 색으로 작은 원 2개를 양옆에 더해 가운데에서 퍼지게 한다.

## 공통 부품 (확장성)

| 부품 | 위치 | 하는 일 |

| `TabletTwoPane` | `core/layout/` | 위쪽 줄(전폭) + 왼쪽 고정폭/비율 칸 + 오른쪽 스크롤 칸. 두 홈이 같이 씀 |
| `TabletHeroScene` | `core/widgets/` | 하늘·언덕·구름·별 + 캐릭터 그림 장면. 홈·빈 상태 등에서 재사용 |

## 실패 경로
- 캐릭터 미선택: 기존처럼 고양이.
- 단계 0개: 상세 화면 진입 자체가 없음(홈이 거름). 순서 줄은 빈 목록이면 그리지 않는다.
- 보상 없음: 순서 줄 끝 칸 없음.
- 낮은 창(분할 보기, 높이 < 480): 두 칸 대신 한 열(기존 규칙). 카드 상세는 카드가 세로형으로 바뀐다.
- 동작 줄이기: 별 반짝임·원 움직임 정지.
