근거: [실증 1차 회의록](../../meetings/20261019_특수학교_실증1차_보호자/README.md) 5·6장 · 정리 이슈 #780
목표: **2차 실증(2026-10-20, 이룸이와 보호자) 전에** 현장에서 바로 느낄 세 가지를 넣는다. 서버 배포 없이 앱만으로 동작한다.

## 1. 체크 칭찬 소리

| 항목 | 결정 |
| --- | --- |
| 언제 | 이룸이가 카드를 **체크하는 순간**(해제·재체크 해제 제외). 마지막 카드면 일과 완료 칭찬 |
| 무엇 | 효과음(반짝 아르페지오) + 칭찬 음성 한 파일. 체크 3종(`잘했어요!` `멋져요!` `최고예요!`) 돌아가며, 완료 1종(`다 해냈어요! 정말 멋져요!`) |
| 음성 | 서버 TTS(Supertonic F1, 한국어)로 미리 만들어 앱에 넣음(AAC, 5개 합 80KB). 원본 생성 `client/tool/mix_praise_sounds.py` |
| 언어 | 일과 언어가 한국어일 때만 음성. 그 밖은 효과음만 |
| 끄기 | 보호자·이룸이 설정에 `카드 체크 칭찬 소리` 스위치. 진동과 같은 이유로 휴대폰에 속하고 기본 켜짐 |
| 겹침 | 카드 읽기 중이면 읽기를 먼저 멈춘다 |

실패 경로: 재생 오류는 기록만 하고 삼키지 않으며 별 화면 흐름은 계속된다.

## 2. 일과별 알림

| 항목 | 결정 |
| --- | --- |
| 어디서 | 보호자 일과 상세 시트, 보상 줄 아래 `알림` 줄 (오늘 일과만) |
| 설정 | 시각(휠) + `매일 같은 시각에 알리기`(기본 켜짐) → 알림 켜기 / 시각 바꾸기 / 끄기 |
| 예약 | `flutter_local_notifications` 로 **이 휴대폰에만** 예약. 매일이면 시:분 반복 |
| 권한 | 처음 켤 때 묻는다(앱 시작 때 안 묻는다). 거부하면 이유와 우회 경로 안내(`E-REMINDER-PERM`), 앱은 그대로 |
| 정시 | 안드로이드는 정확한 알람이 허용된 기기만 정시, 아니면 몇 분 늦을 수 있다(권한을 조르지 않는다) |
| 저장 | `reminder.routines` JSON(로그아웃해도 유지). 깨진 값은 비우고 시작 |

**확장 지점:** 예약은 `ReminderScheduler` 인터페이스 뒤에 있다. 보호자가 정한 알림을 이룸이 휴대폰으로 보내야 하면(서버 푸시·FCM) 구현체를 더하고, 알림 정의를 서버로 옮긴다. 요일 반복은 #782.

## 3. 예시 일과 (카테고리별 템플릿)

| 항목 | 결정 |
| --- | --- |
| 어디서 | 일과 만들기 화면, 추천 칩 아래 `예시 일과 둘러보기` → 시트 |
| 분류 | 6개: 몸 돌보기 · 하루 흐름 · 집안일 · 밖에서 해 보기 · 공부 · 마음과 관계 (실증 요구: 자조·학습·사회참여·감정 카드) |
