# Pro 요금제 1차: 가격 · Free 픽토그램 · 고쳐서 다시 그리기

- 날짜: 2026-11-05
- 관련: #1070 (요금제 화면 시안), #1072 (결제 화면), #1075 (다시 그리기 무료), #1081 (Pro 총괄), #247 (Free 픽토그램), #958 (사업자등록·통신판매업 신고)

## 왜

develop 에 인앱 구독 결제와 Pro 기능이 들어와 있지만 가격과 Free·Pro 경계가 정해지지 않아 릴리스가 보류돼 있다.
Free 는 지금처럼 쓸 만하게 두고, Pro 는 "보호자 시간을 아껴 주는 새 기능"으로 계속 쌓는다.
Pro 를 고르게 만드는 중심은 **AI 맞춤 그림**이다. 그림이 원가의 거의 전부라 원가를 맞추는 축도 그림이다.

## 정한 것

### 1. Free · Pro 경계

| 구분 | 기준 |
|---|---|
| Free | **main(스토어 v2.87.x) 에 있는 기능 전부**, 단 AI 맞춤 그림은 뺀다 (아래 2) |
| Pro | develop 에 새로 들어온 기능 전부 + AI 맞춤 그림 + 앞으로 더하는 편리한 기능 |
| 결제 기반 | 구독 결제·구매 복원·내 요금제·Free 에게 Pro 미리 보여 주기는 누구나 |

develop 의 Pro 기능: 주간 리포트(선생님·치료사에게 보내는 한 장), 다른 언어로 바꾸기, 이룸이 기기로 일과 시간 알림, 보호자 목소리 녹음, 전문가 일과 묶음, 진화형 행동카드(AI 메모리), 다시 그리기 무료.
- 카드 내보내기(이미지·한 장 정리본·오려 쓰는 카드 PDF)는 develop 코드대로 **Free 도 쓰되 워터마크**, Pro 는 워터마크 없이 (`CARD_EXPORT_WITHOUT_WATERMARK`). (내 판단: 이미 그렇게 구현돼 있어 그대로 둠)
- 그림 방식 고르기(`ImageStyle`)는 main 기능이라 Free 에도 그대로 둔다. Free 새 일과에는 효과가 없고 Pro 가 되면 바로 적용된다. (내 판단)

- 이룸이 여러 명은 **Free 그대로** (부모는 보통 이룸이 한 명이라 Pro 로 나눠도 의미가 없다).
- 고품질 그림은 **쓰지 않는다**. 그림은 OpenAI 기본 품질 하나 (`IMAGE_HIGH_QUALITY` Free·Pro 모두 꺼짐 유지). 요금제 화면 혜택 줄에서 뺀다.

### 2. Free 는 새 일과부터 픽토그램

- Free 회원이 **새로 만드는** 일과·카드에는 AI 그림을 그리지 않는다. 카드에는 이미 함께 골라 두는 픽토그램(Mulberry Symbols)이 보인다.
- **이미 만든 AI 그림은 그대로 둔다.** 조회·이미지 응답은 요금제를 보지 않는다 (지금 동작, 바꾸지 않는다). 아이가 매일 보던 카드 그림이 어느 날 바뀌지 않게.
- Free 는 다시 그리기·그림 그리기를 쓸 수 없다. 앱은 Free 에게 다시 그리기 버튼 자리에 Pro 안내를 보여 준다 (Pro 미리 보여 주기와 같은 방식).
- 보호자 사진 올리기·"사진만 쓰기"는 Free 그대로 (AI 원가 없음).
- 켜는 시점: **결제가 들어간 릴리스와 함께** 관리자에서 `FREE_AI_IMAGE_GENERATION=false`. 그 전에 끄면 Free 가 그림을 잃는데 살 방법이 없다.
- 같은 날 `MIN_APP_VERSION_IOS/ANDROID` 를 결제 릴리스 버전으로 올린다. 옛 앱은 서버가 그림을 건너뛰면 "그림 만드는 중"이 끝나지 않을 수 있고 결제 수단도 없다. (내 판단)
- 서버가 그림을 건너뛴 카드는 응답에서 "그림 만드는 중"으로 보이지 않아야 한다 (새 앱이 픽토그램을 바로 그리게).

지금 코드 사실 (2026-11-05 develop 조사):
- `FREE_AI_IMAGE_GENERATION` 은 회원 응답에 값만 실릴 뿐 **어디서도 막지 않는다** (일과 만들기·카드 추가·다시 그리기 모두 요금제를 안 봄). 앱도 이 값을 읽지 않는다.
- 일과 만들기(`RoutineAiPipeline`)와 카드 추가(`RoutineStepEditService`)는 그림과 함께 `pictogramId` 를 항상 채운다 → 그림만 건너뛰면 픽토그램으로 보인다.
- 설정 주석 "픽토그램이 아직 없어 켜 둔다"는 #247 이전 내용이라 틀렸다 → 고친다.

### 3. 가격 · 체험

| 상품 | 가격 | 무료 체험 |
|---|---|---|
| Pro 월간 | ₩5,900 | 7일 |
| Pro 연간 | ₩49,000 (월 ₩4,083, 31% 할인) | 7일 |

- 체험은 월간·연간 모두, 처음 구독하는 사람에게 한 번 (스토어가 구독 묶음당 1회만 준다).
- 실제 금액은 App Store·Play 가격표에서 가장 가까운 값으로 정한다 (₩5,900·₩49,000 이 표에 정확히 있는지는 미확인).
- 결제 화면에 체험 뒤 자동 결제·해지 방법을 보여 준다 (App Store 3.1.2, #1070 규칙).

### 4. 크레딧 (결제 릴리스 때 관리자 값으로)

| 값 | 지금 운영 | 바꿀 값 |
|---|---|---|
| Free 주간 크레딧 | 100 | **30** |
| Pro 주간 크레딧 | 300 | **100** |
| Pro 다시 그리기 무료 하루 한도 (`IMAGE_REGENERATE_FREE_DAILY_CAP`) | 30 | **5** (넘으면 장당 크레딧 1) |
| Free AI 맞춤 그림 (`FREE_AI_IMAGE_GENERATION`) | true | **false** |
| 최소 앱 버전 iOS·Android | 2.86.0 | 결제 릴리스 버전 |
| 기존 가입자 Pro 선물 | (없음) | 켜기, 기준 시각 = 결제 릴리스 시각, 종료 = 그 6개월 뒤 |
| Pro AI 메모리 (`PRO_ROUTINE_MEMORY`) | false | 켤지 확인 (켜지 않으면 요금제 혜택 줄에서 뺌) |

원가 근거 (추정, 출시 전 OpenAI 가격표로 다시 확인):
- 그림 1장 `gpt-image-1-mini` low 약 $0.005 ≈ ₩7. 글은 장당 몇 원 수준.
- Pro ₩5,900 → 부가세 10% 빼면 ₩5,364 → 스토어 수수료 15% 빼면 **약 ₩4,560**.
- Pro 를 끝까지 쓰는 경우: 주 100 (월 약 430장) ≈ ₩3,000 + 다시 그리기 하루 5 (월 약 150장) ≈ ₩1,050 = **약 ₩4,050** < ₩4,560.
- Free 는 그림을 그리지 않아 원가가 거의 0. 주 30 이면 새 일과(카드 6장 ≈ 7크레딧, 글만이면 더 적음)를 충분히 만든다.

### 5. Pro: 고쳐서 다시 그리기

**왜:** Pro 를 냈는데 그림이 마음에 안 든 채로 끝나면 기분이 상한다. 지금 다시 그리기는 요청 없이 같은 조건으로 한 번 더 그려 같은 문제가 다시 나올 수 있다.

**대상 카드 두 가지:**
- AI 그림이 있는 카드 → "다시 그리기"
- AI 그림이 없는 카드(Free 때 만든 픽토그램 카드, 해지 뒤 만든 카드 등, 사진만 쓰기 방식·보호자 사진 카드는 제외) → **"AI 그림 그리기"** (Pro 가 된 보호자가 기존 카드에 처음 그림을 얻는 길, 사용자 결정 2026-11-05). 처음 그리기도 아래 흐름과 같고, 크레딧은 카드 그림 단가로 센다 (무료 다시 그리기 한도에는 넣지 않는다, 내 판단)

**동작:**
1. 보호자 화면 카드의 "다시 그리기"(또는 "AI 그림 그리기")를 누르면 고치고 싶은 점을 짧게 적는 칸이 나온다 (비워 두면 지금처럼 그냥 다시 그린다).
2. 자주 쓰는 요청은 누르는 칩으로: 더 단순하게 · 배경 빼기 · 사람 빼기 · 더 밝게. 칩과 직접 쓴 글은 함께 쓸 수 있다.
3. 새 그림이 나오면 **원래 그림(또는 지금 픽토그램)과 나란히 보여 주고 고르게** 한다. 고르기 전에는 카드 그림이 바뀌지 않고, 이룸이 화면에는 고른 그림만 나간다 (AI 결과는 보호자 승인 뒤 노출 원칙).
4. 보호자가 원래 그림을 고르면 새 그림은 버린다. 크레딧·무료 횟수는 돌려주지 않는다 (그림은 이미 그렸다).
5. 횟수는 다시 그리기 무료 하루 한도(5) 안에서 세고, 넘으면 장당 크레딧 1.

**지킬 것:**
- 요청 글은 짧게 (상한은 만드는 사람이 정한다, 60자 안팎). 그림 지시문에 "보호자 요청"으로 덧붙인다.
- 화면에 개인정보 안내 문구는 넣지 않는다 (사용자 결정).
- 실패하면 원래 그림을 그대로 두고 에러 코드와 "다시 해 볼까요?"를 보인다. 실패한 그림의 크레딧·무료 횟수는 돌려준다.
- 고르는 중에 앱을 끄거나 나가면 원래 그림이 그대로다. 다음에 그 카드를 열면 고르기를 이어서 할 수 있는지는 만드는 사람이 정한다.

### 6. 기존 가입자 Pro 선물 (6개월)

**왜:** 결제가 들어오기 전부터 이룸을 써 온 보호자에게, Pro 가 생기는 날 그동안 쓰던 AI 그림이 갑자기 막히지 않게 하고 고마움을 전한다 (사용자 결정 2026-11-05).

- **대상:** 기준 시각 **이전에 가입한** 회원 (구독 행이 없는 회원. 구독 중인 회원은 구독이 우선)
- **기간:** 관리자가 정한 **종료 시각까지 Pro** — 결제 릴리스 날 시작해 6개월 (가입일부터 세지 않는다. 가입일부터 세면 오래된 회원은 이미 끝나 버린다)
- **방식:** 신규가입 Pro 이벤트(`SIGNUP_PRO_EVENT_*`)처럼 조회 시점에 계산 (DB 쓰기 없음). 끄면 바로 원래 요금제로. 기본 꺼짐이라 배포만으로는 바뀌지 않는다
- **관리자 값 3개 (새로):** 켜기 / 가입 기준 시각 / Pro 종료 시각. (이름·그룹은 만드는 사람이, 내 판단: 기준 시각과 종료 시각을 둘 다 직접 적게 해 "6개월"을 코드에 박지 않음)
- **끝나면:** Free 로 돌아가고, 이미 만든 AI 그림은 그대로 (2번 규칙). 체험 7일은 스토어가 관리하므로 선물 기간과 상관없이 처음 구독 때 쓸 수 있다
- **보여 주기:** 내 요금제에 "Pro 선물 · ~종료일까지"를 보인다 (문구·자리는 #1070 시안). 종료 7일 전 안내 알림은 이번 범위에서 하지 않는다

## 하지 않는 것

- main 에 있는 Free 기능을 Pro 로 옮기기 (AI 맞춤 그림만 예외, 그것도 새 일과부터)
- 이미 만든 AI 그림을 숨기거나 픽토그램으로 바꾸기
- 이룸이 화면에 결제·잠금 표시
- 한도 도달 팝업으로 막기
- 고품질 그림, Gemini 그림

## 실패 경로

| 상황 | 동작 |
|---|---|
| Free 가 다시 그리기 API 를 직접 부름 | 서버가 거절 (권한 없음 에러 코드), 앱은 Pro 안내 |
| Free 일과 만들기에서 그림 생략 | 카드는 픽토그램, 픽토그램도 없으면 기본 카드 (지금 대체 순서) |
| 고쳐서 다시 그리기 AI 실패·시간 초과 | 원래 그림 유지, 에러 코드, 다시 시도, 크레딧·무료 횟수 환불 |
| 하루 무료 5장 다 씀 | 크레딧 1 로 계속 (크레딧 없으면 지금 크레딧 부족 안내) |
| 선물 기간 끝남 | Free 로, 이미 만든 AI 그림 그대로, 새 일과부터 픽토그램 |
| Pro 가 해지돼 Free 가 됨 | 이미 만든 AI 그림은 그대로, 새 일과부터 픽토그램 |

## 만드는 사람에게 맡기는 것

- Free 그림 생략 검사를 둘 정확한 위치 (일과 만들기·카드 추가·다시 그리기 진입점)
- 요청 글 상한, 칩 문구의 최종 표현, 영어 지시문으로 합치는 방식
- 나란히 고르기 화면 배치 (#1070 시안이 오면 맞춘다)
- 앱이 `entitlements.aiImageGeneration` 을 읽는 방식

## 이슈로 나눌 것

1. 서버·앱 (한 이슈, 같은 코드를 만져 나누지 않음): Free AI 그림 생략(새 일과부터) + Free 다시 그리기·그림 그리기 막기 + Pro 고쳐서 다시 그리기·픽토그램 카드 AI 그림 그리기 (요청 글·칩·나란히 고르기·환불) + 기존 가입자 Pro 선물 (관리자 값 3개, 조회 시 계산, 내 요금제 표시) + 설정 주석 정리 + 시험
3. 운영: 결제 릴리스 때 관리자 값 (Free 30 / Pro 100 / 무료 다시 그리기 5 / `FREE_AI_IMAGE_GENERATION=false`) + 스토어 상품 가격·체험 등록
4. 시안: #1070 에 가격·체험·혜택 줄 반영 (고품질 그림 줄 빼기, AI 맞춤 그림 줄 넣기)
