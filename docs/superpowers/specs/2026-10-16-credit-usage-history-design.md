# 크레딧 사용 내역 (#658)

설정 크레딧 카드의 `크레딧 사용 내역 보기` 줄로 들어가, 언제 얼마를 어디에 썼는지 보는 화면과 서버 조회.
시안: Figma `1589:8359`(내역), `1532:7501`(카드 줄). 디자인 요청 #685, 광고 보상 줄은 #695.

## 서버

`GET /api/credits/ledger?page=&size=` (보호자 인증, 본인 계정만). 한 쪽은 최근 것부터 30줄(1~50).

| 원장 | 보이는 줄 |
|---|---|
| CONSUME | 일과 생성: 시작 단가로 글 몫·그림 몫 두 줄(`ROUTINE_TEXT`, `CARD_IMAGES`). 잔액이 모자라 덜 차감되면 글 몫을 먼저 채움. 그 밖: `CARD_IMAGE`, `IMAGE_REGENERATE` |
| GRANT | 출처별 `WEEKLY_GRANT` · `AD_REWARD` · `ADMIN_BONUS` · `OTHER_GRANT` |
| EXPIRE | `EXPIRED` |
| ADJUST | `ADJUSTED` (내부 사유 글은 내려주지 않음) |
| RESERVE · RELEASE · OVERAGE | 숨김 (정산 때 사용 줄로 합쳐지거나 증감 0) |

- 일과 제목은 `RoutineQueryService.findTitlesByIds`로 한 번에 가져온다. 지워진 일과는 제목 null.
- 작업·적립·일과를 줄마다 따로 읽지 않고 쪽 단위로 모아 읽는다 (N+1 방지).
- 계정이 아직 없으면 빈 쪽. 조회로 계정을 만들지 않는다.
- 시각은 `occurredAt`(한국 시각)과 `occurredAtOffset`(오프셋 포함)을 함께 준다. 앱은 오프셋 값을 기기 시간대로 바꾼다.

## 앱

- 설정 크레딧 카드(정상 조회일 때만) 맨 아래 `크레딧 사용 내역 보기 >` 줄. 글자 24, 누름 48.
- 내역 화면: 날짜별 흰 카드(r20, 줄 69). 사용 줄은 일과 제목 + `종류・시각`, 지급·만료·조정은 종류 + 시각. 증감은 사용 회색, 지급 보라.
- 끝에 닿으면 다음 쪽을 이어 받고 겹친 줄은 한 번만 보인다.

### 실패 경로

| 상황 | 동작 | 잡는 시험 |
|---|---|---|
| 첫 쪽 조회 실패 | 다시 시도 + 에러 코드. 0건 화면으로 보이지 않는다 | `credit_history_test` 화면 |
| 0건 | 로딩·실패와 다른 빈 화면 | 〃 |
| 다음 쪽 실패 | 받은 내역 유지, 아래에 다시 하기 + 코드 | 〃 |
| 응답 줄 하나가 깨짐 | 그 줄만 건너뜀 | 〃 응답 읽기 |
| 모르는 종류 | 증감 부호로 일반 문구 | 〃 |
| 카드 조회 실패 | 내역 줄을 그리지 않음 | `ai_credit_card_test` |
