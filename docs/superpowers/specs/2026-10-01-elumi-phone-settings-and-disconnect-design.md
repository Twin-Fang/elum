# 이룸이 휴대폰 설정과 보호자의 연결 끊기 (#363)

> 상태: 구현 (2026-10-01) · 단계: 다중 보호자 3단계 (명세 [2026-09-23-multi-guardian-design.md](./2026-09-23-multi-guardian-design.md))
> 근거: 이슈 #363 · #198 19번 · 화면 전체명세 §8-4·§8-5
> 확정한 결정(명세 2장·4-2·4-3)은 뒤집지 않는다. 이 문서는 명세가 **#363 에서 정한다고 남겨 둔 것**만 채운다.

## 1. 정한 것

명세 9-1 이 #363 으로 미룬 물음과 이슈 "정할 것" 표의 답이다.

| 물음 | 정한 것 | 이유 |
|---|---|---|
| 보호자 B 가 A 가 붙인 이룸이 휴대폰을 끊을 수 있나 | **끊을 수 있다.** 그 이룸이를 함께 돌보는 보호자는 누구나 | 권한 표(4-2)가 "연결 암호 발급·끊기 ✅"를 연결된 보호자 전부에게 준다. 4-3 의 "붙인 보호자에게 묶인다"는 **토큰의 주인(`sub`)** 이야기라 세션은 붙인 보호자 것을 폐기하면 둘이 함께 선다 |
| 연결 상태 화면에 누가 붙였는지 | **보이지 않는다** | 서버가 계정 식별자를 다른 보호자에게 내리지 않는다(#361). 이룸이 기준으로 휴대폰만 보여 준다 |
| 이룸이 휴대폰 로그아웃·탈퇴가 부르는 서버 경로 | **`DELETE /api/device-links/current`** (이룸이 토큰 전용). 어느 연결인지는 토큰의 `linkId` 가 정한다 | 예전 로그아웃은 리프레시 토큰만 끊고 연결은 두어 보호자 설정에 `연결됨`이 남았다 |
| 이미 연결된 상태에서 연결 화면을 열면 | **새로 붙은 휴대폰만** `연결 성공`으로 알린다 | 설정은 연결된 보호자를 상태 화면으로 보내므로 이 화면은 새 암호를 만드는 자리다. 열 때의 연결 목록을 기준 삼아 그 뒤 새로 붙은 것만 본다 |
| 이룸이 휴대폰의 `회원탈퇴` | **로그아웃과 같은 일** — 이 휴대폰의 연결만 끊는다. 보호자 계정·이룸이·일과·별은 지우지 않는다 | 이룸이 휴대폰에는 계정이 없다(#158). 시안(19번)이 둘을 두고 사용자가 찾는 말이 달라 둘 다 둔다. 팝업 문구만 다르다 |

## 2. 화면

```
보호자 휴대폰                         이룸이 휴대폰
[로고]        [⭐12] [⚙️→비밀암호]      [로고]    [⚙️→설정 시트] [⭐12]

설정                                  설정 시트
  이룸이 휴대폰 연결하기 ›  (연결 전)     로그아웃
  이룸이 휴대폰  연결됨 ›   (연결 뒤)     회원탈퇴 (위험색·가장 약하게)
        ↓
  이룸이 휴대폰 (상태·끊기)
    연결됨 · 9월 18일부터
    [ 연결 끊기 ] (위험색 테두리·주 버튼 아님)
    끊으면 이룸이 휴대폰에서 일과를 볼 수 없어요
```

- 보호자 휴대폰의 톱니는 시안(1197:6810)대로 별 **오른쪽**이다. 이룸이 휴대폰만 별 **왼쪽**에 둔다(#198 19번) — 시안에 이룸이 휴대폰 배치가 없다.
- 이룸이 휴대폰은 보호자 화면 경로(`/guardian/**`, `/mode-switch?to=guardian`)로 들어갈 수 없다. 라우터가 최종으로 막는다(#355 A 경로). 세션이 없으면 로그인이 아니라 연결 화면이다(#206).

## 3. 흐름과 실패 경로

### 보호자가 끊는다

| 상황 | 동작 |
|---|---|
| 확인 팝업 `연결을 끊을까요?` | 되돌릴 수 있다고 함께 말한다("다시 연결하려면 새 암호를 만들면 돼요") |
| 성공 | 목록을 다시 받는다. 남은 휴대폰이 없으면 설정으로 돌아가 `연결을 끊었어요`, 줄은 `연결하기`로 되돌아간다 |
| 이미 끊김(404 `DEVICE_LINK_NOT_CONNECTED`) | 실패가 아니다 — `이미 끊겨 있어요`. 이룸이 휴대폰이 스스로 끊었거나 다른 보호자가 먼저 끊었다 |
| 실패(5xx·오프라인·403) | 화면에 머문다. 이유와 에러 코드(`E-LINK-OUT`·서버 코드·`E-NET-OFFLINE`)를 팝업으로. 연결은 그대로다 |
| 상태 조회 실패 | 빈 화면·무한 로딩 없이 이유 + `다시 시도` + 에러 코드(`E-LINK-STATUS`). 끊기 버튼은 보이지 않는다 |
| 연결 없음 | `연결된 휴대폰이 없어요` + `이룸이 휴대폰 연결하기` |
| 설정 줄에서 상태를 못 알 때 | `연결하기`로 둔다 — 설정이 멈추지 않는다. 잘못 눌러도 새 암호만 만들어질 뿐 기존 연결은 그대로다 |

### 이룸이 휴대폰이 스스로 끊는다 (로그아웃 · 회원탈퇴)

서버가 연결을 끊은 **뒤에만** 로컬을 비우고 연결 화면으로 간다. 서버가 안 끊겼는데 로컬만 비우면 보호자 설정에 `연결됨`이 남는다(#187).

| 상황 | 동작 |
|---|---|
| 성공 | 토큰·이룸이 정보·일과 캐시·체크 기록을 비운다. `이룸이 휴대폰` 표식은 남긴다. 연결 암호 넣기로 간다(뒤로 갈 수 있게 역할 선택을 깐다) |
| 이미 끊김(404·401) | 원하는 결과가 이미 됐으므로 정리하고 끝낸다 |
| 실패(5xx·403·오프라인) | 시트에 머문다. 이유와 에러 코드. **아무것도 지우지 않는다** |
| 인터넷이 없을 때 | 로그아웃할 수 없다 — 서버에서 끊기지 않으면 보호자 쪽과 어긋나기 때문이다. 인터넷 안내와 `E-NET-OFFLINE` 을 보여 준다 |

### 연결이 밖에서 끊긴다 (보호자가 끊음 → #359 와 관련)

서버가 그 휴대폰의 리프레시 토큰을 폐기 → 다음 요청이 401 → 갱신 실패 → 세션 종료. 이때 이룸이 휴대폰은 스스로 연결 해제 상태가 된다.

1. 토큰·이룸이 정보·일과 캐시·체크 기록을 비운다(카드 그림 캐시는 세션 종료 때 이미 비워진다). 메모리의 이전 이룸이 값도 이동 뒤에 비운다.
2. `연결이 끊어졌어요` 표식을 저장한다 — 앱을 껐다 켜도 연결 화면이 그 말을 한다. 새로 연결하면 내린다.
3. 연결 암호 넣기로 보낸다.

### 보호자 로그인과의 관계

소셜 로그인 성공은 이 휴대폰을 보호자 휴대폰으로 만든다 — `이룸이 휴대폰` 표식을 내린다. 표식이 남으면 라우터가 보호자 화면을 막아 로그인하고도 들어가지 못한다.

## 4. 서버

| 변경 | 내용 |
|---|---|
| `GET /api/device-links` | 이룸이 기준(`profile_id`)으로 휴대폰을 보여 준다. 이룸이 없는 보호자는 오류가 아니라 빈 목록 |
| `DELETE /api/device-links/{linkId}` | 그 이룸이를 돌보는 보호자면 끊는다. 아니면 없는 연결과 같은 404. 세션은 붙인 보호자 것을 폐기 |
| 🆕 `DELETE /api/device-links/current` | 이룸이 토큰 전용. 보호자 토큰이면 403 `DEVICE_LINK_ONLY_FOR_ELUMI` |

## 6. 하지 않은 것

- 이룸이 휴대폰에서 일과를 만들거나 고치는 길, 암호를 묻는 설정.
- 연결된 상태에서 휴대폰을 **더** 붙이는 길(서버는 여러 대를 허용하지만 설정은 상태 화면으로 보낸다).
- 연결을 남은 보호자에게 넘기기(명세 11장).
- #355 B 경로(다시 로그인한 보호자 휴대폰에 암호가 없음).
