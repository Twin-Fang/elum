# 국내·외 유사 사례 비교 (PPT 6장 근거)

> 대회 발표 필수 항목 **"국내·외 유사 사례 비교 및 차이점"** 의 근거 자료.
> **참신성 20점**이 여기서 갈린다.
>
> ⚠️ **먼저 알아야 할 사실** — 아래 3장을 반드시 읽고 발표 문구를 정한다.

---

# 1. 🚨 먼저 — "AI가 일과를 쪼개주는 앱"은 이미 있다

조사 결과, **AI로 시각 일정을 자동 생성하는 앱이 해외에 이미 여러 개 존재한다.**

| 앱 | 특징 | 비고 |
| --- | --- | --- |
| **Tiimo** | AI가 작업을 단계로 쪼개고 소요 시간까지 추정 | **2025 App Store Awards iPhone 올해의 앱** |
| **HeyOtto** | 템플릿이 아니라 아이의 실제 하루에 맞춘 시각 일정 생성 | 자폐 아동 대상 |
| **Glint** (nerchat) | ABA·특수교육용 시각 일정 생성기. 단계 재생성·심볼 교체·**언어 수준 조정** | 치료·교육 현장용 |
| **Visual Schedules** (App Store) | *"World's First Autism Communication App Powered by Generative AI"* 표방 | 생성형 AI 기반 |
| **EZducate** | IEP 목표 생성 · ABA 행동 데이터 · 시각 일정 · 소셜 스토리 | 교사용 통합 도구 |

## 이것이 의미하는 것

> **"AI가 과제분석을 자동화한다"는 것만으로는 참신성을 주장할 수 없다.**

심사위원이 검색 한 번만 해도 위 앱들이 나온다.
*"세계 최초"*, *"유일한"* 같은 표현을 쓰면 **그 자리에서 무너진다.**

**대신 정직하게 인정하고 그 위에서 차별점을 말한다.** 이게 더 강하다 —
경쟁을 조사한 팀으로 보이고, 픽포미(2025 본선)가 정확히 이 방식으로 참신성을 인정받았다.

# 2. 전통적 대안

| 대상 | 한계 |
| --- | --- |
| **종이 그림카드 · PECS** | 상황마다 준비물이 달라 **매번 새로 만들어야 한다.** 비 오는 날 우비·장화는 기존 카드에 없다 |
| **벽에 붙이는 고정 일정표** | 오늘만의 변화(병원 가는 날, 처음 가는 곳)를 반영하지 못한다 |
| **Choiceworks** ($6.99) | 180개 이상의 시각·음성 프롬프트 제공. **보호자가 직접 조합해야 한다** |
| **First Then Visual Schedule** ($9.99~14.99) | first-then 보드·과제 분해·소셜 스토리. **역시 사람이 만든다** |
| **일반 일정관리 앱** | 일정은 알려주지만 **행동 단계로 쪼개지 않는다** |

> Choiceworks·FTVS는 이 분야의 **표준 도구**다. 둘 다 잘 만들어졌지만
> **"카드를 만드는 일 자체"는 여전히 보호자 몫**이다.

# 3. 국내 서비스

| 서비스 | 관계 |
| --- | --- |
| **토닥이** (2025 보건복지부장관상) | 발달장애인 근로자의 **정해진 일정**을 예측 가능하게 보여준다. 일정을 **만들어내는 앞단**은 다루지 않는다 |
| 범용 LLM (ChatGPT 등) | 단계를 물어보면 답해주지만 **카드·이미지·수행 흐름·보호자 승인**이 없다 |

> **한국어로, 한국 맥락(학교·주간보호센터·복지관)을 이해하는 AI 행동 카드 서비스는 확인되지 않았다.**

# 4. ELUM의 차별점 — 이렇게 말한다

## ❌ 이렇게 말하지 않는다

```
"AI가 일과를 행동 단계로 쪼개주는 최초의 서비스입니다"
→ Tiimo·HeyOtto·Glint가 이미 한다. 검색 한 번에 무너진다.
```

## ✅ 이렇게 말한다

```
"해외에는 AI로 시각 일정을 만들어주는 앱들이 이미 있습니다.
 Tiimo는 올해 App Store 올해의 앱이기도 합니다.

 그런데 그 앱들은 전부 영어권 서비스이고,
 한국의 보호자가 '비 오는 날 학교 갈 준비'라고 입력했을 때
 우비·장화·여벌 양말을 떠올리지 못합니다.

 이룸은 한국어로, 한국의 하루를 이해하고,
 만들어진 카드를 보호자가 승인해야만 아이에게 전달합니다."
```

## 차별점 5가지 (우선순위 순)

| # | 차별점 | 경쟁 앱은 |
| --- | --- | --- |
| **1** | **한국어 · 국내 생활 맥락** | 전부 영어권. 학교·주간보호센터·복지관 맥락 없음 |
| **2** | **보호자 승인 게이트** | AI 결과가 바로 노출되거나, 교사가 편집은 해도 "승인" 단계는 없음 |
| **3** | **보호자가 정한 현실의 보상을 수행 중 지속 노출** | 대부분 앱 내 스티커·토큰. 현실 보상을 수행 내내 보여주는 구조는 드묾 |
| **4** | **캐릭터 일관 삽화** | 심볼·픽토그램·사진 조합. 같은 캐릭터가 모든 단계에 등장하는 방식은 없음 |
| **5** | **진단명·장애유형 미수집** | 다수가 장애 유형·정도를 입력받아 개인화 |

> 🎯 **1번이 가장 현실적으로 강하다.** 이 대회는 국내 대회이고,
> 심사위원은 한국 발달장애인 현장을 아는 사람들이다.
> "영어권에는 있지만 한국에는 없다"는 **실제 격차**다.

# 5. 발표 6장 비교표 (그대로 사용)

| 구분 | 대표 서비스 | 한계 |
| --- | --- | --- |
| 종이 그림카드 | PECS · 수제 카드 | 상황마다 새로 만들어야 함 |
| 시각 일정 앱 | Choiceworks · First Then | **사람이 직접 카드를 조합** |
| AI 일정 앱 (해외) | Tiimo · HeyOtto · Glint | **영어권 · 한국 생활 맥락 부재** |
| 국내 수상작 | 토닥이 (2025) | 정해진 일정 표시 — **만들어내는 앞단 없음** |
| 범용 LLM | ChatGPT 등 | 카드·이미지·수행 흐름·승인 구조 없음 |

**→ ELUM**: 한국어 자연어 한 문장 → 행동 단계 자동 분해 → **보호자 승인** → 캐릭터 삽화 카드 → **보상 상기**
