# 상용화 전략 (PPT 12장 근거)

> 대회 필수 항목 **"상용화 전략 및 활용방안 — 적극적 활용을 위한 방안, 활용 시 발생가능한 제약 사항과 해결방안"**
> 심사 항목으로는 **기대효과(20점)** 와 **적용가능성(20점)** 에 함께 걸린다.

---

# 1. 🚨 앱스토어 등록은 유통이 아니다

> **"플레이스토어에 올리면 되지 않나요?"**

스토어 등록은 **설치 경로를 여는 것**이지 사용자를 만나는 방법이 아니다.

| 왜 안 되는가 | 이유 |
| --- | --- |
| **발견되지 않는다** | 발달장애인 보호자가 "행동 카드 앱"을 검색해서 찾을 확률은 낮다. 무엇을 검색해야 할지도 모른다 |
| **신뢰를 못 얻는다** | 아이에게 쓰는 도구다. 스토어에서 처음 본 앱을 바로 자녀에게 쓰지 않는다 |
| **돈을 낼 사람이 아니다** | 보호자의 우울 점수가 19.43이다(우울증 의심 기준 16 초과). 여기에 월 구독을 얹는 것은 현실적이지 않다 |

> 💡 **이 서비스는 "소비자가 찾아오는 앱"이 아니라 "현장이 권하는 도구"다.**

---

# 2. 확산 경로 — 기관을 먼저 통과한다

```
① 전문기관 검증          ② 현장 기관 보급         ③ 보호자 확산
서울 ABA연구소      →    복지관·센터·학교    →    보호자 입소문
전문가 자문·실증          지도자가 권한다          "우리 선생님이 추천"
```

## ① 전문기관 — 이미 시작했다

| 기관 유형 | 역할 |
| --- | --- |
| **서울 ABA연구소** | 자문·실증 협력 (진행 중) |
| 발달장애인지원센터 | **전국 17개 광역 + 기초센터** — 발달장애인 지원 정책의 접점 |
| 대학 특수교육과·행동분석 전공 | 이론 검증·논문 협력 |

> 전문가가 "이건 과제분석 구조에 맞다"고 말해주는 것이,
> 광고 100번보다 보호자에게 신뢰를 준다.

## ② 현장 기관 — 실제 사용처

| 기관 | 왜 필요한가 |
| --- | --- |
| **장애인복지관** | 이미 일상생활 훈련 프로그램을 운영한다. 카드를 손으로 만들고 있다 |
| **주간보호센터 · 직업재활시설** | 성인 발달장애인의 하루가 여기서 돌아간다 |
| **특수학교 · 특수학급** | 개별화 교육 과정에서 시각 일정표를 쓴다 |
| **ABA·언어치료 센터** | 과제분석·강화를 매일 다루는 사람들 |
| **발달장애인 고용기업** | 작업 순서·안전 수칙 전달에 그대로 쓸 수 있다 |

> 이들은 **이미 종이로 하고 있는 일**이다. 새 습관을 만드는 게 아니라
> 하던 일을 덜 힘들게 만드는 것이라 도입 장벽이 낮다.

## ③ 보호자 — 기관을 통해 만난다

기관에서 쓰는 것을 보고, 지도자가 권해서 집에서도 쓰기 시작하는 경로가 현실적이다.

# 3. 수익 모델

## 3-1. B2B · B2G 우선 (현실적)

| 모델 | 내용 |
| --- | --- |
| **기관 라이선스** | 복지관·센터가 이용자 N명분을 구매. 기관 관리자 화면 제공 |
| **지자체 사업** | 광역·기초 지자체의 발달장애인 지원 사업에 포함 |
| **공공 조달** | 조달청 등록 후 기관 구매 |

## 3-2. 바우처 연계 (조사 필요)

국내에는 **발달재활서비스 바우처**가 운영 중이다.

| 항목 | 내용 |
| --- | --- |
| 대상 | 만 18세 미만 등록장애인 (지적·자폐성 포함), 기준 중위소득 180% 이하 |
| 금액 | **월 18만~26만 원** (소득 등급별), 본인부담 0~8만 원 |
| 영역 | 언어·청능 / 미술·음악 / **행동·놀이·심리** / 감각·운동 |
| 성인 | 별도로 **주간활동서비스** 운영 |

> ⚠️ **앱이 바우처 대상인지는 확인이 필요하다.** 현재는 대면 서비스 중심이다.
> 다만 "행동" 영역이 존재하고, 정부가 **2027년 발달재활서비스 6천 명·성인 주간활동 5천 명 확대**를
> 예고한 만큼 디지털 도구의 편입 가능성은 열려 있다.
>
> **발표에서는 "바우처 대상이다"라고 단정하지 않는다.** "연계를 검토하고 있다"로 말한다.

## 3-3. B2C는 무료 + 부가 기능

보호자에게 직접 과금하지 않는다. 기본 기능은 무료로 두고,
이미지 재생성 횟수·다자녀 관리 같은 부가 기능만 유료화하는 정도가 적절하다.

# 4. 대상 확장 — 표현을 정확히 한다

> **"학습장애·ADHD까지 확장할 수 있지 않나요?"** — 가능하다. 다만 **말하는 방식이 중요하다.**

## ⚠️ 이렇게 말하면 안 된다

```
"발달장애에는 ADHD와 학습장애도 포함됩니다"
→ 부정확하다. 국내 법률상 발달장애인은 지적장애·자폐성장애 중심이다.
   장애인 전문가 심사위원 앞에서 이 실수는 크게 보인다.
```

## ✅ 이렇게 말한다

```
"국내 법률상 발달장애인은 지적장애·자폐성장애를 말합니다.
 다만 저희 서비스의 핵심은 '복잡한 일을 수행 가능한 단계로 나눠 보여주는 것'이고,
 이 방식이 도움이 되는 사람은 더 넓습니다.

 경계선 지능, ADHD, 학습장애처럼 순서 유지와 실행 기능에 어려움이 있는 경우,
 그리고 인지 저하 초기나 뇌손상 재활 과정에서도 같은 구조가 쓰일 수 있습니다."
```

## 확장 우선순위

| 순위 | 대상 | 근거 |
| --- | --- | --- |
| 1 | **성인 발달장애인** | 지적장애인 중위연령 33.8세 — 이미 핵심 대상이다 |
| 2 | 경계선 지능 | 등록 장애는 아니지만 같은 어려움을 겪는다 |
| 3 | ADHD · 학습장애 | 실행 기능 지원이라는 점에서 구조가 동일하다 |
| 4 | 인지 저하 초기 · 재활 | 같은 방식이 통하는 다른 영역 |

> ⚠️ **발표에서 확장을 앞세우지 않는다.** 역대 장관상 수상작은 전부
> **문제를 좁게 잡은 팀**이었다. 확장은 기대효과 슬라이드에서 **한 줄**로만 언급한다.

# 5. 제약 사항과 해결 방안 (필수 항목)

| 제약 | 해결 방안 |
| --- | --- |
| **AI가 만든 카드가 개인에게 안 맞을 수 있다** | 보호자 승인 게이트 + 추가·삭제·수정. **AI 결과는 정답이 아니라 초안**으로 다룬다 |
| **보호자 입력 부담** | 온보딩 4단계 고정 · 보상 설정 건너뛰기 허용 · 최근 사용 항목 재사용 |
| **AI 생성 비용** | 지난 일과 **재사용(다시 하기)** 으로 재호출을 줄인다 · 이미지 재사용 |
| **통신 불안정** | 오프라인 우선 구조 — 사용자 화면은 네트워크와 무관하게 동작 |
| **개인정보** | 진단명·장애유형을 수집하지 않는다 · 입력 원문을 보관하지 않는다 |
| **글을 못 읽는 사용자** | 그림 + 음성 안내 · 보상도 프리셋 그림으로 표시 |
| **기관 도입 시 관리 부담** | 기관 관리자 화면 (향후) — 여러 이용자를 한 화면에서 관리 |

# 6. 사업성을 어떻게 어필할 것인가

## 6-1. 시장 규모

| 지표 | 수치 |
| --- | --- |
| 등록 발달장애인 | **약 25만 명** |
| 그중 일상생활 도움 필요 | **22.5%** |
| 보호자 (부모 68.8%) | 사실상 **25만 가구** |
| 발달장애인지원센터 | 전국 **17개 광역 + 기초** |
| 정부 확대 계획 | **2027년 발달재활서비스 6천 명 · 성인 주간활동 5천 명 확대** |

> 💡 **"사용자 25만 명"이 아니라 "가구 25만"으로 말한다.**
> 실제 사용자는 발달장애인 본인과 보호자 **둘**이다.

## 6-2. 비용 절감 논리 (기관 설득용)

```
지금                                이룸 도입 후
─────                               ──────────
지도자가 이용자마다 카드를 손으로 만든다    자연어 한 문장 → 카드 자동 생성
상황이 바뀌면 처음부터 다시 만든다         수정·재사용
보호자가 매일 아침 같은 설명을 반복한다     앱이 순서를 대신 보여준다
수행 여부를 기억에 의존한다               수행률이 자동으로 기록된다
```

**기관에 파는 논리는 "좋은 서비스"가 아니라 "지도자의 시간"이다.**

## 6-3. 정책 연계

- **발달장애인 권리보장 및 지원에 관한 법률** — 자립생활 지원이 국가 책무로 명시
- 정부의 **성인 발달장애인 주간활동서비스 확대** 기조
- 장애인 **디지털 접근성** 정책 (이 대회의 주제이기도 하다)

> 정책 방향과 같은 쪽을 보고 있다는 것은 **지속 가능성의 근거**가 된다.

# 7. 발표 12장 구성안

```
[상용화 전략]

1. 이 앱은 스토어에서 찾는 앱이 아닙니다
   → 현장이 권하는 도구입니다

2. 확산 경로
   전문기관 검증 → 현장 기관 보급 → 보호자 확산
   (서울 ABA연구소 자문·실증이 첫 단계)

3. 수익 모델
   기관 라이선스 · 지자체 사업 · 바우처 연계 검토
   보호자에게 직접 과금하지 않습니다

4. 제약과 해결
   AI 정확도 → 보호자 승인 게이트
   입력 부담  → 온보딩 최소화·재사용
   생성 비용  → 다시 하기로 재호출 절감
```

# 8. 확인이 필요한 것

| # | 확인할 것 | 왜 |
| --- | --- | --- |
| 1 | 발달재활서비스 바우처에 **디지털 도구 편입 가능 여부** | 단정하면 안 된다. 사무국·센터에 문의 |
| 2 | 장애인복지관·주간보호센터 **전국 개소 수** | 시장 규모 슬라이드의 정확도 |
| 3 | 소장님께 **기관 도입 현실성** 의견 | 현장이 실제로 살지, 무엇이 걸림돌인지 |

> 3번은 **2차 자문 안건**으로 두면 좋다. 상용화는 현장을 아는 사람에게 묻는 게 가장 빠르다.
