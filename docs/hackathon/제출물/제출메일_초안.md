## 보내기 전 확인

- [ ] **첨부가 실제로 붙었는가** — 가장 흔한 사고입니다
- [ ] 파일명이 `팀이름_개발물이름_분야` 규칙에 맞는가
- [ ] APK가 **제출용 빌드**인가 (개발용 아님) → `scripts/build-apk.sh submit`
- [ ] APK를 **실기기에 설치해 열어봤는가**
- [ ] 개발노트·발표자료가 **PDF**인가 (HWP·PPTX 원본 요구 여부 확인)
- [ ] 대용량 링크가 **외부에서 열리는가** (로그인 없이)
- [ ] 링크 유효기간이 심사 기간보다 긴가
- [ ] 팀장 연락처가 실제로 받는 번호인가
