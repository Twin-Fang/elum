# 2. 오버뷰 — ✏️ 문구 수정

## 제목

```
오버뷰                                          ← 작게

현재  발달장애 아동의 일상 수행과 자립을 돕는 모바일 서비스
수정  발달장애인의 일상 수행과 자립을 돕는 모바일 서비스
                ↑ '아동' 을 뺍니다
```

## 본문

```
현재  아이에게는 이해하기 쉬운 일상과 긍정적인 수행 경험을,
      보호자에게는 반복적인 준비 부담의 완화를 제공합니다.

수정  사용자에게는 이해하기 쉬운 일상과 긍정적인 수행 경험을,
      보호자에게는 반복적인 준비 부담의 완화를 제공합니다.
                ↑ '아이' → '사용자'
```

## 왜

지적장애인 **중위연령이 33.8세**입니다. 절반 이상이 성인입니다.
전문가 자문에서 *"생활연령과 발달연령은 다르다"* 는 지적을 받아 대상을 다시 정의했습니다.

# 3. 페인포인트 / 타겟팅 — ✏️ 문구 수정

## 제목

```
페인포인트 / 타겟팅                             ← 작게

현재  보호자와 발달장애 아동
수정  보호자와 발달장애인
```

## 본문 — 두 카드는 그대로, 라벨만

```
왼쪽 카드   보호자          (그대로)
            · 구두 지시의 무한 반복
            · 시각 일정표 / 그림 카드의 직접 제작 부담

오른쪽 카드 현재: 발달장애 아동  →  수정: 발달장애인
            · 추상적 / 복합적 지시 이해의 어려움
            · 일상 행동을 스스로 연결하고 수행하기 어려움

오른쪽 결론  하나의 일상 행동을 어떻게 스스로 수행하게 할 것인가?   (그대로)
```

## 그림

인물 아이콘이 지금 **아동 한 명**인데, **아동과 성인이 함께** 보이면 좋겠습니다.

# 4. 🆕 신규 — 규모와 추이

## 제목

```
기획의도 / 필요성                               ← 작게, 회색

늘어나는 사람들, 커지는 지원, 그래도 남는 일      ← 크게
```

## 구조 — 3칸 가로

### ① 인구는 늘고 있다

```
전체 장애인 중 발달장애 비율

    7.0%  →  9.4%
    2010     2020

전체 등록장애인은 263만 명에서 정체 상태입니다.
발달장애만 계속 늘고 있습니다.
```

### ② 지원은 커지고 있다

```
발달장애인 관련 정부 예산

    2조 8천억 원  (＋15.9%)
    2027년 정부안

· 복지부 발달장애인 지원   4,880억 → 5,721억
· 성인 주간활동서비스      1.5만 명 → 2만 명 → 2030년 3만 명
```

### ③ 그런데 집은 남는다

```
발달장애인              약 25만 명
주간활동서비스 대상        2만 명   (8%)
최중증 통합돌봄 대상       2,760명  (1.1%)

그리고 주간활동서비스는 낮 시간, 기관에서의 활동입니다.
```

## 맨 아래 한 줄 — 이 장에서 가장 크게

```
아침에 옷을 입고 가방을 챙기는 일은 어떤 제도도 대신해 주지 않습니다.
```

## 맨 아래 출처 — 아주 작게

```

## 요청

- 큰 숫자 세 개(`9.4%` · `2조 8천억` · `2,760명`)가 **멀리서도 읽히게**
- ③은 25만 → 2만 → 2,760이 **줄어드는 게 보이게** (막대나 깔때기)

# 6. ABA 설계 — ✏️ 문구 수정 (가장 중요)

## 제목

```
3단계 구조                                      ← 작게

현재  ABA 기반 설계
수정  ABA·특수교육 원리를 참고한 설계
```

**"기반"은 임상에서 검증된 치료 앱으로 읽힙니다.** 저희는 검증받은 적이 없어
근거를 요구받으면 답할 수 없습니다. 심사위원 5명 중 3명이 장애인 전문가입니다.

## 본문 — ③번만 수정

```
① 지시     짧고 명확한 행동 안내                        (그대로)

② 행동     현재: 아동이 하나씩 따라하며 수행
           수정: 사용자가 하나씩 따라하며 수행

③ 강화     현재: 행동 완료 후 칭찬과 보상 제공
           수정: 보호자가 정한 보상을 행동 전·중·후에 상기
```

**③이 핵심입니다.** 지금 문구는 앱이 보상을 준다고 읽힙니다.
자문의 요지는 **앱이 보상을 정하지도, 주지도 않는다**는 것이었습니다.
정하는 것도 주는 것도 보호자이고, 앱은 약속을 **기억하고 보여줄 뿐**입니다.

# 10. 사용자 화면 — 완료 — ✏️ 문구 수정

## 제목

```
현재  아이 화면                                 ← 작게
수정  사용자 화면

현재  행동 완료 후 칭찬과 별을 제공해요
수정  행동 완료 후 칭찬과 별로 성취를 표시해요
```

## 본문

```
현재  아이가 행동을 완료하면 칭찬과 별을 강화물로 제공합니다.
수정  사용자가 행동을 완료하면 칭찬과 별로 성취를 표시합니다.
              ↑ '아이' → '사용자',  '강화물로 제공' → '성취를 표시'
```

## 왜

**별은 강화물이 아니라 앱 안의 토큰입니다.**
실제 강화물은 보호자가 정한 현실의 보상(간식·놀이·산책)입니다.
둘을 같은 말로 쓰면 자문에서 지적받은 부분을 이해하지 못한 것으로 보입니다.

## 제목

기대효과                                        ← 작게, 회색

```

## 위쪽 — 3칸

| | 무엇이 달라지나 |
| --- | --- |
| **보호자** | 매일 아침 반복하던 설명을 앱이 대신합니다. 카드를 손으로 만들지 않아도 됩니다 |
| **당사자** | 다음에 무엇을 하는지, 다 하면 무엇이 있는지 스스로 확인하며 일과를 이어갑니다 |
| **기관·지도자** | 이용자별 과제분석을 매번 새로 만들지 않고, 수행률을 기록으로 남깁니다 |

## 가운데 — 이 장에서 가장 크게

```
10단계짜리 일과를,
보호자 도움 없이 10단계까지.
```

**이게 기대효과이자 측정 지표입니다.** 자문에서 받은 정의 그대로이고,
상담·치료 현장에서 실제로 쓰는 방식이라 심사위원이 바로 알아듣습니다.

## 아래 — 한 줄

```
10월, 서울 ABA연구소와 함께 실제 사용자에게 확인합니다.
```

```
순서를 유지하기 어려운 다른 이용자에게도 같은 구조가 쓰일 수 있습니다.
```

## 요청

- `10단계 → 보호자 도움 없이 10단계` 가 **가장 큽니다.** 숫자 두 개가 눈에 박히게
- 실증 줄은 **여기까지만**. 인원·기간을 화면에 적지 마세요
- ⚠️ **"ADHD·학습장애로 확장"이라고 쓰지 마세요.** 국내 법률상 발달장애인은 지적·자폐성뿐입니다
