## 문구 (v3, 사용자 확정 2026-10-25)

- [비대면 설문] 8문항 막대그래프 · 각주 "5점 만점 · 안내 7명 중 3명 응답 · 모두 1일 사용"
  - 개선: 낮았던 이미지·음성, 완료·보상 표시 > 가이드라인을 추가하고 보상이 필요한 이유를 보강했어요 (코치마크, 보상 설명 팝업 "보상이 왜 필요한가요?")
- [가정 방문 실증] 피드백 내용
  - 잘게 쪼갠 단계가 ABA 기반 교육과정과 닮았어요
  - 생성된 카드 사진을 원하는 실제 사진으로 바꿀 수 있어 좋았어요
  - 처음엔 사용법이 막막했는데, 코치마크를 추가해 사용법을 잘 알게 됐어요
  - 아동의 움직임에 반응하는 움직임·소리 피드백이 있으면 좋겠어요
- [특수학교 방문 실증]
  - 학부모: 쪼개서 가르치는 방법이 보여요. 활용이 어려운 보호자를 위한 기본 가이드라인이 있으면 좋겠어요 / 사용법 지도가 어렵지 않아 정말 잘 쓸 것 같아요 / 태블릿을 지원했으면 좋겠어요 / 좋은 일과를 보호자끼리 공유하는 커뮤니티가 있으면 좋겠어요
  - 교사(교감 선생님): 늘 들고 다니던 종이 행동카드를 앱으로 바로 보여 줄 수 있어 좋아요 / 교사가 앱으로 일과를 만들어 여러 학생에게 쓸 수 있으면 좋겠어요
