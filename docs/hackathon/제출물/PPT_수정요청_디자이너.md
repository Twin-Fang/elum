# PPT 수정 요청 (디자이너용)

> 파일: `이룸_ppt_추가슬라이드.pptx` — **기존 9장 + 내용 슬라이드 10장 = 19장**
> 추가한 10장은 **내용만 담은 텍스트 슬라이드**입니다. 디자인을 입혀주세요.

# 1. ⚠️ 기존 슬라이드 중 **문구를 고쳐야 하는 것** 4곳

전문가 자문 결과 **그대로 두면 감점 요인이 되는 표현**입니다.

## ① 4장 「ABA 기반 설계」 — 가장 시급

```
현재:  ABA 기반 설계
수정:  ABA·특수교육 원리를 참고한 설계
```

**이유** — *"ABA 기반"* 은 **임상 ABA 중재로 검증된 치료 앱**으로 들립니다.
저희는 검증받은 적이 없어 근거를 요구받으면 답할 수 없습니다.
심사위원 5명 중 **3명이 장애인 전문가**라 이 표현이 가장 먼저 걸립니다.

> 권장 문구: **"ABA 및 특수교육에서 활용되는 과제분석·강화·연쇄 원리를 참고했습니다"**

## ② 4장 3단계 구조 — "지시 → 행동 → 강화"

```
현재:  ③ 강화 — 행동 완료 후 칭찬과 보상 제공
수정:  ③ 강화 — 보호자가 정한 보상을 행동 전·중·후에 상기
```

**이유** — 앱이 보상을 "제공"하는 것처럼 읽힙니다.
자문의 핵심은 **앱이 보상을 정하지도, 주지도 않는다**는 것이었습니다.
정하는 것도 주는 것도 보호자이고, 앱은 약속을 **기억하고 보여줄 뿐**입니다.

## ③ 8장 「칭찬과 별을 강화물로 제공해요」

```
현재:  아이가 행동을 완료하면 칭찬과 별을 강화물로 제공합니다
수정:  아이가 행동을 완료하면 칭찬과 별로 성취를 표시합니다
```

**이유** — **별은 강화물이 아니라 앱 안의 토큰**입니다.
실제 강화물은 보호자가 정한 현실의 보상(간식·놀이·산책)입니다.
둘을 같은 말로 쓰면 자문에서 지적받은 부분을 이해하지 못한 것으로 보입니다.

## ④ 2·3장 「발달장애 아동」

```
현재:  발달장애 아동의 일상 수행과 자립을 돕는 모바일 서비스
수정:  발달장애인의 일상 수행과 자립을 돕는 모바일 서비스
```

**이유** — 지적장애인 **중위연령이 33.8세**입니다. 절반 이상이 성인입니다.
자문에서 *"생활연령과 발달연령은 다르다"* 는 지적을 받아 대상을 다시 정의했습니다.

> 3장 페인포인트의 인물 아이콘도 **아동 + 성인**이 함께 보이면 좋겠습니다.

# 2. 추가한 10장 — 디자인 요청

각 장은 `상단 카테고리 / 큰 제목 / 본문`으로만 되어 있습니다.
**민트색 소제목**은 강조 블록, **빨간 글씨**는 발표자 주의사항이니 화면에서는 빼거나 작게 처리해주세요.

| # | 슬라이드 | 디자인 요청 |
| --- | --- | --- |
| 10 | 얼마나 많은 사람의 문제인가 | **숫자 3개(25만 / 22.5% / 19.43)를 크게.** 우울 점수는 기준선(16)과 비교되게 |
| 11 | 연령이 아니라 기능 수준으로 | `7~12세 → 33.8세 → 새 정의` **흐름이 보이게.** 기준 4개는 체크리스트 형태 |
| 12 | 이미 있는 것과 없는 것 | **비교표.** 마지막 줄(ELUM)만 강조. 해외 앱 로고는 넣지 않습니다 |
| 13 | 전문가 자문 — 받은 지적과 바꾼 것 | **좌: 지적(인용) / 우: 반영** 2단 대조. 인용은 큰따옴표를 살려서 |
| 14 | 핵심 기술 — 한 문장을 행동 단계로 | **한 문장 → 8단계 카드**가 펼쳐지는 그림. 이 장이 가장 시각적이어야 합니다 |
| 15 | 장애와 개발물의 연관성 | **좌: 원리 / 우: 기능** 1:1 매핑. 과제분석·연쇄·강화·개별화 4행 |
| 16 | 상용화 전략 | **①②③ 확산 경로**를 흐름으로. 수익 모델은 `일반/기업·기관/구독/공공` 4구분 |
| 17 | 리스크 해결방안 | **문제 → 대응** 2단. 6행 |
| 18 | 기대효과 | **보호자 / 사용자 / 기관** 3열. 마지막 확장은 작게 |
| 19 | 현재 고민하는 것 | 질문 3개. **가장 담백하게** — 꾸미면 진정성이 떨어집니다 |

# 3. 최종 순서 (19장 → 발표용 14장 + 부록)

```
발표 (10분)
 1  표지                          (기존)
 2  오버뷰                        (기존, 문구 수정 ④)
 3  페인포인트 / 타겟팅            (기존, 문구 수정 ④)
10  얼마나 많은 사람의 문제인가     (신규)
11  연령이 아니라 기능 수준으로     (신규)
12  이미 있는 것과 없는 것          (신규) ★참신성
 5  보호자 화면 — 일과 입력         (기존)
 6  보호자 화면 — 카드 생성         (기존)
 7  아이 화면 — 수행               (기존)
 8  아이 화면 — 완료               (기존, 문구 수정 ③)
14  핵심 기술                      (신규)
 4  ABA 원리 참고 설계             (기존, 문구 수정 ①②)
15  장애와 개발물의 연관성          (신규) ★적용가능성
13  전문가 자문 — 지적과 반영       (신규) ★우리 무기
16  상용화 전략                    (신규) ★필수
17  리스크 해결방안                (신규) ★필수
18  기대효과                       (신규) ★필수
19  현재 고민하는 것               (신규)
 9  QR                            (기존, 마지막)

부록 (제출용 · 발표에서는 넘김)
 A  플로우차트      ← ⚠️ 아직 없음, 만들어야 합니다
 B  메뉴 구조도     ← ⚠️ 아직 없음, 만들어야 합니다
```

> ⚠️ **플로우차트와 메뉴 구조도는 대회 필수 항목입니다.**
> 발표에서 설명할 필요는 없지만 **자료집에 없으면 감점**입니다.
