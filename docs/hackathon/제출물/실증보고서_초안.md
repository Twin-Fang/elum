# Part A. 작성 방향 — 심사석에서 본 2025 보고서

## A-1. 2026 양식이 2025와 다른 한 곳

2026 양식 2번 제목은 **"중간심사 피드백 및 주요 실증 필요 포인트"**다.
2025(센소리아)는 "주요 실증 기능/포인트"였다. 올해는 **중간심사 지적을 실증으로 확인했는지**를 본다.
→ 지적 7개를 2번에 그대로 옮기고, 각 지적에 **실증에서 무엇을 재서 답할지**를 1:1로 붙인다.

- "치료·치료 효과·자립한다" 금지. "3일 써 보니 이랬다" 수준만.

## B-3. 카드별 촉구 수준 관찰지 — 이 보고서의 핵심 숫자

2025 보고서와 갈리는 지점. 점수 대신 **관찰된 사건**을 센다. ABA 촉구 위계를 쓰므로 장애 전문가가 바로 읽는다.

| 카드 | 도움 없이 | 말로 알려 줌 | 손짓·가리킴 | 몸으로 도와줌 | 안 했는데 체크 | 걸린 시간 | 메모 |
| --- | :-: | :-: | :-: | :-: | :-: | ---: | --- |
| 1. 🔴 | ☐ | ☐ | ☐ | ☐ | ☐ | | |
| 2. | ☐ | ☐ | ☐ | ☐ | ☐ | | |
| … | | | | | | | |

```
도움 없이 끝낸 카드 비율 = 도움 없이 칸 ÷ 전체 카드 수
안 했는데 체크한 비율   = 안 했는데 체크 칸 ÷ 체크한 카드 수
```

> 비교 기준은 **2번 사전 질문(보호자가 말한 평소 도움 정도)**이다. 같은 날 앱 없이 한 번 더 시키는 비교는
> 이룸이에게 부담이라 하지 않는다. 보고서엔 "기준선은 보호자 회상"이라고 **한계로 적는다.**

## 1. 개발 내용 요약

**이룸은 보호자가 말로 적은 하루 일과를, 발달장애인이 한 장씩 따라 할 수 있는 행동 카드로 바꿔 주는 앱이다.**

■ 개발 환경: Flutter(Android·iOS) · Spring Boot · 생성형 AI(일과 단계 나누기 · 카드 그림)
■ 출시 상태: 🔴 앱스토어·플레이스토어 출시 버전 v2.27.x (제출일 기준 버전으로 고친다)

■ 주요 기능
가. 일과 만들기 — 보호자가 말이나 글로 "양치하기"를 적으면 AI가 단계 카드로 나누고, 모호한 곳은 되묻는다
나. 보호자 검토 — AI가 만든 카드는 보호자가 **고치고·더하고·지우고·순서를 바꾼 뒤** 보낸다. 승인 전에는 이룸이 화면에 나오지 않는다
다. 캐릭터 일관 그림 — 같은 캐릭터로 카드 그림을 그린다. 그림 방식(기본 그림·만화·실사) 선택, **직접 찍은 사진**으로 바꾸기
라. 이룸이 화면 — 카드 한 장에 행동 하나, 글 읽어 주기(음성), 체크 시 진동·별·완료 팡파르
마. 보상 — 보호자가 정한 보상을 일과 끝에 보여 준다
바. 함께 보기 — 이룸이 휴대폰 연결(연결 코드), 다른 보호자 초대, 수행 결과가 보호자 화면에 30초 안에 반영
사. 의견 보내기 — 앱 안에서 의견과 앱 상태 기록을 보낸다(실증 피드백 수집 통로)

### 2-2. 주요 실증 포인트

1. **[이해] 이룸이가 카드를 보고 할 일을 알았는가** — 카드별 촉구 수준(도움 없이 / 말 / 손짓 / 몸으로)
2. **[신뢰] 체크가 실제 수행과 맞는가** — 안 했는데 체크한 비율 (지적 5에 대한 답)
3. **[보호자 부담] 일과 하나를 만드는 데 얼마나 걸리고, AI 카드를 얼마나 고쳤는가**
4. **[대상] 어떤 이룸이에게 맞고, 어떤 이룸이에게 어려운가** (지적 7에 대한 답)
5. **[현장] 특수학교 교사가 보기에 학교·가정에서 쓸 수 있는가**

## 3. 실증 진행 내용

■ 참여자 모집 관련
1) 실증 1(학교 대면): 세종대학교 교육학과 권현수 교수님(상담심리/특수교육전공)의 소개로 서울 소재 지적장애 특수학교 🔴(학교명 공개 동의 시 "동천학교") 교감선생님의 협조를 받았다. 학교가 가정통신문으로 안내하고 **희망 가정이 직접 신청**했다. 학교는 학부모 연락처를 팀에 넘기지 않았다.
2) 실증 2(가정 원격): 테스터 모집 폼 신청자 🔴명에게 안내 메일을 보내(10/12) 🔴명이 참여했다.
3) 선정 기준: 그림 카드를 보고 뜻을 알고, 순서를 따라갈 수 있으며, 스마트폰 화면을 누를 수 있는 발달장애인과 그 보호자 (이룸의 대상 정의). 🔴 기준에 일부 못 미치는 참여자도 **어려운 경우를 확인하려고** 포함했다면 그렇게 쓴다.
4) 동의 방법: 보호자(법정대리인) 서면 동의, 장애유형 기재는 별도 선택 동의. 참여 학생 본인에게는 그림 안내 카드로 설명하고 의사를 확인했다. 교사는 서면 동의. 얼굴 사진·실명은 받지 않았다.
