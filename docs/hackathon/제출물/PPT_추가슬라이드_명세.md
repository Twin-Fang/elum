# 슬라이드 A — 기획의도 및 필요성 (규모·추이)

**들어갈 위치: 기존 3장(페인포인트) 바로 뒤**

## 제목

```
기획의도 / 필요성                        ← 작게, 회색 (기존 3·4장과 같은 위치)

늘어나는 사람들, 커지는 지원, 그래도 남는 일   ← 크게, 검정 볼드
```

## 각 칸에 들어갈 문구

### ① 👥 인구는 늘고 있다

```
전체 장애인 중 발달장애 비율

    7.0%  →  9.4%
    2010     2020

전체 등록장애인은 263만 명에서 정체 상태입니다.
발달장애만 계속 늘고 있습니다.
```

### ② 💰 지원은 커지고 있다

```
발달장애인 관련 정부 예산

    2조 8천억 원  (＋15.9%)
    2027년 정부안

· 복지부 발달장애인 지원   4,880억 → 5,721억
· 성인 주간활동서비스      1.5만 명 → 2만 명
                          → 2030년 3만 명
```

### ③ 🏠 그런데 집은 남는다

```
발달장애인              약 25만 명
주간활동서비스 대상        2만 명   (8%)
최중증 통합돌봄 대상       2,760명  (1.1%)

그리고 주간활동서비스는 낮 시간, 기관에서의 활동입니다.
```

### 맨 아래 한 줄 (가장 크게 강조)

```
아침에 옷을 입고 가방을 챙기는 일은 어떤 제도도 대신해 주지 않습니다.
```

## 디자인 요청

| | |
| --- | --- |
| **구조** | 3칸 가로 배치. 기존 3장(보호자/아동 2칸)과 같은 카드 박스 톤 |
| **숫자** | 세 개 큰 숫자(`9.4%` · `2조 8천억` · `2,760명`)가 **멀리서도 읽히게** |
| **③의 감소** | 25만 → 2만 → 2,760명이 **줄어드는 것**이 보이게. 막대나 깔때기 형태 권장 |
| **아이콘** | 이모지 그대로 쓰지 마시고 기존 톤의 아이콘으로 바꿔주세요 |
| **마지막 줄** | 민트 강조. 이 장에서 **가장 크게** |
| **출처** | 맨 아래 한 줄, 아주 작게. **연도는 빼지 마세요** |

## 발표자가 할 말 (참고용, 화면에는 안 들어감)

> "발달장애인은 계속 늘고 있습니다. 전체 장애인 수는 263만 명에서 거의 멈춰 있는데,
> 발달장애 비율만 7%에서 9.4%로 올라갔습니다.
>
> 국가 지원도 커지고 있습니다. 내년 발달장애인 관련 예산은 2조 8천억 원으로 16% 늘고,
> 주간활동서비스는 2030년까지 두 배가 됩니다.
>
> 그런데 그건 **낮 시간에, 기관에서** 일어나는 일입니다.
> 25만 명 중 2만 명이 대상이고, 최중증 통합돌봄은 2,760명입니다.
>
> 아침에 옷을 입고 가방을 챙기는 일은 여전히 보호자가 매일 반복합니다."
