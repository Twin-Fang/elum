# 3. 동의 확인서

## 3-1. 보호자용 (구글폼 첫 페이지)

> **필수 2 + 선택 2.** 장애 종류는 **민감정보**라 일반 동의와 분리한다.

**제목**: 이룸 사용 의견 참여 동의 확인서

```
이룸 팀은 "이룸" 앱의 사용 의견을 보고서와 발표자료에 쓰기 위해
아래 정보를 받으려고 해요. 내용을 읽고 동의해 주세요.

1. 받는 정보
   · 보호자 연락처 (이미 받은 번호 / 학교 경유 신청 시 직접 적어 주신 번호)
   · 이룸이의 연령(만 나이)
   · 앱 사용 기록 — 일과 수, 카드 수, 완료 횟수 등 개수만 (입력한 글 원문은 보지 않아요)
   · 설문 응답

2. 쓰는 목적
   · 사용 의견 보고서와 발표자료 작성
   · 앱 개선

3. 보관 기간
   · 사용 의견 정리가 끝난 뒤 🔴 30일 안에 지워요 (연락처·설문 원본)
   · 보고서에는 이름 없이 숫자와 요약만 남아요

4. 알려드릴 것
   · 동의하지 않으셔도 앱을 쓰는 데 불이익이 없어요
   · 동의하신 뒤에도 언제든 철회하고 정보를 지워 달라고 하실 수 있어요
   · 받은 정보를 다른 곳에 넘기지 않아요 (보고서에는 이름 없는 요약만 실어요)
   · 학교를 통해 알게 되셨더라도, 학교는 응답 내용을 알지 못해요

□ [필수] 위 1~4를 읽었고, 보호자 연락처와 사용 기록·설문을 위 목적으로 쓰는 데 동의해요
□ [필수] 이룸이의 보호자(법정대리인)로서, 이룸이의 연령과 사용 기록을 위 목적으로 쓰는 데 동의해요
□ [선택] 이룸이의 장애 종류(자폐성·지적 등)를 보고서에 이름 없이 쓰는 데 동의해요 (민감정보)
□ [선택] 적어 주신 말을 이름 없이 발표자료·보고서에 인용해도 좋아요
```

# 5. 교사 의견 듣기 — 15분 (시연 후)

> 교사는 3일 사용하지 않는다. **앱을 15분 보여 드리고** 의견을 듣는다.

| # | 질문 |
| :-: | --- |
| T-1 | 학생들이 일과를 수행할 때 **어느 단계에서 도움이 가장 필요**한가요? |
| T-2 | 지금은 어떤 방식(그림 카드·시각 일정표 등)으로 지원하시나요? **만드는 데 얼마나** 드나요? |
| T-3 | 이 앱을 보시고 **현장에서 쓰기에 걸리는 점**은 무엇인가요? |
| T-4 | 가정과 학교가 **같은 일과를 공유**하면 도움이 될 것 같으세요? |
| T-5 | **어떤 학생에게 더 맞고, 어떤 학생에게는 어려울 것** 같으세요? (수준별) |
| T-6 | 이 앱에 **빠졌다고 느끼는 것**이 있나요? |

> T-5가 지적 7번(수준별 확인)에 대한 **전문가의 직접 답**이 된다. 가장 가치 있다.
> T-6에서 결과 사진·목적 제시가 나오면 우리 판단을 다시 본다. 안 나오면 근거가 된다.

# 6. 결과를 어떻게 쓰나 (3일 기준)

| 결과 | 문장 형태 |
| --- | --- |
| 사용 일수 · 응답 수 | "□명이 □일 사용, □명 응답" — **분모를 함께** |
| 문항 3 | "도움 없이 끝낸 카드 □ / □장" |
| 문항 4 | "하지 않았는데 체크한 경우: 없음 □명 · 가끔 □명" |
| 문항 8 | "더 필요한 것: □" |
| 문항 9·T-5 | **원문 인용** (이름 없이) |

- 표본이 작다. "경향"이라고 쓰고 단정하지 않는다.
- 부정적 응답도 숨기지 않고 "다음 단계"에 쓴다.
- **"실증 결과가 완벽하다"가 아니라 "써 보고 고칠 것을 찾았다"가 점수가 된다.**
