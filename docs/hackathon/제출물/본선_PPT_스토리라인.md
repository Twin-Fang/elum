## 1. 2025 1위 두 팀이 PPT를 짠 방식

| | 센소리아 (분야1 1위) | 토닥이 (분야2 1위) |
| --- | --- | --- |
| 분량 | 본문 8장 | 28쪽 |
| 흐름 | 필요성 → 비교 → **기능 설명 40%** → 피드백 → 상용화 → 리스크 → 효과 | 숫자 → **현장 사진·페르소나**로 대상 좁힘 → 기능 4개 → **피드백 반영 약 30%** → 리스크 |
| 피드백 반영 | 1장, 표(피드백 / 요청 / 적용결과). 반영 후 화면 없음 | 4장. **지적 원문 인용 박스 → 바뀐 화면에 빨간 박스·화살표** |
| 실증 | **PPT에 없음.** 보고서에만 | 5장. 현장 사진 3, 인용 4, 설문지 스캔 2, 협력기관 2곳(자폐인사랑협회·브라보비버) |
| 실증 숫자 | 교사 체크리스트 5점(전부 4~5) | 설문 68/75(90.7%), 반영 7/10 · 미반영 3건 사유 공개 |
| 약점 | 사용자 증거 0, 문제 근거 통계 없음 | 표본 2명, 기대효과 슬라이드 거의 빈 장, 목차 슬라이드 반복 |

**읽은 것**
1. 둘 다 **피드백 → 반영**을 따로 보여 줬다. 토닥이는 원문 인용 + 화면 대조로 훨씬 강하게 했다.
2. 토닥이는 **현장 사진과 당사자 말**로 처음부터 끝까지 근거를 이었다. 올해 공고는 본선 PPT에 실증 내용을 **반드시** 넣으라고 바뀌었다 — 토닥이 방식이 기준선이다.
3. 둘 다 **기대효과가 약했다**(키워드·빈 장). 여기서 이기면 차이가 난다.
4. 둘 다 실증 지표가 **만족도 설문뿐**이었다. 우리가 "도움 없이 끝낸 단계"를 재면 전문가 3명에게 바로 차이가 보인다.

### ⭐ 두 장이 승부처

- **S8 여기까지 온 길** — 2025 어느 팀도 없던 장이다. ABA 현장(한상민 소장)과 특수교육(권현수 교수·동천학교) **두 경로**로 검증했다는 것을 한 장으로 보여 준다.
- **S12 실증 결과** — 중간심사 7번이 요구한 *"도움 없이 어느 단계까지, 중증도별로"*에 숫자로 답한다. 만족도 점수만 낸 2025 팀들과 갈리는 지점이다.

## 3. 하지 않는 것

- 목차 슬라이드 반복(토닥이) — 10분에서 시간만 쓴다.
- 기능 설명이 덱의 절반(센소리아) — 시연 영상 하나로 끝낸다.
- 비반영 피드백 숨기기(토닥이는 PPT에서 뺐다) — 7개 전부 보이고, 비반영은 근거와 함께.
- 만족도 점수만 — 관찰한 사건(도움 없이 / 안 했는데 체크)을 센다.
- 중간심사 발표본 4번의 **"보호자의 지속적인 개입 없이도"** — 피드백 7이 정면으로 짚은 문장. 잰 값으로 바꾼다.
- "치료" "자립한다" — 잰 것만 쓴다.
