## 2. 고칠 것 — 우선순위

### 🔴 반드시 (보내기 전에)

| # | 문제 | 고칠 것 | 이유 |
| :-: | --- | --- | --- |
| 1 | **개인정보·민감정보 동의 문항이 없다.** 장애유형·장애정도는 민감정보다 | 첫 섹션에 동의 문항(필수): 수집 항목·목적·보관 기간·거부 권리. 장애유형·정도는 **별도 동의** | 법적 문제. 실증보고서 3장 "동의 방법"에 쓸 근거 |
| 2 | **"아이" "아동"이 제목 설명·문항 전체에 있다** | "이룸이" 또는 "사용자(이룸을 쓴 분)" | 대상은 연령이 아니라 기능 기준. 테스터 중 성인 당사자가 있다. 중간심사 피드백 7(타겟 구체화)과도 맞지 않는다 |
| 3 | **피드백 7의 핵심 질문이 없다** — "도움 없이 어느 단계까지" | 새 문항(아래 3-①) | 실증 결과 슬라이드의 핵심 숫자. 지금 문항으로는 만들 수 없다 |
| 4 | 장애정도 "경증 / 중증" | **"심하지 않은 장애 / 심한 장애 / 모름·응답 안 함"** | 2019 장애등급제 개편 후 법정 표현. 장애 전문가 심사위원 3명 |
| 5 | 8번만 척도 방향이 거꾸로(1=쉬움) | 1=매우 어려웠다 · 5=매우 쉬웠다 로 통일 | 평균 낼 때 섞이면 결과가 뒤집힌다 |

### 🟢 다듬기

- 7번 "긍**적**적" → "긍정적" 오타
- 14·17번 장문 **필수 해제** — 필수면 "없음" 같은 빈 응답이 쌓이고 중간에 그만두는 사람이 생긴다
- 마지막 **"제목 없는 섹션"** 삭제
- "자폐성 장애" → "자폐성장애" (법정 표기)
- 문항 수: 지금 17 + 추가 8 = 25. 5점 척도 기능 4개(10~13)는 하나의 그리드로 묶으면 화면이 짧아진다

## 3. 이 설문이 보고서·PPT에서 맡는 것

| 산출물 | 이 설문에서 오는 것 |
| --- | --- |
| 보고서 3장 참여자 기본정보 | 1~4번 + ⑥ (장애정도 표기 고친 뒤) |
| 보고서 3장 실증 기간·횟수 | ④ |
| 보고서 4장 정량 | 5·6·8·9·10~13·15 평균 **+ 최솟값·분모** · ①② 분포 |
| 보고서 4장 정성 | 14·17 원문 (⑧ 동의분만 인용) |
| 피드백 7 답 | ①②를 4번(장애정도)별로 나눠서 |
| 피드백 2·3·5·6 답 | ⑦ |
| PPT 실증 결과 | ② "도움 없이 끝낸 단계" + 6번 "부담이 줄었다" + 인용 1~2개 |

> 설문은 **보호자의 기억**이다. 대면 실증(가정·동천학교)에서는 관찰로 직접 센 값을 따로 남기고,
> 보고서에는 "설문(보호자 응답)"과 "관찰(팀 기록)"을 구분해서 쓴다.
