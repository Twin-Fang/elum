# 1. 설문 구성

| 대상 | 방식 | 시간 | 문항 |
| --- | --- | ---: | ---: |
| **보호자·센터 선생님용** | 구글폼 (온라인) | 약 6분 | 29개 |
| **이룸이용** | 보호자가 옆에서 쉬운 말로 묻고 **대신 기록** | 약 2분 | 5개 |
| **기록지** (1주간 수행 기록) | 보호자가 표에 체크 | 하루 1분 | 7일 |

> 이룸이는 글을 못 읽을 수 있으므로 **그림 척도(😊 😐 ☹️)**를 쓰고, 보호자가 "이룸이의 반응을 관찰한 것"으로 적는다.
> 보고서에는 **"보호자 관찰 기록"**이라고 쓴다. 이룸이 본인의 응답이라고 쓰지 않는다.

## 0. 안내·동의 (필수)

```
이 설문은 "이룸" 앱의 실증 결과를 모으기 위한 것이에요.
· 응답은 이름 없이 처리하고, 결과는 숫자와 요약으로만 발표자료·보고서에 써요.
· 이룸이의 사진·얼굴·실명은 받지 않아요. 적으신 말은 이름을 지우고 인용할 수 있어요.
· 참여하지 않으셔도 불이익이 없고, 중간에 그만하실 수 있어요.
· 이 설문에서 받는 정보는 대회 제출용이에요. 앱은 진단명을 수집하지 않아요.
□ 위 내용을 읽었고 응답을 보고서에 쓰는 데 동의해요
```

# 3. 이룸이용 — 보호자가 옆에서 묻고 대신 기록

> 보호자가 "이룸이가 가리킨 것" 또는 "표정에서 읽은 것"을 기록한다. **응답을 이끌지 않는다.**

# 4. 1주 수행 기록지 — **"도움 없이"를 숫자로**

| 날짜 | 일과 이름 | 카드 수 | **도움 없이 한 카드 수** | 체크했지만 안 한 카드 | 메모 |
| --- | --- | :-: | :-: | :-: | --- |
| 1일차 | | | | | |
| … | | | | | |
| 7일차 | | | | | |

**여기서 나오는 것**

```
도움 없이 한 비율 = Σ(도움 없이 한 카드) ÷ Σ(카드 수)
거짓 체크 비율   = Σ(체크했지만 안 한 카드) ÷ Σ(체크한 카드)
```

> 🎯 PPT S9의 헤드라인 숫자가 여기서 나온다.
> **"체크 수"가 아니라 "도움 없이 한 비율"을 쓴다.** 거짓 체크 비율은 A3 공격의 **직접 답**이다.

## 해석 주의

- **표본이 9명이다.** "효과가 있다"가 아니라 **"사용성과 경향을 확인했다"**로 쓴다.
- 백분율은 쓰되 **분모를 함께 쓴다.** ("9명 중 7명")
- 기능 수준별 비교는 한 집단이 한두 명일 수 있다. **"경향"이라고 쓰고 단정하지 않는다.**
- 부정적 응답(D-3 번거로움, G-1 걱정)도 **숨기지 않고** S10 "다음 단계"에 쓴다.
