## 1. 한 줄 요약

**프로토타입 → 전문가 자문 → 중간심사 → 고쳐서 다시 찾아감 → 테스터 모집 → 가정 대면 실증 → 특수학교 실증**

발표에서 쓰는 문장:

> "만들고 끝내지 않았습니다. 전문가에게 먼저 보여 줬고, 지적받은 것을 고쳐 다시 찾아갔고,
> 그 길로 실제 사용자와 특수학교까지 연결됐습니다."

## 4. 발표 슬라이드 한 장 구성안

```
[실증까지 오는 길]

 9/13        9/18          10월 초         10/14           10/19
 1차 자문 →  중간심사  →  고쳐서 출시  →  테스터 7명  →  특수학교 방문
 서울ABA연구소 피드백 7건  다시 찾아감     가정 대면 실증    동천학교
 한상민 소장                               확보             (세종대 권현수 교수 연결)
```

- 각 화살표 아래에 **바뀐 것 하나**만 쓴다(대상 재정의 → 사진 카드 → 대면 요청 …).
- 소장님·교수님·학교 이름은 그대로 쓴다. 참여자 사진은 얼굴 없이(공고: 모자이크 또는 얼굴 안 나오게).
