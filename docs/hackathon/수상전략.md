# 2. 왜 뽑혔는가 — 공통 성공 요인 5가지

## ① 당사자의 목소리를 **그대로 인용**한다

**픽포미**는 제안서에 시각장애인 인터뷰를 따옴표째 넣었다.

> *"비건이라 음식 성분표를 꼭 확인해야 해요. 그런데 성분 정보가 이미지로만 제공되니 확인이 불가능했죠.
> 성분을 알 수 없어서 구매를 포기한 경우도 많았어요."*
>
> *"기존 쇼핑몰은 그림 설명이 없어서 같은 제품인데 왜 가격이 다른지 알 수 없었어요.
> 결국 지인에게 물어서 색상 차이라는 걸 알았지만, 매번 그렇게 도움을 받을 수 있는 건 아니죠."*

**요약하지 않고 원문 그대로** 넣었다는 게 핵심이다. 심사위원 5명 중 3명이 장애인 전문가이고,
본선 시민평가단 30점에는 **장애인 당사자와 가족**이 포함된다. 이들에게는 통계보다 이 문장이 먼저 닿는다.

## ② **자체 조사 데이터**를 만든다

| 팀 | 자체 데이터 |
| --- | --- |
| 픽포미 | **시각장애인 20명 대상 자체 설문** — "40%가 사람 해설자에게 사진 공유를 거부" |
| 픽포미 | 창업 초기 MVP 테스트 — "수집된 사진 해설 의뢰의 **약 1/3이 쇼핑 관련**" |
| 캡픽 | 장애인 체육봉사 **300시간 이상** 현장 경험 |

**남의 통계만 인용한 팀과, 자기가 조사한 숫자를 가진 팀은 다르게 읽힌다.**
"우리가 직접 확인했다"가 곧 적용가능성 20점의 근거가 된다.

## ③ 경쟁 서비스를 **이름을 대고 해부**한다

픽포미는 유사 서비스 4개를 각각 소항목으로 나눠 한계를 짚었다.

```
1. Seeing AI / 설리번 플러스
   a. 사진 정보 입력 과정의 불편함 — 캡처 → 앱 업로드 → 해설 확인 반복
   b. 미흡한 해설 — 광고 문구와 실제 상품 설명을 구분 못 함
                    kg·ml·3x3 같은 기호를 스크린리더가 어색하게 읽음
2. Be My Eyes
   a. 상품 이미지 공유 과정의 불편함
   b. 자원봉사자에 대한 심리적 거부감 (자체 설문 40%)
3. ChatGPT
   - 쇼핑 특화 아님 · 접근성 미흡
```

그리고 **"픽포미의 차별점" 3가지**로 받았다. 이게 **참신성 20점**의 정석이다.

> 발표 필수 항목에 **"국내·외 유사 사례 비교 및 차이점"** 이 있다.
> 형식적으로 한 줄 쓰는 팀과, 이렇게 해부하는 팀의 점수가 같을 수 없다.

## ④ 통계에 **출처와 연도**를 붙인다

캡픽의 제안서는 표가 세 개다.

| 형태 | 예 |
| --- | --- |
| 연도별 추이 표 | 장애인 생활체육 참여율 2021~2024 · 비장애인 대비 격차 |
| 제약 요인 응답률 | "혼자 운동하기 어려워서 29.9%" |
| 공급 구조 | 전국 장애인 전용 체육시설 69개 · 시설당 38,400명 |

전부 **출처(국민생활체육조사, 경기복지재단)와 연도**가 붙어 있다.
여기에 **뉴스 클리핑 이미지**까지 넣어 "이건 실제 사회 문제다"를 시각적으로 못 박았다.

## ⑤ **현장 기관과 연결**되어 있다

| 팀 | 연결 |
| --- | --- |
| 토닥이 | 한국자폐인사랑협회 부산지부 방문 · **브라보비버(발달장애인 고용기업)** 실증 |
| 캡픽 | 장애인 체육봉사 300시간 |
| 픽포미 | 시각장애인 20명 설문 · 창업 MVP 운영 |

**혼자 상상해서 만든 앱이 아니라는 증거**다. 심사에서 "실제로 써봤나요"를 물었을 때
기관 이름을 댈 수 있는 팀과 없는 팀은 다르다.

# 3. 💡 실무적으로 가장 유용한 발견

## 실증 사진은 **얼굴 사진이 아니어도 된다**

`pillypilly` 실증보고서의 **「6. 실증 진행 사진」** 은 현장 사진이 아니다.
**구글폼 응답 그래프 30여 장 + 참여자 정보 스프레드시트 캡처**로 채워져 있다.

```
참여자 정보 시트 컬럼 (실제)
개인정보 수집·이용 동의 | 시각 장애 정도 | 결과 요약(자유서술)
| 이해가 잘 되었는지(5) | 앱 이용률(5) | 전반적 만족도(5) | 기타(5)
```

> 🎯 **실증 부담이 크게 줄어든다.**
> "얼굴 안 나오게 사진 3장"을 걱정할 게 아니라, **설문을 제대로 설계**하면 그 결과 화면이 곧 사진이 된다.
> 다만 **현장 사진 2~3장은 함께 넣는 것**이 신뢰도에 낫다 (토닥이는 실제 현장 사진을 썼다).

## 실증 설문은 **리커트 5점 + 자유서술** 조합이 표준

토닥이는 **관리자용·사용자용 2종**, pillypilly는 이해도·이용률·만족도 축으로 구성했다.
우리도 **보호자용·사용자용 2종**을 만든다.

# 5. 우리의 무기 — 다른 팀에 **없는** 것

## 🏆 전문가 검증 + 이론적 근거

| 팀 | 근거의 출처 |
| --- | --- |
| 캡픽 | 대표의 개인 경험 |
| 픽포미 | 당사자 인터뷰 + 자체 설문 |
| 토닥이 | 협력 기관 방문 |
| **ELUM** | **행동중재 전문기관 소장의 직접 자문 + ABA 이론 정합성 검증** |

**ELUM만 "이론"을 가지고 있다.** 다른 팀은 "사용자가 불편해한다"에서 출발하지만,
우리는 **과제분석(Task Analysis) · 연쇄(Chaining) · 강화(Reinforcement)** 라는
행동분석 체계에 기능을 1:1로 매핑할 수 있다.

```
AI가 한 문장을 행동 단계로 분해   →  과제분석(Task Analysis)
카드를 순서대로 수행              →  연쇄(Chaining)
보호자가 정한 보상을 상기          →  강화(Reinforcement)
보호자의 카드 수정                →  개별화
```

심사위원 **3명이 장애인 전문가**다. 이 매핑 한 장이 *"현장을 아는 팀"* 이라는 신호가 된다.

> ⚠️ 단, **"ABA 기반 치료 앱"이라고 하면 안 된다.**
> 표현 규칙은 [발표 표현 가이드](./발표_표현가이드.md) 참고.

## 🏆 "자문 → 반영" 이 이미 증명됐다

토닥이가 수상한 결정적 이유는 **중간심사 지적을 받아 구조를 바꾼 것**이었다
(*"타겟 명확화 필요"* → 발달장애인 근로자로 확정 + 관리자 모드 추가).

**우리는 그걸 중간심사 전에 이미 했다.**

| 소장님 지적 | 우리가 바꾼 것 |
| --- | --- |
| "마음 다스리기 같은 건 안 된다. 행동으로 해야 한다" | 추천 일과 5개 교체 + **AI 프롬프트에 규칙 추가** |
| "아들이 회사 다니는데 '학교에 가요'가 뜬다" | 성인 일과 8개 추가 + 타겟 재정의 |
| "강화가 없다" | 보상 설정·노출 기능 구현 중 |
| "단계 수가 고정이면 안 된다" | 카드 수 고정 해제 |

**"지적 → 반영"을 슬라이드 한 장에 표로 넣는다.** 이게 토닥이가 쓴 방식이고, 우리는 한 사이클 앞서 있다.

# 6. 2주 안에 채울 것 — 우선순위

## 🔴 A. 통계 확보 (반나절, 즉시)

지금 기획 문서에 **숫자가 하나도 없다.** 발표 2번째 슬라이드를 채울 수 없다.

| 필요한 숫자 | 출처 후보 |
| --- | --- |
| 국내 발달장애인 인구 | 보건복지부 장애인 현황 (토닥이는 **약 25만 명, 2023** 인용) |
| 보호자 돌봄 부담 | 한국장애인개발원 장애인 가족지원 실태조사 (토닥이: **보호자 73% 돌봄피로·정보부족, 2022**) |
| 발달장애인 스마트폰 보유·이용률 | 과기정통부 디지털정보격차 실태조사 |
| 성인 발달장애인 고용·주간활동 참여 | 한국장애인고용공단 |
| 일과 수행 지원 필요 비율 | 발달장애인 실태조사 |

> 캡픽처럼 **연도별 추이 표 1개 + 응답률 표 1개**면 충분하다. 반드시 **출처와 연도**를 붙인다.

## 🔴 B. 보호자 인터뷰 2~3건 (실증과 함께)

픽포미의 인터뷰 인용이 가장 강력했다. 우리도 **보호자의 말을 따옴표로** 넣는다.

```
받아야 할 말
· "아침마다 같은 말을 몇 번씩 반복해요"
· "카드를 만들어 주고 싶은데 그림을 어디서 찾아야 할지 모르겠어요"
· "다 하면 뭘 준다고 해야 그나마 움직여요"
```

> 소장님께 **연구소를 통해 보호자 2~3분 인터뷰**를 요청할 수 있다. 10월 실증과 함께 진행한다.

## 🔴 C. 경쟁 서비스 비교 (1일)

토닥이만으로는 부족하다. **픽포미처럼 4~5개를 해부**한다.

| 비교 대상 | 한계 |
| --- | --- |
| 종이 그림카드 · 그림교환의사소통(PECS) | 상황마다 준비물이 달라 매번 새로 만들어야 함 |
| 일반 일정관리 앱 (구글 캘린더 등) | 일정은 알려주지만 **행동 단계로 쪼개지 않는다** |
| **토닥이** (2025 수상작) | 정해진 일정을 보여줌 — 일정을 **만들어내는 앞단**이 없음 |
| 해외 앱 (Choiceworks, First Then Visual Schedule 등) | 카드를 **사람이 직접 만들어야** 함 · 한국어·국내 맥락 부재 |
| ChatGPT 등 범용 LLM | 카드·이미지·수행 흐름이 없고 보호자 승인 구조가 없음 |

> **해외 앱 조사가 특히 중요하다.** "국내·외 유사 사례"가 필수 항목인데
> 국내만 보면 "외"가 빈다. Choiceworks·FTVS는 이 분야의 대표 앱이다.

## 🟠 D. 실증 설문 설계 (실증 전)

```
보호자용 (리커트 5점 + 자유서술 4문항)
 · 카드가 실제 수행에 도움이 되었는가
 · 보상 설정이 어렵지 않았는가
 · AI가 만든 단계가 우리 아이에게 맞았는가
 · 수정 기능을 사용했는가 / 무엇을 고쳤는가
 · 계속 사용하고 싶은가

사용자용 (쉬운 말 + 그림 척도)
 · 화면을 이해하기 쉬웠는가
 · 다음에 뭘 해야 할지 알 수 있었는가
 · 보상이 있으면 더 하고 싶은가
 · 또 쓰고 싶은가
```

> **정량(수행률·만족도)과 정성(자유서술)을 함께** 받는다.
> 설문 결과 화면이 곧 실증보고서의 "진행 사진"이 된다 (3장 참고).

# 7. 우리가 더 잘할 수 있는 지점

| 축 | 역대 수상팀 | **ELUM이 더 나은 이유** |
| --- | --- | --- |
| **근거** | 개인 경험 · 당사자 인터뷰 | **전문기관 자문 + 행동분석 이론 정합성** — 이론까지 가진 팀은 없었다 |
| **AI 활용** | 해설 생성 · 행동 추천 | **과제분석 자동화** — 사람이 하던 인지 노동을 대체한다 |
| **피드백 반영** | 중간심사 후 반영 | **중간심사 전에 이미 한 사이클 돌았다** |
| **개인정보** | 다루지 않음 | 진단명 미수집 · 최소 정보 개인화 (발표에선 리스크 항목으로만) |
| **시각자료** | 픽토그램 · 사진 | **캐릭터 일관성 있는 AI 삽화** — 매 단계 같은 캐릭터가 등장 |

## 한 문장으로

> **"우리는 보호자가 매일 머릿속으로 하던 과제분석을 AI로 옮겼고,
> 그게 맞는 방향인지 행동중재 전문가에게 검증받아 이미 한 번 고쳤습니다."**

역대 어느 팀도 **"전문가에게 검증받고 구조를 바꿨다"** 를 중간심사에서 말하지 못했다.
토닥이는 중간심사에서 **지적을 받고** 바꿨고, 우리는 **미리 받아서** 바꿨다.
