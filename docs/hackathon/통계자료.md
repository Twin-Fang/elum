# 통계 자료 — 발표·제안서용

> 발표자료 「기획의도 및 필요성」과 개발노트·실증보고서에 쓸 숫자를 모아둔다.
> **반드시 출처와 연도를 함께 쓴다.** 역대 수상팀(캡픽·픽포미)의 공통점이 이것이었다.

---

# 1. 발달장애인 규모

| 지표 | 수치 | 출처 |
| --- | --- | --- |
| 등록장애인 전체 | **263만 1,356명** (전체 인구의 **5.1%**) | 보건복지부, 2024년 등록장애인 현황(2025.4 발표) |
| 지적장애 비중 | 전체 장애유형 중 **8.9%** (5위) | 동일 |
| 등록 발달장애인 | **약 25만 명** | 보건복지부, 2021년 발달장애인 실태조사 |
| 일상생활 도움 필요 | **22.5%** | 동일 |

---

# 2. 🎯 타겟 재정의를 뒷받침하는 숫자

> **소장님 자문의 "연령이 아니라 기능 수준" 주장이 통계로 증명된다.**

| 지표 | 수치 | 의미 |
| --- | --- | --- |
| **지적장애인 중위연령** | **33.8세** | **절반이 34세 이상 성인이다** |
| 자폐성장애인 중위연령 | 15.1세 | 아동·청소년 비중이 높다 |
| 자폐성장애인 중 아동청소년기 | **51%** | 절반은 성인 |

**출처**: 보건복지부, 2024년 등록장애인 현황

## 이 숫자가 발표에서 갖는 힘

```
"저희는 처음에 7~12세 아동을 대상으로 잡았습니다.
 그런데 지적장애인의 중위연령은 33.8세입니다. 절반이 성인입니다.
 자문에서 '생활연령과 발달연령은 다르다'는 지적을 받고,
 대상을 연령이 아니라 '행동 카드의 시각정보와 순서를 이해할 수 있는 발달장애인'으로 다시 정의했습니다."
```

> 자문 → 통계 → 설계 변경이 한 줄로 이어진다. **심사위원이 가장 좋아하는 구조다.**

# 3. 보호자 부담

| 지표 | 수치 | 출처 |
| --- | --- | --- |
| 발달장애인의 보호자가 **부모**인 비율 | **68.8%** (형제자매 7.9%) | 보건복지부, 2021년 발달장애인 실태조사 |
| 보호자 **우울 점수** | **19.43** (우울증 의심 기준 16 초과) | 동일 |
| 보호자 사후에 대한 막막함 | **34.9%** | 동일 |
| 미래에 대한 막연한 불안감 | 12.2% | 동일 |
| 코로나19로 가족 돌봄 시간 증가 | 32.6% (자폐성장애 **51.9%**) | 동일 |

## 활용 포인트

**보호자 우울 점수 19.43**이 가장 강한 숫자다. 임상적 우울증 의심 기준(16)을 넘는다.

```
"발달장애인 보호자의 우울 점수는 19.43으로, 우울증 의심 기준선을 넘습니다.
 그래서 저희는 보호자에게 무언가를 더 시키지 않는 방향으로 설계했습니다.
 온보딩은 네 단계를 넘지 않고, 보상 설정도 건너뛸 수 있습니다."
```

> **"보호자 부담 통계"를 제품 설계 근거로 직접 연결**하는 팀은 드물다.
> 숫자를 보여주고 끝내지 않고, 그래서 우리가 무엇을 하지 않았는지로 잇는다.

# 4. 아직 확보하지 못한 숫자

| 필요한 것 | 찾을 곳 |
| --- | --- |
| 발달장애인 스마트폰 보유·이용률 | 과기정통부 디지털정보격차 실태조사 |
| 성인 발달장애인 고용률·주간활동 참여율 | 한국장애인고용공단 EDI |
| 일과 수행에 도움이 필요한 비율(세부) | 2021·2024 발달장애인 실태조사 원문 |
| 그림교환·시각일정표 사용 실태 | 특수교육 관련 학술자료 |

> **스마트폰 이용률이 특히 중요하다.** "이 앱을 쓸 수 있는 사람이 얼마나 되는가"에 대한 답이고,
> 소장님이 말한 기능 수준 기준(스마트폰 조작 가능 여부)과 직결된다.

# 5. 출처 표기 형식

발표자료·제안서에 쓸 때는 아래 형식을 지킨다.

```
등록 발달장애인 약 25만 명 (보건복지부, 2021년 발달장애인 실태조사)
지적장애인 중위연령 33.8세 (보건복지부, 2024년 등록장애인 현황)
```

연도를 숨기면 최신 데이터인 척하는 것이 된다.
