# 3. ① 개발노트 (별첨 3) — 분량 적음

```
1. 주요 개발 내용
   · 보상(강화) 기능 — 설정·노출·수정
   · 일과 목록 정리 — 오늘/지난/임시저장
   · 추천 일과 개편 — 내면 조절 제거, 성인 일과 추가

2. 제안서 대비 변경사항 및 사유        ← 가장 중요
   · 타겟: 7~12세 아동 → 기능 수준 기준 발달장애인
   · 강화(보상) 기능 신규 추가
   · 행동 카드 단계 수 고정 해제
   · 추천 일과에서 내면 조절 항목 제거
   → 사유: 서울 ABA연구소 전문가 자문 (2026-09-13)

3. 기타 이슈 및 보고 사항
   · 실증 계획 — 10월, 서울 ABA연구소 협력
   · 인증·계정 구조 개편 예정 (실증 전)
```

> **2번을 숨기지 않는다.** 계획을 바꿨다는 사실보다 **왜 바꿨는지**가 중요하고,
> 전문가 자문이라는 근거가 있으면 오히려 강점이 된다.

# 5. ④ 시연 영상 — 가장 오래 걸린다

| 항목 | 내용 |
| --- | --- |
| 길이 | 2분 30초 |
| 녹화 | **실기기** 화면 녹화 (에뮬레이터 X) |
| 자막 | **필수** — 현장 스피커를 신뢰할 수 없다 |
| 나레이션 | 없음 — 발표자가 직접 설명하며 재생 |
| 강조 | 카드 생성 순간 · 캐릭터 일관 삽화에서 2초 정지 |
| 개인정보 | 실명·실제 학교명 입력 금지 (데모 페르소나 `하늘이`) |
| 백업 | 주요 장면 **스크린샷 5~6장**을 PPT에 별도 삽입 |

## 시나리오

```
보호자 온보딩 → 일과 입력 → AI 추가 질문 → 보상 설정
→ 카드 생성 → 검토·승인 → 아이 모드 전환
→ 카드 수행 (상단 보상 바) → 완료 → 보상
```

> ⏳ **보상 기능이 9/15에 완료되므로 9/16 저녁부터 녹화 가능하다.**
> 영상이 밀리면 7장이 비고 발표 리허설도 못 한다. **이 일정이 전체 병목이다.**
