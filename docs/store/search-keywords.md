## 칸별로 넣는 법

| 칸 | 넣는 것 |
|---|---|
| App Store 이름 (30) | 브랜드 + 핵심 1개 (`이룸 ELUM: 행동카드 만들기·일과표`) |
| App Store 부제 (30) | 대상 + 현장 (`발달장애·ADHD·ABA 특수교육 도우미`) |
| App Store 키워드 (100) | 이름·부제에 **없는** 나머지 전부, 쉼표만 (공백 없이) |
| Play 제목 (30) | 브랜드 + 핵심 + 대상 |
| Play 간단한 설명 (80) | 핵심 + 대상 + 현장을 한 문장으로 |
| 자세한 설명 | 모든 묶음을 **문장 안에** (Play 는 나열 금지) |
