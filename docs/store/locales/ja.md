## 자세한 설명 (두 스토어 공용, 4000)

```
ELUMは、毎日の生活を助ける行動カードアプリです。一日の日課を行動カード（絵の順番カード）で見せる、視覚的な日課表です。

保護者が「朝、顔を洗って服を着る」のように場面を書くと、まねしやすいステップに分けて行動カードにします。作ったカードは、保護者が確認してからElumiの画面に表示されます。

■ こんな方を思い浮かべて作りました
・文字より絵と順番のほうがわかりやすい、発達障害・自閉スペクトラムの当事者
・やることの順番をひと目で見たい、ADHD・学習障害の当事者
・一日の日課を一つずつ見守りたい保護者
・子育てや特別支援教育の現場で、行動カードや視覚的なスケジュールを使う先生

■ 行動カード一枚に、行動ひとつ
カードには一度にひとつの行動だけを入れます。絵と短い文で見せて、声に出して読み上げます。できたらチェックして、最後まで終えたら、あらかじめ決めたごほうびがもらえます。

■ こんな毎日に寄りそいます
登校の準備、朝のルーティン、洗顔と歯みがき、着替え、お出かけの準備、寝る前のルーティン、片づけなど、毎日くり返すことを視覚的なスケジュールにして見せます。

■ 保護者モードとElumiモード
・保護者モード：日課を作り、行動カードを直し、順番を変えます。今日どれだけできたかも見られます
・Elumiモード：今日やることを行動カードで一枚ずつ見てチェックします
・Elumiモードから保護者モードに戻るときは、パスコードが必要です
・端末を2台つなぐと、保護者が作った日課がElumiの端末に表示されます
・家族や先生を招待して、一緒に日課を見守れます

■ 毎日の日課はまとめて
前の日課をそのまま使えるので、毎日くり返す日課表もかんたんに準備できます。

■ 個人情報は書かないでください
カードを作るときに書いた内容はAIに送られます。名前、電話番号、住所など、人を特定できる内容は書かないでください。何を集めてどう扱うかは、アプリの設定とプライバシーポリシーに書いてあります。

お問い合わせ先は、アプリの設定画面の「お問い合わせ」で確認できます。
```
