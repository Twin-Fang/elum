## 자세한 설명 (두 스토어 공용, 4000)

```
ELUM 是一款帮助日常生活的行为卡片应用。它用行为卡片（图片顺序卡）展示一天的日常，是一份视觉日程表。

监护人写下“早上洗脸、穿衣服”这样的情境，ELUM 就会把它拆成容易跟着做的步骤，做成行为卡片。做好的卡片要经过监护人确认后，才会显示在 Elumi 的画面上。

■ 我们想着这些人做了 ELUM
· 比起文字，更容易理解图片和顺序的发育障碍、自闭症谱系当事人
· 想一眼看清要做的事和顺序的 ADHD、学习障碍当事人
· 想一步步陪伴一天日常的监护人
· 在育儿和特殊教育现场使用行为卡片和视觉日程表的老师

■ 一张卡片，一个行为
每张卡片只放一个行为。用图片和短句展示，并朗读出来。做完就打勾，全部完成后可以得到事先定好的奖励。

■ 陪伴这样的日常
上学准备、早晨日常、洗脸刷牙、穿衣服、出门准备、睡前日常、整理东西等，把每天重复的事做成视觉日程表来展示。

■ 监护人模式和 Elumi 模式
· 监护人模式：制作日常，修改行为卡片，调整顺序。也能看到今天完成了多少
· Elumi 模式：用行为卡片一张张查看今天要做的事并打勾
· 从 Elumi 模式回到监护人模式时需要密码
· 连接两台设备后，监护人制作的日常会出现在 Elumi 的设备上
· 可以邀请家人或老师一起照看日常

■ 每天的日常一次搞定
可以直接重复使用以前的日常，每天重复的日程表也能轻松准备。

■ 请不要填写个人信息
制作卡片时写下的内容会发送给 AI。姓名、电话号码、地址等能认出一个人的内容请不要填写。我们收集什么、如何处理，写在应用内设置和隐私政策中。

联系方式可以在应用设置画面的“联系我们”中查看。
```
