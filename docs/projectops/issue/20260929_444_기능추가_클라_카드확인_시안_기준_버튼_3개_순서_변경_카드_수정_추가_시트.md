📝 현재 문제점
---

- 보호자 카드확인 시안이 새로 나왔는데 앱은 예전 구성이다. **시안이 유일한 기준이다.**
- 하단이 알약 칩 하나(`이 카드 수정하기`)뿐이라 **카드 순서 변경과 카드 추가 진입점이 없다.** 서버에는 `PATCH /steps/order`, `POST /steps`가 이미 있는데 카드확인 화면에서 쓰지 않는다.
- 카드 수정 시트는 시안 없이 만든 것(#77)이라 새 시안과 다르다.
- 머리 문구·반짝임 색과 크기, 보상 줄 모양, 저장 버튼 문구, 카드 그림자, 상단 `임시저장`이 시안과 다르다.

🛠️ 해결 방안 / 제안 기능
---

시안 5장을 그대로 옮긴다. 시안끼리·시안과 앱이 어긋난 곳은 아래처럼 정했다.

| 어긋남 | 결정 |
|---|---|
| 머리 아래 `AI 그림 N장 · M크레딧`(#407) | 이 화면에서 뺀다 (새 시안에 없다) |
| 카드 추가의 그림 생성 선택 | 두지 않는다. 그림 없는 카드로 추가한다 (시안은 `추가하기` 하나) |
| 순서 변경 모드의 카드 X | 숨긴다 (시안 첫 카드에 없다) |
| 추가 시안의 잔재 `설명` 텍스트(`1197:6160`)와 `메일 복사 버튼` 이름 | 그리지 않는다 |
| 카드 그림자 | 넣는다. #401의 "없앰"을 새 시안이 뒤집었다 |
| 상단 `임시저장` | 홈 버튼과 같다: "임시저장에 두고 나갈까요?" 팝업 후 나간다 |
| 순서 저장 시점 | 로컬에 두고 `저장하기`에서 함께 보낸다. 서버가 카드 전체를 요구하는데 뺀 카드는 저장 때까지 서버에 남기 때문이다 |

설계 문서: `docs/superpowers/specs/2026-09-29-card-review-redesign-design.md`
