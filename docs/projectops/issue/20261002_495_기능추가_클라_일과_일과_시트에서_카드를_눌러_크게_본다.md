📝 현재 문제점
---

보호자 홈의 일과 시트(오늘 일과 행동단계)에서 카드는 작은 줄로만 보인다. 그림과 설명을 크게 보려면 방법이 없다. 디자이너가 **카드를 눌러 크게 보는 화면**을 새로 그렸다.

- Figma `이룸` 파일 `1274:8864` (`보호자_홈_오늘일과_행동단계`, 섹션 `309:2836`)
- 코드의 `routine_detail_sheet.dart`의 `_StepCard`에는 누름 동작이 없다.

![시안](https://github.com/Twin-Fang/elum/releases/download/qa-evidence/design1002_20261002-001733_issue_card_zoom.png)

🛠️ 해결 방안 / 제안 기능
---

- 시트의 카드를 누르면 **큰 카드 보기**를 연다. 화면 뒤는 어둡게 깔고, 오른쪽 위에 `✕`를 둔다.
- 큰 카드는 카드 확인 화면의 카드와 같은 모양이다: 그림, 번호 배지와 제목, 스피커와 설명. 옆 카드가 좌우로 살짝 보여 넘겨 볼 수 있게 한다.
- 카드 색은 번호 색(민트, 파랑, 주황, 노랑 순환)을 그대로 따른다.
- `✕`를 누르면 시트로 돌아온다.
- 보상 줄(`유튜브 시청 20분`)은 카드가 아니므로 누르지 않는다.
- 지난 일과 시트(`1274:8038`)에서도 같은 동작이 맞는지 확인한다.

⚙️ 작업 내용
---

- 큰 카드 보기 위젯 추가, 카드 확인 화면의 카드 위젯 재사용 가능 여부 확인
- 시트 `_StepCard` 에 누름 동작 연결 (오늘 일과, 지난 일과)
- 시안 대조 테스트에 `1274:8864` 추가, 열기 닫기 넘기기 위젯 테스트
- 그림이 없는 카드(그림 없는 기본 카드)와 설명이 긴 카드에서 화면이 깨지지 않는지 확인

확인이 필요한 것
---

- 스피커 아이콘이 있는데, 누르면 읽어 주는 기능인지 모양만인지 (이룸이 화면의 카드와 같은 동작이어야 한다)
- 바깥을 눌러도 닫히는지 (시안은 `✕`만 그림)
- 설명 글자가 길 때 카드 안에서 스크롤인지 잘림인지 (시안은 한 줄 설명만 그림)
