📝 현재 문제점
---

이룸이가 일과에 들어가 행동카드를 체크하면 **별 화면이 뜨고, 닫으면 방금 끝낸 카드가 그대로 남습니다.** 다음 카드로 가려면 화면을 옆으로 밀어야 합니다.

**지금 흐름** (`child_routine_detail_screen.dart`)

```
카드 체크 → 컨페티 → (잠깐 기다림) → 별 화면 push
          → 이룸이가 버튼을 눌러 닫음 → 방금 체크한 그 카드로 돌아옴
          → 다음 카드는 직접 밀어야 나온다
```

**이룸이에게 이 마지막 한 걸음이 부담입니다.**

- 저장소 규칙은 **한 화면에 행동 하나**입니다. 체크가 끝난 카드가 계속 떠 있으면 지금 할 일이 무엇인지 흐려집니다.
- 옆으로 미는 동작(스와이프)은 누르기보다 어렵습니다. 터치 타겟을 64×64로 크게 잡는 것과 같은 이유입니다.
- 해냈다는 연출(별)까지 보고 나면 다음 행동으로 이어져야 하는데, 거기서 흐름이 끊깁니다.

**참고 — 이미 되어 있는 것과 안 되어 있는 것을 나눕니다.**

| | 상태 |
|---|---|
| 카드마다 별 화면이 뜬다 | ✅ 이미 그렇습니다 (`shouldReward = !wasChecked && !rewarded.contains(card.id)`) |
| 별 화면에 보호자가 정한 보상이 함께 보인다 | ✅ 이미 그렇습니다 (#239) |
| **별 화면 뒤 다음 카드로 넘어간다** | ❌ **없습니다. 이번에 만듭니다** |

> 곁가지로 `_toggle`의 주석이 사실과 다릅니다. "마지막 카드를 끝냈으니 보상을 함께 보여준다"고 적혀 있지만 **실제로는 카드마다** 뜹니다. 이번에 함께 고칩니다.

🛠️ 해결 방안 / 제안 기능
---

**별 화면이 닫히면 다음 카드로 자동으로 넘어갑니다.**

```
카드 체크 → 컨페티 → 별 화면 → (닫힘) → 다음 카드가 스르륵 나타난다
```

- 전환은 **애니메이션으로** 보여줍니다. 갑자기 바뀌면 이룸이가 무엇이 일어났는지 모릅니다. 저장소 규칙대로 **300ms 이상**을 씁니다.
- **동작 줄이기(Reduce Motion)** 가 켜져 있으면 애니메이션 없이 바로 바꿉니다. 지금 컨페티를 생략하는 것과 같은 방침입니다.

### ✋ 정해야 할 것 둘

**1) 별 화면을 어떻게 닫을까요**

| 안 | 내용 | |
|---|---|---|
| **가** | 지금처럼 **버튼을 눌러** 닫는다 | 이룸이가 별을 충분히 보고 스스로 넘어갑니다. 누르는 동작이 한 번 더 필요합니다 |
| **나** | **몇 초 뒤 저절로** 닫힌다 | 아무것도 누르지 않아도 진행됩니다. 별을 덜 본 채 지나갈 수 있습니다 |
| **다** | 저절로 닫히되 **누르면 즉시** 넘어간다 | 둘을 합친 안입니다 |

**2) 마지막 카드를 끝냈을 때는 어디로 갈까요**

| 안 | 내용 |
|---|---|
| **가** | 일과 상세에 그대로 머문다 (지금 동작) |
| **나** | 일과 목록(홈)으로 돌아간다 |
| **다** | "다 했어요" 화면을 따로 보여준다 |

**실패·경계 경로** (설계에 함께 넣습니다)

| 상황 | 어떻게 |
|---|---|
| 마지막 카드를 체크했다 | 다음 카드가 없습니다 → 위 2)에서 정한 대로 |
| 이미 체크한 카드를 다시 체크했다 | 별 화면이 뜨지 않습니다(`rewarded`에 이미 있음). 이때도 넘길지 정해야 합니다 |
| 중간 카드를 건너뛰고 뒤 카드를 체크했다 | "다음"이 무엇인지 — 바로 다음 순서인지, 아직 안 한 것 중 가장 앞인지 |
| 체크를 해제했다 | 넘어가지 않습니다. 되돌리는 동작에서 화면이 움직이면 더 헷갈립니다 |
| 별 화면이 떠 있는 동안 뒤로가기를 눌렀다 | 전환이 두 번 일어나지 않게 막습니다 |
