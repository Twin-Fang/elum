# 🚀[기능개선][서버][공지] 공지를 휴대폰 언어별로 보여주기

📝 현재 문제점
---

- 영어 휴대폰으로 보호자 화면에 처음 들어가면 공지 팝업 2개가 한국어로 뜬다 (#529 운영 실기 확인 중 발견).
  - 개인정보처리방침 변경 안내 ("개인정보처리방침이 10월 22일에 바뀌어요…", 버튼 "방침 보기")
  - 베타 서비스 오픈 안내 ("[ 이룸 베타 서비스 오픈 안내 ]")
- 공지(`AppNotice`)에 언어 구분이 없다. 관리자가 쓴 한국어 본문 하나를 모든 휴대폰에 그대로 보낸다.
  - `server/src/main/java/com/chuseok22/elumserver/notice/infrastructure/entity/AppNotice.java`
  - `server/src/main/java/com/chuseok22/elumserver/notice/application/controller/NoticeController.java`
  - `server/src/main/java/com/chuseok22/elumserver/admin/application/controller/AdminNoticeController.java`
  - 클라 표시: `client/lib/features/notice/presentation/notice_popup.dart`
- 운영에서 영어 일과를 켰으므로(`ENABLED_CONTENT_LOCALES=ko,en`) 영어 사용자가 첫 화면에서 읽지 못하는 팝업을 보게 된다.

🛠️ 해결 방안 / 제안 기능
---

- 공지를 언어별로 쓸 수 있게 한다 (제목, 본문, 버튼 이름).
- 휴대폰 화면 언어에 맞는 공지를 보낸다. 그 언어 본문이 없으면 정할 것: 보내지 않기 또는 한국어로 보내기.
- 관리자 공지 화면에서 언어별로 입력하고 미리 본다.
- 기존 한국어 공지는 그대로 한국어 공지로 남는다.

⚙️ 작업 내용
---

- 공지 언어 구분 추가 (DB 변경 포함)
- 공지 조회 시 휴대폰 언어 반영, 없는 언어일 때의 동작
- 관리자 공지 화면 언어 입력
- 운영 공지 2건 영어 본문 작성
