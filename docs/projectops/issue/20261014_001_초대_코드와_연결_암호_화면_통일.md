📝 현재 문제점
---

- **초대 코드 화면**에는 "링크로 보내기"만 있고 코드 복사가 없다. **이룸이 휴대폰 연결 화면**에는 링크도 복사도 없다. 같은 일(여섯 글자를 다른 휴대폰에 전하기)을 하는 두 화면의 기능이 다르다.
- 두 화면의 문구와 버튼이 다르다: "초대 코드 다시 만들기"와 "코드 다시 만들기", 아래 안내 유무, 머리말 구성.
- 화면을 나갔다 들어오면 코드가 새로 만들어지고 앞 코드는 못 쓰게 된다. 그래서 코드를 전하는 동안 이 화면을 계속 띄워 둬야 한다. 명세(multi-guardian E9)는 "다시 발급하면 이전 미사용 코드는 폐기"만 정했고, 들어올 때마다 발급하라는 규칙은 없다.

🛠️ 해결 방안 / 제안 기능
---

- 두 화면 모두 **"링크로 보내기"와 "코드 복사하기"**를 둔다. 버튼 이름, 다시 만들기 이름, 안내 문구, 배치를 같은 부품으로 맞춘다.
- 연결 암호도 링크로 보낼 수 있게 한다. 이룸이 휴대폰에서 링크를 열면 연결 암호 화면에 암호가 채워진다(로그인 없이).
- **유효한 코드가 있으면 다시 들어와도 그 코드를 보여 준다.** 서버에는 아직 살아 있는지만 묻고, 없거나 쓰였으면 새로 만든다. 다시 만들기는 사용자가 누를 때만 한다.
