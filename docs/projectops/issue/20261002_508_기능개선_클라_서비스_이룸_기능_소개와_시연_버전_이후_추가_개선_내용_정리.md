## 1. 이룸은 어떤 앱인가

보호자가 평소 말하듯 입력한 일과를, **이룸이**(앱을 쓰는 당사자)가 하나씩 따라 할 수 있는 **행동 카드**로 바꿔 주는 앱이다.

- 대상: 그림과 순서를 이해할 수 있는 발달장애인. 나이로 나누지 않는다.
- 하나의 앱 안에 **보호자 화면**과 **이룸이 화면**이 있고, 비밀암호로 전환한다.
- 흐름: 일과 입력 → 추가 질문 → 카드 생성(문장 + 그림) → **보호자 확인·수정** → 이룸이가 카드를 한 장씩 수행 → 완료하면 보상
- 서비스 원칙: 진단명·장애 유형을 받지 않는다 / 이룸이 화면에는 보호자가 확인한 결과만 나온다 / 한 카드에는 행동 하나 / 어떤 실패에도 화면이 끝까지 이어진다.

| 구분 | 주요 기능 |
|---|---|
| 보호자 화면 | 일과 만들기, 카드 확인·수정·추가·순서 바꾸기, 임시저장, 보상 설정, 지난 일과, 이룸이 연결·관리, 설정 |
| 이룸이 화면 | 오늘 일과 카드 넘겨 보기(그림 + 짧은 문장 + 음성), 카드 완료 체크, 완료 별, 보상 확인, 일과완료 |
| 관리자 화면 | 회원·일과·AI 호출·크레딧·공지·점검·강제 업데이트·시스템 설정 운영 |

## 2. 처음(시연 버전)과 지금

| 영역 | 처음 | 지금 |
|---|---|---|
| 보상 | 카드를 끝낼 때 앱 안의 별만 받음 | 일과마다 보호자가 **실제 보상**을 정하고, 이룸이가 수행하는 동안 계속 볼 수 있음 |
| 카드 수 | 5장 고정 | 일과에 맞춰 단계 수가 달라지고, 보호자가 카드를 추가·삭제·순서 변경 |
| 카드 그림 | 미리 만든 그림 위주 | AI 그림, 무료 픽토그램, 직접 찍은 사진·갤러리 사진으로 바꾸기, 그림 방식(만화·실사·직접 사진) 선택 |
| 로그인 | 이름·비밀번호 가입 | 소셜 로그인(카카오·네이버·애플), 첫 화면에서 바로 로그인 |
| 사용자 구조 | 보호자 1명 + 이룸이 1명 | 이룸이 한 명에 **보호자 여럿**, 초대 코드로 합류, 보호자 계정과 이룸이 프로필 분리 |
| 이룸이 휴대폰 | 같은 휴대폰에서 모드 전환 | 이룸이 휴대폰을 **6자리 연결 암호**로 따로 연결·해제 |
| 일과 목록 | 단순 목록 | 오늘 일과 / 지난 일과, 임시저장, 밀어서 지우기, 일과 시트에서 순서 바꾸기 |
| 개인정보 보호 | 보호자 입력을 마스킹해 AI로 보냄 | 마스킹 방식은 쓰지 않음. 이룸이 이름·보호자 원문이 AI·로그·캐시에 남지 않게 정리하고 약관·방침에 사실대로 안내 |
| 문구 | "아이" 중심 | **이룸이** 호칭, 해요체·능동형 문구로 통일 |
| 디자인 | 기능 위주 화면 | 새 시안으로 전 화면 재정리, 시안과 화면을 값으로 대조하는 도구 도입 |
| 운영 | 개발자 도구 중심 | 관리자 콘솔 개편, 점검 모드·강제 업데이트·공지, AI 크레딧, 제공자 전환 |

## 3. 추가된 기능 (영역별)

### 보상과 일과
- 일과별 **보상 설정**(보호자가 정함, 앱은 보여주기만 함)과 이룸이 화면 3곳 노출
- 카드를 체크하면 별을 보여준 뒤 다음 카드로 이동
- 이룸이가 일과를 다 끝내면 **일과완료 화면**
- 일과를 누르면 바텀시트로 열고, 카드를 눌러 크게 보기, 길게 눌러 단계 순서 바꾸기(번호는 제자리 고정)
- 만들다 나가면 **임시저장**에 남고 이어서 만들기, 밀어서 지우기(지우기 전 확인)
- 지난 일과 보기, 오늘 일과 자동 초기화
- 로딩 연출이 실제 걸린 시간을 따라가도록 개선, 인터넷이 끊기면 자동 재시도

### 카드
- 보호자 **카드 추가·순서 변경·삭제 확인**, 추가 시 AI 그림까지 생성
- **무료 픽토그램** 그림 자리 표시와 출처 표기(이용약관에 안내)
- 카드 그림을 **카메라·갤러리 사진**으로 교체, 그림 방식(만화·실사·직접 사진)을 온보딩·설정에서 선택
- 카드 설명을 짧게 만들도록 생성 규칙 정리, 고른 캐릭터가 그림에 나오도록 수정
- 그림이 기기에 저장되어 다시 열거나 오프라인이어도 보임, 서버가 재배포되는 중에도 그림 재시도
- 카드 확인 화면 재구성, 카드 넘기기에서 양옆 카드가 살짝 보임

### 계정·보호자·이룸이
- 소셜 로그인(카카오·네이버·애플), 최근 로그인 표시, 로그아웃·회원탈퇴·계정 전환 시 이전 계정 정보 정리
- **이룸이 한 명에 보호자 여럿**: 초대 코드·링크로 합류, 나가기, 이룸이를 바꿔 보기
- 이룸이 휴대폰 연결(6자리 암호 발급·검증·끊기), 이룸이 휴대폰 안에 설정 페이지
- 보호자 화면 **비밀암호** 설정·변경, 암호가 없는 휴대폰 보호
- 탈퇴를 소프트 삭제로 바꿔 보관 기간 관리, 약관 동의 흐름(전체 동의·선택 항목)

### AI 크레딧·광고·요금
- 회원별 **주간 AI 크레딧**(일과 글·그림 생성에 사용), 잔액·다음 초기화 표시
- 크레딧이 없을 때 **광고를 보고 더 만들기**(보상형 광고, 서버가 시청을 검증)
- 보호자 화면 광고(배너·목록 내 광고, 이룸이 화면은 제외)
- 글·그림 생성 제공자를 관리자에서 전환

### 운영·안정성
- 관리자 콘솔 개편(회원, 일과 목록 페이지 나누기, AI 호출 로그, 크레딧, 공지·이벤트 미리보기)
- **점검 모드, 강제 업데이트**(스토어 주소를 관리자에서 변경), 앱 공지 팝업(일주일간 보지 않기)
- 약관·개인정보처리방침을 서버에서 관리하고 앱은 캐시로 읽음
- 서버 에러를 앱 전역에서 받아 **에러 코드**와 함께 안내, 실패를 실패로 보여주기
- 서버를 여러 대로 늘려도 깨지지 않도록 저장 지점 분리, 배포 자동화(테스트 빌드·스토어 제출·비공개 테스트 트랙)

### 디자인
- 새 시안으로 전 화면 정리: 스플래시·로그인·역할 선택·온보딩·홈·일과·보상·설정
- 공통 팝업·스낵바·바텀시트 통일, 글꼴을 가장 크게 해도 깨지지 않게 보정

## 4. 아직 구현하지 않고 남겨 둔 것 (고려 중)

| 항목 | 내용 | 비고 |
|---|---|---|
| 수행률 리포트 | 이룸이가 어디까지 했는지 기간별로 보여주기 | 완료 데이터는 이미 쌓임 |
| 행동 시작 알림 | 다른 활동 중에도 일과 시작을 상기 | 알림 권한 거부 시 우회 경로 필요 |
| 보호자용 보상 안내 문구 | "보상이란?" 짧은 안내와 예시 | 디자인 협의 필요 |
| 온보딩 최소화 | 처음 입력 항목을 더 줄이기 | 일부는 시작하기 화면 제거로 반영 |
| 요금제 | 무료/Pro에 따른 광고·크레딧 차등 | 서버에 권한 값 구조만 있고 결제 연동은 정해지지 않음 |
| 보상 이미지 | 글을 읽지 못하는 이룸이를 위한 보상 그림 | 입력 부담과 함께 검토 |
