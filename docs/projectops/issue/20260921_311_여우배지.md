📝 현재 문제점
---

**보호자 홈 오른쪽 위 여우 배지가 둥근 사각형 밖으로 삐져나옵니다.** 아래 가장자리가 톱니처럼 깨져 보입니다. 고양이 배지는 멀쩡합니다.

**원인은 마스크입니다.**

| 에셋 | `<mask>` 개수 |
|---|---|
| 고양이 (`character_badge_framed_ruru`) | **1** |
| **여우** (`character_badge_framed_popo`) | **3** |

`flutter_svg`가 겹친 마스크를 온전히 그리지 못해 잘려야 할 부분이 남습니다. **시안(`382:3257`)에서 다시 받아도 마스크는 그대로 셋**이라 에셋 교체로는 풀리지 않습니다.

🛠️ 해결 방안 / 제안 기능
---

**그리는 쪽에서 잘라냅니다.** 배지는 모서리 16의 둥근 사각형이므로 그 모양으로 잘라내면 밖으로 나간 부분이 보이지 않습니다.

- 에셋을 손으로 평탄화하는 방법도 있지만, **디자이너가 다시 내보낼 때마다 되돌아갑니다**
- PNG로 바꾸는 방법은 화면 배율마다 흐려집니다

⚙️ 작업 내용
---

- [ ] 배지를 둥근 사각형으로 잘라낸다
- [ ] 이룸이 홈에도 같은 배지가 있는지 확인
- [ ] 실기기에서 여우·고양이 둘 다 확인
