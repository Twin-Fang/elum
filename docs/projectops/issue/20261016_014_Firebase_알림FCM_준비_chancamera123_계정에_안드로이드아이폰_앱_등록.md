📝 현재 문제점
---

- 앱에는 알림(푸시)이 없다. 보호자가 이룸이의 일과 완료나 연결 소식을 앱을 열어야만 안다.
- Firebase는 안드로이드 테스트 배포(App Distribution)에만 쓰고 있고, 알림용 설정이 없다. 안드로이드 앱 `kr.twinfang.elum`과 아이폰 앱 `kr.twinfang.elum`이 알림용으로 등록돼 있지 않다.
- 알림을 보내려면 서버에 보낼 수 있는 권한(서비스 계정)과 기기 쪽 설정 파일이 필요한데 어디에도 없다.

🛠️ 해결 방안 / 제안 기능
---

- 개발자 계정 `chancamera123@gmail.com`(AdMob과 같은 계정)의 Firebase에 이룸 프로젝트를 만들고 안드로이드·아이폰 앱을 등록한다.
  - 안드로이드: 패키지 `kr.twinfang.elum`, 설정 파일 `google-services.json`
  - 아이폰: 번들 `kr.twinfang.elum`, 설정 파일 `GoogleService-Info.plist`
- 클라우드 메시징을 켜고 아이폰 알림 키(APNs)를 올린다. 키는 애플 개발자 계정에서 만들어야 한다.
- 설정 파일과 서버용 서비스 계정 키는 저장소에 올리지 않고 GitHub Secrets로 관리한다(기존 방식).
- 이 이슈는 **준비**까지다. 어떤 알림을 언제 보낼지(예: 이룸이가 일과를 끝냈을 때)와 알림 화면·문구는 디자인과 정책을 정한 뒤 후속 이슈로 나눈다.
