📝 현재 문제점
---

일과 시트의 **상단 모서리가 각져 있었는데 대조 도구를 돌리고도 못 찾았습니다.**
시트는 대조 장치에 이미 올라가 있었고(`일과 시트 (Figma 956:4084)`), diff도 돌아갔습니다.

**도구는 사실 리포트했습니다.**

```
다른 덩어리 22개 (넓이 200 이상, 위에서부터)
         y범위           x범위          크기  평균차
  ...
  476~519         0~785      786x44     77     ← 이게 그 모서리다
  ...
다른 픽셀   66,849 / 1,213,584  (5.51%)
```

`476~519 / 0~785` 가 시트 상단 전체 폭입니다. 그런데 이 한 줄만 보고
"모서리가 각졌다"를 읽어낼 수 있는 사람은 없습니다. **좌표와 평균차만 있고
무엇이 어떻게 다른지가 없습니다.**

**실측 (786폭, 시트 top y=476)**

| | y+2 | y+6 | y+12 | y+20 | y+30 |
|---|---|---|---|---|---|
| 시안 | x≥28 부터 채움 | x≥18 | x≥12 | x≥6 | x≥2 |
| 렌더 | **x=0 부터 채움** | x=0 | x=0 | x=0 | x=0 |

시안은 20 곡선을 그리며 들어오는데 렌더는 첫 줄부터 직각으로 꽉 찹니다.
Figma 원본도 명시하고 있습니다 — 헤더 배경(`980:4891`)의
`rectangleCornerRadii: [20, 20, 0, 0]`.

### 왜 못 읽었나 — 세 가지가 겹쳤습니다

**1. 전체가 5.51% 다르고 덩어리가 22개다.** 진짜 결함이 잡음에 묻힙니다.
   시트가 시안보다 **1px 아래**에 있어서(top 476 vs 477) 글자·줄·버튼이 전부
   조금씩 어긋나 보이고, 그 미세한 밀림이 덩어리 수를 부풀립니다.

**2. 덩어리에 이름표가 없다.** `786x44 평균차 77` 이 모서리인지, 그림자인지,
   글자가 밀린 것인지 구분이 안 됩니다. 사람이 매번 diff 이미지를 열어
   눈으로 찾아야 하는데, 22개를 다 열어보지는 않습니다.

**3. 모서리는 작다.** 20×20 영역이라 덩어리 넓이 순으로 보면 뒤로 밀립니다.
   실제로는 시트 상단 가장자리와 하나로 합쳐져 "전체 폭 띠"로 보고돼
   더 헷갈렸습니다.

🛠️ 해결 방안 / 제안 기능
---

`client/tool/figma_diff.py` 를 **"어디가 다른가"에서 "무엇이 다른가"로** 끌어올립니다.

### 1. 전역 밀림을 먼저 보정한다

세로로 1~2px 통째로 밀린 것은 대개 한 가지 원인입니다. 보정 전에는 화면 전체가
붉어져 나머지가 안 보입니다.

- 렌더를 ±4px 범위에서 움직여 보며 차이가 가장 작아지는 지점을 찾는다
- 그 오프셋을 **먼저 보고**하고(`시트가 1px 아래에 있다`), 보정한 뒤 남은 차이를 낸다

이것만으로 22개 덩어리가 크게 줄어듭니다.

### 2. 덩어리에 이름표를 붙인다

각 덩어리가 무엇인지 한 단어로 분류합니다.

| 판정 | 근거 |
|---|---|
| `모서리` | 덩어리가 어떤 사각 영역의 꼭짓점에 붙어 있고, 한쪽은 배경 한쪽은 채움 |
| `가장자리` | 가로/세로로 길고 얇다 (밀림·두께 차이) |
| `면` | 넓고 평균차가 낮다 (색 차이) |
| `글자` | 좁고 평균차가 높으며 여러 개가 한 줄에 늘어선다 |

### 3. 모서리 전용 검사를 따로 둔다

이번 결함의 본질은 **"둥글어야 할 곳이 각졌다"** 입니다. 일반 diff로는 잡기 어렵지만
전용 검사로는 한 줄로 드러납니다.

- 시안에서 큰 면(시트·카드·버튼)의 경계를 찾고 네 모서리를 샘플링한다
- 시안이 "배경"인 자리에서 렌더가 "채움"이면 **`모서리 각짐`** 으로 보고한다
- 반대면 `모서리 과도함`

```
⚠️ 모서리 각짐  시트 상단 좌/우 — 시안 반지름 ≈20, 렌더 ≈0
```

### 4. 차이가 너무 크면 대조를 멈추고 먼저 경고한다

5% 를 넘으면 십중팔구 **내용이 다른 것**(데이터가 시안과 다름)이라 좌표 비교가
무의미합니다. 그 상태로 22줄을 뽑아 봐야 아무도 안 읽습니다.

```
❌ 전체의 5.5% 가 다릅니다. 내용이 시안과 같은지 먼저 확인하세요.
   (덩어리 목록은 --force 로 볼 수 있습니다)
```

### 5. 종료 코드를 준다

지금은 사람이 읽어야만 압니다. 심각도가 있으면 non-zero 로 끝내 CI 나 스크립트가
붙잡을 수 있게 합니다.
