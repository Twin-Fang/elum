📝 현재 문제점
---

- 책임이 섞인 큰 파일이 있다.

  | 파일 | 줄 수 | 섞인 책임 |
  |---|---|---|
  | `routine_repository.dart` | 968 | 요청, 저장소, provider 8개, 회원 정보 |
  | `routine_notifier.dart` | 831 | 입력, 질문, 보상, 생성, 리뷰 |
  | `local_storage.dart` | 784 | 인터페이스 1개에 메서드가 몰려 있고 구현체 2개가 한 파일에 있다 |
  | `app_router.dart` | 633 | 화면 약 33개 정의 |
  | `dev_tools_overlay.dart` | 946 | 개발 도구 화면 12개 이상 |

- 화면이 저장소를 직접 부르는 곳이 27곳이다(로그인, 동의, 역할 선택, 화면 전환 등). 화면 build에 로직을 두지 않는다는 규칙과 어긋난다.
- 로그인 버튼의 제공자 이름(`'카카오'` 등)이 코드에 한글로 박혀 있다. 문구는 ARB에만 둔다는 규칙과 어긋난다.

🛠️ 해결 방안 / 제안 기능
---

- 위 파일을 책임별로 나눈다.
- 화면마다 Controller(Notifier)를 두어, 화면은 상태를 보고 동작을 부르기만 하게 한다.
- 라우트는 기능별로 나눠 정의하고 core에서 합친다.
- 제공자 이름을 ARB 문구로 옮긴다. 5개 언어 패리티를 지킨다.
