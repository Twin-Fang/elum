🗒️ 설명
---

**심각도: 높음 (운영 배포 앱).** 이룸이 휴대폰에서 로그아웃하면 연결 코드 입력 화면에 갇힌다. 뒤로가기를 눌러도 같은 화면만 다시 나오고, 로그인 화면으로 갈 방법이 없다. 앱을 다시 켜도 같은 화면에서 시작한다.

원인 (develop `c7d8faf3` 기준)

1. 이룸이 설정의 로그아웃과 회원탈퇴는 토큰만 지우고 `이룸이 휴대폰` 표식과 역할(`elumi`)은 남긴다 (`device_link_repository.dart` `releaseThisPhone`). 그래서 로그인 화면이 아니라 연결 코드 화면으로 보낸다.
2. 연결 코드 화면으로 보낼 때 `goToLinkEnter`는 뒤로가기 자리로 역할 선택 화면을 깔아 둔다 (`app_router.dart` `linkEnterStack`). 그런데 역할 선택은 로그인해야 열리는 화면이다. 토큰이 없으면 라우터 가드가 이 화면을 다시 연결 코드 화면으로 바꾼다.
3. 그 결과 화면 스택이 `[코드 화면, 코드 화면]`이 된다. 뒤로가기를 한 번 누르면 같은 화면이 나오고, 한 번 더 누르면 돌아갈 곳이 없다.

같은 결함이 나타나는 경로 (코드로 확인)

| 경로 | 지금 | 기대 |
| --- | --- | --- |
| 이룸이 설정 → 로그아웃 | 코드 화면에 갇힘 | 로그인 화면 |
| 이룸이 설정 → 회원탈퇴 (이 휴대폰의 연결만 끊음) | 코드 화면에 갇힘 | 로그인 화면 |
| 보호자가 연결을 끊음 → 이룸이 휴대폰 세션 종료 | 코드 화면에 갇힘 | 코드 화면에 `연결이 끊어졌어요`가 나오고, 뒤로가기는 로그인 화면 |
| 세션이 끊긴 이룸이 휴대폰을 다시 켬 | 코드 화면에 갇힘 | 위와 같음 |

함께 찾은 결함

- **로그아웃했던 사람이 다시 로그인하면 역할 선택을 건너뛰고 보호자 온보딩(이름 입력)으로 간다.** 약관에는 동의했지만 이룸이 정보가 없는 계정(이룸이로 가입했던 계정이 그렇다)은 로그인 결과가 `onboarding`이고, 로그인 화면이 곧장 이름 입력으로 보낸다. 이룸이로 쓰던 사람이 이룸이를 다시 고를 길이 없다.
- 연결 코드 화면의 뒤로가기는 돌아갈 곳이 없을 때를 따로 처리하지 않는다. 앞으로 어떤 경로로 들어와도 막다른 화면이 되지 않게 막아야 한다.

왜 지금까지 안 걸렸나

- 테스트는 깔아 둘 화면 목록이 `[역할 선택, 코드 화면]`인지와 라우터 가드를 따로따로 확인했다. 둘을 함께 돌린 결과(가드가 역할 선택을 코드 화면으로 바꾸는 것)는 아무 테스트도 보지 않았다.
- #363 커밋에 "앱 전체를 띄운 세션 만료 경로는 함수 단위로만 검증, 실제 휴대폰으로 밟기 못 함"이라고 적혀 있다. 로그아웃 다음 뒤로가기는 실기기에서 한 번도 밟지 않았다.
- #206의 전제(이룸이 휴대폰에는 로그인할 계정이 없어 로그인 화면이 막다른 길)가 지금 흐름과 맞지 않는다. 지금 이룸이 휴대폰도 소셜 로그인 → 약관 → 역할 선택 → 연결 순서로 들어온다.

🔄 재현 방법
---

1. 새 휴대폰에서 소셜 로그인 → 약관 동의 → 역할 선택 `이룸이`
2. 보호자 휴대폰에서 받은 코드를 넣어 연결
3. 이룸이 화면 → 설정 → 로그아웃 → 확인
4. 연결 코드 화면이 뜬다. 뒤로가기를 누르면 같은 화면이 다시 나오고, 한 번 더 누르면 반응이 없다.
5. 앱을 껐다 켜도 같은 화면에서 시작한다.

✅ 예상 동작
---

- 이룸이 휴대폰에서 직접 로그아웃하거나 회원탈퇴하면 로그인 화면으로 간다. 이 휴대폰에 남은 이룸이 표식과 역할도 지운다.
- 보호자가 연결을 끊어 세션이 끝나면 연결 코드 화면에서 `연결이 끊어졌어요`를 보여 준다. 뒤로가기는 로그인 화면으로 간다.
- 연결 코드 화면은 어떤 경로로 들어와도 뒤로가기로 나갈 수 있다.
- 다시 로그인했는데 이룸이 정보가 없는 계정이면 역할 선택부터 묻는다.
- 실기기 E2E(새로 만든 에뮬레이터, 계정 둘)로 위 경로를 전부 밟아 확인한다.
