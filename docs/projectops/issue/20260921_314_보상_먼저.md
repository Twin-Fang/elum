📝 현재 문제점
---

**보상을 AI에 다녀온 뒤에 묻습니다.** 먼저 물어야 합니다.

지금 흐름입니다.

```
입력 → 로딩(AI 질문 생성) → 추가질문 → 보상입력 → 로딩(AI 카드 생성) → 카드확인
                                    ↑ 여기서 묻는다
```

**AI를 한 번 다녀온 뒤에 보상을 묻는 셈**이라, 보호자는 기다린 다음에 또 입력해야 합니다. 보상은 AI가 만들어 주는 것이 아니라 보호자가 정하는 값이므로, **기다리기 전에 받아 두는 편이 낫습니다.**

🛠️ 해결 방안 / 제안 기능
---

**보상을 맨 앞으로 옮깁니다.**

```
입력 → 보상입력 → 로딩(AI 질문 생성) → 추가질문 → 로딩(AI 카드 생성) → 카드확인
        ↑ AI 에 가기 전에 묻는다
```

**볼 것**

| | |
|---|---|
| 건너뛰기 | 보상은 없어도 된다(#308). 건너뛸 수 있어야 한다 |
| 뒤로가기 | 보상에서 뒤로 가면 입력 화면으로 — 적던 글이 남아야 한다 |
| 카드 확인의 보상 줄 | 지금 카드 확인에서 보상을 다시 고칠 수 있다. 그대로 둘지 |
| 임시저장 | 보상만 정하고 나가면 어디까지 저장되나 |
