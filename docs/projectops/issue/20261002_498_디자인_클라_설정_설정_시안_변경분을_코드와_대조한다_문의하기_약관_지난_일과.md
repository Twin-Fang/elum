### 1. `문의하기` 프레임은 흐린 잔재다 (조치 없음, 확인만)

- 시안 `1045:5005`(문의하기 시트)는 프레임 불투명도가 **10%** 로 남은 옛 프레임이고, 최신 설정 `1022:4467`에는 `문의하기`가 없다.
- 코드는 일부러 뺀 상태이고(#312) 2026-09-27 에 시안에서도 빼기로 합의했다(`settings_conformance_test.dart` 주석). 따라서 코드는 그대로 둔다.
- 디자이너에게는 흐린 옛 프레임(`1045:5005`)을 지우거나 `보관` 표시를 해 달라고 요청한다. 계속 남아 있으면 같은 오해가 반복된다.
- 새 설정 시안(`1022:4467`)에 `함께하는 사람`, `앱 정보 버전정보`가 그려져 있다. 개발이 임시로 넣은 줄(#362, #418)을 디자이너가 받아들인 것으로 보이므로, 설정 대조 테스트의 `알려진 차이` 주석을 새 export 로 다시 맞대 정리한다.

### 2. 약관 목록과 상세 프레임이 새 id 로 옮겨졌다

- 옛 `1027:4683`(약관 목록)은 이제 `비밀암호 변경` 프레임이 됐고, 약관 목록은 `1274:9315`, 상세는 `1274:9342` 로 새로 그려졌다 (옛 상세는 `1027:4831`).
- 상세 본문이 시안은 짧은 요약(`일과 카드를 만들 때 아래 정보가 국외로 전달됩니다 ...`)이고, 코드는 전체 약관 원문이다 (`consent_documents.dart`).
- **법적 문구는 임의로 바꾸지 않는다.** 시안 문구가 법무 확인을 거친 것인지, 단지 화면 예시인지 확인한다.
- 시안 대조 테스트(`settings_conformance_test.dart`)의 프레임 id 를 새 id 로 바꾼다.
