🖌️ 요청 내용
---

디자이너가 이룸이 화면 시안을 새로 정리했다. 최신 시안 섹션 `이룸이 휴대폰_이룸이모드`(Figma 1197:6774)의 9개 화면 기준으로 이룸이 화면 전체를 맞춘다.

**대상 화면**: 홈, 홈_아무것도X(루루·포포), 일과 진행, 일과 진행_완료, 별, 보상(루미·포포·루루)

**바꿀 것**

- **홈**
  - 인사말: "오늘 하늘이가 / 할 일들이에요. 힘내봐요!"
  - 일과 타일: 361×92, 제목 → "다하면" → 보상 순서, 우측에 체크·진행률 링·화살표
  - 별 배지: x271 자리로 이동
  - 오른쪽 위 캐릭터 얼굴 버튼: 톱니바퀴 아이콘(24×24, 345·86)으로 교체
- **홈_아무것도X**: 문구를 "보호자 모드에서 일과를 만들 수 있어요"로 변경, 상단은 홈과 같은 구성
- **일과 진행**
  - 보상 칩을 상단 바 밖(y159)으로 이동
  - 카드 333×410 @ y231, 그림 313×230, 번호 뱃지 40×40, TTS 24×24로 조정
- **일과 진행_완료 · 별 · 보상 3종**: 시안 대조 후 어긋난 곳만 수정

**정하고 가는 것**

- 톱니바퀴는 누르면 기존 비밀암호 화면(보호자 화면 전환)을 연다. 시안에 동작이 그려져 있지 않아 임시로 이렇게 잇고, 디자이너에게 확인해 바꾼다.
- "보호자 모드" 문구는 2026-09-18 합의 예외에 따라 시안 그대로 쓴다.

**하지 않는 것**

- 옆 카드에 그려진 삭제 버튼: 보호자 화면에서 복사된 잔재로 판단해 제외
- 옆 카드가 가장자리에 걸치는 구성: #394에서 승인한 이탈이라 유지

🎯 기대 결과
---

- 이룸이 화면 9개가 최신 시안과 같은 모양이 된다.
- 톱니바퀴로 보호자 화면 전환이 지금처럼 동작한다.
- 시안 대조 테스트와 골든 테스트가 통과한다.
