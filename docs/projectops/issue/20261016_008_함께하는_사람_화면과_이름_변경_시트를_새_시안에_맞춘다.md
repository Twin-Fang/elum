📝 현재 문제점
---

- 설정 > **함께하는 사람** 화면과 **이름 변경 시트**가 시안 없이 만든 임시 구현이다. 디자인 요청(#644)에 대한 시안이 나왔다.
- 시안과 앱을 대조한 결과 줄 구조, 칩 색·문구, 시트 모양, 머리 글, 그만두기·초대 카드가 모두 다르다.

🛠️ 해결 방안 / 제안 기능
---

시안(Figma `VSmGuv1iuOpLZmp6QeBHWr`)의 세 프레임에 맞춘다. 줄 높이 같은 픽셀 값은 큰 글자에서 잘리지 않도록 최소 높이로 지킨다.

| 노드 | 화면 |
| --- | --- |
| `1027:4617` | 설정_함께하는사람 (목록) |
| `1532:6877` | 설정_함께하는사람_이름변경 (이름 비어 있음, `보호자` 선택) |
| `1532:7013` | 설정_함께하는사람_이름변경 (`2반 선생님`, `선생님` 선택) |

**정한 것 (시안끼리 어긋나거나 시안에 없는 곳)**

- 이름이 없는 내 줄은 목록에서 `보호자`로 보인다(앱의 기본 호칭과 같다). 시트 배경의 `이름없음`은 시안 안의 표기 불일치로 보고 따르지 않는다.
- 목록의 초대 카드 줄이 화면 제목과 같은 문구(`이룸이 휴대폰 연결하기`, `함께하는 사람`)로 그려져 있다. 복사 실수로 보고 시트 배경에 나온 `다른 보호자 초대하기`, `받은 초대 코드 넣기`를 쓴다. 디자이너 확인 필요.
- 구분 칩 `센터 선생님`은 시안대로 `선생님`으로 바꾼다(한국어 화면 문구). 다른 언어 번역은 건드리지 않는다.
- 혼자 돌볼 때(마지막 보호자)의 그만두기 문구는 지금의 문구를 유지한다. 시안의 `내가 만든 일과만 사라져요`는 혼자일 때 사실과 다르다.
- 시안에 없는 상태(불러오는 중, 실패, 0건, 큰 글자, 저장 중)는 기존 동작을 유지한다.
- 시안이 뺀 안내 두 줄(이룸이 휴대폰 연결 안내, `하늘이를 함께 돌보는 사람이에요`)은 시안대로 뺀다.
