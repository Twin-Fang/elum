📝 현재 문제점
---

저장소는 공개 상태인데, 처음 온 사람이 "무슨 앱이고 어디서 받나"를 알 수 없고 일부 서술은 사실과 다릅니다.

- **README가 실제 서비스와 정반대로 적혀 있습니다.** 게시된 개인정보처리방침은 보호자가 쓴 상황 설명을 "가공하지 않고 그대로" Google, OpenAI, fal에 전달한다고 밝히는데, README와 docs는 AI DLP가 민감정보를 마스킹해 외부로 나가지 않는다고 소개합니다(폐기된 기능, #377). 같은 서비스의 두 문서가 서로 다른 말을 하고 있습니다. README에는 AI 업체도 Gemini 하나만 적혀 있습니다.
- **앱을 받을 곳이 없습니다.** 스토어 링크도 안내도 없고 화면 이미지는 0개입니다. 게시 페이지(도움말 사이트)도 도움말 성격이라 신규 방문자를 위한 앱 소개와 설치 안내가 없습니다.
- **README 수치와 호칭이 낡았습니다.** 테스트·워크플로 개수가 다르고 "아이·아동" 표현이 남아 있습니다(용어 규칙은 "이룸이").
- **저장소 정보가 비어 있습니다.** About 설명과 topics가 없고, 홈페이지 링크는 해커톤 소개 페이지입니다. 게시 페이지(`twin-fang.github.io/elum`)에는 어디서도 링크하지 않습니다.
- **라이선스·저작권 표기가 없습니다.** 상용 운영 서비스인데 이용 조건이 적혀 있지 않습니다.
- **공개 범위를 점검하지 않았습니다.** 외부 자문기관 회의록 원문 등이 공개 docs에 올라 있습니다.

🛠️ 해결 방안 / 제안 기능
---

공개 레포를 **이룸 앱 설치 허브**로 정비합니다. 보호자와 이룸이를 돕는 분들이 읽는다는 전제이며, 스타 모으기나 기여자 모집은 목표가 아닙니다.

- 비개발자 방문자의 첫 화면은 **게시 페이지**, 개발자의 첫 화면은 **README**로 역할을 나눕니다. README 상단과 About 홈페이지에서 게시 페이지로 안내합니다.
- 코드와 디자인(이름·로고·캐릭터·화면)의 저작권은 **팀 룸룸**에 있으며, **모든 권리 보유**로 표기해 상용 서비스를 지킵니다.
- 없는 것을 있다고 쓰지 않습니다. App Store는 공개돼 있어 링크로 안내하고, 아직 열리지 않은 Google Play는 "출시 준비 중" 안내로 자리만 잡았다가 출시되면 링크로 교체합니다.
- 개인정보 관련 서술은 새로 쓰지 않고, 게시된 방침을 기준으로 틀린 부분을 걷어내거나 방침 링크로 대체합니다.
