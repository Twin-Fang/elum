📝 현재 문제점
---

- 감정, 행동 지도 카드(친구와 사이좋게, 감정카드 꺼내기 등)는 생성은 되지만 **일과 안에만** 있다. 필요한 순간에 한 장만 꺼내 보여 줄 곳이 없다 (회의록 5장: 카드 보관함 ❌).
- 교감 (01:45): 감정, 긍정, 부정 행동 카드를 모아 두고 필요할 때 한 장 꺼내 보여 주고 싶다. 지금은 종이 카드를 들고 다닌다 (2장 #7).

🛠️ 해결 방안 / 제안 기능
---

- 보호자가 카드를 **보관함에 모아 두는** 기능 (감정 / 긍정 행동 / 부정 행동 등 분류).
- 보관함에서 카드 **한 장을 골라 이룸이에게 크게 보여 주기** (일과 진행 없이 단독 표시).
- 기존 일과 카드를 보관함에 담기, 보관함 카드를 일과에 넣기.
- 2차 실증(10/20) 이후로 미룬 항목이다.

⚙️ 작업 내용
---

- 설계: 보관함 분류 체계, 카드 원본 공유 vs 복사, 이룸이 화면에서 보여 주는 방식
- 서버: 보관함 저장, 조회 API
- 클라 보호자 화면: 보관함 목록, 담기, 분류, 한 장 보여 주기
- 실패 경로: 보관함 0건 빈 상태, 이미지 로드 실패 대체 표시
