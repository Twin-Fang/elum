🖌️ 요청 내용
---

시안은 대부분 **정상 화면**만 그려져 있다. 불러오지 못했을 때, 0건일 때, 알림(토스트)은 **개발 쪽이 화면마다 따로 만들었다.** 그래서 같은 "못 불러왔어요"인데 모양이 세 가지다.

> 이 요청서는 정답을 드리는 게 아니다. 지금 앱 모습과 디자이너가 보통 안 그리게 되는 상태를 **재료로** 모았다. 모양, 문구, 위치 모두 바꿔도 된다. 개발 쪽 추천은 근거와 함께 한 줄씩만 적었다.

| 캐릭터 그림 + 큰 버튼 + 버튼 아래 코드 | 카드 생성 실패, 질문 준비 실패 |
| 0건 화면 그대로 + 코드만 | 이룸이 홈 |

### 실측 검수 결과 (2026-09-25, Android 에뮬레이터 · 운영 서버)

처음 캡처는 위젯 렌더였다. 실기기로 다시 밟았다.

![real](https://github.com/Twin-Fang/elum/releases/download/qa-evidence/realqa_20260925-135243_real_fail.png)

- 위 보드의 "보호자 홈 · 오늘 일과 실패"는 **실제로 나오지 않는 화면**이다. 오늘 일과는 인터넷이 끊겨도 **기기에 저장해 둔 목록**을 보여준다 (오프라인 우선). 실패 화면은 **지난 일과**에만 뜬다.
- 임시저장은 인터넷이 끊기면 실패 화면이 **약 40초 뒤에야** 뜬다 (그동안 로딩). 개발 쪽 결함으로 #429에 올렸다. 시안에서는 "실패는 바로 보인다"를 전제로 그리면 된다.
- 임시저장 빈 상태는 캡처와 같다.
- 카드 확인 "카드 0장"은 정상 흐름으로 도달하지 않는 방어 화면이다 (서버가 0장 응답을 실패로 막는다). 시안 우선순위를 낮춰도 된다.
- 실패 토스트는 실측에서도 `저장하기` 버튼을 덮는다 (새 일과 첫 저장 + 인터넷 끊김).

### 빈 상태, 알림

![empty](https://github.com/Twin-Fang/elum/releases/download/qa-evidence/undesigned_20260925-114501_board_g1_empty.png)

- **임시저장 화면**은 시안에 헤더만 있고 본문이 비어 있다 (`1045:4910`). 목록, 빈 상태, 실패 모두 개발 쪽 모양이다.
- **토스트(스낵바)**는 Flutter 기본 모양 그대로다. 앱 톤과 맞지 않고, 카드 확인 화면에서는 `저장하기` 버튼을 가린다.

### 꼭 지켜야 하는 것 (`docs/08-design-principles.md`)

- **상태 4개는 항상 그린다**: 정상 / 로딩 / 빈 상태 / 실패. 빈 상태와 로딩을 같게 그리지 않는다 (§5-4).
- **실패해도 화면은 살아 있다**: 무엇이 안 됐는지 + `다시 시도` + **작은 에러 코드** (§⑤). 코드는 제보를 받았을 때 원인을 찾는 유일한 단서다.
- **이룸이 화면은 겁주지 않는다**: 빨강, 경고 아이콘을 쓰지 않는다 (§⑥).
- 말투는 해요체, 능동형, 긍정형.

🎯 기대 결과
---

- 보호자용, 이룸이용 **공통 실패 화면 두 벌**과 **공통 빈 상태**, **토스트** 모양이 정해진다.
- 한 번 정하면 공통 위젯 하나만 바꿔 여러 화면에 한꺼번에 들어간다.

📋 참고 자료
---

### 디자이너가 정해 주면 좋은 것

1. **실패 화면 한 벌로 통일할지.** 크기가 다른 자리(화면 전체 / 칸 하나)에 맞춰 큰 것, 작은 것 두 크기가 필요할 수 있다.
2. **이룸이 홈이 실패했을 때.** 지금은 "아직 하늘이의 일과가 없어요"(0건과 같은 말) + 코드만 보인다. 이룸이를 겁주지 않으려고 일부러 그렇게 했지만, 원칙 ⑤의 `다시 시도`가 없다. 두 원칙이 부딪히는 자리다.
3. **에러 코드 표기.** 지금은 `E-NET-OFFLINE` 같은 앱 코드와 `INTERNAL_SERVER_ERROR` 같은 서버 원문이 섞여 보인다. 크기, 색, 위치(버튼 아래 / 괄호 안)를 정해 주면 좋겠다.
4. **토스트.** 위치(아래 / 위), 버튼을 가리지 않는 방법, 한 번에 보여줄 글자 수.
5. **임시저장 목록 한 줄의 모양.** 제목, 만든 날, `이어서` 버튼.

### 문구 후보

| 자리 | 지금 | 후보 |
|---|---|---|
| 실패 공통 제목 | `~를 불러오지 못했어요` | 유지 (짧고 사실만 말한다) |
| 실패 버튼 | `다시 시도` / `다시 하기` (두 가지) | 하나로 통일: `다시 해볼게요` 또는 `다시 불러오기` |
| 카드 생성 실패 설명 | 잠시 후 다시 해주세요 | 잠시 뒤에 다시 만들 수 있어요 |
| 이룸이 홈 실패 | 아직 하늘이의 일과가 없어요 | 일과를 가져오는 중이에요. 잠시 뒤에 다시 열어 주세요 (0건과 다른 말) |

**개발 쪽 추천 (정답 아님)**: 보호자용은 **"그림 + 한 줄 + 버튼 + 코드"** 하나로 통일하고, 칸 하나짜리 자리에는 그림만 뺀 작은 크기를 쓴다. 지금 카드 생성 실패 화면이 가장 읽기 쉽다.

💡 추가 요청 사항
---

- 카드 확인 화면에서 카드가 0장일 때 "다시 만들어 주세요"라고 하면서 다시 만들 버튼이 없는 것, 토스트가 버튼을 가리는 것은 **개발 쪽이 따로 고친다** (버그 이슈로 분리). 모양은 이 시안을 따른다.
