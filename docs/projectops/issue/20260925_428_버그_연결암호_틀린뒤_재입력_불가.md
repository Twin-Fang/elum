🗒️ 설명
---

이룸이 휴대폰의 **연결 암호 넣기**에서 한 번 틀리면 **다시 입력할 수 없다.** 칸을 눌러도 키보드가 올라오지 않는다. 뒤로 나갔다가 다시 들어와야 입력된다. 이룸이가 혼자서는 다시 시도하기 어렵다.

- Android(에뮬레이터)와 iOS(시뮬레이터) **둘 다** 재현된다.
- 서버에 다녀온 실패(틀린 암호, 인터넷 끊김)에서만 생긴다. 앱이 먼저 거르는 실패(쓰지 않는 글자 `0 1 I L O U` 포함)는 키보드가 남아 있어 다시 입력된다.

**원인 (코드)** `client/lib/features/link/presentation/link_enter_screen.dart`
- 보낼 때 `_focusNode.unfocus()`(78행)로 키보드를 내린다.
- 결과가 오면 `_fail()`이 `_focusNode.requestFocus()`(110행)를 부른다. 포커스는 돌아오지만 **키보드는 다시 뜨지 않는다** (`dumpsys input_method` → `mInputShown=false`).
- 칸을 누르면 `onTap: _focusNode.requestFocus`(160행)가 불리는데, **이미 포커스가 있어 아무 일도 일어나지 않는다.**

함께 보인 것 (같은 화면)
- 인터넷이 끊겼을 때 안내가 같은 말을 두 번 한다: `연결하지 못했어요. 인터넷을 확인해주세요 · 인터넷 연결을 확인해주세요 (E-NET-OFFLINE)`
- 틀림과 인터넷 끊김 모두 **빨간 테두리**다. 빨간 테두리는 #427 ①에서 다룬다.

🔄 재현 방법
---

1. 로그인 없이 앱 첫 실행 → `이룸이가 사용해요` → `다음`
2. 칸에 `ZZZ999` 입력 (모양은 맞지만 없는 암호) → `암호가 맞지 않아요`, 키보드 사라짐
3. 칸을 여러 번 누른다 → 키보드가 안 올라오고 입력도 안 된다
4. 뒤로 → `이룸이가 사용해요` → `다음`으로 다시 들어오면 입력된다

✅ 예상 동작
---

- 틀린 뒤 칸이 비워지고 **키보드가 그대로 남아** 바로 다시 입력할 수 있다.
- 칸을 누르면 언제든 키보드가 올라온다 (포커스가 이미 있어도 키보드를 다시 띄운다).
