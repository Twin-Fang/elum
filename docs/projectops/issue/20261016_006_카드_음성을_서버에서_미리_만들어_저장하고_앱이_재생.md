📝 현재 문제점
---

- 안드로이드에서 카드를 읽어 줄 때 목소리가 쉬고 높낮이가 이상하게 바뀌어 유령 목소리처럼 들린다. 기기 음성 엔진의 한국어 목소리 품질이 기종마다 달라 앱이 통제할 수 없다.
- 서버 음성(AI 서버 Supertonic)은 목소리가 일정하지만, 누를 때마다 만들어서 느리다. 2026-10-16 실측 결과는 아래와 같다.
  - 한 건: 2.3~3.5초 (문장 6~45자, WAV 135~633KB)
  - 요청을 하나씩 처리한다. 동시 5건이면 가장 늦은 건이 7.5초, 20건이면 25.7초다.
- AI 서버가 꺼지면 바로 실패한다. 같은 날 Docker가 내려가 서버 음성이 503으로 실패하고 있었는데, 아무도 모르고 있었다.

🛠️ 해결 방안 / 제안 기능
---

- 카드 음성을 **미리 한 번 만들어 서버에 저장**한다. 이룸이는 저장된 파일을 재생하므로 기다리지 않고, 재생 시점에 AI 서버 상태와 상관없이 소리가 난다.
- 만드는 때: 일과를 만들 때, 단계 글을 고칠 때, 단계를 추가할 때. 복제할 때는 원본 파일을 그대로 쓴다.
- AI 서버 보호: 서버가 음성 요청을 한 줄로 세워 하나씩만 보낸다.
- 실패하거나 빠진 음성(기존 일과 포함)은 주기 작업이 조금씩 다시 만든다.
- 한국어 일과만 만든다. 다른 언어는 지금처럼 기기 음성으로 읽는다.
- 앱(안드로이드): 저장된 음성 > 기기 음성 > 실시간 서버 음성 순으로 읽는다. 받은 파일은 휴대폰에 저장하고, 일과 화면을 열면 미리 받아 둔다. 아이폰은 지금 그대로 둔다.
- 어떤 경우에도 소리가 안 나 화면이 멈추지 않는다. 마지막에는 기기 음성으로 읽는다.

⚙️ 작업 내용
---

- 서버: 단계 음성 저장소, 음성 생성 대기열(한 번에 하나), 주기 재시도, 음성 내려받기 API, 단계 응답에 음성 열쇠 추가, DB 컬럼 추가
- 앱: 저장 음성 재생과 휴대폰 캐시, 일과 화면 진입 시 미리 받기, 안드로이드 재생 순서 변경
- 시험: 생성 대기열, 재시도, 글 수정 시 다시 만들기, 앱 재생 순서와 캐시, 에뮬레이터 실제 재생 확인
