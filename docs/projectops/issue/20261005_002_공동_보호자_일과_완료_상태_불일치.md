🗒️ 설명
---

같은 이룸이 프로필을 공유하는 보호자 A와 B 사이에서 일과 목록은 정상 공유되지만 완료 상태가 일치하지 않습니다. 이룸이 휴대폰에서는 두 일과 모두 완료인데, 각 보호자 홈에서는 자신이 만들지 않은 일과가 0%로 표시됩니다. 보호자 휴대폰에서 이룸이 화면으로 전환해도 불일치가 이어집니다.

사용자 제보상 이룸이 이름은 QA이며, 보호자 초대코드를 입력해 함께하기로 연결했습니다. 완료 상태는 보호자의 판단과 보상에 영향을 주므로 정합성 관점에서 우선 조사해야 합니다.

| 조회 화면 | 처음 학교에 가요 | 음악 수업을 들으러 가요 |
| --- | --- | --- |
| 이룸이 휴대폰 (화면 1) | 완료 | 완료 |
| 보호자 홈 (화면 2) | 0% | 완료 |
| 다른 보호자 홈 (화면 3) | 완료 | 0% |
| 보호자 휴대폰의 이룸이 화면 (화면 4) | 0% | 완료 |

화면 2, 3 중 어느 쪽이 A인지와 일과별 생성자 매핑은 미확인입니다. 표는 첨부 화면 그대로이며, 생성자와 불일치의 관계는 사용자 제보입니다.

🔄 재현 방법
---

1. 보호자 A와 B를 초대코드로 같은 이룸이 QA에 연결합니다.
2. A와 B가 각각 일과 하나씩 만듭니다.
3. 양쪽 보호자 홈과 이룸이 휴대폰에 두 일과가 모두 보이는지 확인합니다.
4. 이룸이 휴대폰에서 두 일과를 모두 끝냅니다.
5. 이룸이 휴대폰에서는 두 일과 모두 완료로 표시됩니다.
6. 양쪽 보호자 홈에서는 자신이 만들지 않은 일과가 0%로 표시됩니다.
7. 보호자 휴대폰에서 이룸이 화면으로 전환해도 한 일과가 0%입니다.
