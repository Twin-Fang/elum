📝 현재 문제점
---

- 카드확인 화면에서 `저장하기`를 눌렀는데 "일과를 저장하지 못했어요 / ROUTINE_INVALID_STATUS" 팝업이 떴다. 홈에 가 보면 일과는 정상으로 저장돼 있다.
- 운영 서버 로그(2026-10-10 19:36)를 보면 저장이 **두 번** 실행됐다.
  - 1번째 저장: 뺀 카드 2장 삭제 → 승인 200 (여기서 저장 완료)
  - 약 1초 뒤 2번째 저장: 카드 삭제 404 → 승인 409 `ROUTINE_INVALID_STATUS` → 팝업
- 저장이 1초쯤 걸리는 동안 버튼이 잠기지 않고 진행 중 표시도 없어, 보호자가 반응이 없는 줄 알고 한 번 더 눌렀다.
- 앱 전체를 전수조사했더니 누르면 서버로 요청이 가는 곳이 36곳이었다. 화면마다 진행 중 플래그를 따로 두고 있고 공통 장치가 없어 빠진 곳이 생긴다.
  - 중복 실행 방지 없음 7곳: 높음 1(카드확인 저장하기), 중간 1(홈 오늘 일과 스와이프 삭제), 낮음 5
  - 방지는 있지만 진행 중 표시 없음 13곳: 비밀암호 변경 저장, 온보딩 시작하기, 홈 일과 만들기, 로그아웃/탈퇴, 그림 방식 선택, 함께하는 사람 나가기/수정, 연결 끊기 등
  - 둘 다 있음 6곳: 로그인, 약관, 의견 보내기, 연결 암호 입력, 초대 참여, 광고 대기

🛠️ 해결 방안 / 제안 기능
---

- 로그인 화면처럼 **누르는 즉시 잠기고 진행 중임이 보이게** 앱 전체를 맞춘다.
- 화면마다 따로 만들지 않고 공통 부품을 만들어 모든 곳이 그것을 쓰게 한다.
  - 하단 공통 버튼에 진행 중 상태 추가: 누를 수 없고 버튼 오른쪽에 스피너가 돈다 (의견 보내기 화면의 모양을 표준으로 삼는다)
  - 화면용 공통 실행 장치: 진행 중이면 다시 실행하지 않고, 성공/실패와 상관없이 끝나면 잠금을 푼다. 목록 항목별 잠금도 지원
  - 상태 관리용 공통 장치: 진행 중인 같은 작업은 결과를 공유해 서버로 한 번만 보낸다
  - 공통 팝업 버튼: 빠르게 두 번 눌러도 한 번만 닫힌다
  - 설정 타일에 진행 중 상태 추가
- 서버 API 동작은 바꾸지 않는다 (운영 중).

⚙️ 작업 내용
---

- 공통 부품 5종 추가
- 적용: 카드확인 저장하기, 홈 오늘 일과 삭제, 카드 추가, 임시저장 삭제, 홈 일과 만들기, 보호자 설정 로그아웃/탈퇴, 그림 방식, 비밀암호 변경, 온보딩 시작하기, 약관 뒤로가기, 연결 끊기, 이룸이 설정, 함께하는 사람 나가기/수정, 이룸이 바꾸기, 의견 보내기(공통 버튼으로 교체)
- 하지 않는 것: 카드 수정 시트, 드래그 순서 변경(같은 값 재전송이라 무해, 표시가 드래그를 방해), 이미 잘 된 로그인/약관/연결 암호/초대/광고
- 검증: 공통 부품 단위 시험, 저장하기 두 번 눌러도 승인 1번인지 화면 시험, 전체 시험, iOS 시뮬레이터에서 저장하기 연타 실측
