📝 현재 문제점
---

- 같은 모양을 화면마다 따로 그리고 있다.
  - 바텀시트 4곳이 배경, 둥근 모서리, 손잡이를 각자 그린다. 카드 수정, 일과 상세, 사진 선택, 보호자 수정 시트다.
  - 연결 암호를 보여주는 화면 두 개(`link_code`, `invite_code`)가 거의 같은 코드다. 암호를 입력하는 화면 두 개(`link_enter`, `invite_enter`)도 같은 입력 위젯을 따로 갖고 있다.
  - 공통 로딩 화면이 있는데도 스피너를 직접 그리는 곳이 약 12곳이다.
- 한쪽만 고치면 다른 쪽이 어긋난다.

🛠️ 해결 방안 / 제안 기능
---

- 아래 공통 위젯을 만들고 기존 화면에 적용한다.
  - 바텀시트
  - 연결 암호 표시 패널
  - 암호 입력칸
  - 작은 스피너
- 간격, 모서리, 크기는 지금 값 그대로 둔다. 화면이 달라지면 안 된다.
- 입력 화면 두 개의 화면 로직은 합치지 않는다. 입력 위젯만 공통으로 쓴다.
