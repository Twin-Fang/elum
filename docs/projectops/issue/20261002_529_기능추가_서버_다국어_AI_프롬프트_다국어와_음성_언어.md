📝 현재 문제점
---

- AI 프롬프트(`prompt_template`)에 언어 구분이 없고 일과 글 생성이 한국어를 전제로 한다. 출력 언어를 지정하는 곳이 없다.
- 호칭 치환(`NicknamePlaceholder`)이 한국어 조사에 묶여 있어 다른 언어에서 성립하지 않는다.
- 이미지 프롬프트의 한국어→영어 변환 단계가 한글만 걸러서 일본어·중국어 입력이 그대로 통과한다.
- 음성(TTS)이 `ko-KR`로 고정돼 있다.

🛠️ 해결 방안 / 제안 기능
---

- 프롬프트에 언어 열을 더한다. 기존 한국어 프롬프트는 **한 글자도 바꾸지 않는다.** 다른 언어는 영어 기준 지시문에 출력 언어와 어조를 채워 언어별 행으로 만든다.
- 일과 언어를 AI 호출에 실어 보낸다. 한국어 조사 복원은 한국어에서만 유지하고, 다른 언어는 호칭을 직접 치환한다.
- 이룸이 폰이 일과 언어로 카드 글과 음성을 보여준다. 기기 음성이 안 되면 서버 음성, 그것도 안 되면 글만 보여준다.
- 관리자 프롬프트 화면에 언어 구분을 더하고, 프롬프트가 없는 언어는 켜지 못하게 막는다.

- [ ] 이미지 프롬프트 변환 단계의 언어 검사 수정
- [ ] 음성 언어: 클라이언트 3단 대체(2개 Task), 서버 음성은 외부 서비스라 확인 절차만
