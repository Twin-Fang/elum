📝 현재 문제점
---

![전후 비교](https://github.com/Twin-Fang/elum/releases/download/qa-evidence/issue543_20261002-203352_snack_compare.png)

> "전"은 실제 시뮬레이터 캡처, "후"는 같은 보호자 홈을 위젯 테스트로 렌더한 화면이에요(일과 2개, 지난 일과 1개).

- 저장·변경 뒤 화면 아래에 잠깐 뜨는 알림(스낵바)이 Flutter 기본 모양 그대로 나온다.
  - 앱 어디에도 스낵바 공통 스타일이 없어, 각진 직사각형이 화면 바닥에 붙고 배경은 테마에서 자동으로 뽑힌 갈색이 된다.
  - 글꼴·색·모서리가 앱의 다른 요소(카드·팝업·시트)와 어울리지 않는다.
- 스낵바를 띄우는 곳은 7곳이며 모두 문구만 넘기고 모양은 기본값에 맡긴다.
  - 그림 방식 설정: `그림 방식을 바꿨어요`
  - 비밀암호 변경: `비밀암호를 바꿨어요` / `비밀암호를 만들었어요`
  - 지난 일과 복사: `○○을(를) 오늘 일과에 담았어요`
  - 연결 상태, 보호자 목록(`○○에서 나왔어요`), 초대 입력(`함께 돌보게 됐어요`), 이룸이 바꾸기(`이룸이를 바꿨어요`)
- 관련 파일
  - `client/lib/core/theme/app_theme.dart` (스낵바 테마 없음)
  - `client/lib/features/guardian/presentation/image_style_settings_screen.dart` 외 6곳

🛠️ 해결 방안 / 제안 기능
---

- 시안이 나오기 전까지 **임시 테마**로 한 곳에서 정리한다. 7곳은 따로 손대지 않아도 함께 바뀐다.
  - 바닥에 붙지 않고 떠 있는 모양, 둥근 모서리, 앱 글꼴, 앱 본문색 계열의 진한 바탕
- 시안은 디자이너에게 별도 디자인 이슈로 요청하고, 시안이 나오면 이 테마 값을 시안대로 바꾼다.

⚙️ 작업 내용
---

- 앱 테마에 스낵바 공통 스타일 추가 (임시 값임을 주석으로 남긴다)
- 7곳을 실제로 띄워 문구가 길어져도 깨지지 않는지 확인
- 디자인 요청 이슈 등록 (현재 화면 캡처 첨부)
