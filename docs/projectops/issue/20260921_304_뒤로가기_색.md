**뒤로가기 아이콘만 색이 연합니다.** 바로 옆 홈 아이콘과 나란히 놓으면 눈에 띄게 다릅니다.

| | 시안 (`262:4569`) | 지금 앱 |
|---|---|---|
| 뒤로가기 | `#242634` | **`#374957`** ← 회색빛이 돈다 |
| 홈 | `#242634` | `#242634` ✅ |

모양은 같습니다. **에셋 파일의 칠 값만 다릅니다.**

`#374957`은 **앱 색 토큰 어디에도 없는 값**입니다. 시안에서 받을 때 다른 상태의 것을 받았거나, 손으로 만들면서 값이 섞인 것으로 보입니다.

**뒤로가기는 화면 다섯 곳이 같은 파일을 씁니다.** 그래서 앱 전체에서 어긋납니다.

- 공통 골격 (`elum_scaffold`)
- 일과 만들기 흐름 (`routine_flow_scaffold`)
- 일과 입력
- 이룸이 일과 상세
- 이룸이 별 화면

### 아이콘 칠 값을 전수로 훑었습니다

열일곱 개 중 **둘만** 토큰에 없는 값을 씁니다.

| 아이콘 | 칠 | 판정 |
|---|---|---|
| `icon_back` | **`#374957`** | 🔴 시안은 `#242634` |
| `icon_card_delete` | **`#374957`** | 🟡 시안 확인 필요 — 같은 값이라 의심스럽다 |
| `icon_home` · `icon_volume` · `icon_sparkles_large` · `icon_angle_small_up` | `#242634` | ✅ |
| `icon_time_past` · `icon_today_routine` | `#74757D` | ✅ 시안 `sub_color` |
| `icon_settings` | `#898B98` | ✅ |
| `icon_clock` · `icon_sparkles` | `#9CADF1` | ✅ |
| `icon_check_done` | `#55CFBA` | ✅ 시안 `point_color` |

🛠️ 해결 방안 / 제안 기능
---

**`icon_back.svg`의 칠을 `#242634`로 바꿉니다.** 모양은 그대로이므로 파일의 값 하나만 고칩니다.

- **새 40×40 컴포넌트로 통째로 교체하지 않습니다.** 시안이 최근 뒤로가기·홈을 40×40 누름 영역이 있는 컴포넌트(`976:4549` · `976:4537`)로 다시 그렸는데, 지금 코드는 24×24로 그리고 바깥에서 누름을 받습니다. **통째로 갈면 화면 다섯 곳의 여백이 함께 움직입니다.** 색만 맞추는 것이 이번 범위입니다
- `icon_card_delete`는 **시안 노드를 찾아 확인한 뒤** 판단합니다. 같은 값이라 함께 잘못 받았을 가능성이 있지만, 확인 없이 바꾸면 멀쩡한 것을 건드립니다

**왜 여태 안 드러났나** — 아이콘 하나만 보면 알아채기 어렵습니다. **홈 아이콘과 나란히 놓였을 때** 비로소 보입니다. 골든 테스트도 이 차이를 잡지 못합니다(시안과 대조하지 않으므로).
