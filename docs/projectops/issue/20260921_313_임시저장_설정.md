📝 현재 문제점
---

**임시저장한 일과를 볼 곳이 없습니다.** 명세(§8-4)는 설정 화면에 두라고 하는데 아직 없습니다. 코드에도 그렇게 적혀 있습니다.

> *"명세 §8-4는 위에 임시저장·알림도 두지만 아직 없다. 있는 것만 먼저 올린다."*

**서버는 준비돼 있습니다** — `getDraftRoutines`가 아직 이룸이에게 보내지 않은(`PENDING_REVIEW`) 일과를 돌려줍니다. **앱에만 그 길이 없습니다.**

일과를 만들다 중간에 나가면 임시저장되는데, 그것을 다시 찾아 이어 만들 방법이 지금은 없습니다.

🛠️ 해결 방안 / 제안 기능
---

**설정 화면에 `임시저장` 줄을 넣고, 누르면 목록을 보여줍니다.**

**정해야 할 것**

| 물음 | |
|---|---|
| 목록에서 고르면 어디로 | 만들던 자리로 돌아가는가, 카드 확인부터인가 |
| 몇 개까지 | 서버는 전부 준다. 화면에서 끊을지 |
| 지우기 | 임시저장을 버릴 수 있어야 하나 |
| 빈 상태 | 하나도 없을 때 무엇을 보여주나 |
