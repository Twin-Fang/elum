📝 현재 문제점
---

- 이룸이가 카드를 체크해도 화면(컨페티, 별 화면)과 소리로만 알 수 있고, 손에 느껴지는 반응이 없다.
- 이룸이 화면에는 진동이 하나도 없다. 지금 진동은 보호자 화면과 공용 위젯에만 있다.
- 화면을 보지 않고 있거나 소리를 끈 상태에서는 체크가 됐는지 알기 어렵다.

🛠️ 해결 방안 / 제안 기능
---

이룸이가 카드를 하나씩 끝낼 때마다 짧은 진동으로 "됐어요"를 알려준다. 진동은 보조 신호이고, 화면과 소리가 이미 알려주는 것을 손으로 한 번 더 느끼게 하는 역할만 한다.

**원칙**

- 기본은 약하고 짧게 한다. 소리나 진동에 예민한 이룸이가 있을 수 있다.
- 가장 긴 패턴도 약 0.3초 안에 끝낸다.
- 진동이 안 되는 휴대폰(태블릿 등)이거나 호출이 실패해도 화면 흐름은 그대로 진행한다.

**진동 구성**

| 순간 | 느낌 | 구성 | 세기 |
|---|---|---|---|
| 카드 체크 | 톡 | 짧게 한 번 (약 20ms) | 중간 |
| 별 화면이 뜰 때 | 반짝 | 약하게 두 번 (15ms, 60ms 쉬고, 15ms) | 약함 |
| 일과 전체 완료 | 축하 | 점점 세지는 세 번 (약함, 중간, 강함, 사이 70ms) | 강함으로 끝남 |
| 체크 해제 | 스윽 | 아주 약하게 한 번 (10ms) | 약함 |

- 체크 순간의 진동은 컨페티가 터지는 타이밍에 맞춘다.
- 세기와 패턴 값은 한 곳에 모아 두어 실기기에서 느껴 보며 조정할 수 있게 한다.

**끄는 스위치**

- 보호자 설정과 이룸이 설정, 두 곳 모두에 진동 켜기/끄기 스위치를 둔다.
- 한 휴대폰에 저장하는 하나의 값이므로 어느 쪽에서 바꿔도 같은 값이다. 기본값은 켜짐이다.
- 동작 줄이기 설정은 진동을 끄는 기준으로 쓰지 않는다. 움직임과 진동은 서로 다른 감각이다.

**실패 경로**

- 진동 기능이 없는 휴대폰: 스위치가 있어도 아무 일 없이 넘어간다. 앱은 계속 동작한다.
- 진동 호출이 실패: 화면을 막지 않는다. 개발 중에는 로그로 남긴다.
- 저장된 스위치 값을 읽지 못하면 켜짐으로 본다.

**검증**

- 위젯 테스트로 "체크 시 한 번, 해제 시 해제 패턴, 마지막 카드 시 완료 패턴, 스위치 끔이면 울리지 않음"을 확인한다.
- 위젯 테스트는 가짜 진동기만 검증하므로 실제 세기는 Android 실기기와 iPhone에서 밟아 확인한다. 에뮬레이터는 진동을 느낄 수 없다.

⚙️ 작업 내용
---

- 이룸이 화면 전용 진동 패턴 4종 정의 (세기, 길이)
- 카드 체크, 별 화면, 일과 완료, 체크 해제 시점에 진동 연결
- 진동 켜기/끄기 값 저장
- 보호자 설정, 이룸이 설정에 스위치 한 줄씩 추가
- 위젯 테스트 추가, 실기기 확인
