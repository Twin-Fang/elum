📝 현재 문제점
---

- 서버가 요청 언어를 모른다. `Accept-Language` 처리가 없고, 에러 응답 104개와 서버가 만드는 문장(AI 폴백 질문, 추천 목록 58개)이 한글로 박혀 있다.
- 일과가 어떤 언어로 만들어졌는지 저장하지 않고, 일과를 만들 수 있는 언어를 관리자가 조절할 방법이 없다.

🛠️ 해결 방안 / 제안 기능
---

- 요청 언어를 판정한다: 헤더가 없으면 한국어, 5개 밖이거나 깨진 값이면 영어. 이미 배포된 앱의 응답은 바뀌지 않는다.
- 에러 문구를 서버가 요청 언어로 번역해 내려보낸다. 클라이언트는 지금처럼 서버 문구를 그대로 보여준다(#347 원칙 유지).
- 폴백 질문과 추천 목록을 언어별 리소스로 옮기고, 비어 있으면 서버가 뜨지 않게 한다.
- 일과에 언어를 저장하고, 관리자 설정으로 일과를 만들 수 있는 언어를 조절한다.

⚙️ 작업 내용
---

- [ ] 요청 언어 판정과 요청 범위 접근자
- [ ] 에러 문구를 번역 리소스로 이동(한국어는 기존 문구와 글자 하나까지 같음을 패리티 테스트로 증명)
- [ ] 응답을 만드는 모든 곳(예외 핸들러, 인증 진입점, 점검 모드 필터 등)이 요청 언어를 쓰게 한다
- [ ] 폴백 질문과 추천 목록의 언어별 리소스와 기동 검사
- [ ] 일과 언어 열, 응답 필드, 관리자 화면 표시
- [ ] 일과 생성 가능 언어 설정과 관리자 가드
- [ ] 통과 조건: 서버 테스트 전체 통과, 헤더 없는 요청의 에러 응답이 이전과 바이트 단위로 같음
