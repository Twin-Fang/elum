## 추가 확인 — 함께하는 사람 화면도 같은 결함

같은 큰 글씨 설정(`UICTContentSizeCategoryAccessibilityXXXL`)으로 QA563 Guardian A에서 추가로 밟은 화면.

- **설정 > 함께하는 사람**: `다른 보호자 초대하기` · `받은 초대 코드 넣기` · `함께 돌보기 그만두기` 항목이 2줄로 줄바꿈되면서 바로 아래 항목과 겹쳐 전혀 읽을 수 없다.
- 보호자 홈 `새로운 일과 만들기` 버튼, 오늘/지난 일과 타일 오버플로는 이미 보고된 내용과 동일하게 재현됨(아래 캡처).

**환경**: QA563 Guardian A, iOS 18.3 시뮬레이터, elum build 246, iOS 설정 > 손쉬운 사용 > 디스플레이 및 텍스트 크기 > 더 큰 텍스트 최대.

이미 고정 높이/오버플로 패턴으로 보고된 결함이 ListTile류 목록 화면(함께하는 사람)에도 같은 성격으로 퍼져 있음을 확인. 고칠 때 홈뿐 아니라 설정 하위 목록 화면도 함께 봐야 함.
