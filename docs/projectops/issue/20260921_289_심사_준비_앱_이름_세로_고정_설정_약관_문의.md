📝 현재 문제점
---

스토어 심사 준비(#286) 0단계에서 정한 것들을 앱에 반영해야 합니다. 스크린샷을 찍기 전에 끝나야 하는 것들입니다.

- **홈 화면 앱 이름이 영문입니다.** iOS는 `Elum`, Android는 `elum`입니다. 한국어만 지원하는 서비스인데 홈 화면에는 영문만 보입니다.
- **iOS가 iPad까지 지원하도록 설정돼 있습니다.** `TARGETED_DEVICE_FAMILY = "1,2"`입니다. 이대로면 iPad 스크린샷이 필수가 되고 심사관이 iPad에서도 확인합니다. iPad 화면은 검증한 적이 없습니다. 한 번 iPad로 출시하면 이후 업데이트에서 빼기 어렵습니다.
- **화면 방향이 고정돼 있지 않습니다.** iOS `Info.plist`는 가로 두 방향을 허용하고, Android 매니페스트에는 방향 지정이 없습니다. 가로 레이아웃은 검증한 적이 없는데 심사관이 돌려보면 그대로 보입니다.
- **가입한 뒤에는 앱 안에서 개인정보처리방침을 다시 볼 곳이 없습니다.** 설정 화면에는 휴대폰 연결, 로그아웃, 회원 탈퇴만 있습니다. Apple은 앱 안에서도 쉽게 찾을 수 있어야 한다고 요구합니다(가이드라인 5.1.1(i)).
- **게시된 지원 페이지가 사실과 다릅니다.** 문의할 때 적어 달라는 항목으로 "앱 버전 — 설정 화면 맨 아래"를 안내하는데, 설정 화면에 버전이 없습니다.

🛠️ 해결 방안 / 제안 기능
---

- 홈 화면 이름을 **이룸**으로 바꿉니다. 스토어 이름은 `이룸(ELUM)`으로 따로 둡니다(#286).
- iOS를 **iPhone 전용**으로 바꾸고, iOS와 Android 모두 **세로로 고정**합니다.
- 설정 화면에 **약관 및 개인정보처리방침**을 추가합니다. 새 화면을 만들지 않고 동의 화면이 쓰는 문서 묶음(`consentBundleProvider`)과 전문 화면(`ConsentDocumentScreen`)을 그대로 씁니다. 서버 → 캐시 → 앱 번들 순서도 그대로 따라가므로 네트워크가 없어도 읽힙니다.
- 설정 화면에 **문의하기**를 추가합니다. 외부 브라우저로 보내지 않고 문의 이메일을 보여주고 복사하게 합니다. 새 의존성을 넣지 않기 위해서입니다.
- 설정 화면 맨 아래에 **앱 버전**을 표시해 게시된 안내와 맞춥니다. `package_info_plus`가 이미 있습니다.

⚙️ 작업 내용
---

- [ ] iOS `TARGETED_DEVICE_FAMILY`를 `1`로 (Debug/Release/Profile 세 곳)
- [ ] iOS `Info.plist` 화면 방향을 세로만 남기고, `CFBundleDisplayName`을 `이룸`으로
- [ ] Android 매니페스트 `android:label`을 `이룸`으로, `MainActivity`에 세로 고정 추가
- [ ] 설정 화면에 `약관 및 개인정보처리방침` 추가 (문서 목록 → 전문)
- [ ] 설정 화면에 `문의하기` 추가 (이메일 표시와 복사)
- [ ] 설정 화면 맨 아래 앱 버전 표시
- [ ] 문의 이메일을 `.env`(`ELUM_SUPPORT_EMAIL`)로 빼고 `AppConfig`에 기본값과 함께 추가
- [ ] 위젯 테스트: 설정 화면에 새 줄이 보이는지, 문서 목록에서 전문으로 넘어가는지
- [ ] `flutter analyze`, `flutter test` 통과 확인
