🗒️ 설명
---

카드 수정 시트에서 카드 제목을 고치면 시트와 카드 검토 화면에는 새 제목이 보인다. 그런데 `카드 저장하기`로 저장하면 서버에는 원래 제목이 남아 보호자 화면과 이룸이 휴대폰 모두 옛 제목을 보여준다. 같은 시트에서 바꾼 사진은 저장된다. 사용자는 고쳤다고 믿는데 아무 안내 없이 수정이 사라진다.

코드 기준 원인 후보: `RoutineRepository.updateStep`이 `PATCH /api/routines/{id}/steps/{stepId}`에 `{'description': ...}`만 보낸다. 서버의 `RoutineStepUpdateRequest`는 `title`도 받는다(보낸 필드만 바뀐다). 제목은 화면에만 반영되고 서버로 가지 않는다.

🔄 재현 방법
---

1. 설정의 그림 방식을 `직접 찍은 사진`으로 하고 일과를 만들어 카드 검토 화면까지 간다(저장된 일과의 `편집하기`로도 된다).
2. 카드 1에서 `이 카드 수정` → 제목을 `Get toothbrush`로 바꾸고 키보드를 내린 뒤 시트 `완료`.
3. 카드 검토 화면에 `Get toothbrush`가 보인다.
4. `카드 저장하기`로 저장한 뒤 홈에서 그 일과를 열면 카드 1 제목이 원래대로 `칫솔을 챙겨요`다. 이룸이 휴대폰에서도 같다.

두 번 재현했다(처음 생성 직후 저장, 저장된 일과를 편집해 다시 저장).
