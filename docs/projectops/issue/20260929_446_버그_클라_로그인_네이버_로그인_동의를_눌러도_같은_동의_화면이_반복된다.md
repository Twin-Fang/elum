🗒️ 설명
---

네이버 로그인에서 동의 화면의 `OK` 를 눌러도 앱으로 돌아오지 않고 **같은 동의 화면이 계속 반복된다(도돌이표).** 로그인이 끝나지 않는다.

원인은 `MainActivity` 의 `android:taskAffinity=""` 로 확인했다(Flutter 기본 템플릿이 넣는 줄이고 최초 이관 때부터 있었다). 그러면 네이버 SDK 의 결과 수신 Activity(`NidOAuthCustomTabActivity`)가 `MainActivity` 와 다른 태스크에 놓여 인증 결과를 받지 못한다. `flutter_naver_login` 안내도 "task affinity 가 필요하지 않으면 `android:taskAffinity=""` 를 제거하라"고 한다.

🔄 재현 방법
---

1. 안드로이드에서 로그인 화면의 `네이버로 로그인` 을 누른다.
2. 네이버 동의 화면에서 `전체 동의` 를 체크하고 `OK` 를 누른다.
3. 앱으로 돌아오지 않고 같은 동의 화면이 다시 열린다. 체크는 풀려 있다. 몇 번을 눌러도 같다.

📸 참고 자료
---

![naver_loop_before_after](https://github.com/Twin-Fang/elum/releases/download/qa-evidence/naver379_20260929-165539_naver_loop_before_after.png)

Chrome 원격 디버깅으로 `OK` 직후 네트워크를 잡은 결과 (`code` 값은 가림).

| 순서 | 무엇이 | 결과 |
|---|---|---|
| 1 | `POST nid.naver.com/login/noauth/allow_oauth` | 동의 수락 |
| 2 | `GET oauth2.0/authorize?…&oauth_token=…` | 302 → 200 |
| 3 | 페이지가 `intent://authorize/#Intent;package=kr.twinfang.elum;scheme=naver3rdpartylogin;S.code=…;S.state=…;end` 로 이동 | **네이버는 인증 코드를 정상 발급**하고 앱으로 넘긴다 (`ERR_ABORTED` = 앱 전환) |
| 4 | 앱 SDK `NidOAuthCustomTabActivity: getDecodedString() \| str : null` | **SDK 가 결과를 못 읽는다** |
| 5 | SDK 가 `authorize` URL 을 다시 연다 | 처음 동의 화면 (도돌이표) |

서버 로그에는 이 시도가 한 건도 없다 — 앱 안(SDK 수신 단계)에서 끝난다. 요청 파라미터(`response_type=code`, `redirect_uri=kr.twinfang.elum`, `client_id`, SDK `android-5.10.0`)는 정상이다.

✅ 예상 동작
---

- 동의(OK) 뒤 앱으로 돌아와 토큰이 저장되고 약관 동의 화면으로 넘어가야 한다.

⚙️ 환경 정보
---

- **OS**: Android 16 (API 36) 에뮬레이터
- **브라우저**: Chrome 154 (커스텀 탭)
- **기기**: Medium_Phone_API_36.1 (앱 v2.0.0 디버그 빌드, `flutter_naver_login` 2.1.1 · 네이버 SDK 5.10.0)

🛠️ 수정과 검증
---

- `AndroidManifest.xml` 의 `MainActivity` 에서 `android:taskAffinity=""` 를 뺀다.
- **같은 에뮬레이터·Chrome·계정에서 줄만 바꿔 A/B 검증했다.** 수정 전 반복, 수정 후 앱 복귀 → `elum.refreshToken` 저장(`lastLoginProvider=naver`) → 약관 화면.
- 되돌리면 실패하는 회귀 테스트(`android_naver_login_manifest_test.dart`)를 붙인다.
