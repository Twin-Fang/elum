📝 현재 문제점
---

- 보호자 화면에서 일과(행동카드 묶음)를 만들고 이룸이 화면으로 넘어가면, 방금 만든 일과가 바로 보이지 않는다.
- #517에서 넣은 오늘 일과 자동 갱신은 화면에 들어올 때 **30초 주기만 시작하고 첫 갱신은 하지 않는다.** 그래서 전환 직후에는 직전 목록을 보여주고, 최대 30초 뒤에야 새 일과가 나타난다.
- 바로 다시 받는 경우는 앱이 백그라운드에서 돌아올 때뿐이다.
- 관련 파일
  - `client/lib/features/child/application/routine_auto_refresh.dart` (주기 갱신)
  - `client/lib/features/child/presentation/child_home_screen.dart` (이룸이 홈)
  - `client/lib/features/guardian/presentation/guardian_home_screen.dart` (보호자 홈, 같은 자동 갱신을 씀)

🛠️ 해결 방안 / 제안 기능
---

- 자동 갱신이 화면에 붙는 순간 오늘 일과를 **한 번 바로 다시 받고**, 그 뒤부터 30초 주기를 돈다.
- 보호자 홈도 같은 자동 갱신을 쓰므로 함께 적용된다. 이룸이 화면에서 보호자 화면으로 돌아올 때도 진행 상황이 바로 반영된다.
- 지금 지키고 있는 동작은 그대로 둔다.
  - 이미 받는 중이면 건너뛴다(요청이 쌓이지 않게).
  - 다시 받는 동안과 실패했을 때 직전 목록을 유지한다(깜빡임, 빈 화면 없음).
  - 백그라운드에서는 멈춘다.

⚙️ 작업 내용
---

- 진입 즉시 갱신 추가
- 위젯 테스트: 진입 직후 1회 갱신, 받는 중 중복 요청 없음, 실패 시 직전 목록 유지
- 실기기 확인: 보호자 화면에서 일과 저장 → 이룸이 화면 전환 시 바로 보이는지
