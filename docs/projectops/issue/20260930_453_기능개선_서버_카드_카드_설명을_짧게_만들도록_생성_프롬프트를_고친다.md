📝 현재 문제점
---

- 현장 피드백: 카드의 이미지, 제목, 내용 중 내용이 너무 길어서 발달장애인이 이해하기 어렵다.
- 생성 프롬프트가 설명을 "제목보다 조금 더 자세히, 소리 내어 읽어주는 한 문장"으로 요구해 문장이 길어지기 쉽다. 제목은 이미 "2~4어절"이다.
- 이룸이 화면은 제목과 설명을 모두 소리 내어 읽어 주므로 설명이 길면 듣는 시간도 길어진다.
- 서버 입력 상한(설명 300자)은 사용자가 직접 고칠 때의 안전망일 뿐 생성 길이를 줄여 주지 않는다.

🛠️ 해결 방안 / 제안 기능
---

- 서버 상한이나 검증을 새로 두지 않고, **생성 프롬프트를 고쳐 짧게 요청**한다.
- 설명은 "한 문장, 20자 안팎, 어려운 말과 꾸밈말 없이 행동 하나만"으로 바꾼다. 제목과 같은 말을 되풀이하지 않게 한다.
- 20자라는 숫자는 제안값이다. 자문 기관이나 피드백을 준 현장 담당자에게 확인이 필요하다.
- 운영 프롬프트는 DB(`prompt_template`)에 있어 코드 기본값을 고쳐도 덮이지 않는다. 코드 기본값과 함께 **관리자 프롬프트 화면에서 운영 값도 고친다.**
- 이미 만들어 둔 일과는 그대로 두고, 새로 만드는 일과부터 적용한다.
- 프롬프트를 고친 뒤 실제 생성 결과를 몇 건 보고 길이가 줄었는지 확인한다. 글 생성은 이미지보다 싸지만 반복 호출은 피한다.

⚙️ 작업 내용
---

- 카드 생성 프롬프트 기본값의 설명 규칙 수정
- 운영 DB 프롬프트를 관리자 화면에서 같은 내용으로 수정 (수정 이력 확인)
- 생성 결과 몇 건으로 길이 확인, 확인된 문장 길이는 이슈에 기록
- 새 규칙에 맞는 예시 문장을 프롬프트에 넣을지 검토
