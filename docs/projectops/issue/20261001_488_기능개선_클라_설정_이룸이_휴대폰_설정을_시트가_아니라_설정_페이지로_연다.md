📝 현재 문제점
---

이룸이 휴대폰에서 홈 오른쪽 위 설정 톱니를 누르면 **바텀시트**가 올라온다.
보호자 휴대폰은 설정을 누르면 **설정 페이지**로 이동하는데, 이룸이 휴대폰만 모양이 다르다.

- 이룸이 설정 시트는 #363에서 시안이 없어 **임시로** 만든 것이다. 디자인 요청 대상으로 남겨 두었다.
- #485에서 이 시트에 약관과 앱 정보 줄을 더하면서 시트 모양을 그대로 두었다.
- 약관 줄을 누르면 시트 위에 화면이 덮여 시트와 화면이 겹쳐 쓰인다.

🛠️ 해결 방안 / 제안 기능
---

- 이룸이 휴대폰의 설정 톱니를 누르면 **보호자 설정과 같은 모양의 설정 페이지**로 이동한다. 뒤로가기와 같은 줄의 `설정` 제목, 줄 목록 모양을 보호자 설정과 맞춘다.
- 줄은 지금 시트와 같다: `약관 및 개인정보처리방침`, `앱 정보`, `로그아웃`, `회원탈퇴`. 보호자 설정의 AI 크레딧, 이룸이 휴대폰 연결, 임시저장, 비밀암호 변경은 넣지 않는다.
- 로그아웃과 회원탈퇴는 시트일 때와 동작이 같다. 이 휴대폰의 연결만 끊고 연결 암호 입력 화면으로 가며, 실패하면 설정 페이지에 머물고 에러 코드를 보여준다.
- 시트는 쓰는 곳이 없어지므로 설정 페이지로 바꾼다.

⚙️ 작업 내용
---

- 이룸이용 설정 페이지 화면 추가와 경로 등록
- 홈 톱니가 시트 대신 설정 페이지로 이동하게 연결
- 기존 시트 테스트를 페이지 기준으로 수정, 설정 페이지 진입·뒤로가기 확인 추가
