📝 현재 문제점
---

- 설정의 두 화면 시안이 바뀌었다. `이룸이 휴대폰 연결`(Figma `1532:6671`)과 `다른 보호자 초대하기`(Figma `1579:8206`)다.
- 새 시안은 두 화면이 같은 모양이다. 암호 여섯 글자 아래에 `코드 복사하기` 알약, 그 아래 빨간 `09:59`와 `뒤에 코드가 바껴요`, 맨 아래 `링크로 보내기` 큰 버튼 하나다.
- 지금 앱은 시안과 다르다.
  - 이룸이 휴대폰 연결(설정 진입): `다시 만들기` 칩과 `09:59`만 있고, 안내 문구 둘과 하단 버튼 둘(`링크로 보내기`, `코드 복사하기`)이 붙어 있다.
  - 다른 보호자 초대: 화면 설명에 `임시 시안`이라고 적혀 있고, 시간이 다 되면 `만료됐어요`와 흐린 코드, `다시 만들기`가 나온다.
- 온보딩 진입은 이미 새 시안(`뒤에 코드가 바껴요`)으로 바뀌어 있어, 같은 코드인데 진입 경로에 따라 화면이 다르다.
- `만료`라는 말은 쓰지 않기로 했다. 시간이 다 되면 사용자가 아무것도 하지 않아도 새 코드로 바뀌는 것이 맞다.

🛠️ 해결 방안 / 제안 기능
---

- 두 설정 화면을 시안대로 맞춘다. 온보딩 진입과 같은 암호 패널(복사 알약 + `뒤에 코드가 바껴요`)과 하단 버튼 하나를 쓴다.
- 시간이 다 되면 `만료됐어요` 표시 없이 새 코드를 자동으로 받는다. 받지 못하면 `다시 만들기` 칩과 에러 코드를 보여 준다.
- 시안에 없는 안내 문구(앞 암호를 못 쓰게 된다, 휴대폰 안내)는 시안대로 뺀다. 되돌릴 수 없는 일을 먼저 알리는 규칙은 `코드가 바뀌면 앞 코드는 못 써요`를 짧게 남길지 디자이너에게 확인한다.
- 두 화면을 시안 프레임에 올려 속성과 픽셀로 대조한다.
