📝 현재 문제점
---

이룸이가 일과의 마지막 카드를 체크해도 지금은 카드마다 뜨는 별 화면(`축하해요!`)만 나온다. 일과 전체를 끝냈다는 것을 알려 주는 화면이 없다.

- 디자이너가 `일과완료` 시안을 새로 그렸다 (Figma `이룸` 파일 `1274:9831`, 섹션 `425:4392`).
- 코드에는 `일과를 끝냈어요`가 없고, 일과 진행 화면의 `_advanceToNextUnchecked` 주석에도 "일과를 다 끝냈을 때 보여줄 화면은 시안이 나온 뒤 따로 만든다"고 남아 있다.

🛠️ 해결 방안 / 제안 기능
---

- 마지막 카드를 체크하면 **별 화면 → 일과완료 화면** 순서로 보여 주고, 일과완료 화면을 닫으면 이룸이 홈으로 돌아간다.
- 일과완료 화면은 시안 그대로 만든다.
  - 배경: 위에서 아래로 `#0C0D1A` 7% → `#39514D` 100% 그라디언트
  - 루미 캐릭터와 빛나는 별 5개
  - 제목 `일과를 끝냈어요!` (30pt, 800, 가운데)
  - 보상 칩: 333×80, 모서리 20, 반투명 `#EEE9E6` 30%, 글자는 보상 문구만(`다하면` 없음)
  - 버튼 `오예!` (일반 버튼, 360×66)
- 보호자가 정한 보상이 **없으면 보상 칩을 그리지 않는다.** 칩 자리를 비워도 시안과 어긋나지 않게 제목과 버튼 자리는 시안 좌표에 고정한다.
- 이미 끝낸 일과의 카드를 다시 체크하거나 체크를 풀었다 다시 하는 경우에는 이 화면이 뜨지 않는다. 별 화면이 뜨는 조건(처음 체크할 때)과 같다.

⚙️ 작업 내용
---

- 일과완료 화면 추가와 경로 등록
- 마지막 카드 체크 → 별 화면 → 일과완료 → 홈 흐름 연결
- 시안 대조 테스트에 `1274:9831` 추가, 흐름 위젯 테스트(보상 있음/없음, 재체크 시 안 뜸) 추가

확인이 필요한 것
---

- 카드마다 뜨는 별 화면에 보상 칩이 지금 남아 있다 (시안 `보상_루미` 등에도 남아 있음). 일과완료 화면에 보상이 생겼으니 별 화면의 칩은 빼는 것이 맞는지 디자이너 확인이 필요하다. 확인 전까지는 별 화면을 건드리지 않는다.
- 이룸이 휴대폰 시안(`1197:6774`)에는 일과완료 프레임이 없다. 두 휴대폰이 같은 화면을 쓴다고 보고 만든다.
