📝 현재 문제점
---

- 클라이언트에 번역 기반이 없다. 사용자에게 보이는 한글 문구 549줄(99개 파일)이 코드에 박혀 있고, 번역 파일, 로케일 설정, 폰트 대체가 없다.
- 조사, 숫자 단위, 날짜와 요일이 한국어를 전제로 코드에서 직접 조립된다.
- 줄바꿈 보조(`keepWords`)가 한글 전용이라 공백 없는 언어(일본어, 중국어)에 맞지 않는다.

🛠️ 해결 방안 / 제안 기능
---

- 번역 파일(ARB)을 도입하고 **한국어 화면은 지금과 똑같이** 두면서 문구를 옮긴다. 앱 안에는 언어 선택 화면을 만들지 않고 휴대폰 언어를 따른다. 번역이 빠진 문구는 한국어로 대체한다.
- 모든 서버 요청에 `Accept-Language`를 붙인다. 개발자 도구에만 언어 강제 스위치를 둔다.
- 조사, 숫자 단위, 날짜를 언어별 문구 규칙으로 바꾼다. 일본어와 중국어 폰트는 시스템 대체로 시작한다.

⚙️ 작업 내용
---

- [ ] 기반(11개 Task): 의존성, 번역 파일 골격, 언어 판정, 개발자 언어 스위치, 폰트 대체, 앱 연결, 요청 헤더, 테스트 도구, 줄바꿈, 조사·날짜 헬퍼
- [ ] 폴더별 문구 추출(12개 Task): 사용자 노출 한글 540줄(94개 파일)
- [ ] 일과 언어 필드와 카드 글·음성 언어 소비 지점
- [ ] 통과 조건: `flutter analyze` 0건, 기존 앱 테스트 전체 통과, 골든·시안 변경 0건(한국어 화면 불변)
