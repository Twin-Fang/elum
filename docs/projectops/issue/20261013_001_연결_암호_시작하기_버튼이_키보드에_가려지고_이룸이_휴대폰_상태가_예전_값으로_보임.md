🗒️ 설명
---

이룸이 휴대폰 연결 화면과 보호자의 이룸이 휴대폰 상태 화면에서 찾은 결함 다섯 가지다.

1. **"시작하기"가 키보드에 가려진다.** 이룸이 휴대폰에서 연결 암호를 치는 동안 버튼이 키보드 뒤에 있다. 6글자를 다 쳐도 자동으로 넘어가지 않아 키보드를 내려야 버튼이 보인다. 초대 코드 넣기 화면은 6글자에서 자동으로 넘어가 두 화면이 다르다.
2. **6글자를 넘게 받는다.** 7번째 글자가 들어가도 칸에는 6글자만 보이고 "시작하기"는 꺼진다. 화면에서는 이유를 알 수 없다.
3. **실패 안내에 에러 코드가 없다.** "암호가 만료됐어요. 새 암호를 받아주세요"만 나온다. 초대 코드 화면은 코드를 붙인다.
4. **이룸이 휴대폰 상태가 예전 값으로 보인다.** 설정 화면이 같은 상태 값을 붙잡고 있어서, 이룸이 휴대폰 화면이 설정을 처음 연 시점의 값을 보여 준다. 공동 보호자(교사) 휴대폰에 이미 끊긴 휴대폰이 "10월 7일부터 연결됨"으로 보였다(실제로는 10월 13일에 새 휴대폰 연결).
5. 4번 상태에서 "연결 끊기"를 누르면 "이미 끊겨 있어요" 뒤 다른 휴대폰이 "연결됨"으로 바뀌어 보인다. 끊었는데 연결됨이 남은 것처럼 보인다.

🔄 재현 방법
---

1. 이룸이 휴대폰 연결 화면에서 연결 암호 칸을 누른다 → 키보드에 "시작하기"가 가려진다
2. 7글자를 친다 → 칸은 6글자, "시작하기"는 꺼짐
3. 만료된 암호를 넣는다 → 에러 코드 없는 안내
4. 공동 보호자 휴대폰에서 설정을 열어 둔 채, 다른 보호자가 이룸이 휴대폰을 끊고 새로 연결한다 → 공동 보호자가 설정 → 이룸이 휴대폰을 열면 옛 휴대폰이 보인다
