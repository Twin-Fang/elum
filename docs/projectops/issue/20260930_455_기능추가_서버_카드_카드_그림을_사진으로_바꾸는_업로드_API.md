📝 현재 문제점
---

- 카드 그림은 AI가 만든 것만 쓸 수 있고, 보호자가 직접 찍은 사진으로 바꿀 방법이 없다. 카드 수정 API는 제목, 설명, 순서만 받는다.
- 현장 피드백: 애니메이션풍 그림은 발달장애인에게 추상화가 어렵고(옷장인지 모를 수 있다) 실제 물건 사진이 필요할 때가 있다.
- 서울 ABA 연구소 1차 자문(`docs/meetings/20260913_서울ABA연구소_1차자문` 4-8절)도 사진이 가장 이해하기 쉽다고 정리했다.
- AI 그림을 쓰지 않는 사용자를 위한 "직접 사진" 그림 방식(별도 이슈)의 전제 기능이다.

🛠️ 해결 방안 / 제안 기능
---

- 카드 한 장의 그림을 사용자가 올린 사진으로 교체하는 API를 만든다.
- 저장은 기존 카드 그림 저장소(서버 로컬 디스크)를 그대로 쓰고 카드의 그림 경로를 새 파일로 바꾼다. 이전 파일은 정리한다.
- 올라온 사진은 서버에서 크기를 줄이고 위치 정보(EXIF)를 지운다. 이미지가 아닌 파일, 너무 큰 파일은 거절한다.
- AI 크레딧을 쓰지 않는다. AI 서비스로 사진을 보내지 않는다.
- 클라이언트가 이전 그림을 캐시하고 있어도 새 사진이 보이도록 경로를 바꾸거나 갱신 표시를 준다.
- 보호자가 아닌 사용자, 남의 일과 카드는 기존 권한 규칙대로 거절한다.
- 원본 사진을 감사 로그에 남기지 않는다(원칙 5).

⚙️ 작업 내용
---

- 카드 그림 교체 엔드포인트와 요청·응답 정의
- 이미지 검증(형식, 크기), 리사이즈, EXIF 제거
- 저장소 저장과 기존 파일 정리, 실패 시 기존 그림 유지
- 서버 테스트: 정상 교체, 형식 오류, 용량 초과, 권한 없음, 저장 실패 시 기존 그림 유지
