🗒️ 설명
---

함께하는 사람 화면을 사용자 눈으로 밟다가 나온 낮은 심각도 항목이다. 기능은 되지만 처음 쓰는 사람이 멈칫한다.

1. **자기 초대 코드를 넣었을 때**: "이미 함께하고 있는 이룸이예요. (PROFILE_ALREADY_GUARDIAN)". 내가 만든 코드를 내 휴대폰에 넣은 것인데 문구는 "이룸이"가 이미 함께한다고 읽혀 무슨 말인지 모호하다.
2. **내 이름을 비우고 저장**: 저장된다. 행이 `보호자 [나] 보호자`로 이름과 역할이 같은 글자가 되고, 가입 때 받은 원래 이름은 돌아오지 않는다.
3. **입력 중 키보드가 주 버튼을 가린다**: 연결 암호 입력의 `시작하기`, 이룸이 이름 입력의 `다음`이 키보드 밑에 있어 6글자/이름을 넣고도 버튼이 보이지 않는다. 키보드의 `done`/`완료`로 내려야 한다. 초대 코드 입력은 6글자에서 자동 제출되어 화면마다 방식이 다르다 (아래 댓글에 캡처).

> 정정(2026-10-07): 처음 올린 항목 3(이름 칸이 좁다)과 4(한글 줄바꿈이 한 글자만 남는다)는 뺐다. 보호자 시뮬레이터의 글자 크기가 큰 글씨 시험 뒤 기본값으로 돌아오지 않은 채였고, 기본 글자 크기에서는 두 문제가 없었다. 큰 글씨에서의 깨짐은 #572에서 다룬다.

🔄 재현 방법
---

1. 설정 → 함께하는 사람 → `다른 보호자 초대하기`에서 코드를 본다.
2. 뒤로 가서 `받은 초대 코드 넣기`에 그 코드를 넣는다.
3. 내 행을 눌러 `내 이름 고치기`에서 이름을 모두 지우고 `저장`.
4. 이룸이 휴대폰에서 연결 암호 6글자를 넣어 `시작하기`가 보이는지 본다.

✅ 예상 동작
---

- 자기 코드를 넣으면 "내가 만든 코드예요. 함께할 보호자에게 알려주세요"처럼 상황이 읽히는 문구가 나온다.
- 이름을 비우면 저장되지 않거나 원래 이름으로 돌아가고, 같은 단어가 두 번 보이지 않는다.
- 키보드가 올라와도 주 버튼이 보이거나, 6글자가 차면 자동으로 진행한다.
