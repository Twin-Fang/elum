보호자 홈에서 일과를 눌러 올라오는 **바텀시트의 상단 모서리가 각져 있습니다.**

![sheet_corner_design_vs_render](https://github.com/Twin-Fang/elum/releases/download/qa-evidence/issue-sheet-corner_20260922-173130_sheet_corner_design_vs_render.png)

*왼쪽 시안 · 오른쪽 렌더. 시안은 곡선을 그리며 들어오고 렌더는 첫 줄부터 직각이다.*

**픽셀 실측** (786폭, 시트 top y=476)

| | y+2 | y+6 | y+12 | y+20 | y+30 |
|---|---|---|---|---|---|
| 시안 | x≥28 부터 채움 | x≥18 | x≥12 | x≥6 | x≥2 |
| 렌더 | **x=0 부터 채움** | x=0 | x=0 | x=0 | x=0 |

**Figma 원본도 명시하고 있습니다.** 헤더 배경 사각형(`980:4891`, 393×68)의 값이
`rectangleCornerRadii: [20, 20, 0, 0]` 입니다 — 좌상 20 · 우상 20 · 하단 0.

### 원인

`routine_detail_sheet.dart` 의 루트가 라운드를 **배경에만** 주고 자식을 자르지 않습니다.

```dart
return Container(
  decoration: BoxDecoration(
    color: colors.background,
    borderRadius: BorderRadius.vertical(top: Radius.circular(20.r)),  // 배경만 둥글다
  ),
  child: Column(children: [
    _Header(...),   //  Container(color: colors.background) — 라운드 없이 전체 폭을 덮는다
```

Flutter `Container` 는 `decoration.borderRadius` 로 **배경만** 둥글게 칠하고 자식은
자르지 않습니다(`clipBehavior` 기본 `none`). 헤더가 같은 색 사각형을 그 위에 덮어
모서리가 메워졌습니다.

헤더 배경은 **의도적으로 넣은 것**입니다 — 없으면 스크롤되는 목록이 제목 뒤로 비칩니다(#310).
그 수정이 이 문제를 만들었습니다.

### 단계 뱃지도 같이 걸렸습니다

속성 대조를 돌리니 2번 단계 뱃지(40×68, r=16)도 네 모서리 모두 각짐으로 나옵니다.
드래그 중 프록시가 라운드를 잃는 것으로 보입니다 — 함께 확인합니다.

🛠️ 해결 방안 / 제안 기능
---

루트 `Container` 에 `clipBehavior: Clip.antiAlias` 를 준다.

```dart
return Container(
  clipBehavior: Clip.antiAlias,   // 자식도 둥근 모양으로 자른다
  decoration: BoxDecoration(...),
```

헤더에 같은 라운드를 따로 주는 방법도 있지만 `clipBehavior` 가 낫습니다.
나중에 다른 자식이 배경을 깔아도 다시 터지지 않습니다.

**실패 경로** — 클리핑이 `ReorderableListView` 의 드래그 프록시를 자르지 않는지 확인합니다.
프록시는 이미 시트 안에 그리도록 바꿔 두었지만(#274) 눈으로 한 번 봅니다.
