📝 현재 문제점
---

### 1. 로그인 실패를 화면 안 글자로만 알린다

실패하면 버튼 위에 회색 글자 한 줄이 붙습니다.

```dart
if (_errorMessage != null) ...[
  Text(_errorMessage!, ...)   // 버튼 위에 끼워 넣는다
```

- 버튼 바로 위라 **눌린 버튼에 가려 안 보이기 쉽다.** 배경이 캐릭터 그림이라 대비도 약하다
- 글자가 생기면서 **버튼 묶음이 위로 밀린다.** 누르려던 자리가 움직인다
- 이 앱에는 이미 공통 팝업 `showElumDialog`(#232)가 있는데 로그인만 다른 방식을 쓴다

### 2. `최근 로그인` 표시가 시안과 다르다

시안(`로그인_iOS` 238:1808)은 **버튼 우상단에 겹쳐 놓인 알약**입니다.
지금 코드는 버튼 **위에 가운데 정렬**로 놓고 문구도 다릅니다.

| | 시안 | 현재 |
|---|---|---|
| 자리 | 버튼 우상단에 겹침 | 버튼 위 가운데, 줄을 따로 차지 |
| 문구 | `최근 로그인` | `지난번에 이걸로 로그인했어요` |
| 크기 | 91×28 · r20 | 글자에 맞춰 늘어남 |
| 색 | `#FFFADC` 투명도 50% | 흰색 72% |
| 글자 | Pretendard 500 / 12 / `#242634` | caption / textSecondary |

줄을 따로 차지하기 때문에 **최근 로그인이 있을 때만 버튼 묶음이 밀립니다.**

### 참고 — `E-AUTH` 가 무엇인가

`AuthOutcome.failed` 입니다. **네트워크 문제(`E-NET`)도 중복 가입(`E-DUP`)도 아닌 나머지 전부**이고
구체적으로는 네 갈래입니다.

1. 소셜 SDK 자체가 실패 (`OAuthSdkFailure`)
2. 서버가 200 을 줬는데 응답에 토큰이 비어 있음
3. 토큰 교환 API 가 오프라인도 409 도 아닌 오류 (4xx·5xx)
4. 그 밖의 예외

네 갈래가 한 코드로 뭉쳐 있어 **제보를 받아도 어디서 터졌는지 못 가립니다.**
특히 1번은 스토어로 받은 빌드에서만 나기 쉽습니다 — Play 가 앱을 다시 서명하므로
앱 서명 키의 SHA-1·키해시를 카카오·구글에 등록하지 않으면 그 빌드에서만 로그인이 깨집니다(#286 4단계).

🛠️ 해결 방안 / 제안 기능
---

### 1. 실패는 모달로 알린다

`showElumDialog` 를 그대로 씁니다. 화면마다 팝업을 새로 그리지 않는다는 기존 결정(#232)을 따릅니다.

| 결과 | 제목 | 설명 |
|---|---|---|
| `emailConflict` | 이미 가입된 계정이에요 | 처음 쓰신 방법으로 로그인해주세요 (E-DUP) |
| `offline` | 인터넷 연결을 확인해주세요 | 연결한 뒤 다시 해주세요 (E-NET) |
| `failed` | 로그인하지 못했어요 | 잠시 후 다시 해주세요 (E-AUTH) |

- 아이콘은 `warning` — 붉은 경고는 쓰지 않습니다(이 앱 규칙)
- **에러 코드는 그대로 노출합니다.** 제보를 받았을 때 추적할 수단입니다
- `_errorMessage` 상태와 인라인 `Text` 는 지웁니다. 버튼 묶음이 더 이상 밀리지 않습니다

### 2. `E-AUTH` 를 갈래별로 나눈다

지금은 네 갈래가 한 코드입니다. 뒤에 한 글자만 붙여도 제보 추적이 달라집니다.

| 갈래 | 코드 |
|---|---|
| 소셜 SDK 실패 | `E-AUTH-SDK` |
| 응답에 토큰 없음 | `E-AUTH-TOKEN` |
| 교환 API 오류 | `E-AUTH-API` |
| 그 밖의 예외 | `E-AUTH` |

### 3. `최근 로그인` 을 시안값으로 맞춘다

Figma `로그인_iOS`(238:1808) 실측 그대로 둡니다.

| 값 | |
|---|---|
| 알약 | 91×28 · `cornerRadius 20` |
| 색 | `#FFFADC` · opacity 0.5 |
| 자리 | 버튼 **우측에서 16**, 버튼 상단에서 **위로 10** (겹침) |
| 글자 | `최근 로그인` · Pretendard 500 · 12 · `#242634` · 알약 정중앙 |

버튼 간격이 12 라 위로 10 겹쳐도 **레이아웃이 밀리지 않습니다.**
`Stack(clipBehavior: Clip.none)` 으로 얹습니다.

> AOS 시안(`1022:4333`)에는 이 표시가 없습니다. 같은 기능이므로 **양쪽 다 보여줍니다** —
> 안드로이드만 빼면 기기에 따라 동작이 달라집니다.
