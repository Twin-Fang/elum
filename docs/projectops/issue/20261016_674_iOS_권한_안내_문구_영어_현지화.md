# 🚀[기능개선][클라][다국어] iOS 권한 안내 문구 영어 현지화

📝 현재 문제점
---

- 영어 휴대폰에서 iOS 권한 팝업 설명이 한국어로 뜬다 (#529 운영 실기 확인 중 발견, 추적 권한 팝업에서 확인).
- `client/ios/Runner/Info.plist`에 한국어 문구만 있고 `en.lproj/InfoPlist.strings`가 없다 (`Base.lproj`만 있음).
  - `NSCameraUsageDescription`: 카드 그림으로 쓸 사진을 찍으려고 카메라를 사용해요
  - `NSPhotoLibraryUsageDescription`: 카드 그림으로 쓸 사진을 고르려고 사진 보관함을 사용해요
  - `NSUserTrackingUsageDescription`: 보호자 화면에 알맞은 광고를 보여드리는 데 사용해요. 이룸이의 정보는 사용하지 않아요.
- 앱 화면은 영어인데 시스템 팝업만 한국어라 영어 사용자가 권한을 허용할지 판단하기 어렵다. App Store 심사에서도 권한 설명은 사용자 언어로 이해할 수 있어야 한다.

🛠️ 해결 방안 / 제안 기능
---

- 권한 설명 3개를 영어로 현지화한다 (`en.lproj/InfoPlist.strings`). 한국어는 지금 문구 그대로 둔다.
- 영어 문구는 앱 영어 용어(이룸이 = Elumi)를 따른다.
- 홈 화면 앱 이름(`CFBundleDisplayName` "이룸")을 영어 휴대폰에서 바꿀지 함께 정한다. 브랜드 이름이라 그대로 둘 수도 있다.
- Android 쪽에 같은 성격의 한국어 고정 문구가 있는지 함께 확인한다.

⚙️ 작업 내용
---

- iOS 권한 설명 영어 현지화
- 영어 시뮬레이터에서 카메라, 사진, 추적 권한 팝업 확인
- 앱 이름 현지화 여부 결정
