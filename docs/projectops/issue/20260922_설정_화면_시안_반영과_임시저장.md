### 1. 설정 목록을 시안값으로 맞춘다

행을 60 고정으로 두고 라벨·화살표·간격을 실측값에 맞춘다. 회원탈퇴만 `#DA5050` w500.

### 2. 임시저장 = 만들다 만 일과

**서버에 이미 개념이 있다.** `RoutineStatus.PENDING_REVIEW` — 카드까지 만들어졌지만 보호자가
아직 확인하지 않은 일과다. 용어 규칙도 이것을 `임시저장`이라 부르라고 정해 두었다
(`승인 대기` ❌ → `임시저장` ✅ — 만들다 만 것이지 심사가 아니다).

디자인이 없으므로 **이 앱에 이미 있는 것들로만** 짠다. 새 시각 언어를 만들지 않는다.

- 목록은 보호자 홈의 일과 타일과 같은 모양을 쓴다
- 각 줄을 누르면 카드확인 화면으로 이어진다 — **`이어서`**
- 0건이면 빈 상태를 따로 그린다 (로딩과 구분한다)

**빈 상태 문구**
```
만들다 만 일과가 없어요
일과를 만들다 그만두면 여기에 남아요
```

### 3. 실패 경로 (정상 경로만 만들지 않는다)

| 상황 | 요구 |
|---|---|
| 목록 조회 실패 | 재시도 버튼 + 에러 코드. 무한 로딩 금지 |
| 0건 | 로딩과 구분되는 빈 상태 |
| 이어서 눌렀는데 그 사이 지워짐 | 목록을 새로고침하고 안내 |
