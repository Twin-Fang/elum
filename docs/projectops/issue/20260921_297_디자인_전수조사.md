📝 현재 문제점

**화면이 시안과 얼마나 어긋나 있는지 아무도 모릅니다.**

일과 시트 하나를 열어 대조했더니(#295) 글꼴·글자 크기·체크 동그라미·보상 줄 짜임이 전부 달랐습니다. **한 화면에서 여섯 군데가 나왔다면 나머지 화면도 성할 리 없습니다.**

### 왜 여태 못 잡았나 — 검증에 구멍이 있습니다

**골든 테스트는 "시안과 같은가"를 판단하지 못합니다.** CLAUDE.md에도 적혀 있습니다. 첫 이미지가 시안과 다르면 **틀린 것을 그대로 고정**하고, 이후에는 그 틀린 그림에서 벗어나는 것만 잡아냅니다. 회귀는 막지만 정합은 못 봅니다.

지금 골든 여러 장이 그 상태일 수 있습니다.

🛠️ 해결 방안 / 제안 기능
---

**화면·공통 컴포넌트를 하나씩 시안과 맞대어 보고, 어긋난 것을 전부 적습니다.**

### 어떻게 보나 (화면 하나당)

1. 시안 노드를 덤프해 **값**(글꼴·크기·색·여백·모서리)을 읽는다
2. 같은 노드를 **PNG로 받아 눈으로** 본다 — 덤프에는 화면에 안 그려지는 레이어도 섞여 나온다
3. 코드의 토큰 값과 하나씩 맞댄다
4. 다른 것을 **표로 적는다.** 이 이슈에서는 **고치지 않는다** — 고치는 것은 화면별 이슈로 나눈다

### 먼저 볼 것 — 공통 컴포넌트

한 번 어긋나면 **모든 화면이 함께 어긋나므로** 화면보다 먼저 봅니다.

- [ ] 체크 동그라미 (`채크_라운드` 726:4881) — enable / Default 두 상태 ⚠️ #295에서 시트 것만 고쳤고 **다른 화면은 그대로입니다**
- [ ] 버튼 (`일반 버튼` 187:299) — enable / disable
- [ ] 모드 변경 버튼 (736:5954)
- [ ] 순서변경 손잡이 (931:4390)

- [ ] 색 토큰 — `textSecondary`(#898B98)가 시안 `sub_color`(#74757D)와 다른 것부터
