📝 현재 문제점
---

개발자 도구의 로그를 내보내면 두 가지가 불편하거나 오류를 낸다. 디자이너 휴대폰 로그(2026-10-02)에서 확인했다.

- **이미지 바이트를 글자로 찍는다.** 카드 그림을 받을 때 응답 본문(수 MB 이미지)을 `[137,80,78,71,...]` 숫자 목록으로 펼쳐 로그에 넣는다. 한 줄이 수천 자이고 장마다 반복돼 로그를 내보내거나 읽기 어렵다. 502 오류 때도 HTML 오류 페이지가 숫자 목록으로 찍혀 무슨 오류인지 알아보기 어렵다.
- **로그 글자를 눌렀을 때 오류가 난다.** `Null check operator used on a null value` (`Overlay.of` ← `SelectionOverlay.showHandles` ← `SelectableText`). 개발자 도구 패널은 화면 최상단(Navigator 위)에 떠 있어 글자 선택 손잡이를 그릴 Overlay 가 없다. 개발자 도구에서만 일어난다.

🛠️ 해결 방안 / 제안 기능
---

- 로그에 넣는 값이 **바이트 목록**이면 숫자를 펼치지 않고 `바이트 N개`로 줄인다. 앞부분이 글자로 읽히면(HTML 오류 페이지 등) 앞 120자만 함께 보여 준다.
- 개발자 도구 패널이 자기 Overlay 를 갖게 해서 로그와 정보 화면의 글자를 눌러도 오류가 나지 않게 한다.

⚙️ 작업 내용
---

- `AppLogger` 값 펼치기에서 바이트 목록 요약
- `DevToolsOverlay` 패널을 자체 Overlay 로 감싸기
- 시험: 바이트 목록이 줄어든다, 글자로 읽히는 오류 본문은 앞부분이 남는다, 패널의 글자를 눌러도 오류가 없다
