🚀[기능개선][클라][의견 보내기] 의견 한 건으로 원인을 좁히도록 진단 정보 확장

🗒️ 설명
---

- 2026-10-19 안드로이드 카카오 로그인 실패 건(#771)에서, 폰이 보낸 의견으로 원인을 확정하지 못했다.
- 현재 의견 첨부 기록 머리글은 앱 버전, OS 문자열, 언어, 글자 배율, 역할, 온보딩 여부, 화면 크기 7줄뿐이다.
- 설치 경로와 앱 서명 해시가 없어 "스토어 설치본"이라는 잘못된 전제로 추정을 두 번 틀렸다.
- 의견 한 건만 보고 환경 의존 문제를 판별할 수 있도록 진단 구역을 머리글에 더한다.

📋 변경 내용
---

- 머리글(`core/logger/app_log_header.dart`)에 진단 구역 추가
  - 설치: 설치 경로, 서명 인증서 해시, 설치 식별자(설치 때 만든 무작위 값)
  - 기기: 제조사, 모델, OS 버전, SDK 번호, 기기 언어, 지역, 시간대
  - 연결: 현재 연결 종류
  - 상태: 권한 허용 여부, 저전력 모드, 빌드 종류, 앱 시작 후 경과 시간, 남은 저장 공간
  - 소셜 로그인: 카카오톡 설치 여부와 버전, 카카오 SDK 키 해시, 마지막 로그인 시도 제공자와 결과 코드
- 읽지 못한 값은 `-`, 전송은 막지 않는다.
- 의견 보내기 화면 안내 문구에 기기 정보가 함께 간다는 것을 알린다.
- 개인정보처리방침의 의견 보내기 수집 항목에 위 항목을 더한다 (번들 문서와 서버 시딩 txt를 글자까지 같게).

🚫 하지 않는 것
---

- IMEI, 시리얼, 광고 ID 같은 기기 하드웨어 식별자는 수집하지 않는다 (안드로이드 10 이상에서 불가, Google Play 금지, 서비스 원칙).
- 위치, 연락처, 설치된 앱 목록, 진단명, 카드 원문은 담지 않는다.
- 서버 스키마와 API는 바꾸지 않는다.

✅ 완료 조건
---

- [ ] 의견을 보내면 서버 `feedback.app_log` 머리글에 진단 구역이 들어간다 (안드로이드 실기기에서 확인)
- [ ] 각 값을 읽는 데 실패해도 의견 전송이 된다
- [ ] 의견 보내기 화면 안내 문구가 바뀌고 한 줄로 이해된다
- [ ] 개인정보처리방침 문구와 서버 시딩 txt가 같다
- [ ] 방침 시행일 이전에는 새 항목이 전송되지 않는다 (시행일은 사용자 결정)
