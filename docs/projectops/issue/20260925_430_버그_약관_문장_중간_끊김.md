🗒️ 설명
---

설정 → 약관 및 개인정보처리방침 → **서비스 이용약관** 본문이 **문장 중간에서 끊겨** 보인다.

- `2. 로그인 수단마다 별개의 계정이 만들어집니다. 다른 수단으로 로그인하면`까지 **굵은 제목**처럼 나오고, 이어지는 `이전 계정의 정보가 보이지 않습니다.`는 다음 줄에 **보통 글자**로 떨어진다.
- 반대로 `제4조 (이용자의 의무)`처럼 조항 제목이어야 할 줄은 본문처럼 보인다.
- 같은 모양이 `2. 서비스를 정상적인 용도 외로 ... 자동화된 방법으로 과도하게` / `요청을 보내지 않습니다.`, `1. 천재지변 ... 서비스를 제공하지` / `못한 경우 ...`, `2. AI가 만든 카드의 내용은 ... 보호자가 확인하고 사용하며,` / `그 결과에 대해 ...`에서도 보인다.

법적 문서라 **문장을 고치는 것이 아니라 표시(줄 나눔·강조 해석)를 고치는 것**이다. 원문 문구는 바꾸지 않는다.

🔄 재현 방법
---

1. 보호자 설정 → `약관 및 개인정보처리방침` → `서비스 이용약관`
2. 끝까지 스크롤
