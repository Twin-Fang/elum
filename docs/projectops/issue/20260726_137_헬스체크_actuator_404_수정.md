📝 현재 문제점
---

- 서버 컨테이너 헬스체크가 `/actuator/health`를 30초마다 호출하지만, 서버에 Actuator가 없어 항상 404가 반환됩니다.
- 이 때문에 컨테이너 헬스체크가 계속 실패 상태로 돌고, 운영 로그에 30초마다 에러 dispatch 기록이 무한히 쌓여 실제 장애 로그를 가립니다.
- 배포 검증 단계는 다른 폴백 경로(스웨거)로 통과해 버려서 이 문제가 드러나지 않고 있었습니다.

🛠️ 해결 방안 / 제안 기능
---

- 의존성 추가 없이 가벼운 상태 확인 엔드포인트 `/healthz`를 추가합니다 (200 + 상태 JSON 응답).
- 컨테이너 헬스체크가 이 경로를 바라보도록 수정합니다.
- 배포 검증 단계가 이미 `/healthz`를 폴백 경로로 지원하고 있어 추가 변경 없이 맞물립니다.

⚙️ 작업 내용
---

- 상태 확인 컨트롤러 추가 (인증 불필요, 문서화 포함)
- 컨테이너 헬스체크 경로를 `/healthz`로 교체
- 단위 테스트 추가
