시안 최상위(`238:1846`)의 `팝업` 컴포넌트 세트(`931:4878`)에는 변형이 **info / 로그인실패 / 삭제 / 로그아웃/회원탈퇴 / 방침** 다섯 개뿐이다. **노란 경고(warn) 변형은 없다.**

그런데 앱은 실패와 주의를 노란 경고 팝업과 스낵바로 따로 보여주고 있다.

- 실패 팝업(`showFailure`)이 노란 경고 아이콘 + 민트 확인 버튼이다. 시안 `로그인실패`(`1045:5079`)는 붉은 느낌표 + 문장 하나 + 붉은 확인이다
- 흐름을 막지 않는 실패는 화면 아래 스낵바로 뜬다(보상 저장, 카드 문장 수정, 순서 저장, 일과 삭제, 탈퇴 실패, PIN, 소리 재생 등)
- 크레딧 소진 막힘, 로그아웃 확인, 만드는 흐름 나가기(잃는 경우)가 노란 경고를 쓴다

#242(이룸이도 보는 화면이라 빨강을 쓰지 않는다)와 #188/#353(로그아웃은 한 단계 낮춘다)의 결정을 **뒤집는다** (2026-09-27 사용자 결정).

🎯 기대 결과
---

- 실패는 모두 시안 `로그인실패` 팝업으로 뜬다: 붉은 느낌표, 문장 하나, 붉은 `확인`
- 에러 코드는 팝업 안에 글자로 함께 보인다
- 실패 스낵바는 없다. 성공 알림(예: 오늘 일과에 담았어요)만 스낵바로 남는다
- 로그아웃 확인은 시안 `로그아웃/회원탈퇴`(`1045:5194`) 그대로: 느낌표 + 회색 취소 / 붉은 확인
- 크레딧 막힘, 만드는 흐름 나가기(잃는 경우)도 느낌표 + 붉은 버튼으로 바꾼다
- 이룸이 화면의 소리 재생 실패도 같은 팝업이다. `client/CLAUDE.md`의 "이룸이 화면에 빨강 금지" 문장을 함께 고친다
- 노란 경고 아이콘, 노란 버튼 톤은 앱에서 사라진다
