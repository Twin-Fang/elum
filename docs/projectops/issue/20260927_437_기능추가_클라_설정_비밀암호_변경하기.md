📝 현재 문제점
---

- 보호자 비밀암호(보호자 화면으로 넘어갈 때 묻는 4자리)는 온보딩에서 한 번 정하면 **바꿀 방법이 없다.** 앱을 지우고 다시 깔아야 한다.
- 설정 시안(`1022:4467`)에 `비밀암호 변경하기` 줄이 새로 추가됐다(임시저장과 약관 사이). 앱에는 없다.
- 비밀암호는 휴대폰 안에만 저장된다(서버에 보내지 않는다).

🛠️ 해결 방안 / 제안 기능
---

- 설정에 `비밀암호 변경하기` 줄을 시안 위치대로 추가한다.
- 흐름: **지금 암호 확인 → 새 암호 → 한번 더 → 저장**
  - 지금 암호를 먼저 묻는다. 보호자 화면이 열린 휴대폰을 이룸이가 들고 있을 때 암호를 바로 바꿀 수 있으면 보호자 화면을 지키는 의미가 없다.
- 안쪽 화면은 **시안이 없다.** 온보딩 비밀번호 화면(`238:1909` / `238:2767`)의 점 4개·키패드를 그대로 써서 임시로 만들고, 디자인 요청 이슈를 따로 올린다.

⚙️ 작업 내용
---

- 설정 줄 추가 + 시안 대조 골든 갱신
- 비밀암호 변경 화면 (3단계, 온보딩 부품 재사용)
- 실패 경로: 지금 암호 틀림은 흔들림만, 새 암호 불일치는 다시 입력 단계만 다시 받기, 저장 실패는 공통 실패 팝업
- 위젯 테스트 + 에뮬레이터 실측
