# 🚀[기능개선][클라][음성] 영어 음성이 없는 휴대폰에서 소리 안내창 대신 글만 보여주기

📝 현재 문제점
---

- #529에서 한국어가 아닌 일과는 서버 음성으로 보내지 않게 했다. 영어 일과를 한국어 목소리로 읽던 문제를 막기 위해서다.
- 그런데 휴대폰에 그 언어의 음성이 없으면 음성 호출이 "실패"만 돌려준다. 그래서 화면에 "소리를 낼 수 없어요 (E-TTS)" 안내창이 뜬다.
- 휴대폰 고장이나 네트워크 실패가 아니다. "이 언어는 읽을 수 없는 휴대폰"일 뿐인데 오류처럼 보인다.
- 같은 방식으로 처리하는 화면이 세 곳이다.
  - 이룸이 일과 진행: `client/lib/features/child/presentation/child_routine_detail_screen.dart`
  - 보호자 카드 확인: `client/lib/features/guardian/presentation/card_review_screen.dart`
  - 보호자 카드 보기: `client/lib/features/guardian/presentation/widgets/step_card_viewer.dart`
- 휴대폰은 대부분 영어 음성을 갖고 있어서 드문 경우다. 그래서 #529에서는 범위 밖으로 남겼다.

🛠️ 해결 방안 / 제안 기능
---

- 음성 호출 결과를 "읽음 / 이 언어 음성 없음 / 실패" 셋으로 나눈다.
- "이 언어 음성 없음"이면 안내창을 띄우지 않는다. 카드 글은 화면에 그대로 있으니 조용히 넘어간다.
- 진짜 실패(엔진 오류, 네트워크 실패)는 지금처럼 E-TTS 안내창과 에러 코드를 보여준다.
- 세 화면이 같은 판단을 하므로 판단 기준은 한 곳에 둔다.

⚙️ 작업 내용
---

- 음성 결과 구분 추가 (휴대폰 음성 유무 확인, 서버 음성 미지원 언어)
- 세 화면의 안내창 조건 변경
- 영어 일과 + 영어 음성 없음 상황에서 안내창이 뜨지 않는지 확인하는 테스트
- 한국어 일과 동작은 그대로인지 확인
