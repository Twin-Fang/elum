🗒️ 설명
---

- 이룸이 휴대폰은 소셜 로그인 → 약관 → 역할 선택에서 "이룸이"를 골라야 연결 암호 화면에 닿는다.
- 그런데 **이미 온보딩을 마친 계정**(부모·교사 계정)으로 로그인하면 역할 선택을 건너뛰고 곧장 보호자 비밀암호 만들기로 간다. 그래서 보호자가 자기 계정으로 이룸이의 휴대폰을 이룸이 휴대폰으로 만들 수 없다. 새 소셜 계정을 따로 만들어야만 이룸이를 고를 수 있다.
- 연결이 끊긴 이룸이 휴대폰은 "연결이 끊어졌어요" 화면에서 뒤로가기를 누르면 소셜 로그인 화면으로 떨어진다. 앱을 다시 켜도 로그인 화면이다. 연결 암호 화면으로 돌아갈 길이 없어, 위 문제와 겹치면 이룸이 휴대폰을 다시 연결할 수 없다.
- 2일 뒤 특수학교 시연(교사가 학생 휴대폰을 붙이는 장면)에서 바로 막힌다.

🔄 재현 방법
---

1. 새로 설치한 휴대폰에서 이미 이룸이를 등록한 보호자 계정으로 로그인한다
2. 역할 선택 없이 "보호자님만 아는 비밀암호를 만들어주세요"가 뜬다. 뒤로가기를 누르면 로그인 화면이다
3. (연결된 이룸이 휴대폰) 보호자가 설정 → 이룸이 휴대폰 → 연결 끊기
4. 30초 안에 이룸이 휴대폰이 "연결이 끊어졌어요" 화면으로 바뀐다. 뒤로가기를 누르면 소셜 로그인 화면이고, 앱을 다시 켜도 같다

✅ 예상 동작
---

- 로그인 화면에서 로그인하지 않고 바로 연결 암호 화면으로 갈 수 있다 (사용자 결정: 로그인 버튼 아래 "이룸이 휴대폰이에요" 입구).
- 연결이 끊긴 이룸이 휴대폰은 뒤로가기나 다시 켜기 뒤에도 연결 암호 화면으로 돌아올 수 있다.
