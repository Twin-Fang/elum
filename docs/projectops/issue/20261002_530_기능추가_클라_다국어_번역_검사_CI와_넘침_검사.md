📝 현재 문제점
---

- 번역 파일 간 키와 자리표시자(`{name}`) 불일치를 잡는 검사가 없다. 서버 테스트를 돌리는 CI도 없다(현재 `-x test`로 빌드).
- 긴 번역문(스페인어)과 큰 글자에서 화면이 넘치는지 검사하는 방법이 없다. 한국어 화면이 이미 큰 글자에서 넘치는 곳이 있다(역할 선택, 약관 동의, 연결 암호).
- 번역에 쓸 용어집과 언어를 여는 절차가 정해져 있지 않다.

🛠️ 해결 방안 / 제안 기능
---

- 번역 파일 간 키, 자리표시자, 복수 형식 일치를 CI가 검사한다. 서버 번역 리소스 검사 워크플로를 새로 만든다.
- 5개 언어와 큰 글자 배율로 주요 화면을 띄워 넘침을 확인하는 위젯 테스트를 둔다. 기준은 "한국어보다 나빠지지 않는다"이다. 시안 대조는 한국어에만 적용한다.
- 용어집, 번역 작업 절차, 언어 출시 체크리스트를 문서로 만든다.

⚙️ 작업 내용
---

- [ ] 번역 검사 테스트와 CI 연결, 서버 번역 검사 워크플로
- [ ] 5개 언어 넘침 검사 하네스와 대표 화면
- [ ] 용어집(`이룸이` 번역 여부는 결정 항목), 번역 절차, 언어 출시 체크리스트
- [ ] 이미 넘치는 한국어 화면 3곳은 별도 버그 이슈로 분리
