📝 현재 문제점
---

- 강제 업데이트 화면의 `업데이트하러 가기` 버튼이 여는 스토어 주소가 **앱 안에 고정**되어 있다 (`AppConfig.iosAppStoreId`, `androidPackageId`).
- 이 화면은 **옛 버전 앱에서 뜨는 화면**이라, 이미 설치된 앱의 주소는 앱을 다시 내지 않는 한 바꿀 수 없다.
  - 실제로 App Store 1.24.1은 iOS 앱 ID가 비어 있어서, 나중에 막히면 스토어 버튼 대신 `업데이트했어요`만 뜬다 (#279).
  - 안드로이드는 아직 Play 스토어 심사 중이라 공개 전인데, 주소는 이미 박혀 있다.

🛠️ 해결 방안 / 제안 기능
---

- 관리자 설정(앱 제어)에 **플랫폼별 스토어 주소**를 둔다. `/api/app/status` 응답에 실어 보낸다.
- 앱은 **서버 값이 있으면 그 값을 쓰고, 없거나 서버를 못 보면 앱에 넣어 둔 값을 쓴다.** 서버가 죽어도 버튼은 동작한다.
- 스토어 주소가 아닌 값은 받지 않는다.
  - 서버: 관리자 화면에서 저장할 때 거절한다.
  - 앱: 응답에 이상한 값이 와도 무시하고 앱에 넣어 둔 값을 쓴다.

⚙️ 작업 내용
---

- [ ] 서버: 설정 키 `IOS_STORE_URL`, `ANDROID_STORE_URL` 추가 (기본값 빈 값 = 앱 기본값 사용), 저장할 때 스토어 주소인지 검사
- [ ] 서버: `/api/app/status`의 `ios`와 `android`에 `storeUrl` 추가, API 문서 갱신
- [ ] 앱: `storeUrl` 파싱, 서버 값 → 앱 기본값 순서로 주소 결정, 허용 주소 검사
- [ ] 테스트: 서버 검증과 응답, 앱의 우선순위·잘못된 값·옛 서버 응답
