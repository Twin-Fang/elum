📝 현재 문제점
---

일과 만들기 입력 화면(`238:1643`)이 시안과 두 군데 다릅니다. **아이폰·갤럭시 모두** 같습니다.

### 1) 시안에 없는 문구가 화면에 있습니다

하단에 **`이룸이 정보를 안전하게 지켜요`** 가 그려집니다. **시안에는 이 문구가 없습니다.**

시안 `238:1643`이 담은 글자는 셋뿐입니다.

- `오늘은 어떤 준비가 필요한가요?` (제목)
- `AI 루미가 작은 행동 단계로 나눠드려요` (부제)
- `평소 이야기하듯 입력해주세요` (입력칸 플레이스홀더)

코드 주석에는 `하단 안내 (Figma y=794)`라고 적혀 있습니다. **예전 시안에는 있었고 그 뒤 빠진 것**으로 보입니다. 시안이 바뀌었는데 화면이 따라가지 않았습니다.

### 2) 입력칸 글자가 세로 중앙에 있지 않습니다

한 줄일 때 글자가 **박스 아래쪽에 붙습니다.**

| | 시안 | 지금 |
|---|---|---|
| 박스 | 362×**52** · 모서리 20 | `minHeight: 52` ✅ |
| 플레이스홀더 | `x=18, y=18` — 위아래 여백이 **18씩 같다** | 아래로 치우친다 |

원인은 입력칸 줄의 세로 정렬이 **아래 맞춤**(`CrossAxisAlignment.end`)이기 때문입니다. 여러 줄로 늘어났을 때 전송 단추를 아래에 두려고 그렇게 둔 것인데, **한 줄일 때는 글자까지 아래로 끌어내립니다.**

🛠️ 해결 방안 / 제안 기능
---

- **하단 문구를 뺍니다.** 시안에 없습니다. 개인정보를 지킨다는 안내는 동의 화면과 처리방침이 맡습니다 — 입력 화면에서 한 번 더 말할 자리가 아닙니다
- **입력칸 줄을 가운데 맞춤으로 바꿉니다.** 한 줄일 때 글자가 박스 가운데 서고, 여러 줄일 때도 전송 단추가 글자 높이 가운데에 옵니다

**확인할 것**

| 경우 | 기대 |
|---|---|
| 아무것도 안 썼을 때 | 플레이스홀더가 박스 가운데 |
| 한 줄 입력 | 글자와 전송 단추가 나란히 가운데 |
| 여러 줄 입력 (최대 4줄) | 박스가 늘어나고 단추가 따라온다 |
| 좁은 기기(360dp) | 박스가 찌그러지지 않는다 |
