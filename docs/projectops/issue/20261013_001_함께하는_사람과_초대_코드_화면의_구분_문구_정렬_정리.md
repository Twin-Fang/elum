📝 현재 문제점
---

함께 돌보기 E2E(보호자 2명 + 이룸이 휴대폰 1대)에서 본 화면 어긋남이다.

1. **함께하는 사람 두 줄이 똑같다.** 이름이 비면 "보호자", 구분도 "보호자"라 `보호자 · 보호자` 줄이 두 개다. 합류할 때 이름을 묻지 않아 처음엔 항상 이렇다.
2. **구분 글자가 거의 안 보이고 줄마다 끝 위치가 다르다.** 오른쪽 "보호자" 회색이 매우 흐리고, 꺾쇠가 있는 내 줄과 없는 줄의 글자 끝이 다르다.
3. **보낸 사람 화면이 합류를 모른다.** 초대 코드를 받은 사람이 들어와도 보낸 사람 화면은 코드와 남은 시간을 그대로 보여 준다. 이룸이 휴대폰 연결 화면은 "휴대폰 연결에 성공했어요!"를 띄운다.
4. **오류 안내에 서버 이름이 그대로 나온다.** `초대 코드가 맞지 않아요. (PROFILE_INVITE_NOT_FOUND)` 형식. 다른 화면은 `E-…` 코드이고 문장 끝 마침표도 없다.
5. **한글이 단어 중간에서 줄바뀜한다.** `그 / 대로예요`, `초대해보 / 세요`, `연결 / 이 끊어져요`, `눌 / 러주세요`.
6. **초대 코드와 연결 암호 화면의 모양이 다르다.** 같은 역할(여섯 글자 + 남은 시간 + 다시 만들기)인데 글자 크기와 간격, 안내 문구가 다르다. 남은 시간이 처음부터 빨간색이다.
7. 딥링크로 채운 코드 칸의 글자가 칸에 비해 작다.
8. 머리말 `Haneul를 함께 돌보는 사람이에요`의 조사가 고정이다. 초대 코드 화면은 받침에 따라 고른다.

🛠️ 해결 방안 / 제안 기능
---

- 이름이 없는 사람은 구분만 한 번 보이게 하고, 내 이름이 비어 있으면 이름을 넣도록 안내한다.
- 구분 글자 대비를 올리고 줄 끝 정렬을 맞춘다.
- 초대 코드가 쓰이면 보낸 사람 화면에 합류를 알린다 (연결 암호와 같은 방식).
- 오류 안내를 `E-INV-404` 형식으로 맞추고 마침표를 정리한다.
- 한글 줄바꿈을 단어 단위로 맞춘다.
- 초대 코드와 연결 암호 화면을 같은 부품으로 맞춘다.
- 화면 배치·색은 #479 시안 요청과 맞추고, 시안과 달라지는 것은 디자이너 확인을 받는다.
