🛠️ 해결 방안 / 제안 기능
---

- 먼저 정할 것(기획·디자인): 알림 종류(예: 이룸이가 일과를 끝냈을 때, 보호자 초대가 수락됐을 때, 크레딧이 채워졌을 때), 문구, 받는 사람(보호자 또는 이룸이), 끄는 설정 위치. 용어 규칙(이룸이, 휴대폰, 해요체)을 따른다.
- 앱: 알림 권한 안내(거부해도 앱이 그대로 동작), 기기 토큰을 서버에 등록·갱신·로그아웃 때 해제, 알림을 눌렀을 때 이동할 화면.
- 서버: 기기 토큰 저장, 사건이 일어났을 때 발송(실패해도 본 기능은 계속), 보내지 못한 토큰 정리.
- 설정 파일과 서비스 계정 키를 GitHub Secrets로 올리는 이름과 CI 반영.
- 개인정보처리방침에 알림용 기기 식별 정보를 쓴다는 내용을 더해야 하는지 확인한다(법적 문구라 근거를 남기고 확인받는다).
