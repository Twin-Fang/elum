📝 현재 문제점
---

- 디자이너가 온보딩 세 화면의 시안을 고쳤다. 지금 앱은 이전 임시 시안 기준이라 서로 어긋난다.
  - 이름 `204:991`: `초대 코드가 있어요` 링크가 시안에 정식으로 들어왔다. 앱은 "임시 시안"으로 둔 상태다.
  - 초대 코드 입력 `1532:7114`: 시안은 연결 암호 입력 화면과 같은 모양이다(설명 2줄, 여섯 칸, `시작하기` 버튼). 앱은 안내 카드 3줄을 쓰고 여섯 자를 채우면 자동 제출하며 버튼이 없다.
  - 이룸이 연결 `732:5334`: 시안에 `링크로 보내기` 보조 버튼과 `코드 복사하기` 알약이 생기고 `다시 만들기` 칩이 사라졌다. 타이머 문구도 `09:59 뒤에 코드가 바껴요`로 바뀌었다.
- 경로(라우팅)는 세 시안에서 달라진 것이 없다. 화면 구성만 바뀌었다.

---

- 세 시안을 속성 단위로 대조해 앱을 시안대로 맞춘다.

⚙️ 작업 내용
---

- 이름: `초대 코드가 있어요` 링크의 위치와 글자 스타일을 시안과 대조하고 임시 시안 표시를 정리한다. 동작은 그대로다.
- 초대 코드 입력
  - 제목을 `초대 코드를 입력해주세요`로 바꾼다.
  - 안내 카드를 설명 2줄(`코드는 함께하는 보호자 휴대폰의 / 설정 → 함께하는 사람에 있어요`)로 교체한다. 오류가 나면 그 자리에 오류 문구가 뜬다.
  - 하단 `시작하기` 버튼을 둔다. 여섯 자를 채워야 켜지고 자동 제출은 없앤다. 링크로 받은 코드의 `함께하기`는 `시작하기`로 합친다.
  - 합류, 실패, 잠금, 약관 흐름은 바꾸지 않는다.
- 이룸이 연결(온보딩 진입)
  - `링크로 보내기` 보조 버튼을 추가한다(y=593).
  - 코드 아래 `다시 만들기` 칩을 `코드 복사하기` 알약으로 바꾼다.
  - 타이머 문구를 `09:59 뒤에 코드가 바껴요`로 바꾼다.
  - 만료되면 새 코드를 자동으로 발급하고 타이머를 다시 돌린다. 발급에 실패하면 기존 오류 문구와 `E-LINK-NEW` 코드를 보이고 다시 시도할 길을 남긴다.
  - 설정에서 들어오는 연결 화면은 범위에 넣지 않는다.
- 검증: `figma_conformance_test`에 세 프레임을 올려 대조하고, 시뮬레이터로 세 화면을 직접 밟는다.
