---

- 일과관리 화면들이 서로 다른 규칙으로 그려져 통일성이 없다. 확정 시안(claude.ai/artifact/R6YU7Etubc15auyRsY5nHu 「이룸 일과관리 시안」)과도 다르다. (#837 이후 폰 실측 캡처 기준)

| 항목 | 시안 · 홈의 행동카드 순서 변경 | 지금 묶음 열기(순서 편집) |
|---|---|---|
| ⊖ 빼기 | 회색 원 + 흰 `−` (격자 정리 상태의 ⊖ 와 같은 모양) | 빨간 머티리얼 `remove_circle` 아이콘, 번호 왼쪽 |
| 번호 | 번호 칸이 카드 줄과 따로 왼쪽에 서 있고 끌기에 끼지 않는다 | 번호가 줄 안에 있어 줄과 함께 끌려간다 |
| 끌기 손잡이 | 3줄 손잡이(`sheetReorderHandle`). **길게 눌러야** 잡히고 누르는 동안 줄이 떠오르며 진동, 브랜드색 테두리 | 2줄 머티리얼 아이콘. 닿자마자 끌린다 (스크롤하려다 순서가 바뀐다) |
| 줄 모양 | 둥근 카드(68 높이), 제목 + 보조 글(`카드 N장`) | 배경색 줄에 그림 + 이름만 |
| 머리 | ✕ · `순서 편집` 글자 링크 · 가운데 큰 이름 · 일과 N개 안내 | 연필 아이콘 · `완료` |

🛠️ 해결 방안 / 제안 기능
---

일과관리의 정리·순서 변경 UI를 **한 규칙**으로 통일한다. 새 규칙을 만들지 않고 이미 있는 행동카드 순서 변경(`RoutineDetailStepCard`, `RoutineDetailStepBadge`)과 격자 정리 상태의 ⊖ 를 재사용한다.

1. **⊖ 공통 위젯** `ArrangeRemoveBadge`: 격자 정리 상태와 묶음 열기가 같은 위젯을 쓴다 (회색 원 + 흰 `−`).
2. **묶음 열기 목록을 행동카드 순서 변경 구조로**: 번호 칸(`RoutineDetailStepBadge`)을 카드 줄과 떼어 왼쪽에 세워 끌기에 끼지 않게 하고, 카드 줄만 `SliverReorderableList` 로 올린다.
3. **카드 줄 모양**: 둥근 카드 + 그림 + 제목 + `카드 N장`. 평소 오른쪽은 `›`, 순서 편집 중에는 ⊖ 와 손잡이.
4. **손잡이는 길게 눌러야 잡힌다**: 누르는 동안 떠오름 + 진동 + 브랜드색 (행동카드와 같은 동작). 닿자마자 끌리지 않는다.
5. **머리 정리**: ✕ · `순서 편집`/`완료` 글자 링크 · 가운데 이름(그 자리에서 고침) · `일과 N개 · 이 순서대로 이룸이에게 보여요`.

### 하지 않는 것
- 일과 상세(행동카드) 쪽 동작·모양 변경 (재사용만 한다)
- 서버 순서 저장 (별도 이슈)

### 실패 경로 · 엣지케이스
- 저장 중에는 누르기·빼기·끌기를 막는다 (지금과 같음)
- 묶음에서 빼 하나만 남으면 묶음이 풀린다 (지금과 같음)
- 동작 줄이기를 켜면 들어올림 연출 없이 바로 잡힌다
- 큰 글자에서도 번호 칸 높이와 카드 높이가 어긋나지 않게 같은 높이 토큰을 쓴다
