# 시안 대조 도구 — 퍼센트가 아니라 속성으로 묻는다

## 개요

`client/tool/figma_props.py` 를 만들었다. **시안이 선언한 값을 들고 와 렌더의 그 자리를
직접 찍어 보고, 좌표가 아니라 문장으로 답한다.**

```
검사한 면 23개
  ⚠️ 모서리 각짐   background   393x68 @0,238   좌상 r=20 이어야 하는데 렌더는 약 3 이다
```

같은 결함을 픽셀 도구는 이렇게 말했다.

```
476~519   0~785   786x44   평균차 77        ← 22개 덩어리 중 한 줄
다른 픽셀  66,849 / 1,213,584  (5.51%)
```

![corner_cmp](https://github.com/Twin-Fang/elum/releases/download/qa-evidence/issue344_20260922-231729_corner_cmp.png)

## 무엇을 묻나

| 항목 | 묻는 것 | 심각도 |
|---|---|---|
| **곡선** | 꼭짓점에서 대각선으로 들어가며 면이 시작되는 자리로 **반지름을 되짚는다** | 결함 |
| **면 색** | 시안 fill 과 렌더 색. 반투명은 뒤에 얹어 계산한다 | 결함 |
| **자리** | 네 변이 시안이 그은 선 위를 지나가나 | 경고 |
| **이펙트** | 선언된 그림자(안쪽/바깥)가 실제로 그려졌나 | 경고 |

종료 코드는 `0 / 1 경고 / 2 결함` 이라 스크립트가 붙잡을 수 있다.

```bash
python3 tool/figma_props.py --node 956:4084 --render test/figma/sheet_956-4084.png
python3 tool/figma_props.py --dir test/figma      # 올라가 있는 것 전부
python3 tool/figma_props.py --self-test           # 도구 자체 (네트워크 없이)
```

## 만들면서 실측으로 바로잡은 것 여섯

**전부 실제로 틀린 답을 내던 것들이다.** 검사 도구가 조용히 망가지면 "이상 없음"만
찍어 대는데, 그건 검사가 없는 것보다 나쁘다 — 믿고 안 보게 되기 때문이다.

### 1. 탐침 자리 — 시제품은 둥근 모서리를 각졌다고 보고하고 있었다

반지름 r 의 모서리에서 꼭짓점으로부터 대각선 d 들어간 점이 **원호 바깥**일 조건은

```
(r-d)² + (r-d)² > r²   →   d < r(1 - 1/√2) ≈ r × 0.293
```

시제품이 쓰던 `r × 0.3` 은 이 값을 **아슬아슬하게 넘어** 탐침이 곡선 안쪽에 들어간다.
r=16 이면 꼭짓점 중심에서 18.1 이 아니라 15.8 — 원 안이다. 합성 도형으로 확인했다.

### 2. 색 거리 — 채널 최대 차로는 정작 시트를 못 본다

시트 흰색 `#FFFFFF` 과 배경 크림색 `#F7F2EF` 의 **채널 최대 차가 16** 이다.
"면과 배경이 구분된다"는 문턱을 그 위에 두면 **봐야 할 시트를 통째로 건너뛴다.**
유클리드로 바꾸면 22.1 이라 안전하게 갈린다. 면인지 배경인지는 **가까운 쪽**으로 가른다.

### 3. 가림막 — 오탐 42건이 0건이 됐다

바텀시트 시안에는 화면 전체를 덮는 `Scrim`(검정 50%)이 있다. 그 아래 홈 화면 면들은
렌더에서 **어두워진 색**으로 나온다. 가림막을 모르면 전부 "면 색 다름"이다.
자식도 같다 — 부모 면 한가운데는 자식이 덮고 있는 것이 정상이다.

그래서 **그리는 순서를 들고 다니며** 표본 자리마다 "나보다 나중에 그려지는 것이 여기를
덮나"를 묻는다. 아이콘·도형도 가림막으로는 센다.

### 4. 면으로 볼 수 있는 타입만 본다

`VECTOR`·`ELLIPSE`·`STAR` 는 채움이 바운딩박스를 다 덮지 않아, 가운데를 찍으면 도형이
아니라 뒤에 있는 것이 나온다. `RECTANGLE`·`FRAME`·`COMPONENT`·`INSTANCE` 만 본다.

### 5. 반투명 면은 뒤가 고르지 않으면 묻지 않는다

로그인 `최근 로그인` 알약(`#FFFADC` 50%)은 **위쪽이 병아리 그림 위에, 아래쪽이 카카오
버튼 위에** 얹혀 한 알약 안에서 색이 두 가지다. 기대값 하나로 맞대면 멀쩡한 것을
틀렸다고 말한다(실제로 그랬다).

### 6. 자리가 밀린 상자의 모서리 탐침은 거짓말한다

카드확인 화면 카드가 시안보다 위에 있어서, 시안이 말한 좌상 꼭짓점이 **이미 카드
안쪽**이라 `모서리 각짐`으로 잡혔다. 각지지도 않았는데.

두 가지로 막았다.

- **자리를 먼저 본다.** 네 변마다 안쪽 2 와 바깥쪽 3 을 찍어 경계가 그 선을 지나가는지
  확인하고, 아니면 모서리는 묻지 않고 `자리 어긋남` 이라고만 말한다.
  (시트 헤더 배경 아래에 같은 색 시트 몸통이 이어지는 것처럼 **같은 색 면이 맞닿아**
  있으면 정상으로 본다.)
- **모서리를 예/아니오가 아니라 재서 말한다.** 이룸이 홈 번호 배지(40×40, r=12)가 3만
  올라가 있어도 잡히던 것이, 재면 **약 10** 이라 12 와 가깝다. 진짜 각진 시트는 **약 3**
  이라 20 과 확연히 다르다. 절반 아래로 내려가고 차이가 3 이상일 때만 말한다.

### 덤 — 기기 껍데기와 요청 수

시안은 상태바·홈인디케이터·자판을 그리지만 렌더는 `viewInsets` 로 자리만 비운다.
입력 화면마다 **자판 30여 개**가 "면 색 다름"으로 올라왔다. 이름으로 건너뛰되
**가림막으로는 남긴다** — 시안에서 자판이 덮고 있는 것은 애초에 맞댈 수 없다
(PIN 화면 CTA 가 그렇다).

노드를 한 장씩 받다가 Figma 가 **429 Too Many Requests** 로 끊었다(51화면 51요청).
`ids=` 에 열두 개씩 담아 한 번에 받고, 429 면 물러섰다 다시 묻는다.

## 회귀 방지 — 도구가 여전히 잡는지 매번 확인한다

`--self-test` 가 네 가지를 본다. **네트워크 없이 돈다.**

```
  통과  둥근 렌더 → 모서리 각짐 보고 안 함 (기대: 없음)
  통과  각진 렌더 → 모서리 각짐 보고함 (기대: 보고)
  통과  각진 시트(#345 재현) → 모서리 각짐 2건, 그 밖 0건
  통과  고친 시트 → 모서리 각짐 0건, 그 밖 0건
자가검사 통과
```

뒤 둘이 **실물 회귀 샘플**이다. `#345` 가 났을 때처럼 상단 모서리를 메운 시트 렌더와
시안 덤프를 `client/tool/fixtures/` 에 고정해 두었다. 고친 쪽은 **아무 소리도 나지
않아야** 통과다 — 오탐이 섞이면 아무도 안 읽기 때문이다.

파이썬만 따로 돌리는 사람은 없으므로 `flutter test` 안에 묶었다
(`test/figma_props_tool_test.dart`). 파이썬·pillow·numpy 가 없으면 스스로 건너뛴다.

섞이지만, 읽을 것이 22줄이 아니라 한 줄이면 그 판단이 실제로 이뤄진다.

## 못 잡는 것을 알고 쓴다

렌더는 PNG다. **화면에 그려지는 것만** 물을 수 있다 — 글꼴 이름·자간·오토레이아웃
간격은 여기서 못 잡는다. 그건 위젯 테스트가 값으로 단언할 몫이다.
그라디언트·이미지 채움도 한 점으로 비교할 수 없어 건너뛴다.

대신 **여기서 잡는 것들은 위젯 테스트가 거의 못 잡는다.** `clipBehavior` 를 안 줘서
자식이 부모의 둥근 모서리를 덮는 것(#345)은 위젯 트리에 아무 이상이 없다.

## 변경 사항

- `client/tool/figma_props.py` (새 파일) — 속성 대조 도구
- `client/tool/fixtures/` (새 폴더) — 실물 회귀 샘플(시안 덤프 + 각진 시트 렌더)
- `client/test/figma_props_tool_test.dart` (새 파일) — `flutter test` 안에서 자가검사
- `client/dart_test.yaml` — `tool`·`sync` 태그 선언
- `client/docs/figma-frames.md` — **대조는 이 도구부터** 돌리도록 순서를 바꿨다

## 주의사항

- **토큰은 저장소에 적지 않는다.** `FIGMA_TOKEN` 환경변수 · `client/.env` · `~/.figma_token`
  순으로 읽는다.
- 대조 렌더 파일명은 `이름_노드-아이디.png` 규칙을 지켜야 `--dir` 가 짝을 찾는다.
- 렌더는 **1배**여야 한다. 크기가 다르면 늘려서 맞추지 않고 멈춘다 — 늘린 픽셀로
  모서리를 재면 답이 흐려진다.
