# 관리자 화면 기본 테마를 라이트로 변경

## 개요
관리자 화면은 저장된 선택이 없으면 브라우저 시스템 설정을 따라 다크 모드로 열렸다. 선택이 없을 때 항상 라이트로 시작하게 바꿨다. 토글로 직접 고른 값은 그대로 기억한다.

## 변경 사항
- `server/src/main/resources/static/admin/js/admin-ui.js`: 시스템 테마 판별 함수를 없애고 기본값 `DEFAULT_THEME = 'light'`로 고정했다.

## 검증
| 항목 | 결과 |
|---|---|
| 배포 | PR #611 머지, `elum-server-cicd` build·deploy 성공 |
| 운영 반영 | 운영 `/admin/js/admin-ui.js`에 `DEFAULT_THEME` 있음 |
| 문법 | `node --check` 통과 |
| 화면 | 운영 화면을 라이트 기본으로 다시 열어 보지는 않았다 |
| 안드로이드 | `client/` 변경이 없어 안드로이드 배포 워크플로우는 돌지 않았다 |

## 주의사항
- 이전에 토글로 다크를 골라 저장한 브라우저는 계속 다크로 열린다. 저장값이 시스템 설정보다 우선이기 때문이다.
