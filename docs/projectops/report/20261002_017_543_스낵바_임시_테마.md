# 🚀[기능개선][클라][공통] 스낵바가 기본 모양이라 앱과 어울리지 않아 임시 테마로 정리

## 개요

저장·변경 뒤 화면 아래에 잠깐 뜨는 알림(스낵바)이 Flutter 기본 모양 그대로였다. 앱 어디에도 스낵바 공통 스타일이 없어서 colorScheme에서 자동으로 뽑힌 갈색 직사각형이 화면 바닥에 붙어 나왔다. 띄우는 곳 7곳은 모두 `SnackBar(content: Text(...))`로 문구만 넘기므로, 화면은 건드리지 않고 **앱 테마 한 곳에 `snackBarTheme`을 넣어** 7곳을 한꺼번에 바꿨다. 시안이 없는 임시 값이고, 시안 요청은 기존 디자인 이슈 #422에 댓글로 덧붙였다. v2.15.0으로 배포했다.

## 주요 구현 내용

**화면 7곳이 아니라 테마를 고친 이유.** 7곳 모두 문구만 넘기고 모양은 기본값에 맡기고 있어서, 테마 한 곳이 실제로 모든 자리를 결정한다. 공통 함수(`showAppSnackBar`)로 감싸는 방법도 있지만 시안이 없는 지금은 바꿀 것이 모양뿐이라 테마로 충분하다. 시안에서 아이콘이나 성공·실패 구분이 생기면 그때 공통 함수로 넘어간다.

**배경색에 새 토큰을 만들지 않은 이유.** 디자이너가 정하기 전에 색을 새로 만들면 임시 값이 토큰으로 굳는다. 화면 배경(#F7F2EF) 위에서 가장 또렷한 기존 색인 본문색을 그대로 썼다.

| 띄우는 곳 | 문구 |
|---|---|
| 그림 방식 설정 | 그림 방식을 바꿨어요 |
| 비밀암호 변경 | 비밀암호를 바꿨어요 / 만들었어요 |
| 지난 일과 복사 | ○○을(를) 오늘 일과에 담았어요 |
| 연결 상태 | 연결을 끊었어요 / 이미 끊겨 있어요 |
| 보호자 목록 | ○○에서 나왔어요 |
| 초대 입력 | ○○를 함께 돌보게 됐어요 |
| 이룸이 바꾸기 | 이룸이를 바꿨어요 |

## 주의사항

- **긴 문구는 단어 중간에서 줄이 바뀐다.** `…담았어 / 요`처럼 끊긴다. 한글은 글자 단위로 줄을 바꾸기 때문이다. 문구를 줄일지, 두 줄을 허용할지 #422에 물어 두었다.

- **임시 값이다.** 시안(#422)이 나오면 `app_theme.dart`의 `snackBarTheme` 값만 바꾼다. 화면마다 `SnackBar(backgroundColor: ...)`처럼 덧쓰지 않는다. 덧쓰면 테마를 바꿔도 그 자리만 옛 모양으로 남는다. 테스트가 `behavior == null`로 덧쓰기를 일부 잡는다.
- **홈 하단 광고 배너와 겹친다.** 배너는 `Scaffold.bottomNavigationBar`가 아니라 본문 Column 맨 아래에 있어서, 떠 있는 스낵바가 약 4초 동안 배너 위를 덮는다. 위치는 #422에서 디자이너가 정하도록 질문해 두었다.
- **확인 못 한 것: 실기기 화면.** iOS 시뮬레이터는 다른 세션과 공유 중이라 잡지 않았다. 골든 렌더로만 확인했다.
- 하단 고정 버튼이 있는 화면에서 스낵바를 띄우면 버튼 위를 덮는다. 지금 7곳은 모두 저장 직후 앞 화면으로 돌아가거나 버튼이 없는 화면에서 띄워서 해당이 없다. 새로 띄울 때 확인한다.
