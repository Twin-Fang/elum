# 그림 방식 고르기를 정식 시안으로 바꾼다

## 개요

임시로 만들었던 그림 방식 선택을 시안 `그림방식` 1274:9883, 1274:10129대로 다시 그렸다. 카드는 344×94, 왼쪽에 70×70 예시, 오른쪽에 20×20 라디오가 선다.

## 변경 사항

- `client/lib/features/onboarding/presentation/widgets/image_style_option_card.dart`: 카드 재작성. 만화는 고르면 민트 면, 아니면 바탕색 위 캐릭터. 실사는 레고, 직접 찍은 사진은 오리 사진 에셋
- `client/assets/images/image_style_realistic.png`, `image_style_photo.png`: 시안 에셋(280px로 줄여 각각 약 47KB, 32KB)
- `client/lib/features/onboarding/presentation/image_style_screen.dart`: 좌우 24 기본 여백으로 되돌리고 헤더 보정 제거, 카드 사이 16
- `client/lib/features/onboarding/domain/image_style.dart`: 카드 제목을 `직접 찍은 사진`으로
- `client/lib/core/theme/app_typography.dart`: 카드 글자 스타일 토큰 2개 추가, `app_colors.dart`: 임시 자리표시 색 토큰 2개 삭제
- 테스트: `image_style_conformance_test`(골든 2장), `image_style_option_card_test`(5건), 기존 테스트 갱신

## 주요 구현 내용

- 시안 export와 맞대 글줄이 두 장 모두 어긋남 없이 맞는다. 앱 글꼴이 시안보다 3% 넓어 3번째 카드가 세 줄로 꺾이던 것은 문장 끝 줄바꿈과 글 칸 8 확장으로 맞췄다.
- 디자인 토큰 테스트가 화면의 `fontSize` 직접 지정을 막아 글자 스타일을 토큰으로 만들었다.

## 주의사항

- 시안에 없는 `건너뛰기`는 기존 동작(원칙 4)을 유지했다. 시안 10129의 실사 줄 예시가 비어 있는 것은 디자이너 확인 요청으로 남긴다.
