# 바텀시트, 연결 암호, 로딩 스피너 공통 위젯화

## 개요
화면마다 따로 그리던 모양을 공통 위젯 4개로 모았습니다.

- 바텀시트 면
- 연결 암호 표시 패널
- 암호 입력칸
- 작은 스피너

간격·모서리·크기 같은 픽셀 값은 바꾸지 않았습니다. 화면마다 다른 값은 인자로 넘깁니다.

## 변경 사항

### 신규 위젯
- `core/widgets/elum_bottom_sheet.dart`
  - `showElumSheet`: 투명 배경, 높이 조절 가능
  - `ElumSheetSurface`: 배경, 위쪽 둥근 모서리, 손잡이, 고정 높이, 애니메이션
  - `ElumSheetHandle`: 40×4 손잡이
- `core/widgets/elum_spinner.dart`: `ElumSpinner(size, color, strokeWidth)`
- `features/link/presentation/widgets/issued_code_panel.dart`: 발급 화면 두 곳의 레이아웃 상수, 남은 시간 문구, 재발급 칩
- `features/link/presentation/widgets/code_entry_field.dart`: 숨은 입력칸, 코드 칸, 보내는 중 스피너

### 적용
- **바텀시트 4곳**: `card_edit_sheet`, `routine_detail_sheet`, `card_photo_source_sheet`, `guardian_edit_sheet`
- **연결 암호 발급**: `link_code_screen`, `invite_code_screen`
- **연결 암호 입력**: `link_enter_screen`, `invite_enter_screen`. 화면 로직과 에러 모델은 합치지 않았습니다.
- **스피너**
  - 본문 전체 로딩 3곳은 기존 `ElumStateBody.loading()`으로 바꿨습니다.
  - 작은 스피너 3곳은 `ElumSpinner`로 바꿨습니다.

## 주요 구현 내용
- **일과 시트는 손잡이를 헤더 흐름 안에 둡니다.** 처음에는 손잡이를 시트 면 위에 겹쳐 그렸습니다. 그런데 시안 대조 골든 3건에서 0.86%(2,870px)가 어긋났습니다. 그래서 일과 시트만 `showHandle: false`로 두고, 헤더 안에 `ElumSheetHandle`을 원래 자리에 넣었습니다.
- **카드 수정·보호자 수정·사진 선택 시트는 골든이 없습니다.** 그래서 바꾸기 전 코드로 화면을 찍은 골든을 만들고 바꾼 뒤의 화면과 비교했습니다. 4개 모두 픽셀이 같았습니다.

## 검증
- 시안 대조 테스트 52건 통과
- 링크 화면 골든·대조 테스트 통과
- 앱 테스트 3013건 통과. 실패 1건은 develop에 이미 있는 영어 ARB 잔여 키입니다.
- `flutter analyze` 0건

## 주의사항
- **손잡이 그리는 위치가 결과를 바꿉니다.** 손잡이를 내용 위에 겹치는 `ElumSheetSurface`의 기본 방식은 헤더가 배경을 전체 폭으로 까는 시트와 맞지 않습니다. 그런 시트는 `showHandle: false`에 `ElumSheetHandle`을 흐름 안에 둡니다.
- `IssuedCodePanel`은 스크롤 안에서 쓰는 것을 전제로 합니다. 높이가 정해지지 않은 곳에서 `ElumStateBody.loading()`이 단순한 `Center`로 그려져야 화면이 같기 때문입니다.
