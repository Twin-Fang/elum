## 구현 보고서: 함께하는 사람과 초대 코드 화면 정리

### 바꾼 것
- 이름 없는 줄은 구분 이름만 한 번 보이고, 내 이름이 비면 "이름을 넣어보세요"로 안내한다.
- 구분 글자 대비를 올리고(`textSecondary`) 꺾쇠 자리를 항상 남겨 줄 끝을 맞췄다.
- 초대 코드 화면이 3초마다 함께하는 사람 목록을 받아, 새 보호자가 들어오면 "○○님이 함께하게 됐어요"를 띄운다.
- 초대 코드 오류에 서버 이름 대신 `E-INV-404` 형식을 붙였다.
- 안내 문구와 그만두기 팝업을 어절 단위로 줄바꿈한다(`keepWords`).
- 머리말 조사를 받침에 맞추고, 코드 칸을 연결 암호와 같은 크기로 키웠다.

### 검증
- 관련 화면 테스트 통과. 어절 표시(U+2060)가 섞인 문구를 찾는 테스트는 `findKept`로 바꿨다.
- 실기기: 목록 표시, 그만두기 팝업 줄바꿈, B 재합류 때 A 화면 합류 알림 확인.

### 남은 것 / 주의사항
- 남은 시간 빨간색은 연결 암호 시안도 같아 디자이너 확인 대상으로 남겼다.
- `keepWords`를 거친 글은 `find.text`로 못 찾는다. 테스트는 `findKept`를 쓴다.
