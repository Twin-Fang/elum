# 안드로이드 TTS 엔진 고정과 스피커 버튼 피드백

## 개요
안드로이드에서 카드를 읽어 줄 때 목소리가 갈라지는 문제와, 스피커 버튼을 눌렀을 때 읽는 중인지 보이지 않는 문제를 다뤘다. 엔진 고정과 읽는 중 표시는 배포됐고, 스피커 탭 햅틱은 빠져 있어 이슈를 닫지 않는다.

## 변경 사항
- `client/lib/features/child/data/speech_service.dart`: 안드로이드에서 Google 음성 엔진(`com.google.android.tts`)이 있으면 처음 한 번 그 엔진으로 고정한다. 목록을 못 읽거나 엔진이 없으면 기기 기본 엔진을 그대로 쓴다.
- `client/lib/features/guardian/presentation/widgets/action_card_view.dart`: 읽는 중에는 스피커 뒤에 주황 원과 그림자를 깔고 파동이 퍼지게 했다. 동작 줄이기를 켜면 파동은 뺀다.
- `client/test/speech_service_test.dart`: 엔진 선택 5건 추가.

## 배포 경위와 사고
1. PR #616으로 배포했다. 이 커밋이 `ChildHapticKind.tap`을 부르는데, `tap`은 다른 세션이 아직 커밋하지 않은 `child_haptics.dart`에만 있었다. 테스트를 그 미커밋 변경이 섞인 작업트리에서 돌려 놓쳤다.
2. 그 결과 develop과 main이 컴파일되지 않았고, 안드로이드 `Android AAB 빌드`가 실패했다. `Play Store 내부 테스트 배포`는 건너뛰어 깨진 빌드는 테스터에게 나가지 않았다.
3. 다른 세션의 알림을 받고 햅틱 호출 2줄을 걷어 내는 핫픽스를 올렸다. `flutter analyze`로 컴파일 오류 0을 확인한 뒤 PR #618로 main에 반영했다.
4. #618의 안드로이드 Play 내부 테스트와 Firebase 배포, 서버 배포가 성공했다. iOS TestFlight는 빌드가 끝나고 배포 중이었다.
