## 구현 보고서: 이룸이 휴대폰 정보 표시와 여러 대 연결

### 바꾼 것
- 서버: `device_link.device_name`(V35, NULL 허용)을 더했다. 연결할 때 앱이 보낸 기기 모델명을 정리해 저장한다(제어문자 제거, 40자).
- 서버: `GET /api/device-links` 응답에 `deviceName`, `linkedByName`(연결 암호를 만든 보호자의 함께하는 사람 이름), `linkedByMe`를 더했다. 이름은 이룸이별로 한 번만 조회한다.
- 앱: 연결할 때 기기 모델명을 보낸다(`device_info_plus`, 읽기 실패나 2초 초과면 이름 없이 연결).
- 앱: 이룸이 휴대폰 화면에 "iPhone 16 · 연결됨 / 김선생님이 연결 · 10월 13일부터"를 보이고, 연결된 휴대폰이 있어도 "+ 다른 휴대폰 연결하기"로 더 붙일 수 있다.

### 왜 이 방식인가
- 옛 앱은 기기 이름을 보내지 않고 새 필드를 몰라도 동작해야 한다. 그래서 요청 필드는 선택, 응답 필드는 추가만 했다.
- 이메일은 서버에 없다. 새로 받으면 수집 항목과 약관이 바뀌므로 이번에는 넣지 않았다(사용자 요청 메모: 별도 결정 필요).

### 검증
- 운영 배포 후 V35 적용 확인(2026-10-14 00:14). 실기기 연결 뒤 DB `device_name = iPhone 16`.

### 주의사항
- `link` 모듈이 `member` 저장소를 직접 쓰면 구조 규칙에 걸린다. 이름은 `ProfileGuardianService.displayNamesOf`를 거친다.
- 연결한 보호자가 이룸이를 나가면 이름을 못 찾아 "보호자가 연결"로 보인다(의도).
