# 보상 설정 화면과 이룸이 노출 3곳 — 서버는 있는데 화면이 없다

## 개요

**배관은 다 깔려 있었고 수도꼭지가 없었다.** 서버 API·프리셋·클라 모델·getter까지
모두 있는데 **어느 화면도 쓰지 않았다.** 화면을 붙여 기능이 닿게 했다.

## 1. 보상 설정 화면 (8-1) — 보호자

명세는 `docs/03-screens.md`에 2026-09-13 내부 회의로 이미 확정돼 있었다. 그대로 구현했다.

| 구분 | 구현 |
| --- | --- |
| **위치** | AI 추가 질문 다음, **카드 생성 전** |
| **질문** | `다 하면 무엇을 할 수 있나요?` / 보조 `{이룸이}가 좋아하는 걸 골라주세요` |
| **입력** | 프리셋 2열 🍪📺🧸🚶 + ⭐ 직접 입력 |
| **재사용** | 최근 쓴 보상 **최대 3개** 상단에 (`getRecentRewards()`) |
| **안내** | `한 달 뒤 선물보다 오늘 받을 수 있는 것이 더 효과적이에요` |
| **건너뛰기** | 허용 — CTA 아래 밑줄 문구 |

### 왜 질문 다음인가

`createRoutine`이 이미 **"카드 생성 전에 정한 보상"** 을 받도록 설계돼 있었다.
데이터층이 이 자리를 전제로 만들어져 있던 것이다.

카드를 만든 뒤로 미루면 "이미 다 끝났는데 왜 또"가 된다.

## 2. 이룸이 노출 3곳

`RewardBanner` 하나로 묶었다 — 세 곳이 따로 그리면 문구와 그림이 어긋난다.

| 시점 | 형태 | 어디 |
| --- | --- | --- |
| **시작** | 타일에 `다 하면 🍪 젤리 먹기` 한 줄 | 이룸이 홈 |
| 🔴 **수행 중** | **상단 고정 바** (작게) | 카드 수행 |
| **완료** | 크게 + 별 연출과 함께 | 보상 화면 |

### 🔴 수행 중 노출이 자문의 핵심 요구다

> 수행 **중에도** 최종 보상이 계속 보여야 한다. 완료 후에만 보여주는 별(⭐) 연출과는
> 다른 기능이다. — `docs/03-screens.md`

별은 "해냈다"이고 보상은 "이제 받는다"라 **서로를 대신하지 못한다.**
그래서 완료 화면에서도 둘을 함께 보여준다.

## 3. 카드 검토 화면 보상 줄

정한 보상을 보여주고 **뒤늦게 고칠 수 있다.** 건너뛴 사람에게는 `보상 정하기`가 뜬다 —
카드를 다 보고 나서야 "무엇을 주지"가 떠오르는 경우가 있다.

생성 전(`setReward`)과 생성 후(`updateRewardOnRoutine`)가 다르다. 뒤쪽은 이미 일과가
서버에 있으므로 API를 탄다. **저장에 실패해도 로컬에는 반영하고 화면은 되돌아간다** —
보상은 선택 항목이라 실패가 흐름을 막지 않는다. 대신 `E-REWARD`로 알린다.

## 🔴 실기기에서 잡은 버그 — `민준가`

골든만 봤으면 못 잡았다. 실기기로 열어 보니 부제가 이랬다.

```
Haneul가 좋아하는 걸 골라주세요
```

`'$who가'`로 조사를 손으로 붙이고 있었다. 한글 이름이면 **`민준` → `민준가`** 가 된다.
#196에서 만들어 둔 `korean_particle.dart`를 쓰도록 고쳤다.

```dart
'$who${who.subjectParticle} 좋아하는 걸 골라주세요'
// 하늘이 → 하늘이가 (받침 없음) · 민준 → 민준이 (받침 ㄴ)
```

받침 있는 이름으로 테스트를 걸어 고정했다.

## 검증

| 항목 | 결과 |
| --- | --- |
| `flutter analyze` | **error·warning 0건** |
| `flutter test` | **537건 전부 통과** (신규 19건) |
| 골든 | 첫 일과 · 최근 보상 있는 경우 |
| **실기기** | 화면·이모지·선택 상태·CTA 활성 **눈으로 확인** |

신규 테스트가 고정하는 것.

- 아무것도 안 고르면 다음이 안 눌린다
- 직접 입력은 **칸만 열고 비워두면** 안 눌린다
- 건너뛰면 고른 것까지 지워진다 (키만 남으면 문구 없는 이모지가 뜬다)
- 최근 보상이 없으면 **섹션째** 숨긴다
- 최근 보상 조회가 실패해도 화면이 뜬다
- 모르는 프리셋 키가 와도 그림이 나온다
- 수행 중 배너가 완료 배너보다 낮다

## 주의사항

- **보상은 선택 항목이다.** 건너뛴 경로가 전 구간에서 살아 있어야 한다 —
  필수로 만들면 일과 만들기가 한 단계 더 무거워진다.
- **이모지는 임시다.** 프리셋 그림 5종이 나오면 `RewardChip`·`RewardBanner` 두 곳만
  고치면 된다 (#198 D3 🎨 항목).
- 골든 환경에는 이모지 폰트가 없어 **골든에서는 이모지가 안 보인다.** 실기기로 확인한다.
- 배경(aurora)이 무한 반복해 이 화면 테스트에서 `pumpAndSettle`을 쓸 수 없다.
