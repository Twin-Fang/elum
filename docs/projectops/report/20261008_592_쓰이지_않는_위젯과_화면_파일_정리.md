# 쓰이지 않는 위젯과 화면 파일 정리

## 개요
어디서도 import하지 않는 파일 4개(483줄)를 지웠습니다. 이 파일들을 가리키던 주석 2곳과 한글 리터럴 검사기의 건너뛰기 목록도 함께 정리했습니다. 앱 동작은 바뀌지 않습니다. 화면이 쓰는 코드가 아니기 때문입니다.

## 변경 사항

### 삭제
- `client/lib/core/widgets/glowing_svg.dart` (79줄): 별 후광 위젯입니다. 참조는 색상 주석 1곳뿐이었습니다.
- `client/lib/core/widgets/secured_by_dlp_badge.dart` (39줄): AI DLP 배지입니다. DLP를 POC로 끝낸 뒤 쓰이지 않았습니다.
- `client/lib/features/guardian/presentation/dlp_screen.dart` (228줄): 라우터에 등록되지 않은 DLP 화면입니다.
- `client/lib/features/auth/presentation/widgets/consent_chip.dart` (137줄): 약관 항목 칩입니다. `ConsentRow`로 바뀐 뒤 남아 있었습니다.
- 추적되지 않던 임시 프로브 `client/lib/_probe_ad_main.dart`: 바로 지우지 않고 작업 폴더 밖으로 옮겨 두었습니다. git에 없는 파일이라 지우면 되돌릴 수 없기 때문입니다.

### 참조 정리
- `client/lib/core/theme/app_colors.dart`: 지운 `GlowingSvg`를 가리키던 주석 문장을 고쳤습니다.
- `client/lib/features/auth/presentation/widgets/consent_row.dart`: 지운 `ConsentChip`과 이슈 번호를 가리키던 주석을 지금 모양 설명으로 바꿨습니다.
- `client/tool/check_hangul_literals.dart`: 건너뛰기 목록에서 지운 `dlp_screen.dart` 항목을 뺐습니다.

## 주요 구현 내용
- 지우기 전에 `lib`·`test`·`tool`·`.github`에서 파일명과 클래스명을 모두 검색했습니다. 참조가 주석 2곳뿐인 것을 확인한 뒤 지웠습니다.
- `demo_cards.dart`도 lib에서는 쓰이지 않지만 테스트가 참조하고 있어 이번 범위에서 뺐습니다.
