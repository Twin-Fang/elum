# 로그가 이미지 바이트를 통째로 찍고 로그 화면 글자 선택이 오류를 낸다

## 개요

개발자 도구에서 내보낸 로그에서 두 가지를 찾아 고쳤다. 하나는 카드 그림 응답(수 MB)을 숫자 목록으로 펼쳐 한 줄에 수천 자씩 찍던 것, 다른 하나는 로그 화면의 글자를 누르면 `Null check operator used on a null value` 가 나던 것이다.

## 변경 사항

- `client/lib/core/logger/app_logger.dart`: 로그에 넣는 값이 **바이트 목록**(64개 이상의 0~255 정수)이면 `바이트 N개`로 줄인다. 앞 120바이트가 글자로 읽히면(502 HTML 오류 페이지 등) 앞부분을 함께 남겨 무슨 오류인지 알 수 있다. 짧은 정수 목록(id 목록 등)은 그대로 펼친다.
- `client/lib/core/dev/dev_tools_overlay.dart`: 패널을 자체 `Overlay` 로 감쌌다.
- `client/test/app_logger_bytes_test.dart`: 3건 추가. `client/test/dev_tools_overlay_test.dart`: 1건 추가.

## 주요 구현 내용

- **글자 선택 오류의 원인**: 개발자 도구 패널은 `MaterialApp` 의 `builder` 에 놓여 Navigator 와 Overlay 보다 위에 있다. `SelectableText` 를 누르면 선택 손잡이를 그릴 Overlay 를 찾는데(`Overlay.of`) 없어서 null 검사에서 터졌다. 패널이 자기 Overlay 를 갖게 했다. 개발자 도구에서만 나는 오류라 일반 사용자 화면에는 영향이 없다.
- **검증**: 패널 수정을 되돌리면 글자 누르기 테스트가 실패하는 것을 확인했다. 테스트 중 가로챈 `debugPrint` 는 본문 안에서 되돌려야 테스트 틀의 전역값 검사를 통과한다(처음에 이 때문에 실패했다). 앱 테스트 2075 통과, analyze 0건.

## 주의사항

- 이미지 같은 바이너리는 개수만 남으므로 로그로 그림 내용을 볼 수는 없다. 그림이 받아졌는지는 상태 코드와 크기로 판단한다.
- 일반 사용자 빌드(개발자 도구가 꺼진 빌드)의 로그는 원래 목록 개수만 남겨 영향이 없다.
