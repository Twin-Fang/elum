# 뒤로가기, 홈 버튼이 시안보다 12 아래에 있다

## 개요

시안이 일과 만들기 흐름의 뒤로가기·홈 버튼 상자를 y=79에서 **y=67**로 올렸다. 앱은 옛 위치에 있어 12 아래였다. 해당 화면들의 버튼만 12 올리고, 버튼 아래 내용은 시안에서 자리가 바뀌지 않았으므로 그대로 두었다.

커밋: `c29e656` · 배포: v1.47.0 (PR #439, 다른 세션 배포)에 포함

## 변경 사항

- `client/lib/features/guardian/presentation/widgets/routine_flow_scaffold.dart`
  - 로딩·추가질문·카드확인·보상설정이 함께 쓰는 상단바. 위 여백 28 → 16, **아래 여백 12 추가.**
  - 위만 줄이면 상단바가 낮아져 화면 전체가 12 위로 뜬다(#297에서 겪은 함정). 높이를 그대로 두고 버튼만 올린다.
- `client/lib/features/guardian/presentation/routine_input_screen.dart`
  - 새로운 일과 만들기 화면의 뒤로가기. 위 여백 20 → 8, 반짝임까지의 간격 66 → 78.
  - 반짝임은 시안에서 y=185 그대로라, 올린 12를 간격에서 되돌려 준다.
- 시안 대조 렌더 10장(`client/test/figma/`), 보상 설정 회귀 골든 2장(`client/test/goldens/`)을 다시 찍었다.

## 검증

| 항목 | 결과 |
|---|---|
| 시안 대조 렌더 10장 | 화살표·집 아이콘이 시안과 같은 **y75~98**에 선다 (수정 전 y87~110) |
| 바뀐 영역 | 10장 모두 **y75~110(아이콘 자리)뿐**. 아래 내용은 한 픽셀도 움직이지 않았다 |
| 온보딩(`204:991`)·설정(`1022:4467`) | 원래 시안과 같아 손대지 않았고 렌더도 그대로 |
| 앱 테스트 | 1193 통과 (develop 병합 뒤 1205 통과) |
| `flutter analyze` | 0건 |

회귀 골든 두 장(보상 설정)은 버튼을 올려서 실패했다. 바뀐 곳이 버튼 자리(y16~51, 상태바 없이 찍는 골든)뿐인 것을 확인하고 갱신했다.

### 확인하지 못한 것

- 실기기는 밟지 않았다. 위치 계산 방식(안전영역 기준)은 바꾸지 않고 값만 옮겼기 때문에, 대조 렌더와 같은 결과로 본다.

## 주의사항

- **상단바의 위·아래 여백은 합이 28이어야 한다.** 이 합이 상단바 높이를 정하고, 그 아래 모든 화면 내용이 여기에 맞춰 놓여 있다. 버튼 위치만 바꾸려면 위와 아래를 맞바꾼다.
- 입력 화면의 `backTop`과 `topToSparkles`는 한 쌍이다. 하나를 바꾸면 반짝임부터 아래가 통째로 밀린다.
- 온보딩은 y=79, 설정은 y=67이다. 시안이 묶음마다 다르니, 공통 스캐폴드의 기본값(79)을 바꾸면 온보딩 16개가 어긋난다.
