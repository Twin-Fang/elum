## 🔴 팝업을 먼저 공통 위젯으로 만들었다

`lib/core/widgets/elum_dialog.dart`

지금 필요한 것은 연결 성공 하나지만 **확인·경고·삭제 확인이 곧 따라온다.**
그때마다 카드·여백·버튼을 다시 그리면 화면마다 모서리와 간격이 어긋난다 —
하단 시트에서 실제로 그랬다.

빼도 되는 것을 전부 뺄 수 있게 했다.

```dart
showElumDialog<String>(
  context: context,
  icon: ElumDialogIcon.success,   // 없으면 그 자리가 사라진다
  title: '휴대폰 연결에 성공했어요!',
  message: '설명',                 // 없으면 생략
  actions: [                      // 비우면 '확인' 하나가 선다
    ElumDialogAction(label: '취소', value: 'cancel', tone: ElumDialogTone.neutral),
    ElumDialogAction(label: '지우기', value: 'delete', tone: ElumDialogTone.danger),
  ],
);
```

- **아이콘**은 enum이다. 경고·물음이 생기면 값 하나와 에셋 한 줄만 더한다
- **버튼 무게**는 `primary`·`neutral`·`danger` 셋. 색만 다르고 크기는 같다
- **돌아오는 값**은 눌린 버튼의 `value`. 바깥을 눌러 닫으면 null이므로
  **null을 취소로 다루는 쪽이 안전하다**

테스트가 이 확장성을 고정한다 — 아이콘 없이, 설명 없이, 버튼 없이, 버튼 둘로도 선다.

## 변경 사항

| | 전 | 후 |
| --- | --- | --- |
| 제목 | `이룸이 휴대폰에\n이 암호를 넣어주세요` | **`{이름}의 휴대폰을\n연결할까요?`** |
| 부제 | 없음 | **`{이름}의 휴대폰에서 아래 코드를 입력하세요`** |
| 남은 시간 | `10분 동안 쓸 수 있어요` | **`09:59` 카운트다운 (빨강)** |
| 다시 만들기 | 큰 버튼 | **칩** `코드 다시 만들기` |
| 복사 | `암호 복사` 있음 | **없음** |
| CTA | `완료` (연결 후에만) | **`시작하기`** (연결돼야 활성) |
| 연결 성공 | 문구만 바뀜 | **팝업** |
| 연결 후 | 타이머 문구 남음 | **타이머·다시 만들기 사라짐** |

## 만료 10분 — 서버가 이미 맞다

```java
// DeviceLinkService.java
public static final Duration CODE_TTL = Duration.ofMinutes(10);
```

시안의 `09:59`와 일치한다. **서버는 건드리지 않았다.**

## 남은 시간은 올림이 아니라 내림이다

전에는 분 단위라 올림이었다(9분 1초 → 10분). 초까지 세면 **올림은 실제보다 길게
말하는 것**이 되어, 믿고 기다리다 만료된다.

## 암호 여섯 글자를 낱개로 놓는다

`Text` 하나에 `letterSpacing`을 주면 **마지막 글자 뒤에도 자간이 붙어 묶음이 왼쪽으로
치우친다.** 낱개로 놓아야 3-3 묶음의 가운데(40)와 글자 사이(20)를 따로 줄 수 있다.

## 이름과 조사

`의`는 받침과 무관해 그냥 붙는다. 이름이 비면 `이룸이`로 대신한다 —
온보딩을 건너뛰고 설정에서 바로 들어오면 이름이 없을 수 있고, 그때
`의 휴대폰을`처럼 앞이 빈 문장이 나간다.

## `나중에 할게요`는 CTA 아래에 붙는다

`ElumScaffold`에 `belowButton` 슬롯을 새로 냈다. CTA 안에 함께 넣지 않는 이유 —
**이건 버튼이 아니라 빠져나가는 길이다.** 같은 무게로 두면 무엇이 주 동작인지 흐려진다.

## 주의사항

- **골든에서 `pumpAndSettle()`을 쓸 수 없다.** 1초 타이머가 계속 돌아 정착할 프레임이
  없다. `pump()`로 필요한 만큼만 돌린다.
- **성공 팝업은 한 번만 뜬다.** 폴링이 한 박자 늦게 또 돌 수 있어 `_celebrated`로 막는다.
- 팝업을 닫아도 화면에 머문다 — 연결됨 상태를 눈으로 보고 `시작하기`를 누르는 것이
  시안의 흐름이다.
- `암호 복사`를 뺐다. 같은 사람이 두 휴대폰을 다 들고 있을 때는 불편할 수 있다.
  시안을 따랐다.
