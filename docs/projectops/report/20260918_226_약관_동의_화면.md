## 개요

Figma `739:3747`(미동의) · `726:5056`(전체 동의) 두 상태를 구현했다.

| 미동의 | 전체 동의 |
| :-: | :-: |

구현하면서 **법적으로 틀린 문구 하나**와 **테스트 구조 문제 하나**를 함께 잡았다.

### 🔴 부제가 상태를 말한다

| 상태 | 부제 |

## 🔴 법정대리인 문구 — 사실과 달랐다

### 무엇이 틀렸나

전에는 이랬다.

```
[필수] 만 14세 이상이며 아이의 법정대리인입니다
```

찾아보니 **성인 발달장애인에게는 부모가 법정대리인이 아니다.**

| 대상 | 법정대리인 | 근거 |
| --- | --- | --- |
| 만 14세 미만 | 부모 (자동) | 개인정보보호법 §22-2 |
| **성인 발달장애인** | **법원이 선임한 후견인만** | 민법 성년후견·한정후견 |

성인은 성년후견 심판을 받지 않으면 부모라도 법정대리인이 아니다. 복지부가
[발달장애인 공공후견 지원사업](https://www.mohw.go.kr/menu.es?mid=a10710040100)을 따로
운영할 만큼 후견 선임은 예외적이고, 성인은 원칙적으로 본인이 동의 능력을 갖는다.

즉 **대부분의 성인 이룸이 보호자에게 거짓 확인을 시키는 문구**였다.
타겟이 *"20대 당사자가 자기 휴대폰에서 이 앱을 연다"* 인데 문구는 아동을 전제했다.

### 어떻게 고쳤나

체크박스는 **표준 한 줄**만 남겼다.

```
[필수] 만 14세 이상입니다
```

실제 조건은 `개인정보 수집·이용` 전문 맨 앞으로 옮겨 **세 경우를 나눠** 적었다.

```
0. 누가 입력하고, 누가 동의하나

- 이룸이가 만 14세 미만 — 법정대리인(부모 또는 후견인).
  이 동의가 개인정보 보호법이 정한 법정대리인 동의를 갈음한다.
- 성인이고 후견이 개시된 경우 — 법원이 선임한 성년후견인 또는 한정후견인.
- 성인이고 후견이 개시되지 않은 경우 — 이룸이 본인의 동의를 받아 대신 입력한다.
  성인은 원칙적으로 스스로 동의할 수 있으며, 이 경우 보호자는 법정대리인이 아니다.
```

**세 번째가 가장 흔할 경우인데 기존 문구엔 아예 없었다.**

나이 확인은 **계정을 만드는 보호자** 기준이다. 이룸이에게는 나이 제한이 없다 —
만 14세 미만이어도 보호자가 대신 입력하므로 이용할 수 있고, 그 근거가 위 §0이다.

`consentVersion`을 `2026-09-18`로 올렸다. 문구가 바뀌면 무엇에 동의한 기록인지 달라진다.

## 🔴 골든이 네모로 찍히고 있었다

### 무엇이 문제였나

테스트 환경은 폰트를 자동으로 싣지 않는다. 안 실으면 한글이 **전부 네모(□)**가 된다.
골든은 그 상태로 기준이 잡혀 **회귀를 못 잡는다** — 글자가 바뀌어도 네모 개수만 같으면 통과한다.

전에는 골든 파일마다 `FontLoader`를 베껴 넣었다. 새 골든을 쓰는 사람이 그걸 모르면 또 네모다.

### 어떻게 고쳤나

`test/flutter_test_config.dart`(모든 테스트에 자동 적용)에서 **한 번만** 싣는다.

```dart
// pubspec.yaml의 폰트 선언을 그대로 읽어 싣는다.
// 목록을 코드에 박으면 폰트를 추가할 때 어긋난다.
final families = (pubspec['flutter'] as YamlMap?)?['fonts'] as YamlList?;
for (final family in families ?? const []) { ... }

// 아이콘은 pubspec에 없다 — SDK 번들에서 따로 싣는다.
// 체크·화살표가 □면 상태를 눈으로 구분할 수 없다.
FontLoader('MaterialIcons')..addFont(_loadAsset('fonts/MaterialIcons-Regular.otf'));
```

기존 `child_screens_golden_test.dart`의 중복 로더도 걷어냈다.

### 그 덕에 잡힌 버그 2개

폰트가 □였으면 못 봤을 것들이다.

| 증상 | 원인 | 고침 |
| --- | --- | --- |
| `필수` 배지가 `필`/`수`로 줄바꿈 | 배지 자리 28 — Figma 글자 폭 기준이라 실제 렌더보다 좁다 | 38로 |
| 미동의 체크 원이 **안 보인다** | `border`(#EFEFEF)가 배경(#F7F2EF)과 거의 같다 | Figma 원본 픽셀을 떠 `#C9D6D4` |

Figma 원본에는 미동의 상태에도 **원 안에 회색 체크**가 있다. 원만 비워 두면 눌러야 할
자리인지 알기 어렵다 — 그것도 함께 맞췄다.

## 주의사항

- **게시된 개인정보처리방침과 내용이 같아야 한다.** 앱만 고쳤으므로
  `twin-fang.github.io/elum/privacy.html`에도 §0을 반영해야 심사에서 불일치로 걸리지 않는다.
  파일 상단 주석에 이미 적혀 있는 제약이다.
- **법률 검토를 받는 편이 좋다.** 위 §0은 검색으로 정리한 것이다.
  근거는 개인정보보호법 §22-2와 민법 성년후견이고, 판단이 필요한 부분은
  "성인 + 후견 없음"에서 본인 동의만으로 충분한지다.
- **`다른 계정으로 로그인`을 뺐다.** 디자인에 없어서다. 뒤로가기가 막혀 있어
  (`PopScope`) **약관에 동의하지 않으면 나갈 방법이 없다.** 강제 종료 후 다시 켜도
  같은 화면이다. 탈출 경로가 필요한지 확인이 필요하다.
- **`consent_chip.dart`가 안 쓰인다.** 지우지 않고 두었다 — 삭제는 확인받아야 한다.
- **에러 문구 자리**는 항목 아래 빈 공간(항목 끝 590 → CTA 675)에 뒀다. 디자인에
  자리가 없어 CTA를 밀지 않는 쪽을 택했다.
