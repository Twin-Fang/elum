# 약관 및 개인정보처리방침 목록을 새 시안에 맞춘다

## 개요
설정의 약관 목록을 Figma `1274:9315`대로 필수항목 · 선택항목 흰 카드 둘로 바꿨다.

## 변경 사항
- `consent_document_list_screen.dart`: 평면 목록을 묶음 제목 + 흰 카드(`SettingsGroup`, `SettingsTile`)로. 스크롤 고정 영역 아래에서 시작
- `settings_conformance_test.dart`: 약관 목록 시험이 엉뚱한 프레임(`1027:4683`)을 가리키던 것을 시안 노드로 바로잡고 골든 추가

## 주요 구현 내용
- 줄 라벨은 서버가 내려주는 문서 이름 그대로 쓴다. 관리자가 고치는 값이라 키로 고정하지 않았다.
- 줄이 여는 문서, 문서 id, 버전, 동의 기록은 그대로다.

## 검증
- 설정 · 약관 관련 시험 43건 통과, 앱 전체 1228건 통과
- 시안과 맞대면 카드 · 줄 · 간격 일치, 덩어리는 글자 자리뿐

![시안(왼쪽)과 앱(오른쪽)](https://github.com/Twin-Fang/elum/releases/download/qa-evidence/evidence1016_20261016-202858_694_terms.png)

## 주의사항
- 시안의 가운뎃점은 `・`(U+30FB)이고 앱 문서 이름은 `·`(U+00B7)이다. 법적 문구이고 서버 라벨이 원본이라 바꾸지 않았다. 통일하려면 관리자 화면에서 라벨을 고쳐야 한다.
