# 역할 선택 화면 — 다음 버튼으로 확정, 카드 문구·상태 개편

## 개요

Figma `732:5176`(미선택) · `732:5258`(보호자 선택)를 구현했다.

| 미선택 | 보호자 선택 |
| :-: | :-: |
| <img src="https://github.com/Twin-Fang/elum/releases/download/qa-evidence/i229_20260918-175155_r_none.png" width="320"> | <img src="https://github.com/Twin-Fang/elum/releases/download/qa-evidence/i229_20260918-175157_r_guardian.png" width="320"> |

가장 큰 변화는 **탭 즉시 이동 → `다음` 버튼 확정**이다.

## 변경 사항

| | 전 | 후 |
| --- | --- | --- |
| 확정 | 카드 탭 즉시 이동 | **`다음` 버튼** |
| 제목 | `서비스를\n누가 사용하나요?` | **`이 휴대폰은 누가\n사용하나요?`** |
| 부제 | 없음 | **`보호자모드와 이룸이모드가 나눠져 있어요`** |
| 카드 제목 | `보호자예요` / `이룸이예요` | **`보호자가 사용해요` / `이룸이가 사용해요`** |
| 카드 설명 | `일과를 만들어요` / `만들어 준 일과를 해요` | **`일과를 만들고 관리해요` / `일과를 실천해요`** |
| 카드 아이콘 | 있음 | **없음** — 제목 색이 그 역할을 한다 |
| 선택 상태 | 없음 | **있음** (민트 채움 + 테두리) |
| 뒤로가기 | 없음 | **`canPop()`이면 표시** |

### 왜 탭 즉시 이동을 버렸나

**한 번 고르면 온보딩 경로가 갈린다.** 보호자는 이름 입력으로, 이룸이는 연결 암호로
간다. 잘못 눌렀을 때 되돌릴 여지가 있어야 한다.

전에는 되돌림을 **다음 화면의 뒤로가기**로만 줬다. 이제 이 화면에서 바로 고쳐 고를 수 있다.

### 카드 제목의 색

`보호자`는 민트(`checkDone` #55CFBA), `이룸이`는 주황(`roleElumi` #FFAA00).
**글을 빨리 읽지 못해도 어느 쪽이 자기인지 보인다.**

`AppRole`을 세 조각으로 나눴다 — 앞부분만 색이 다르기 때문이다.

```dart
String get roleWord => switch (this) {        // 색이 다른 앞부분
      AppRole.guardian => '보호자',
      AppRole.elumi => '이룸이',
    };
String get labelSuffix => '가 사용해요';
String get label => '$roleWord$labelSuffix';  // 테스트·접근성용 전체
```

## 🔴 용어 — `기기`만 바꾸고 나머지는 시안대로 (이슈 #228 합의)

시안이 `기기` · `코드` · `보호자모드`로 그려져 나왔다. 셋을 나눠 정했다.

| 시안 | 결정 |
| --- | --- |
| **기기** | **`휴대폰`으로 바꾼다** |
| **코드** | 시안 그대로 |
| **보호자모드 · 이룸이모드** | 시안 그대로 |

`기기`는 50대 보호자가 실제로 못 알아듣는 말이라 바꿀 값어치가 있다. `코드`와 `모드`는
이미 널리 쓰이고, 시안을 고치면 디자이너와 화면이 어긋나 매번 대조해야 한다.
**바꿀 값어치와 어긋나는 비용을 견줘 나눴다.**

합의를 `CLAUDE.md` 용어 규칙에 남겼다 — 다음에 같은 판단을 다시 하지 않기 위해서다.

## 🔴 골든이 진짜 화면을 찍게 바꿨다

처음에는 골든에서 **레이아웃을 다시 짜서** 찍었다. 잘못된 방법이다 —
**화면이 바뀌어도 골든은 그대로라 회귀를 못 잡는다.** 재구성한 쪽만 고치면 통과한다.

진짜 `RoleSelectScreen`을 렌더하도록 바꿨다. `GoRouter`로 스택을 한 겹 쌓아
뒤로가기까지 그려지는 상태를 만든다.

```dart
await tester.pumpWidget(wrap());
router.push('/before/role');        // 뒤로가기가 그려지도록
await tester.pumpAndSettle();
await expectLater(find.byType(RoleSelectScreen), matchesGoldenFile(...));
```

## 검증

| 항목 | 결과 |
| --- | --- |
| `flutter analyze` | **error·warning 0건** |
| `flutter test` | **501건 전부 통과** |
| 골든 | 두 상태 — **진짜 화면 위젯을 렌더해 눈으로 확인** |

기존 테스트 8건이 옛 문구·동작을 기대해 깨졌다. 전부 맞추고 3건을 새로 넣었다.

- 카드를 눌러도 바로 안 넘어가고 `다음`을 눌러야 간다
- 아무것도 안 고르면 `다음`이 안 눌린다
- 고른 카드가 남고, 다시 고르면 하나만 남는다

`#194 회귀 방지`(양쪽 다 `push`)와 `isElumiDevice`를 여기서 세우지 않는 동작은
그대로 통과한다.

## 주의사항

- **양쪽 다 `push`로 이동한다.** `go`로 갈아끼우면 스택이 없어 `pop`이 실패한다
  (이슈 #194). 보호자 쪽만 `go`로 뒀다가 실제로 갇힌 적이 있다.
- **`isElumiDevice`를 여기서 세우지 않는다.** 라우터 가드(#206)가 곧바로 다시
  연결 화면으로 잡아가 뒤로가기가 막힌다. 그 값은 연결 성공 시에만 선다.
- **실기기 확인은 못 했다.** 이 화면은 세션이 있어야 들어갈 수 있는데, 더미 토큰을
  넣으면 서버가 401을 주고 앱이 로그아웃시킨다. 대신 골든이 진짜 화면 위젯을
  렌더하므로 레이아웃·문구·상태는 확인됐다. **실기기 확인이 필요하면 실제 계정으로
  로그인해 밟아야 한다.**
- **카드 아이콘 에셋(`roleGuardianMock`·`roleElumiMock`)이 안 쓰인다.**
  지우지 않고 두었다 — 삭제는 확인받아야 한다.
