# 보상 화면 구조를 뒤집는다 — 프리셋 칩을 걷고 직접 입력을 주인공으로

## 무엇이 어긋났나

`docs/03-screens.md`의 8-1 명세가 **프리셋 칩에서 고르는 화면**으로 적혀 있었고,
그대로 만들었더니 셋이 어긋났다.

| 지금 | 문제 |
| --- | --- |
| 프리셋 4개가 화면 절반 | **보상은 고르는 게 아니라 적는 것**이다 |
| 직접 입력이 다섯 번째 칩 | 주인공이 맨 아래 곁다리로 밀렸다 |
| 최근 보상이 맨 위 | 첫 일과에서는 비어서 자리만 남았다 |
| 흰 칩 + 회색 테두리 | 배경 위에서 **뒤가 잘려 두 조각**으로 보였다 |

`젤리 먹기`처럼 **그 집에서만 통하는 말**이 진짜 보상이다.
`좋아하는 간식`은 그걸 뭉뚱그린 말이라 이룸이에게 와닿지 않는다.

## 바꾼 것

| | 전 | 후 |
| --- | --- | --- |
| 프리셋 4개 | 칩으로 나열 | **없앴다** |
| 직접 입력 | 다섯 번째 칩 → 눌러야 열림 | **맨 위 · 항상 열려 있음** |
| 최근 보상 | 맨 위 | **입력칸 아래** |
| 면 처리 | 불투명 흰색 | **반투명 유리 + blur 12** |
| 부제 | `골라주세요` | **`적어주세요`** |

### 유리로 바꾼 이유

불투명한 흰 상자를 배경 그라데이션 위에 올리면 **뒤가 잘려 화면이 두 조각**으로 보인다.
반투명으로 두면 색이 비쳐 한 장면으로 이어진다 — 실기기 사진이 그 차이다.

`glassFill`(#8CFFFFFF) · `glassBorder`(#B3FFFFFF) 토큰을 새로 뒀다.
테두리가 면보다 밝아야 가장자리가 잡힌다.

> 골든에서는 `BackdropFilter`가 제대로 안 걸린다. **유리는 실기기로 봐야 한다.**

## 프리셋을 없애고 따라온 것

- `rewardPresetKey`는 직접 적으면 `CUSTOM`, **최근 보상을 다시 고르면 그 키를 이어받는다**
- 키가 빠지면 이룸이 화면 그림이 ⭐로 바뀌므로 이어받는 것이 중요하다
- 서버 `RewardPreset` enum은 **건드리지 않았다** — 기존 행이 깨진다

## 주의사항

- **명세 문서가 아직 옛날 것이다.** `docs/03-screens.md` 8-1이 프리셋 칩으로 적혀 있다.
  다음에 이 화면을 건드리는 사람이 그걸 보고 되돌릴 수 있다 — **문서를 고쳐야 한다.**
- 첫 일과에서는 최근 보상이 없어 **입력칸 하나만** 남는다. 그래서 힌트(`예) 젤리 먹기`)가
  유일한 안내다. 이 문구를 지우지 않는다.
