# 전체 동의가 선택 항목을 빠뜨리고 약관 전문이 회색으로 묻힌다

## 개요

실기기에서 쓰다 발견된 세 가지를 고쳤다. **전부 실기기로 다시 확인했다.**

## 1. 🔴 `전체 동의`가 선택 항목을 안 켜던 것 — #189를 되돌렸다

버튼 문구는 `서비스 이용약관 전체 동의`인데 **필수만** 켰다.

#189에서 일부러 그렇게 막았다. 이유는 이랬다.

> 선택 항목은 화면 아래로 밀려 보이지 않을 수 있어, 여기서 함께 켜면
> 본 적 없는 것에 동의하게 된다.

**우려는 타당했지만 해법이 틀렸다.** "전체"라고 써 놓고 일부만 켜면 사용자는
다 켜진 줄 알고 넘어간다. 이름과 동작이 어긋나는 쪽이 더 나쁘다.

#189가 걱정한 것은 실은 **켜진 것을 볼 수 없던 것**이다. 지금은

- 항목마다 체크가 보이고
- 다섯 개가 한 화면에 다 들어오며 (위 스크린샷)
- **선택만 따로 끌 수 있다**

## 2. 체크 탭 영역 50 → 88

체크 원이 20인데 탭 영역이 50뿐이라 손가락으로 맞추기 어려웠다.

`필수`/`선택` 배지까지 토글에 넣었다. **배지는 누를 것이 없는 라벨이라 여기
붙이면 잃는 것이 없다.**

<img src="https://github.com/Twin-Fang/elum/releases/download/qa-evidence/i235_20260918-183138_20_badge_tap.png" width="300">

배지를 눌러 첫 항목이 꺼진 모습이다 (전체 동의 버튼도 함께 풀렸다).

## 3. 🔴 약관 전문이 통째로 회색이던 것

<img src="https://github.com/Twin-Fang/elum/releases/download/qa-evidence/i235_20260918-183141_21_consent_doc.png" width="320">

원인은 **색을 빼먹은 것**이었다.

```dart
// app_typography.dart:448
bodyMedium: body.copyWith(color: secondary),   // #898B98 회색
```

`Text`는 스타일에 색이 없으면 `DefaultTextStyle`(= `bodyMedium`)과 합친다.
전문 화면이 `context.typo.body`를 **색 없이** 써서 본문이 회색으로 나왔고,
제목(`typo.title`)도 마찬가지라 **제목까지 회색**이었다.

### 색만 고치지 않았다 — 구조를 나눴다

본문 전체가 `Text` 하나였다. 섹션 번호도 소제목도 불릿도 같은 크기·같은 색이라
**글자 벽**처럼 보였다.

`parseConsentBody`(신규)가 전문을 네 종류로 나눈다.

| 덩이 | 원문 | 렌더 |
| --- | --- | --- |
| 섹션 | `0. 누가 입력하고…` | Pretendard 16/w700 + 위 여백 26 |
| 소제목 | `[계정]` | Pretendard 14/w700 + 위 여백 16 |
| 불릿 | `- 이메일 주소` | `·` + 들여쓰기 |
| 문단 | 그 외 | Pretendard 14/w400 |

바꾼 것 셋.

- **폰트를 Pretendard로** — Tmoney RoundWind는 둥근 제목용이라 긴 글에서 뭉친다
- **크기를 16 → 14, 줄간격 1.6**
- **조항 번호를 살린다** — `개인정보 처리방침 3조`처럼 번호로 가리키는 일이 있다

### 하드랩을 푼다

원문은 문장 하나가 여러 줄에 걸쳐 있다. 그대로 두면 화면 폭에 맞춰 **다시**
줄바꿈되며 줄이 들쭉날쭉해진다. 이어 붙여 한 문장으로 만든다.

```
- 만 14세 미만인 경우 — 법정대리인입니다.
  이 동의가 법이 정한 동의를 갈음합니다.     ← 앞 불릿의 이어짐
```

### 실기기에서 잡은 버그 하나 더

전문 화면을 실기기로 보다 `[이룸이 정보] — 보호자가 직접 입력합니다`가 소제목으로
안 잡히는 것을 발견했다. 정규식이 `^\[.+\]$`라 **대괄호 뒤 꼬리를 못 받았다.**
꼬리를 함께 소제목에 붙이도록 고치고 테스트로 고정했다.

## 검증

| 항목 | 결과 |
| --- | --- |
| `flutter analyze` | **error·warning 0건** |
| `flutter test` | **518건 전부 통과** |
| 실기기 | 전체 동의 · 배지 탭 · 전문 화면 **모두 눈으로 확인** |

옛 동작을 고정하던 테스트 2건을 뒤집고 3건을 새로 넣었다.

- 일괄 동의는 선택 항목까지 켠다
- 다시 누르면 전부 꺼진다
- 선택만 따로 끌 수 있다

파서 테스트 8건을 새로 만들었다 — 섹션·소제목·꼬리 붙은 소제목·불릿·하드랩·빈 입력.

## 주의사항

- **`typo`를 쓸 때 색을 함께 준다.** `bodyMedium`이 보조색이라 빼먹으면 회색이 된다.
  이 화면에서 두 번(제목·본문) 같은 실수가 났다.
- 항목이 늘어 한 화면을 넘기면 #189의 우려가 되살아난다. 그때는 **전체 동의를
  누른 뒤 목록 끝까지 스크롤되게** 하는 편이 낫다 — 다시 필수만 켜는 쪽으로
  돌아가지 않는다.
