# 사용자 호칭을 아이에서 이룸이로 바꾸고 말투를 해요체로 통일

## 개요

**20대 당사자가 자기 휴대폰에서 이 앱을 연다.** 거기에 "아이"라고 쓰여 있으면 안 된다.
화면에 나가는 문구 40여 곳을 `이룸이`·해요체로 바꾸고, 말투를 짧고 직관적으로 다듬었다.

훑다가 **문구 밖의 결함 두 가지**를 함께 잡았다.

- 이름 뒤 조사가 `'$name가'`로 박혀 있어 받침 있는 이름에서 **`민준가 할 일`** 이 나왔다
- 이룸이 홈 인사가 **반말**(`할 일들이야. 힘내보자!`)이었다

법적 문구와 DLP 마스킹 규칙은 손대지 않았다.

### 빈 상태·보상 문구

| 전 | 후 |
| --- | --- |
| 아직 만든 일과가 없어요 😢 | **아직 만든 일과가 없어요** |
| N개의 별을 얻었어요\n할 일을 해내고 별을 더 찾아봐요! | **별 N개를 모았어요\n할 일을 하면 더 모을 수 있어요** |
| {name}가 할 일을 해내서\n루루가 선물을 **가져왔다고 해요** | {name}{조사} 할 일을 해내서\n루루가 선물을 **가져왔어요** |

빈 상태에서 슬픈 이모지를 뺐다. 아직 안 만든 것은 사용자 잘못이 아니다.

## 주요 구현 내용

### 조사 — 이름을 보호자가 직접 적는다

```dart
// 전 — 받침 있는 이름에서 깨진다
'오늘 $childName가\n할 일들이야. 힘내보자!'   // → 민준가 ❌

// 후 — 받침을 보고 고른다
'오늘 $childName${childName.subjectParticle}\n할 일이에요'   // → 민준이 ✅
```

한글 음절은 `U+AC00`부터 **종성 28개 주기**로 배열된다. 나머지가 0이면 받침이 없다.

```dart
bool get _hasFinalConsonant {
  if (isEmpty) return false;
  final code = codeUnitAt(length - 1);
  if (code < 0xAC00 || code > 0xD7A3) return false;   // 한글이 아니면 없음으로 본다
  return (code - 0xAC00) % 28 != 0;
}
```

보상 문구는 템플릿이라 `{josa}` 자리를 뒀다.

```dart
return _messageTemplate
    .replaceAll('{name}', name)
    .replaceAll('{josa}', name.subjectParticle);
```

## 🔴 손대지 않은 두 곳

| 파일 | 문구 | 왜 |
| --- | --- | --- |
| `consent_documents.dart:63` | `만 14세 이상이며 아이의 법정대리인입니다` | **법적 효력이 있는 문장.** 바꾸려면 근거를 남기고 확인받는다 |
| `PromptDefaults.java:38` | `"아이", "아동", …은 이름이 아닙니다.` | **DLP 마스킹 판별 규칙.** 지우면 마스킹이 오작동한다 |

둘 다 커밋 후 원문 그대로임을 확인했다.

보호자는 실제로 "우리 아이가…"라고 입력한다. **들어오는 `아이`는 그대로 받고,
나가는 `아이`만 바꿨다.**

## 주의사항

- **조사는 앞으로도 하드코딩하지 않는다.** 이름 뒤에 `가/이`, `을/를`, `은/는`, `와/과`가
  붙는 자리는 `korean_particle.dart`를 쓴다. 이번에 깨진 자리가 두 곳이었다.
- **영문·숫자 이름은 받침 없음으로 본다.** `Alex가`가 나온다. 발음 기준으로 하면
  정답이 없고, 깨지지 않는 쪽을 택했다.
- **문구를 바꾸면 골든이 함께 깨진다.** `--update-goldens`를 바로 돌리지 말고
  `test/failures/*_isolatedDiff.png`로 **바꾼 문구만 달라졌는지** 먼저 확인한다.
  레이아웃이 함께 틀어진 것을 모르고 기준을 덮으면 회귀를 놓친다.
- **후속(별도 이슈)** — 서버 AI 프롬프트 3곳이 아직 *"아이에게 말하듯"* 쓰라고 지시한다
  (`PromptDefaults.java:151` · `GeminiTextClient.java:166`·`183`). 고치지 않으면
  AI가 만든 카드 문구가 그대로 20대 당사자에게 간다. #197에서 일부 다뤘으나
  프롬프트 원문 확인이 필요하다.
