# 연결 암호 칸이 빨갛게 바뀌고, 카드 0장 화면에 다시 만들 방법이 없고, 토스트가 저장 버튼을 가린다

## 개요
결함 5개 중 **①②④를 고쳤다.** ③은 정상 흐름으로는 도달하지 않아 우선순위를 낮췄고, ⑤는 디자인 #424의 결과를 기다린다. ①②는 `c883e82`(#428과 같은 화면이라 함께 커밋), ④는 `2375f8f`에 있다. 둘 다 develop에 푸시했고 main에는 아직 반영되지 않았다.

## 변경 사항
- `link/presentation/widgets/code_boxes.dart` (①): 틀렸을 때 테두리를 `colors.danger` 대신 중립색 `colors.textSecondary`로 바꿨다. 흔들림(`AppShake`)은 그대로 둔다. 근거는 `docs/08-design-principles.md` §6이다.
- `core/network/app_failure.dart` (②): `describe`는 네트워크 안내가 붙을 때 화면 문구의 **첫 문장만** 쓴다(`_headline`). 그래서 `인터넷을 확인해주세요 · 인터넷 연결을 확인해주세요` 같은 중복이 사라진다. 이 함수를 쓰는 모든 토스트가 같이 짧아진다.
- `core/widgets/show_failure.dart` (④): 실패 스낵바를 `floating`으로 바꾸고, 아래 여백을 하단 버튼 높이 + 여백(`buttonH + lg + md`)만큼 줬다. 이제 버튼 위에 뜬다.

## 주의사항
- ④ 여백은 **하단 버튼이 있는 화면**을 기준으로 잡았다. 버튼이 없는 화면에서는 스낵바가 조금 높이 뜬다. 모양은 #422 시안이 나오면 다시 맞춘다.
- ③ `_EmptyCards`는 서버가 카드 0장 응답을 막고(`ROUTINE_STEP_LIMIT_EXCEEDED`) 앱도 마지막 한 장을 못 지우게 해서 정상 흐름으로는 나오지 않는다. 데이터가 깨졌을 때를 위한 방어 화면이다.
