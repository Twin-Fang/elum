# 그림 방식 선택 카드에 크레딧 사용 · 무료 배지를 단다

## 개요

그림 방식을 고를 때 어느 방식이 크레딧을 쓰는지 화면에 보이지 않았다. 만화·실사는 카드 한 장마다 AI 그림을 그려 크레딧이 들고, 기본 그림은 무료 그림 기호가 들어간다. 디자이너 시안(#419 계열 요청)이 나오기 전에 개발 쪽 추천안(C안)을 먼저 구현했다. 온보딩과 설정이 같은 카드를 쓰므로 둘 다 바뀐다.

## 변경 사항

- `image_style_option_card.dart`: 이름 줄을 `Wrap`으로 바꿔 이름 옆에 알약 배지를 단다. 만화·실사는 `크레딧 사용`(주황 글자와 연한 주황 테두리), 기본 그림은 `무료`(기본 글자색과 기본 테두리). 글자를 키우면 배지가 아래로 꺾이고, 낭독기에는 `이름, 배지, 설명` 순으로 읽는다.
- `image_style.dart`: `badge` getter. `app_ko.arb`·`app_en.arb`: `imageStyleBadgeCredit`, `imageStyleBadgeFree`.
- `app_typography.dart`: 배지 글자 토큰 `imageStyleOptionBadge`(12/w700). 화면에서 글자 크기를 직접 지정하지 못하게 하는 검사 때문에 토큰으로 만들었다.
- 기본 그림 설명을 `간단한 그림 기호가 들어가요` 한 문장으로 줄였다. 사진으로 바꾸는 일은 어느 방식에서나 되므로 이 카드에만 적지 않는다(사용자 결정). 영어 설명도 실제 동작에 맞게 `Simple picture symbols are used`로 고쳤다.
- 그림 방식 시안 대조 골든 둘(`imagestyle_cartoon_1274-9883`, `imagestyle_photo_1274-10129`)은 시안에 없는 배지 때문에 알려진 차이로 다시 찍었다.

## 검증

- 앱 테스트 3060건 통과. 실패 1건은 서버 `LOG_*` 에러 코드 동기화로 develop에 이미 있다.
- 새 위젯 테스트: 세 카드의 배지 문구, 글자 2배에서 넘침 없음, 낭독 라벨 순서.
- 렌더한 골든으로 확인했다. 배지가 이름 옆에 붙고 카드 높이(94)는 그대로다.

## 주의사항

- 배지 모양과 문구는 임시다. 시안이 나오면 모양만 바꾼다.
- `app_ja`·`app_es`·`app_zh`에는 새 키를 넣지 않았다. 기존 imageStyle 키처럼 한국어 문구가 대신 나온다.
- 사용자가 본 `직접 찍은 사진` 화면은 v2.23.0보다 오래된 빌드였다. `기본 그림` 이름 변경은 이미 배포돼 있다.
