# 후속: 기기에 없는 언어 음성은 서버 음성으로 넘긴다

## 개요
폰에 한국어 음성이 없으면 기기 엔진이 엉뚱한 발음으로 읽어 소리가 깨졌다. 읽기 전에 언어 사용 가능 여부를 확인해, 안 되면 서버 음성(Supertonic)으로 넘기도록 했다.

## 변경 사항
- `client/lib/features/child/data/speech_service.dart`: `DeviceSpeech`가 언어가 바뀔 때 `isLanguageAvailable`을 먼저 확인한다. 못 읽는다고 답하면 실패(false)를 돌려 `FallbackSpeech`가 서버 음성으로 넘긴다. 확인 자체가 예외면 읽을 수 있다고 보고 진행한다.
- `client/test/speech_service_test.dart`: 언어 미지원이면 서버로 넘기는 경우와 확인이 예외인 경우를 추가했다.
