# 크레딧 카드의 보너스 `+ 추가 N` 줄을 없앤다

## 개요
설정의 `이번 주 AI 생성` 카드에서 보너스 크레딧 줄(`+ 추가 N`)을 없앴다. 큰 숫자(`available`)에 보너스가 이미 들어 있어서 `3 / 50 크레딧 남음 + 추가 3`이 "모두 6개"처럼 읽혔고, 주황색이라 경고처럼도 보였다. 사용자 결정은 "의미가 없다, 없앤다"였다. 커밋은 `1939a79`이고 배포 PR #432에 들어갔다.

## 변경 사항
- `client/lib/features/guardian/presentation/widgets/ai_credit_summary_view.dart`: `+ 추가 N` 줄과 낭독기 문장의 `추가 N`을 뺐다.
- `client/lib/features/credit/domain/credit_summary.dart`: `remainingRatio`의 분모를 `주간 + 보너스`에서 **주간 지급량**으로 바꿨다. 화면 숫자(`N / 50`)와 막대가 같은 기준이 된다. 보너스로 50을 넘으면 가득 찬 것으로 본다.
- 테스트
  - `ai_credit_card_test.dart`: 보너스가 있어도 `추가`가 없고 `90 / 100 크레딧 남음`이 보인다. 낭독기에도 `추가`가 없다.
  - `credit_summary_test.dart`: 주간분을 다 쓰고 보너스 50만 남으면 막대가 절반이다.

## 앱 전체 확인
보너스를 화면에 보여 주는 곳은 **이 카드 하나뿐**이다(`bonus` 전수 검색). 서버 응답의 `bonus` 필드와 관리자 화면의 보너스 지급 기능은 그대로 둔다.

같은 날 사용자 지적으로 잔액 경고 문구가 남아 있는지도 다시 확인했다. 앱에 남은 크레딧 문구는 아래 세 가지뿐이다.
- 잔액이 0일 때: `이번 주 크레딧을 모두 사용했어요`
- `?` 팝업 설명
- 카드 확인 화면의 사용량 줄

지적받은 화면은 경고 문구를 없애기(#421) 전에 설치한 옛 빌드였다.

## 주의사항
- 운영에서 보너스를 줄 때 보호자는 **총 잔액만** 본다. 보너스가 따로 들어왔다는 사실은 화면에 드러나지 않는다. 알려야 하면 공지 팝업으로 알린다.
- 주간분이 남은 상태에서 보너스를 받으면 `70 / 50`처럼 분자가 분모보다 클 수 있다. 막대는 가득 찬다. 모양은 디자인 요청 #420의 시안을 따른다.
