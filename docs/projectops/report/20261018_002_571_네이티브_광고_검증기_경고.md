# 🚀[기능개선][클라][광고] iOS 테스트 광고에서 네이티브 광고 검증기 경고가 계속 뜬다

## 개요

iOS 테스트 광고에서 `MediaView is too small for video` 경고가 뜨던 원인인 네이티브 광고 템플릿을 `small`에서 `medium`으로 바꿨다. (PR #712, develop 머지)

## 변경 사항

- `client/lib/features/ads/data/ad_native_loader.dart`
  - 템플릿 `TemplateType.small` → `TemplateType.medium`: 미디어를 위, 문구를 아래에 그려 미디어가 120x120 이상이 된다
  - 슬롯 높이 100 → 360: medium 템플릿이 잘리지 않는 높이
- `ad_native_slot.dart`의 `광고` 라벨·흰 바탕·테두리는 그대로 (일과 카드 오인 방지)

## 주의사항

- 광고 한 칸이 100 → 360으로 커져 홈 일과 목록에서 차지하는 자리가 늘었다. 디자인 시안이 나오면 다시 정한다.
- 높이를 360보다 줄이면 medium 템플릿이 잘린다.

## 검증

- `flutter analyze` 0건, `test/ads` 전부 통과 (시험은 가짜 로더라 템플릿 값 자체는 잡지 못한다)
- 확인 전: 시뮬레이터에서 검증기 팝업이 사라지는지, 안드로이드 동일 여부, 운영 단위 광고에서의 모양
- passQL 세션이 같은 증상을 #571에 재현해 남겼다
