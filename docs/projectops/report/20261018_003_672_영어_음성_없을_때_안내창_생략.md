# 🚀[기능개선][클라][음성] 영어 음성이 없는 휴대폰에서 소리 안내창 대신 글만 보여주기

## 개요

서버 음성이 읽지 않는 언어(영어 등)에서 기기에 그 언어 음성이 없으면 `E-TTS` 안내창이 뜨던 것을, 안내창 없이 글만 보여주도록 바꿨다. (PR #713)

## 변경 사항

- `speech_service.dart`: `shouldShowSpeechFailure(language)` 추가 — 서버 음성이 읽는 언어(한국어)만 true
- 일과 진행·카드 검토·카드 보기 세 화면이 실패 시 이 함수가 true일 때만 안내창을 띄운다
- 기기·서버 결과를 enum으로 나누는 안 대신, 인터페이스를 건드리지 않는 판단 함수 하나로 처리했다 (테스트 대역 10개 파일 변경 방지)

## 주의사항

- 한국어 동작은 그대로다. 영어에서 기기 음성이 진짜 고장난 경우도 안내창 없이 넘어간다 (로그는 남는다).
- 서버 음성이 다른 언어를 읽게 되면 `RemoteSpeech.supportedLanguages`만 늘리면 된다.

## 검증

- 음성·다국어 시험 89건 통과, analyze 0건
- 확인 전: 영어 실기기에서 안내창이 사라지는지
