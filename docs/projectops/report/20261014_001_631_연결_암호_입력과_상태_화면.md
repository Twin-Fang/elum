## 구현 보고서: 연결 암호 입력과 이룸이 휴대폰 상태 화면

### 무엇이 문제였나
1. 연결 암호를 치는 동안 "시작하기"가 키보드 뒤에 가려졌다.
2. 7번째 글자가 들어가면 칸에는 6글자만 보이고 버튼이 꺼졌다.
3. 실패 안내에 에러 코드가 없었다.
4. 설정 화면이 상태 값을 붙잡고 있어서, 이룸이 휴대폰 화면이 설정을 처음 연 때의 옛 값을 보였다(교사 휴대폰에 끊긴 휴대폰이 "연결됨").

### 바꾼 것
- 6글자를 채우면 **키보드를 내려** 시안 자리의 "시작하기"가 보이게 했다. 자동 전송은 하지 않는다(시안이 버튼을 그렸다). 키보드 완료 키로도 보낸다.
- 입력을 6글자로 제한했다(`CodeEntryField` 포매터, 초대 화면과 공유).
- 실패 안내에 `E-LINK-404`, `E-LINK-410`, `E-LINK-FORM`을 붙였다. 시도 한도(429)에서는 입력을 잠그고, 인터넷이 끊기면 입력을 남긴다.
- 상태 화면에 들어올 때마다 최신 값을 받는다(`linkStatusProvider` invalidate).

### 왜 이 방식인가 (실기기에서 바꾼 결정)
- 처음엔 버튼을 그림만 키보드 위로 옮겼다(`Transform`). 그런데 실기기에서 누르면 **키보드만 내려가고 전송이 안 됐다.** 그림은 옮겨져도 누름 판정이 부모 영역에서 걸러져, 탭이 뒤의 "빈 곳 누르면 키보드 내리기"로 샜다.
- 배치를 실제로 올리면 이 뼈대는 시안 좌표로 높이가 고정돼 있어 245px 넘쳤다. 그래서 6글자에서 키보드를 내리는 방식으로 바꿨다.

### 검증
- 연결 입력·시안 골든 테스트 통과(시안 골든은 갱신 없이 그대로 맞음).
- 실기기: 7글자 막힘, `(E-LINK-404)` 표시, 키보드 완료로 연결 성공.

### 주의사항
- 이 화면 버튼을 다시 키보드 위로 올리려면 `Transform`을 쓰면 안 된다. 누름 판정이 따라가지 않는다.
