# 이슈 번호와 과거 경위 주석 정리 (서버)

## 개요
`server/src/main/java` 215개 파일에서 주석만 고쳤습니다. 코드는 한 글자도 바꾸지 않았습니다.

- 이슈 번호·날짜·출처("검토에서 발견")를 지웠습니다.
- 과거 경위("예전에는…했다", "…하는 사고가 났다")는 지금 코드가 지키는 규칙으로 다시 썼습니다.
- 로직의 이유(WHY)는 남겼습니다.

## 변경 사항
- 215개 파일, +526줄 / −583줄. 모두 주석입니다.
- 이슈 번호가 든 주석 0건. 남은 4건은 `RoutineControllerDocs`의 Swagger 문서 문자열 안에 있습니다. 문자열은 코드라 고치지 않았습니다.
- 에세이식 Javadoc 9개를 줄였습니다(예: `RoutineStepImageFiller` 35줄 → 16줄).
- 계약과 WHY를 설명하는 긴 Javadoc은 그대로 두었습니다.

### 바꾼 예
- `/** 크레딧 계정 상태 (#407). FROZEN 이면 …` → `/** 크레딧 계정 상태. FROZEN 이면 …`
- `// 탈퇴 전에는 행이 지워져 위의 null 에서 걸렸다. 행을 남기게 됐으니 상태로 막는다` → `// 탈퇴해도 행이 남아 위의 null 에서 걸리지 않으므로 상태로 막는다`
- `<p>예전에는 넘어온 토큰의 계정 세션을 전부 끊었다 …(2026-09-23 실측)` → `<p>넘어온 토큰의 계정 세션을 전부 끊으면 보호자 휴대폰 한 대의 로그아웃이 다른 휴대폰까지 끊는다.`

## 주요 구현 내용
- **코드가 바뀌지 않았다는 근거**: 변경 전후 파일에서 문자열은 그대로 두고 주석만 걷어낸 뒤 토큰열을 비교했습니다. 215개 파일 모두 같았습니다. develop에 rebase한 뒤에도 다시 확인했습니다.
- **남긴 표현**
  - "옛 서버로 롤백", "옛 앱" 같은 호환 조건은 지금도 지켜야 하는 규칙이라 남겼습니다.
  - 스펙 항목 번호(`E10`, `S4`)는 이슈 번호가 아니라서 남겼습니다.

## 검증
- 코드 토큰 비교: 바뀐 파일 0개
- `./gradlew compileJava` 성공, 서버 테스트 1548건 통과

## 주의사항
- 주석에 경위를 다시 쓰지 않습니다. 경위는 커밋과 이슈에 있습니다(`server/CLAUDE.md`·루트 규칙).
