# 종 아이콘과 알림·공지사항 화면, 알림 설정 (#826)

## 개요
보호자 홈에 종 아이콘과 빨간 점을 두고, 알림·공지사항 두 탭 화면과 알림 설정 화면을 만들었다. 서버 #827 API만으로 동작하고 푸시(#828)가 없어도 쓸 수 있다. develop 병합 커밋 `10e901cb`.

## 화면과 동작
- **종 아이콘**: 폰은 홈 머리 줄에서 이룸이 캐릭터 배지 왼쪽, 태블릿은 옆 메뉴 ELUM 로고 오른쪽. 이룸이 화면에는 없다. 코치마크는 배지에만 걸린 그대로다.
- **빨간 점**: 안 읽은 알림 또는 아직 안 본 공지가 있을 때. 홈 진입, 앱 복귀, 5분 주기, 알림 화면에서 돌아올 때 갱신. 요약을 못 받으면 조용히 점 없음.
- **알림 탭**: 오늘·어제·이전 묶음, 안 읽은 줄은 연한 민트 바탕, "모두 읽음", 무한 스크롤(키셋 커서, id 중복 제거), 빈 화면은 루미 일러스트, 실패는 `E-NOTIF-LIST` + 다시 시도.
- **누르면**: 읽음 처리 후 종류별 이동 — 일과 완료·일과 보냄 → 그 이룸이의 홈, 새 보호자 → 함께하는 사람, 크레딧 → 크레딧 내역, 의견 → 이동 없음. 다른 이룸이 알림이면 먼저 그 이룸이로 바꾸고, 더 볼 수 없는 이룸이면 `E-NOTIF-PROFILE` 안내.
- **공지사항 탭**: 최근 90일 공지(게시 끝난 것 포함), 탭을 처음 열 때 읽음 기록. 강조 표기(`**…**`)는 홈 공지 팝업과 같은 방식.
- **알림 설정**: 모든 알림 받기 + 5종 스위치, 서버 저장. 화면 먼저 바꾸고 실패하면 되돌림(`E-NOTIF-SETTING`), 연속 토글은 마지막 값만 저장. 기기 알림이 꺼져 있으면 위에 안내와 "기기 설정 열기". 진입: 보호자 설정 줄, 알림 화면 오른쪽 위 톱니.

## 왜 이렇게 했는가
- `NoticePlatform`을 `shared/models`로, 종 버튼을 보호자 기능 쪽(`guardian/presentation/widgets`)으로 옮겼다. 다른 기능의 `data`·`presentation`을 가져오지 못하게 하는 레이어 규칙(`tool/check_layer_imports.dart`) 때문이다.
- 목록 문구는 이름 대신 일과 제목을 쓴다("'세수하기' 일과를 끝냈어요"). 이름 뒤 조사(이/가)가 이름마다 달라져 틀리기 쉽기 때문이다. 이룸이가 2명 이상일 때만 줄 위에 이룸이 이름을 작게 붙인다.
- 묶음 문구에서 "오늘"을 뺐다("일과 N개를 끝냈어요"). 어제 묶음에도 "오늘"이 붙는 문제가 있었다.
- 계정을 바꾸면 안 읽음 요약을 초기화한다(이전 계정의 빨간 점이 남지 않게).

## 실측 (iOS 시뮬레이터 + 로컬 서버)
- 홈 종·빨간 점 위치, 알림 탭(묶음·민트·모두 읽음·톱니), 알림 눌러 함께하는 사람 이동 + 읽음 204, 공지 탭(게시 끝난 공지 포함, 강조 민트), 알림 설정 화면(서버 값 반영, 토글 저장 200) 확인.
- 정적 점검: `flutter analyze`(바꾼 경로) 0건, 한글 리터럴 0줄, 레이어 위반 새 것 0건(develop #849의 기존 2건만).
- 앱 테스트는 develop에서 삭제됐다(#848). 테스트 코드는 쓰지 않았다.

## 주의사항
- 알림 줄을 누를 때 읽음 요청은 기다리지 않고 바로 이동한다. 요약 갱신은 전역 provider를 미리 잡아 두고 부르므로, 목록 provider가 사라져도 점이 남지 않는다. 이 순서를 바꾸면 점이 남는다.
- 탭 컴포넌트(`ElumSegmentedTabs`)와 색 토큰(`notificationUnreadBackground` 등)은 다크 값이 없다. 앱 색 체계가 아직 라이트 전용이다.
- es·ja·zh ARB에는 새 키가 없어 영어로 대체된다(열린 언어는 ko·en).
