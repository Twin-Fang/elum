# 🚀[기능개선][클라][배포] iOS 최소 지원 버전 15.0 상향 (App Store ITMS-90068 대응)

## 개요

v1.0.95(Build 95) 업로드 후 App Store Connect가 **ITMS-90068 MinimumOSVersion too low** 경고를 보냈다. 현재 최소 지원 버전이 13.0인데, Apple 정책상 2027년 봄부터는 15.0 이상만 업로드·배포 제출이 가능하다. 지금은 경고지만 시점이 지나면 TestFlight 업로드 자체가 막히므로 선제적으로 15.0으로 올렸다.

## 변경 사항

### iOS 설정 (세 곳을 같은 값으로)

- `client/ios/Podfile`: 주석 처리돼 있던 플랫폼 선언을 `platform :ios, '15.0'`으로 활성화. 세 설정이 같은 값이어야 한다는 주석 추가
- `client/ios/Runner.xcodeproj/project.pbxproj`: `IPHONEOS_DEPLOYMENT_TARGET` 13.0 → 15.0 (Debug · Release · Profile 3곳)
- `client/ios/Flutter/AppFrameworkInfo.plist`: `MinimumOSVersion` 13.0 → 15.0
- `client/ios/Podfile.lock`: `pod install`이 플랫폼 변경을 반영해 갱신

## 주요 구현 내용

- 설정이 세 파일에 분산돼 있어 하나만 바꾸면 조용히 어긋난다. Xcode 프로젝트 타깃이 실제 바이너리의 `MinimumOSVersion`을 결정하고, Podfile 플랫폼은 의존 라이브러리 컴파일 타깃을, AppFrameworkInfo는 Flutter 프레임워크 메타데이터를 결정하므로 전부 맞췄다.
- **검증**: 로컬 `flutter build ios --release --no-codesign` 성공(Xcode 16.2, 37.7초), 산출물 `Runner.app/Info.plist`의 `MinimumOSVersion`이 **15.0**임을 PlistBuddy로 실측했다.

## 주의사항

- iOS 13·14 기기는 이 빌드부터 설치할 수 없다. 발달장애 아동 지원 서비스 특성상 구형 기기 사용자를 고려했으나 Apple 정책상 선택의 여지가 없다.
- 경고가 실제로 사라졌는지는 **다음 TestFlight 업로드의 App Store Connect 메일**로 확인한다. 이번 배포 후 ITMS-90068 메일이 다시 오지 않으면 완료다.
- Android는 영향 없다.
