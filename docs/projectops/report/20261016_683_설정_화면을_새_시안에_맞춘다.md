# 설정 화면을 새 시안에 맞춘다

## 개요

디자이너가 마무리한 설정 시안(Figma `1532:7501`)대로 보호자 설정 화면을 바꿨다. 줄이 살색 배경 위에 바로 놓이던 모양을 **흰 둥근 카드 네 묶음**으로 나누고, 크레딧 카드의 모양과 줄 모양(높이·여백·글자·화살표·토글)을 시안 값으로 맞췄다. 디자인 요청 #646 중 설정 메인 화면에 대한 답이다. 구현은 PR #684로 `develop`에 반영했고, 배포는 아직 하지 않았다.

## 변경 사항

### 묶음 카드와 줄
- `client/lib/features/guardian/presentation/guardian_settings_screen.dart`: 줄을 연결 / 앱 사용 / 약관 및 정보 / 계정 네 묶음으로 나누고 시안의 보이는 순서로 다시 놓았다. 묶음 사이는 16, 첫 카드는 y=131, 스크롤 고정 영역은 115다.
- `client/lib/core/widgets/settings_tile.dart`: 묶음 카드 안 줄 모양(`isInCard`)을 더했다. 높이 56, 안쪽 여백 왼쪽 20·오른쪽 16, 검정 글자, 값은 `#74757D`, 화살표는 시안 SVG.
- `client/lib/core/widgets/settings_switch_tile.dart`: 시안 토글(56×28 알약, 켜짐 `#55CFBA`)을 더했다.
- `client/lib/core/widgets/settings_group.dart`: 줄 사이 선을 끄는 옵션(`hasDividers`)을 더했다. 기본값은 그대로다.
- `client/lib/core/widgets/app_info_tile.dart`: 앱 정보 줄이 묶음 카드 모양을 받는다.

### 크레딧 카드
- `client/lib/features/guardian/presentation/widgets/ai_credit_summary_view.dart`: 제목 옆 안내 물음표, 반짝임과 보라색 큰 숫자, `/ 100 크레딧 남음` 단위, 막대, `10월 19일(월) 0시에 다시 채워져요` 순서로 바꿨다. 구분선은 없앴다.
- `client/lib/core/theme/app_colors.dart`, `app_typography.dart`: 새 색(`#BAA0F9`, `#9B97A4`, `#EEE9E6` 막대 바탕 등)과 글자 스타일을 토큰으로 추가했다.

### 시험
- `settings_conformance_test.dart`: 골든을 새 프레임(`figma/settings_1532-7501.png`)으로 바꿨다. `ai_credit_card_test.dart`: 숫자와 단위가 따로 그려져 확인 방식을 바꿨다.

## 주요 구현 내용

- 다른 설정 화면(약관 목록, 이룸이 휴대폰 설정, 함께하는 사람)은 아직 시안이 없어 **기존 모양을 그대로 둔다.** 새 줄 모양은 옵션으로만 켜지고, 기본값은 이전과 같다.
- 시안과 앱을 `figma_diff`로 대조했다: 글줄 11개가 모두 같은 자리에 선다. 남은 차이는 글자 모양(시험 환경에 Pretendard가 없어서)뿐이다.

## 주의사항

- **디자이너 확인이 필요한 것**
  - 시안에 `이룸이 바꾸기` 줄이 없다. 이룸이가 둘 이상일 때만 보이는 줄이라, 기능을 잃지 않게 연결 묶음 맨 아래에 조건부로 임시 유지했다.
  - 앱 정보 오른쪽의 `버전 정보`는 자리 표시 글자로 보고 실제 버전을 보인다.
  - 토글 꺼짐 색은 시안에 없어 빈 칸 색(`#DADADA`)을 썼다.
- 이 PR에서 `settingsChevron`(`#CDCDCD`)은 그대로 두었다. 시안 화살표 색은 `#CACACA`로 거의 같다.
- 시안 `1579:7833`은 상태바 하나뿐이라 화면 시안이 아니다. 반영하지 않았다.
- 다른 세션이 맡은 #680(함께하는 사람)은 `settings_tile.dart`, `settings_group.dart`를 같이 쓴다. 기본값을 바꾸지 않아 충돌은 없었지만, 합칠 때 확인이 필요하다.
