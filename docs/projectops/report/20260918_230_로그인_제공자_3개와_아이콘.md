# 제공자 3개로 줄이고 버튼에 아이콘 추가 — 구글 제거

## 개요

Figma `238:1808`을 구현했다. 제공자가 **넷에서 셋**으로 줄고 버튼마다 로고가 붙었다.

<img src="https://github.com/Twin-Fang/elum/releases/download/qa-evidence/i230_232_20260918-180933_login_providers.png" width="320">

> 애플 버튼은 iOS에서만 뜬다. 위 화면은 테스트 환경(호스트 OS)이라 둘만 보인다.

## 변경 사항

| | 전 | 후 |
| --- | --- | --- |
| 제공자 | 카카오·네이버·**Google**·Apple | 카카오·네이버·Apple |
| 로고 | 없음 (글자만) | **버튼마다 왼쪽에** |

| 좌우 여백 | 24 | **16** |
| 하단 여백 | 132 | **85** |

## 🔴 로고는 왼쪽 64에 고정하고 문구는 가운데 둔다

시안 실측이 그렇다 — 카카오 문구 x=116 w=129라 중심이 180.5, 버튼 중심이 180이다.

로고를 문구 바로 앞에 붙이면 **제공자마다 문구 길이가 달라 로고가 들쭉날쭉해진다.**
세 개가 한 줄로 서야 목록으로 읽힌다.

```dart
Stack(
  alignment: Alignment.center,
  children: [
    Text(label, ...),                       // 가운데
    Positioned(left: 64.w, child: Svg...),  // 왼쪽 고정
  ],
)
```

## 구글은 화면에서만 뺐다

`OAuthProvider.google`은 **지우지 않았다.**

- 저장소의 `lastLoginProvider`가 `'google'`일 수 있다. enum에서 지우면 파싱이 깨진다
- 서버 행의 provider 컬럼도 그대로 산다

이슈 본문이 권한 방향("값을 남겨 두는 편이 안전하다")과 같다.

쓰이지 않게 된 `loginGoogleBg`·`loginGoogleLabel`·`loginGoogleBorder` **색 토큰과
`_OutlinedProviderButton` 위젯은 지웠다** — 화면에서 안 쓰는 토큰이 남으면 다음 사람이
"이건 어디에 쓰나" 하고 찾는다.

## 🔴 Apple 버튼 — 규격 위젯에서 직접 그리기로 바꿨다

시안이 세 버튼을 같은 규격(360×66 · r18 · 로고 x=64)으로 그렸는데,
`SignInWithAppleButton`은 그 정렬을 맞출 수 없다.

애플이 요구하는 것은 지켰다 — **검정 배경 · 흰 사과 심볼 · 최소 높이.**

> ⚠️ **다만 문구가 규격 밖이다.** `Apple로 시작하기`는 애플이 승인한 세 가지
> (`Apple로 로그인` · `Apple로 계속하기` · `Apple로 가입`)에 없다.
> **심사에서 지적받을 수 있다.** 지금 문구는 시안과 기존 코드가 쓰던 것을 그대로
> 이어받은 것이라 이번에 생긴 문제는 아니다. 출시 전에 정해야 한다.

## 에셋

저장소에 제공자 로고가 **없었다.** Figma에서 SVG 세 개를 받아
`client/assets/icon/login/`에 넣었다. 색이 파일 안에 박혀 있어 코드에서 덧칠하지 않는다.

## 주의사항

- **구글로 가입한 계정은 다시 로그인할 길이 없다.** 정식 출시 전이라 하위호환을
  고려하지 않기로 한 결정이다 (이슈 본문).
- 안드로이드에서는 애플 버튼이 없어 **버튼이 둘**이다. 시안(셋)과 세로 위치가 다르다.
  기존 동작 그대로 두었다.
