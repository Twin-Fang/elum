# 🚀[기능개선][서버][공지] 공지를 휴대폰 언어별로 보여주기

## 개요

공지마다 언어(ko en ja zh es) 하나를 두고, `/api/app/notices`가 요청 언어와 같은 공지만 돌려주게 했다. (PR #714)

## 변경 사항

- `V38__add_app_notice_locale.sql`: `app_notice.locale VARCHAR(8) NOT NULL DEFAULT 'ko'` (기존 공지는 전부 ko)
- 목록 조회: 요청 언어 공지만 반환. 그 언어 공지가 없으면 **빈 목록** (한국어로 대신 보내지 않음). 응답에 `Vary: Accept-Language`
- 관리자 공지 폼에 언어 선택(기본 ko), 목록에 언어 배지. 허용 언어 밖은 `NOTICE_LOCALE_INVALID`로 거부
- 앱 오류 코드 목록에 `NOTICE_LOCALE_INVALID` 추가 (동기화 시험용)

## 주의사항

- 배포 직후 영어·일본어 등 휴대폰에는 공지가 **안 뜬다**. 관리자에서 해당 언어 공지를 따로 등록해야 한다 (새 공지는 꺼진 채 생성되므로 미리보기 뒤 켠다).
- 관리자 편집 화면의 미리보기는 아직 언어로 거르지 않는다.

## 검증

- 서버 전체 1826건 실패 0, 앱 오류 코드 동기화 시험 통과
- 임시 Postgres에서 V22 → 행 삽입 → V38 실행, 기존 행 ko 확인, 재실행 오류 없음
- 확인 전: Flyway 포함 앱 기동, 관리자 화면 브라우저 확인
